## 조직 클라우드 드라이브(파일 업로드 등 관련 조작)

## 1. 조직 드라이브 새로 만들기

## 대상
학교/기관 마스터 계정

"조직 클라우드 드라이브" 권한을 가진 백오피스 학교/기관 관리자

## 이런 경우에
교육 연구 과정에서 연구팀의 여러 교사가 교육 연구 자료를 공유하고 협업해야 하는 경우가 자주 있습니다. 이 과정을 촉진하기 위해 조직 클라우드 드라이브를 사용하면 교사들의 요구를 충족할 수 있습니다. 개인 클라우드 드라이브 사용 외에도, 조직 클라우드 드라이브는 여러 사람이 함께 공유하고 구축할 수 있는 공간도 제공합니다.

## 사용 설명
학교/기관 마스터 계정과 "조직 클라우드 드라이브" 권한을 가진 백오피스 학교/기관 관리자는 ClassIn 소프트웨어의 "스페이스" 항목 내 "조직 클라우드 드라이브"에서 조직 드라이브를 만들 수 있습니다. 조직 드라이브를 만든 후에야 클라우드 드라이브에 파일과 하위 폴더를 추가할 수 있습니다.

## 유의사항
휴대폰은 조직 클라우드 드라이브에서 조직 드라이브 만들기를 지원하지 않습니다.

## 구체적인 조작 방법

#### 컴퓨터/태블릿
1. 왼쪽 내비게이션에서 "스페이스"로 이동합니다.
2. "조직 클라우드 드라이브"로 이동합니다.
3. "학교/기관"을 선택합니다.
4. "조직 드라이브 만들기"를 합니다.
5. 조직 드라이브의 폴더 이름을 입력합니다.
6. "만들기"를 클릭합니다.

## 2. 파일(폴더) 새로 만들기/업로드하기

폴더에 조작 가능/관리 가능 권한을 가진 교사

해당 권한을 가진 교사, 관리자, 마스터 계정 담당자는 조직 드라이브 아래에 폴더와 파일을 새로 만들거나 업로드할 수 있으며, 내 클라우드 드라이브에서 조직 드라이브로 파일을 업로드하는 것도 지원합니다.

조직 드라이브는 새 폴더 만들기를 지원하며, 판서, 과제 리소스, 온라인 PPT, 협업 문서 등의 파일 새로 만들기도 지원합니다. 태블릿은 온라인 PPT 새로 만들기를 지원하지 않습니다. 휴대폰은 폴더, 판서, 과제 리소스, 협업 문서 만들기만 지원합니다. 폴더 업로드는 컴퓨터에서만 지원합니다.

조직 드라이브는 파일 업로드도 지원하며, ppt, word, pdf, 이미지, 오디오/동영상 등의 파일을 업로드할 수 있습니다.

ClassIn에서는 업로드하는 파일 크기에 일정한 제한이 있습니다: 컴퓨터로 업로드할 때 파일 하나당 500MB를 초과할 수 없습니다. 휴대폰이나 태블릿으로 업로드할 때 파일 하나당 100MB를 초과할 수 없습니다. TXT 파일의 경우 강의실 내에서 정상적으로 사용할 수 있도록 크기를 1MB 이내로 하는 것을 권장합니다. 또한 휴대폰이나 태블릿에서 업로드하는 동영상 파일의 경우, 해상도가 720P 미만인 동영상은 크기가 100MB를 초과할 수 없고, 해상도가 720P 이상인 동영상은 재생 시간이 3분을 초과할 수 없습니다.

폴더 총 개수 상한은 2,000개이며, 각 폴더 내 파일 수 상한은 300개입니다.

컴퓨터에서는 파일과 폴더를 드래그 앤 드롭해 내 클라우드 드라이브에 업로드할 수 있습니다.

파일 업로드 후에는 변환에 일정 시간이 걸리므로 미리 업로드하는 것을 권장합니다.

강의실에서 파일을 사용해야 한다면, 반드시 강의실 내에서 클라우드 드라이브를 통해 열어야 합니다.

모든 형식의 파일을 ClassIn에 업로드할 수 있지만, 강의실에서 정상적으로 열어 사용할 수 있는 것은 아래에 나열된 파일 형식뿐입니다.

ClassIn 강의실에서 사용을 지원하는 파일 유형은 다음과 같습니다:

| 유형 | 형식 |
| --- | --- |
| ClassIn 판서 | edb |
| ClassIn 파일 | edt, edu, edx, eda, edv |
| PowerPoint 프레젠테이션 | pptx, ppt, pptm |
| Word 문서 | docx, doc |
| Excel 표 | xlsx, xls, csv |
| PDF 문서 | pdf |
| 이미지 | jpeg, jpg, png, bmp |
| 오디오 | mp3, wav, wma, aac, flac, m4a, oga |
| 동영상 | mp4, 3gp, mpg, mpeg, 3g2, avi, flv, wmv, h264, m4v, mj2, mov, ogg, ogv, rm, qt, vob, webm |
| 텍스트 문서 | txt, html, htm, css, js, as, cpp, c, cc, cxx, h, java, md, matlab, pascal, pl, php, py, r, rb, ru, sql, swift, rbx, rs, go |
| 바둑 | sgf |
| 체스/장기 | fen, pgn |

1. "조직 드라이브"로 이동합니다.
2. 상단의 "업로드" 또는 "새로 만들기"에서 폴더와 파일을 만듭니다.

#### 휴대폰

3. "+"를 탭합니다.
4. "폴더와 파일 만들기" 또는 "파일 업로드"를 합니다.

## 3. 구성원 권한

"조직 클라우드 드라이브 - 구성원 관리" 권한을 가진 백오피스 학교/기관 관리자

폴더에 관리 가능 권한을 가진 교사

해당 권한을 가진 교사, 관리자, 마스터 계정 담당자는 조직 드라이브와 그 아래 폴더에 구성원을 추가·설정하고 권한을 관리할 수 있습니다. 해당 권한을 가진 구성원은 조직 클라우드 드라이브 아래의 파일을 확인·사용할 수 있습니다.

**조직 드라이브 및 하위 폴더 - 구성원 관리 권한 설명:**

| 권한 | 설명 |
| --- | --- |
| 관리 가능 | 폴더 지원 내용: 구성원 관리(추가, 권한 부여, 구성원 제거) 권한 설정, 그리고 조직 드라이브 아래 폴더의 업로드, 새로 만들기, 복제, 이동, 이름 변경, 삭제.<br><br>파일 지원 내용: 확인, 업로드, 새로 만들기, 전달, 다운로드, 삭제, 복제, 이동, 클라우드 드라이브에 저장, 이름 변경, 인쇄, ppt/edoc 온라인 편집 조작, 그리고 파일 권한에서 파일 전송 저장 기능 설정. |
| 조작 가능 | 폴더 지원 내용: 구성원 관리 권한 확인, 그리고 조직 드라이브 아래 폴더의 업로드, 새로 만들기, 복제, 이름 변경.<br><br>파일 지원 내용: 확인, 업로드, 새로 만들기, 복제, 이름 변경, 인쇄, ppt/edoc 온라인 편집 조작.<br><br>자신이 업로드한 파일과 만든 폴더 삭제를 지원. |
| 확인만 가능 | 폴더 및 그 아래 파일의 확인만 지원합니다. |
| 표시 안 함 | 폴더와 그 아래 파일을 확인할 수 없습니다. |

**슈퍼 관리자:** "조직 클라우드 드라이브" 권한을 가진 백오피스 학교/기관 관리자를 말합니다. 백오피스 관리 시스템에서 관리자에게 "조직 클라우드 드라이브" 권한만 체크한 경우, 백오피스와 ClassIn 소프트웨어의 조직 클라우드 드라이브에서 조직 드라이브를 확인·만들기·이름 변경할 수 있고 구성원 관리를 확인할 수 있지만, 폴더를 삭제하거나 폴더 구성원 권한을 설정할 수는 없습니다. 파일의 경우 확인, 업로드, 새로 만들기, 전달, 복제, 이동, 클라우드 드라이브에 저장, 이름 변경, 인쇄, ppt/edoc 온라인 편집 조작을 할 수 있지만, 파일을 다운로드·삭제하거나 파일 전송 저장 기능을 설정할 수는 없습니다.

다음을 하려면 추가로 해당 권한에 체크해야 합니다: 파일/폴더 삭제, 파일 전송 저장 설정("조직 클라우드 드라이브 - 삭제"); 파일 다운로드("조직 클라우드 드라이브 - 다운로드"); 조직 드라이브/폴더에 구성원 권한 설정("조직 클라우드 드라이브 - 구성원 관리").

휴대폰은 조직 클라우드 드라이브에서 구성원 관리(구성원 추가, 권한 부여, 제거) 권한 확인·설정을 지원하지 않습니다.

"기업용 ClassIn"은 같은 기관 소속 교사만 추가할 수 있습니다.

"학교용 ClassIn"은 학교의 교사와 학생을 조직 폴더 구성원으로 추가할 수 있습니다(학생은 현재 "확인만 가능"과 "표시 안 함" 권한 설정만 지원).

"백오피스 관리 시스템"에서 비활성화된 교사는 시스템이 자동으로 조직 클라우드 드라이브 권한을 해제합니다. 다시 활성화한 후에는 신규 구성원 절차에 따라 권한을 다시 획득해야 합니다.

"초중고 백오피스 관리 시스템"을 사용하는 학교의 경우, 교사가 퇴직/삭제되거나 학생이 졸업/삭제되면 시스템이 자동으로 조직 클라우드 드라이브 권한을 해제합니다. 퇴직한 교사가 복직하거나 학생이 재입학하면 신규 구성원 절차에 따라 조직 클라우드 드라이브 권한을 다시 획득해야 합니다.

1. 권한을 부여해야 하는 폴더를 찾아 오른쪽의 "···"을 클릭합니다.
2. "구성원 관리"로 이동합니다.
3. "구성원 추가" 또는 "구성원 권한 수정"을 합니다.

## 4. 파일 권한

"조직 클라우드 드라이브 - 삭제" 권한을 가진 백오피스 학교/기관 관리자

해당 권한을 가진 교사, 관리자, 마스터 계정 담당자가 파일에 대해 "조작 가능/확인만 가능 구성원의 전달/다운로드/개인 클라우드 드라이브 저장 허용"(전송 저장) 기능을 켜면, "조작 가능" 또는 "확인만 가능" 권한을 가진 구성원도 해당 파일을 전송 저장할 수 있습니다.

협업 문서 edoc, edu, edx, 과제 리소스 등은 파일 전송 저장 권한 설정을 지원하지 않습니다.

휴대폰은 조직 클라우드 드라이브에서 파일 전송 저장 기능 확인·설정을 지원하지 않습니다.

1. 폴더로 들어갑니다.
2. 파일을 찾아 "···"을 클릭하고 "파일 권한"으로 이동합니다.
3. 파일 권한을 수정합니다.

## 7. 파일 다운로드하기

"조직 클라우드 드라이브 - 다운로드" 권한을 가진 백오피스 학교/기관 관리자

컴퓨터는 조직 클라우드 드라이브에서 이미지, 판서, PPT, PDF, Word 문서 등의 파일을 다운로드할 수 있습니다. 다만 ClassIn 전용 파일 형식(온라인 슬라이드〈eppt 형식〉, 문서〈edoc 형식〉 등)은 다운로드나 다른 앱에서 열기를 지원하지 않습니다.

휴대폰과 태블릿은 이미지를 로컬 앨범에 저장하는 것을 지원하지만, PPT, PDF 등의 파일에는 다운로드 기능이 없어, 조직 클라우드 드라이브에서 연 후 공유 기능을 탭해 다른 앱으로 열어 확인·사용할 수 있습니다.

#### 컴퓨터
1. 다운로드하려는 파일에 체크합니다.
2. 아래의 "다운로드"를 클릭합니다.

#### 태블릿
1. 이미지나 파일을 엽니다.
2. 이미지를 길게 눌러 저장하거나, 파일 페이지에서 공유 버튼을 탭해 다른 앱으로 열기를 선택합니다.

내 클라우드 드라이브에서 이미지나 파일을 엽니다.

## 8. 파일 인쇄하기

"조직 클라우드 드라이브"에 저장된 교육 파일을 실물 종이 문서로 만들어야 할 때, 교사는 ClassIn의 인쇄 기능을 사용할 수 있습니다. 컴퓨터는 이미지, PPT, PDF 등의 파일 인쇄를 지원합니다.

휴대폰과 태블릿에는 "인쇄" 기능이 없습니다.

1. 파일을 엽니다.
2. 파일 오른쪽 상단의 "인쇄"를 클릭합니다.

## 9. 파일(폴더) 삭제하기

해당 권한을 가진 교사, 관리자, 마스터 계정 담당자는 ClassIn 소프트웨어의 조직 클라우드 드라이브에서 파일(폴더)을 찾은 후 삭제할 수 있습니다. 또한 "조작 가능" 권한을 가진 교사는 자신이 만든 폴더 삭제, 자신이 업로드한 파일 삭제도 지원됩니다.

파일과 폴더는 삭제하면 복구할 수 없습니다.

1. 삭제하려는 파일이나 폴더를 찾습니다.
2. "삭제"를 클릭합니다.
