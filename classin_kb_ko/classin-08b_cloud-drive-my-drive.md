## 내 클라우드 드라이브(파일 업로드 등 관련 조작)

## 1. 파일(폴더) 새로 만들기/업로드하기

## 대상
전체 사용자

## 이런 경우에
교사나 학생은 수업 전에 자신의 컴퓨터 로컬이나 휴대폰 로컬에 있는 파일을 ClassIn "클라우드 드라이브"에 업로드할 수 있으며, 이렇게 하면 수업 중 이미 업로드한 파일을 강의실 내 다른 사람들에게 보여줄 수 있습니다.

## 사용 설명
내 클라우드 드라이브는 새 폴더 만들기를 지원하며, 수업 준비 패키지, 판서, 과제 리소스, 온라인 PPT, 협업 문서 등의 파일 새로 만들기도 지원합니다. 태블릿은 온라인 PPT 새로 만들기를 지원하지 않습니다. 휴대폰은 폴더, 판서, 과제 리소스, 협업 문서 만들기만 지원합니다. 폴더 업로드는 컴퓨터에서만 지원합니다.

내 클라우드 드라이브는 파일 업로드도 지원하며, ppt, word, pdf, 이미지, 오디오/동영상 등의 파일을 업로드할 수 있습니다.

ClassIn에서는 업로드하는 파일 크기에 일정한 제한이 있습니다: 컴퓨터로 업로드할 때 파일 하나당 500MB를 초과할 수 없습니다. 휴대폰이나 태블릿으로 업로드할 때 파일 하나당 100MB를 초과할 수 없습니다. TXT 파일의 경우 강의실 내에서 정상적으로 사용할 수 있도록 크기를 1MB 이내로 하는 것을 권장합니다. 또한 휴대폰이나 태블릿에서 업로드하는 동영상 파일의 경우, 해상도가 720P 미만인 동영상은 크기가 100MB를 초과할 수 없고, 해상도가 720P 이상인 동영상은 재생 시간이 3분을 초과할 수 없습니다.

## 유의사항
폴더 총 개수 상한은 2,000개이며, 각 폴더 내 파일 수 상한은 300개입니다.

컴퓨터에서는 파일과 폴더를 드래그 앤 드롭해 내 클라우드 드라이브에 업로드할 수 있습니다.

파일 업로드 후에는 변환에 일정 시간이 걸리므로 미리 업로드하는 것을 권장합니다.

강의실에서 파일을 사용해야 한다면, 반드시 강의실 내에서 클라우드 드라이브를 통해 열어야 합니다.

모든 형식의 파일을 ClassIn에 업로드할 수 있지만, 강의실에서 정상적으로 열어 사용할 수 있는 것은 아래에 나열된 파일 형식뿐입니다.

ClassIn 강의실에서 사용을 지원하는 파일 유형은 다음과 같습니다:

| 유형 | 형식 |
| --- | --- |
| ClassIn 판서 | edb |
| ClassIn 파일 | edt, edu, edx, eda, edv |
| PowerPoint 프레젠테이션 | pptx, ppt, pptm |
| Word 문서 | docx, doc |
| Excel 표 | xlsx, xls, csv |
| PDF 문서 | pdf |
| 이미지 | jpeg, jpg, png, bmp |
| 오디오 | mp3, wav, wma, aac, flac, m4a, oga |
| 동영상 | mp4, 3gp, mpg, mpeg, 3g2, avi, flv, wmv, h264, m4v, mj2, mov, ogg, ogv, rm, qt, vob, webm |
| 텍스트 문서 | txt, html, htm, css, js, as, cpp, c, cc, cxx, h, java, md, matlab, pascal, pl, php, py, r, rb, ru, sql, swift, rbx, rs, go |
| 바둑 | sgf |
| 체스/장기 | fen, pgn |

## 구체적인 조작 방법

#### 컴퓨터/태블릿
1. 왼쪽 내비게이션에서 "스페이스"로 이동합니다.
2. "내 클라우드 드라이브"로 이동합니다.
3. 상단의 "업로드" 또는 "새로 만들기"에서 폴더와 파일을 만듭니다.

#### 휴대폰
1. "스페이스"로 이동합니다.
2. 내 클라우드 드라이브에서 "+"를 탭합니다.
3. "폴더와 파일 만들기" 또는 "파일 업로드"를 합니다.

## 2. 업로드한 PPT 파일 수정하기(온라인 편집)

ClassIn 사용 시, 교사가 업로드한 PPT를 수정해야 한다면, "스페이스"의 "내 클라우드 드라이브"에 들어가 해당 파일을 찾아 연 후 "온라인 편집"을 클릭하면, PPT가 ClassIn 전용 eppt 형식(온라인 편집 지원)으로 변환되며, 교사는 바로 수정하고 저장할 수 있습니다.

휴대폰과 태블릿에는 "온라인 편집" 기능이 없습니다.

온라인 편집으로 저장된 eppt 파일은 다운로드할 수 없습니다.

#### 컴퓨터
1. 왼쪽 내비게이션에서 "스페이스"로 이동합니다.
2. 업로드한 PPT 파일을 찾아 엽니다.
3. "온라인 편집"을 선택합니다.

## 3. 파일 전달하기

내 클라우드 드라이브의 파일은 ClassIn 반이나 친구에게 전달하는 것을 지원합니다.

1. "내 클라우드 드라이브"로 이동합니다.
2. 전달하려는 파일에 체크합니다.
3. 아래의 "전달"을 클릭합니다.

## 4. 파일 다운로드하기

컴퓨터는 내 클라우드 드라이브에서 이미지, 판서, PPT, PDF, Word 문서 등의 파일을 다운로드할 수 있습니다. 다만 ClassIn 전용 파일 형식(온라인 슬라이드〈eppt 형식〉, 문서〈edoc 형식〉 등)은 다운로드나 다른 앱에서 열기를 지원하지 않습니다.

휴대폰과 태블릿은 이미지를 로컬 앨범에 저장하는 것을 지원하지만, PPT, PDF 등의 파일에는 직접 다운로드 기능이 없어, 내 클라우드 드라이브에서 연 후 공유 기능을 탭해 다른 앱으로 열어 확인·사용할 수 있습니다.

1. 다운로드하려는 파일에 체크합니다.
2. 아래의 "다운로드"를 클릭합니다.

#### 태블릿
1. 이미지나 파일을 엽니다.
2. 이미지를 길게 눌러 저장하거나, 파일 페이지에서 공유 버튼을 탭해 다른 앱으로 열기를 선택합니다.

## 5. 파일 인쇄하기

"내 클라우드 드라이브"에 저장된 교육 파일을 실물 종이 문서로 만들어야 할 때, 교사는 ClassIn의 인쇄 기능을 사용할 수 있습니다. 컴퓨터는 이미지, PPT, PDF 등의 파일 인쇄를 지원합니다.

휴대폰과 태블릿에는 "인쇄" 기능이 없습니다.

1. 파일을 엽니다.
2. 파일 오른쪽 상단의 "인쇄"를 클릭합니다.

## 6. 파일(폴더) 삭제하기

내 클라우드 드라이브의 파일과 폴더는 삭제를 지원하며, 삭제하면 복구할 수 없습니다.

1. 파일이나 폴더에 체크합니다.
2. 아래의 "삭제"를 클릭합니다.
3. "삭제"를 클릭합니다.

## 7. 이미지 편집하기

내 클라우드 드라이브의 이미지는 확인(원본 이미지 포함), 편집, 확대/축소, 클라우드 드라이브/로컬 앨범 저장, ClassIn 반이나 친구에게 전달하는 것을 지원합니다.

컴퓨터에서는 추가로 이미지 화면 채우기/복원, 인쇄도 지원합니다. 편집 완료 후에는 기본적으로 이미지가 복사되어 다른 소프트웨어에 붙여넣을 수 있습니다.

1. 이미지를 엽니다.
2. "편집"을 클릭합니다.
3. 이미지 편집 후 "완료"를 클릭합니다.

이미지를 길게 눌러 "편집"을 선택합니다.
이미지 편집 후 "완료"를 클릭하면 "전달" 또는 "저장"을 선택할 수 있습니다.

## 8. edb 판서 파일 편집하기

내 클라우드 드라이브에서 연 edb 판서는 편집을 지원합니다. 컴퓨터에서 연 판서는 edb, png, pdf 형식으로 저장 및 다른 이름으로 저장을 지원합니다. 휴대폰이나 태블릿에서 연 경우에는 내 클라우드 드라이브에 저장하는 것만 지원합니다.

1. edb 판서 파일을 엽니다.
2. edb를 편집한 후 "저장"하거나 "···"을 클릭해 "다른 이름으로 저장"합니다.

edb를 편집한 후 "저장"을 클릭합니다.

내 클라우드 드라이브에서 edb 판서 파일을 엽니다.
