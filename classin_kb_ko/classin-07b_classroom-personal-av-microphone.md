## 마이크

## 1. 마이크 모드

### 대상
전체 사용자

### 이런 경우에
ClassIn 사용 중 사용자는 다음과 같은 마이크 문제를 겪을 수 있습니다:

컴퓨터 사용자가 강의실에서 마이크를 켰고 마이크 아이콘이 초록색으로 표시되지만, 말할 때 소리가 나지 않는 경우. 이때 "하드웨어 드라이버 수정" 기능을 이미 사용했고, 마이크가 다른 소프트웨어에서는 정상적으로 작동합니다.

컴퓨터 사용자가 강의실에서 마이크를 켰지만, 마이크 스위치가 자주 자동으로 "비활성화" 상태로 전환되는 경우.

안드로이드 휴대폰이나 안드로이드 태블릿 사용자가 강의실에서 마이크를 켰지만, 말할 때 소리가 나지 않는 경우.

위와 같은 상황을 겪은 컴퓨터 사용자는 ClassIn 설정에서 "마이크 모드"의 "레거시 모드 1" 또는 "레거시 모드 2"에 체크해 보시길 권장합니다. 안드로이드 휴대폰이나 안드로이드 태블릿 사용자는 설정에서 "마이크 모드"를 활성화할 수 있습니다.

### 유의사항
컴퓨터 사용자가 "마이크 모드"를 수정한 후에는 ClassIn을 재시작해야 변경 사항이 적용됩니다.

안드로이드 휴대폰이나 안드로이드 태블릿 사용자가 "마이크 모드"를 활성화한 후에는, 다시 "수업 받기" 버튼을 탭해 강의실에 들어가야 합니다.

### 조작 방법

#### 컴퓨터
1. 왼쪽 하단의 "아바타"를 클릭합니다.
2. "강의실 설정"으로 이동합니다.
3. "마이크 모드"를 수정합니다.

## 2. 마이크 수정하기

Windows 시스템 컴퓨터에서 로컬 녹음기를 사용하면 정상적으로 말할 수 있지만, ClassIn 강의실에서 마이크에 다음과 같은 문제가 발생하는 경우, 이 기능으로 마이크를 수정할 수 있습니다:

말할 때 마이크에 파형 변화가 없음

말할 때 마이크에 파형 변화는 있지만 소리가 나지 않음

마이크 수정이 완료된 후에는 컴퓨터를 재시작하는 것을 권장합니다.

휴대폰과 태블릿에는 "하드웨어 드라이버 수정" 기능이 없습니다. 휴대폰이나 태블릿에서 이런 문제가 발생하면 기기를 재시작해 보세요.

맥 컴퓨터에는 "하드웨어 드라이버 수정" 기능이 없습니다. 맥 컴퓨터에서 이런 문제가 발생하면, 먼저 맥 컴퓨터의 로컬 설정에서 "마이크"가 ClassIn의 호출을 허용하도록 승인되어 있는지 확인하고, 승인되어 있지 않다면 먼저 "승인"을 진행해 주세요. 이미 승인되어 있는데도 정상적으로 사용할 수 없다면 컴퓨터를 재시작해 보세요.

#### 컴퓨터(Windows 시스템)
1. "시스템 설정"으로 이동합니다.
2. 오른쪽 스크롤바를 맨 아래까지 내립니다.
3. "하드웨어 드라이버 수정"에서 "수정"을 클릭합니다.
4. (방화벽이 차단하는 경우 "허용" 또는 "예"를 클릭) "마이크 수정"을 클릭하고, 마이크 수정 완료 메시지가 표시되면 컴퓨터를 재시작하는 것을 권장합니다.

## 3. 마이크 게인

휴대폰이나 태블릿으로 수업을 받을 때 자신의 목소리가 너무 작게 들린다면, 휴대폰과 태블릿의 물리 볼륨 버튼은 스피커 음량만 조절할 수 있고 마이크 음량은 조절할 수 없다는 점을 참고하세요. 따라서 강의실을 나간 후 소프트웨어 설정에서 "마이크 자동 게인" 기능을 켜서 자신의 발언 음량을 높인 후 다시 강의실에 들어가야 합니다.

컴퓨터를 사용하는 경우, 강의실 내에서 마이크 음량 조절을 지원합니다.

#### 휴대폰
1. "마이크 자동 게인"을 켜거나 끕니다.

## 4. 음악 모드에서 마이크 부스트 활성화

강의실 내에서 교사가 음악 모드를 켠 경우, Windows 컴퓨터를 사용하는 사용자의 목소리가 작다면, 해당 사용자는 강의실 설정에서 "음악 모드에서 마이크 부스트 활성화" 기능을 켤 수 있습니다. 활성화 후에는 즉시 ClassIn을 재시작하고 다시 로그인해야 적용됩니다.

### 사용 설명
이 기능은 Windows 시스템 컴퓨터만 지원합니다.

1. "음악 모드에서 마이크 부스트 활성화"를 켜거나 끕니다.

## 5. 마이크 AI 노이즈 캔슬링

휴대폰이나 태블릿으로 수업을 받을 때, 주변 환경이 너무 시끄러워 강의실 내 다른 사람들이 사용자의 말소리를 잘 듣지 못하는 경우, 소프트웨어 설정에서 "AI 노이즈 캔슬링" 기능을 켜서 개선을 시도할 수 있습니다.

컴퓨터를 사용하는 경우, 강의실 내에서 배경 소음 감소 활성화를 지원합니다.

교사가 강의실에서 음악 모드를 켠 경우, 악기 소리가 정상적으로 전달되도록 하기 위해 강의실 내 사용자가 노이즈 캔슬링 기능을 켜도 적용되지 않습니다. 반대로 강의실에서 음악 모드가 켜져 있지 않다면, 사용자의 노이즈 캔슬링 기능은 정상적으로 작동합니다.

1. "AI 노이즈 캔슬링"을 켜거나 끕니다.

## 6. 다른 방식으로 오디오 열기

iOS 시스템의 아이폰이나 아이패드 사용자는 ClassIn 사용 중 특정 상황을 겪을 때, AI 노이즈 캔슬링 기능을 켠 상태에서 "다른 방식으로 오디오 열기" 기능을 켜보실 수 있습니다. 구체적인 상황은 다음과 같습니다:

**미러링 문제:** 아이폰이나 아이패드의 ClassIn 화면을 TV로 미러링했을 때, TV에서 ClassIn의 소리가 정상적으로 재생되지 않지만 휴대폰이나 태블릿의 다른 앱에서는 소리가 정상적으로 재생되는 경우, AI 노이즈 캔슬링 기능이 켜진 상태에서 "다른 방식으로 오디오 열기" 기능을 켜보실 수 있습니다.

**마이크 문제:** 아이폰이나 아이패드에서 AI 노이즈 캔슬링 기능을 켠 후 강의실에서 발언 음량이 작은 경우, AI 노이즈 캔슬링 기능이 켜진 상태에서 "다른 방식으로 오디오 열기" 기능을 켜보실 수 있습니다.

아이폰이나 아이패드에서는 고급 설정 내 AI 노이즈 캔슬링 기능을 켜야만 "다른 방식으로 오디오 열기" 기능을 켤 수 있습니다.

컴퓨터와 안드로이드 시스템의 휴대폰/태블릿에는 "다른 방식으로 오디오 열기" 기능이 없습니다.

#### 아이폰
1. 왼쪽 하단의 "홈"을 탭합니다.
2. 먼저 "AI 노이즈 캔슬링" 기능을 켠 후, "다른 방식으로 오디오 열기"를 켜거나 끕니다.
