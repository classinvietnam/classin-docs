## 과제

## 1. "과제" 새로 만들기

### 대상
"담임교사"와 "교사"

### 이런 경우에
"과제" 기능이란 교사가 학생에게 일정량의 학습 과제나 문제를 부과하고, 지정된 시간 내에 완료해 제출하도록 요구하는 기능을 말합니다. 교사가 과제를 부과하는 목적은 학생이 수업 내용을 다지고 자기주도 학습 능력과 문제 해결 능력을 기르도록 돕는 데 있으며, 동시에 학생의 학습 상황을 평가하고 피드백하는 방법이기도 합니다.

### 사용 설명
교사는 반 페이지에 들어간 후 코스 항목 아래에 과제를 배포할 수 있습니다. 과제에는 여러 유형의 첨부파일을 추가할 수 있으며, 이미지, 음성, 클라우드 드라이브 파일, 로컬 파일, 웹사이트 링크를 지원해, 학생이 과제 내용을 더 잘 이해하고 파악하는 데 도움이 됩니다. 파일 개수 제한: 이미지 첨부파일 15장, 녹음 첨부파일 15개, 동영상 첨부파일 15개이며, 로컬 파일·클라우드 드라이브 파일·링크의 합계는 15개를 초과할 수 없고, 각 동영상 또는 파일 크기는 500MB 이내여야 합니다. 컴퓨터에서 과제 첨부파일을 업로드할 때는 이미지와 파일을 과제로 드래그 앤 드롭할 수 있습니다.

컴퓨터나 태블릿에서 교사는 교육 목표나 특정 지식 포인트를 기반으로 AI 에이전트가 과제 내용 생성이나 다듬기를 돕도록 할 수 있습니다.

교사는 기관이 권한을 부여한 과제 리소스나 내 클라우드 드라이브 내의 과제 리소스를 선택할 수 있습니다.

교사는 과제에 모범 답안을 설정할 수도 있으며, 답안에도 첨부파일을 업로드할 수 있습니다. 답안의 공개 범위는 공개 안 함, 즉시 공개, 제출 후 공개, 교사 채점 후 공개, 과제 종료 후 공개 중에서 선택할 수 있습니다.

**"과제" 생성 시 설정할 수 있는 항목:**

| 설정 | 기능 |
| --- | --- |
| 시간 | 과제의 시작 및 마감 시간을 설정합니다. |
| AI 채점 | 켜면 AI 에이전트가 과제 내용을 바탕으로 학생의 답안을 채점하며, AI 채점 결과는 초안으로 저장되어 교사의 확인을 기다립니다. 이 기능은 교사가 컴퓨터나 태블릿을 사용할 때만 설정할 수 있습니다. |
| 평가 | 과제의 평가 제도와 점수를 설정합니다. |
| 발행 대상 | 특정 반, 반 내 일부 그룹 구성원 또는 일부 학생에게 발행하거나, 여러 반에 동시에 발행할 수 있습니다. |
| 교사 | 활동 담당 교사를 지정해 관련 알림을 받습니다. |
| 코스 | "과제"를 어느 코스에 속하게 할지 선택합니다. 기본값은 현재 코스입니다. |
| 단원 주제 | "과제"를 어느 단원 주제로 분류할지 선택합니다. 선택하지 않으면 기본 단원으로 분류됩니다. |
| 활동 종료 후 추가 제출 허용 | 켜면 학생이 기한 내에 과제를 완료하지 못한 경우, 활동 종료 후에도 제출할 수 있습니다. |
| 학생 간 과제·성적 상호 열람 허용 | 학생끼리 서로의 모든 과제와 성적을 열람할 수 있는지 설정합니다.<br><br>켜면 "전체 표시 가능" 또는 "우수 내용과 성적만 표시 가능"을 선택할 수 있으며, 표시 시점은 "즉시 표시", "학생 제출 후 표시", "채점 후 표시", "종료 후 표시" 중에서 설정할 수 있습니다. |
| 새로 참여한 학생 제출 허용 | 켜면 과제 활동이 끝나기 전에 새로 반에 참여한 학생도 배포된 과제에 참여할 수 있습니다. |
| 학생의 첨부파일 다운로드 허용 | 켜면 학생이 과제 내 교사가 업로드한 첨부파일을 다운로드할 수 있습니다. |
| 잠금 해제 조건 | 완료가 필요한 선행 활동을 추가합니다. 잠금 해제 조건을 추가하면, 학생은 선행 조건을 완료해야 현재 과제 활동을 시작할 수 있습니다. |

### 유의사항
"학생이 교사에 의해 반에서 내보내짐", "반이 해산됨", "학생이 스스로 반을 떠남"의 경우, 이미 반을 떠난 학생이 과제 내 첨부파일을 열람할 수 있는지는 반 설정의 "반을 떠난 학생 또는 반 해산 후에도 코스 내용을 열람할 수 있도록 허용" 설정에 따라 결정됩니다.

AI 채점에서 "AI 채점 도우미", "과제 첨삭·피드백 어시스턴트(과제 답안 지원 버전)", "서술형 채점 어시스턴트(과제 답안 지원 버전)", "RE 받아쓰기 채점 어시스턴트(과제 답안 지원 버전)" 중 하나를 선택하면, AI는 교사가 과제에 업로드한 모범 답안을 기준으로 채점해 정확도를 높입니다.

## 2. "과제" 수정하기

과제는 편집을 지원하지만, 상태에 따라 편집 가능한 내용이 다릅니다.

초안 및 미시작 과제는 "코스"를 변경할 수 없으며, 나머지 내용과 설정은 모두 변경할 수 있습니다.

진행 중인 과제는 내용을 수정할 수 있지만, 설정 항목 중 "시작 시간"과 "코스"는 변경할 수 없습니다.

종료된 과제는 내용을 더 이상 수정할 수 없으며, 설정 항목 중 시간, 발행 대상, 교사, 코스, 새로 참여한 학생 제출 허용, 잠금 해제 조건은 변경할 수 없습니다.

진행 중 및 종료된 과제는 과제 리소스를 클라우드 드라이브에 저장할 수 있어, 이후 활용에 도움이 됩니다.

1. 코스로 들어갑니다.
2. 과제를 찾아 "···"을 클릭하고 "편집"을 선택합니다.

## 6. 성적 업로드하기

교사가 ClassIn 플랫폼에서 과제를 발행했으나 학생이 실제로는 오프라인에서 과제를 완료한 경우, 교사는 과제 내 "성적 업로드" 기능을 사용해 학생이 오프라인에서 완료한 과제의 성적을 ClassIn에 업로드할 수 있습니다. 이렇게 하면 이후 성적 통계·분석이 편리해집니다.

교사는 컴퓨터를 사용해, 평가 방식이 설정된 진행 중 및 종료된 과제에 대해 성적을 업로드할 수 있습니다.

ClassIn의 과제 성적 업로드 기능은 개별 학생에게 수동으로 성적을 추가하는 것도, 템플릿을 다운로드해 일괄로 학생 성적을 추가하는 것도 지원합니다. 성적을 기입해 업로드하면 학생의 기존 성적은 덮어써집니다.

과제 성적 업로드용 표는 특정 형식을 따라야 ClassIn이 인식할 수 있으므로, 일괄 업로드 시에는 교사가 ClassIn의 성적 업로드 화면에서 템플릿을 다운로드해야 합니다. 템플릿의 첫 번째 열은 현재 과제 대상 학생의 이름이고, 두 번째 열은 점수입니다. 작성이 완료된 과제 성적 Excel 표를 "성적 업로드" 창에 업로드하면 됩니다.

**컴퓨터**
1. 과제로 들어갑니다.
2. 점 3개 아이콘을 클릭하고 "성적 업로드"를 선택합니다.

## 7. 과제 공유하기

## 14. 과제 내용 다운로드하기

담임교사 또는 반 교사는 컴퓨터를 사용해 발행된 과제 상세 페이지에서 과제 내용을 다운로드할 수 있습니다. 다운로드되는 과제 내용에는 교사가 배포한 과제 내용, 제출된 모든 학생의 과제 내용, 그리고 교사가 채점을 완료한 과제의 채점 후 내용이 포함됩니다.

과제 집계 방식은 2가지 중 선택할 수 있습니다: 하나는 기본 방식으로, 하나의 폴더에 모든 사람의 과제 첨부파일을 집계하며 과제 내용이 섞여 있습니다. 다른 하나는 학생별 집계 방식으로, 학생의 반 닉네임별로 2단계 폴더를 생성해 해당 학생의 모든 과제 내용(교사가 채점을 완료한 내용 포함)을 그 2단계 폴더에 배치합니다. 교사가 배포한 과제 내용도 별도로 2단계 폴더에 저장됩니다.

컴퓨터의 로컬 다운로드 위치를 선택하면 즉시 ClassIn의 파일 전송 기능에서 다운로드 작업이 생성되며, 다운로드가 완료되면 로컬에서 확인할 수 있습니다.

1단계 폴더의 이름은: 과제 이름-반 이름-기관 이름-다운로드 시간입니다.

과제 내용을 로컬로 다운로드하면 다음과 같이 변환됩니다:

**(1) 텍스트:** html 웹페이지 형식으로 표시됩니다.
- 기본 집계: 교사 과제 내용 이름 = 과제 제목, 학생 과제 내용 이름 = 학생 반 닉네임.
- 학생별 집계: 교사/학생 과제 내용 이름 모두 = 과제 제목.

**(2) 파일류(이미지/EDB 판서/음성 동영상/일반 파일):** 원본 형식 그대로 표시됩니다.
(edoc 파일은 ClassIn 내에서만 열람 가능하며, 로컬 표시와 다운로드는 지원되지 않습니다.)
- 기본 집계: 교사 첨부파일 이름 = 과제 제목 + 파일명, 학생 첨부파일 이름 = 학생 반 닉네임 + 파일명.
- 학생별 집계: 교사 첨부파일 이름 = 과제 제목 + 파일명, 학생 첨부파일 이름 = 파일명.

**(3) 링크:** txt 파일 형식으로 표시됩니다.
- 기본 집계: 교사 링크는 하나의 txt에 통합 저장되며 파일명은 "웹페이지 링크"입니다. 학생 링크도 하나의 TXT에 통합 저장되며 파일명은 "학생 반 닉네임 + 웹페이지 링크"입니다.
- 학생별 집계: 링크는 하나의 txt에 통합 저장되며 파일명은 "웹페이지 링크"입니다.

1. 과제 상세 페이지 오른쪽 상단의 "더보기"로 이동해 "과제 내용 다운로드"를 클릭합니다.
2. 집계 방식으로 "기본" 또는 "학생별"을 선택합니다.
