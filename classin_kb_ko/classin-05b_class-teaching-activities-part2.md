## 답안지

## 1. "답안지"란?

ClassIn 플랫폼에서 "답안지"는 시험에 자주 사용되는 답안 작성 도구입니다. 기존 "시험"의 복잡한 문제 입력 방식과 비교해, "답안지"는 문제 내용을 입력할 필요 없이 시험지 이미지를 업로드하고 해당 답안 선택지를 추가하기만 하면 되어, 문제 입력 비용을 크게 줄여줍니다. "답안지"는 객관식, 복수 선택, 참/거짓, 빈칸 채우기, 서술형 등 다양한 문제 유형을 지원합니다. 담임교사와 교사 모두 답안지를 만들 수 있어, 학생에게 편리한 답안 작성 경험을 제공합니다.

## 2. "답안지" 새로 만들기

### 대상
"담임교사"와 "교사"

### 사용 설명
교사는 반 페이지에 들어간 후 코스 항목 아래에 답안지를 만들 수 있습니다. 시험지 파일과 답안 파일에는 업로드 가능한 첨부파일 수에 일정한 제한이 있습니다. 예를 들어 이미지는 최대 15장, 녹음은 최대 15개, 로컬 또는 클라우드 드라이브의 PDF·Word·음성 파일은 최대 15개까지 업로드할 수 있습니다. 컴퓨터에서 업로드할 때는 드래그 앤 드롭을 지원합니다.

답안지에서는 이미 추가한 답안 선택지를 답안지 템플릿으로 저장할 수 있으며, 저장된 템플릿에서 선택해 사용할 수도 있습니다.

답안지에서 추가할 수 있는 문제 유형은 객관식, 복수 선택, 참/거짓, 빈칸 채우기, 서술형입니다. 최대 200문항까지 답안 선택지를 추가할 수 있습니다. 문제 일괄 추가, 구성 설명 추가도 지원합니다.

컴퓨터나 태블릿에서 교사는 시험지 파일을 기반으로 AI가 분석해 답안지를 자동 생성하도록 할 수 있습니다. AI 분석을 지원하는 파일 형식은 이미지, PDF, Word입니다.

**"답안지" 생성 시 설정할 수 있는 항목:**

| 설정 | 기능 |
| --- | --- |
| 시간 | 답안지의 시작 및 마감 시간을 설정합니다. |
| 답안 작성 제한 시간 | 학생이 답안을 작성하는 시간 제한을 설정합니다. |
| 평가 | 답안지의 평가 제도를 설정합니다. |
| 발행 대상 | 특정 반, 반 내 일부 그룹 구성원 또는 일부 학생에게 발행하거나, 여러 반에 동시에 발행할 수 있습니다. |
| 교사 | 활동 담당 교사를 지정해 관련 알림을 받습니다. |
| 코스 | "답안지"를 어느 코스에 속하게 할지 선택합니다. 기본값은 현재 코스입니다. |
| 단원 주제 | "답안지"를 어느 단원 주제로 분류할지 선택합니다. 선택하지 않으면 기본 단원으로 분류됩니다. |
| 빈칸 채우기 수동 채점 | 켜면 학생의 빈칸 채우기 답안이 정답과 일치하지 않을 경우 자동으로 수동 채점으로 전환됩니다. |
| 학생 간 내용·성적 상호 열람 허용 | 학생끼리 서로의 내용과 성적을 열람할 수 있는지 설정합니다. 답안지 제출 후/채점 후/종료 후 중 언제 허용할지 설정할 수 있습니다. |
| 정답과 해설 공개 | 정답과 해설을 공개할지 설정합니다. 답안지 제출 후/채점 후/종료 후 중 언제 공개할지 설정할 수 있습니다. |
| 활동 종료 후 추가 제출 허용 | 켜면 학생이 기한 내에 답안지를 완료하지 못한 경우, 활동 종료 후에도 제출할 수 있습니다. |
| 새로 참여한 학생 제출 허용 | 켜면 답안지 활동이 끝나기 전에 새로 반에 참여한 학생도 발행된 답안지에 참여할 수 있습니다. |
| 잠금 해제 조건 | 완료가 필요한 선행 활동을 추가합니다. 잠금 해제 조건을 추가하면, 학생은 선행 조건을 완료해야 현재 답안지 활동을 시작할 수 있습니다. |

### 유의사항
휴대폰에서는 현재 답안지 생성을 지원하지 않습니다.

### 조작 방법

**컴퓨터/태블릿**
1. "홈"으로 이동합니다.
2. 반으로 들어갑니다.
3. 새 코스를 만들거나 기존 코스로 들어갑니다.
4. "새로 만들기"를 클릭합니다.
5. "답안지"를 선택합니다.
6. "답안지 제목"을 추가합니다.
7. "시험지·답안 파일"을 추가합니다.
8. "답안지"를 설정합니다.
9. "답안지 설정 항목"을 구성합니다.
10. 바로 "발행"하거나 "초안 저장"합니다.

## 3. "답안지" 수정하기

초안 및 미시작 답안지는 "코스"를 변경할 수 없으며, 나머지 내용과 설정은 모두 변경할 수 있습니다.

진행 중인 답안지는 문제 유형과 선택지를 추가·삭제할 수 없으며, 설정 항목 중 시작 시간, 답안 작성 제한 시간, 코스도 변경할 수 없습니다.

종료된 답안지는 문제 유형과 선택지를 추가·삭제할 수 없으며, 설정 항목 중 시간, 답안 작성 제한 시간, 발행 대상, 교사, 코스, 빈칸 채우기 수동 채점, 새로 참여한 학생 제출 허용, 잠금 해제 조건은 변경할 수 없습니다.

초안, 진행 중, 종료된 답안지 모두 템플릿으로 저장하는 것과 선택지에 설정된 답안을 수정하는 것은 지원됩니다.

휴대폰에서는 현재 답안지 수정을 지원하지 않습니다.

1. "홈"으로 이동합니다.
2. 반으로 들어갑니다.
3. 코스로 들어갑니다.
4. 답안지를 찾아 "···"을 클릭하고 "편집"을 선택합니다.

## 7. "답안지" 공유하기

### 이런 경우에
교사는 학생이 ClassIn에 로그인하지 않았거나 ClassIn 알림 기능을 켜지 않은 경우에도, 배포한 답안지를 위챗이나 다른 플랫폼으로 공유할 수 있어, 교사가 학생의 학습을 제때 독려하는 데 도움이 됩니다.

교사가 컴퓨터에서 답안지를 공유할 때는 ClassIn 반이나 친구에게 공유하거나 링크를 복사해 공유할 수 있으며, 휴대폰 위챗으로 QR코드를 스캔해 위챗 친구나 그룹에 공유할 수도 있습니다.

교사가 휴대폰이나 태블릿에서 답안지를 공유할 때는 ClassIn의 반이나 친구에게 공유할 수 있고, 위챗 친구·그룹·모멘트, 웨이보, QQ 친구에게도 공유할 수 있으며, 링크 복사를 통한 공유도 가능합니다.

ClassIn 앱 외부에서 공유된 답안지를 확인할 때는 시험지 구성 등만 볼 수 있고 구체적인 문제 내용은 볼 수 없습니다. 학생이 답안을 작성하려면 ClassIn을 실행해 반에 들어가야 합니다.

1. 오른쪽 상단의 "공유" 버튼을 클릭합니다.

## 8. 학생이 "답안지"를 사용하기

**답안지 찾기:** 반 안의 코스 항목에서 교사가 배포한 답안지를 찾습니다.

**답안 작성 화면 들어가기:** 답안지 오른쪽의 "답안 작성 시작" 버튼을 탭하면 답안 작성 화면으로 들어갑니다. 이 화면 왼쪽은 시험지 파일 페이지로, 표시/숨기기가 가능하며, 파일 이미지 전환, 이미지 확대/축소/원상 복귀를 지원하고, 왼쪽 하단에서 녹음 음성 파일을 재생할 수 있습니다. 이 화면 오른쪽은 답안지 화면으로, 학생은 문제 수와 총점을 확인할 수 있습니다. 동시에 화면 왼쪽 하단에는 남은 답안 작성 시간도 표시됩니다. 이러한 정보는 학생이 답안을 작성하고 시간을 조절하는 데 중요합니다.

**답안 작성 과정:** 이제 학생은 답안 작성을 시작할 수 있습니다. 시험지에 따라, 화면에서 해당 문제의 정답을 선택하거나 답안을 입력합니다. 한 문제를 완료하면 시스템이 자동으로 오른쪽의 답안 목록에서 답안을 작성한 문제를 표시합니다(태블릿에서는 왼쪽, 휴대폰에서는 오른쪽 상단에 표시), 답안을 작성한 문제와 작성하지 않은 문제를 추적하는 데 도움이 됩니다. 문제 목록의 문제도 클릭해 선택할 수 있어, 학생이 해당 문제로 빠르게 이동할 수 있습니다.

**답안지 제출하기:** 학생이 답안 작성을 완료하면 화면 오른쪽 하단의 "제출" 버튼을 탭할 수 있습니다. 이는 학생이 답안 작성을 마쳤다는 의미이며, 시험지는 자동으로 회수됩니다.

학생이 답안지를 제출한 후에는 답안을 수정할 수 없으므로, 제출 전에 답안을 꼼꼼히 확인해 주세요.

시간제한이 있는 답안지의 경우, 도중에 나가더라도 시간은 계속 흘러가며, 남은 시간이 끝나면 시스템이 자동으로 제출합니다.

## 녹화 수업

## 1. "녹화 수업"이란?

"녹화 수업" 기능은 교사가 사전에 수업 영상을 녹화해 "학습 활동" 내의 "녹화 수업" 모듈에 업로드하여, 학생이 언제든지 시청할 수 있도록 하는 기능을 말합니다. 이 형식은 시청 장소와 기기에 제한받지 않으며, 일반적으로 수업 전 예습, 수업 후 복습, 비실시간 수업 코스에 사용됩니다.

## 2. "녹화 수업"과 "수업 다시보기 영상"의 차이는?

ClassIn 플랫폼에서 "녹화 수업"과 "수업 다시보기 영상"은 서로 다른 두 가지 기능입니다.

"수업 다시보기 영상" 기능은, 담당 교사가 강의실에서 수업을 진행하는 동안 ClassIn의 "클라우드 녹화" 기능을 사용해, "담당 교사" 시점에서 수업 과정을 녹화하고 자동으로 "다시보기 영상"으로 저장하는 기능으로, 수업 후 "시간표"에서 다시보기를 시청할 수 있습니다.

반면 "녹화 수업"은 교사가 미리 수업 영상을 녹화해 "학습 활동" 내의 "녹화 수업" 모듈에 업로드하는 것을 말합니다. 이 영상들은 학생이 언제든지 시청할 수 있으며, 수업 전 예습, 수업 후 복습, 비실시간 수업 코스에 적합합니다. 이 형식은 시청 장소와 기기에 제한받지 않습니다.

## 1. "출석 체크"란?

ClassIn의 "출석 체크"는 학습 과제 완료 현황을 기록하는 도구입니다. 교사는 흔히 매일 영어 단어 100개를 외우는 것과 같이 반복적으로 완료해야 하는 과제를 부과합니다. 교사는 ClassIn에서 출석 체크 과제를 만들고 구체적인 요구 사항을 상세히 기재해 학생에게 발행할 수 있습니다. 학생은 과제를 완료한 후 사진 촬영, 동영상 녹화, 음성 녹음 등의 방법으로 출석 체크 기록을 남길 수 있습니다. 이 출석 체크 메커니즘은 주로 교사가 학생의 수업 이해도를 파악하고, 특정 부분을 더 중점적으로 지도할 필요가 있는지 판단하는 데 도움이 됩니다. 교사는 출석 체크 현황에 따라 수업 내용과 방법을 조정해 학생의 학습 요구를 더 잘 지원할 수 있습니다. 동시에 출석 체크는 학생의 학습 의욕과 과제 완료 효율을 높이는 데도 도움이 됩니다.

## 2. "출석 체크" 새로 만들기

### 대상
"담임교사"와 "교사"

### 사용 설명

## 9. 학생이 "출석 체크"를 제출하기

교사가 출석 체크를 발행한 후, 학생은 ClassIn 반이나 할 일에서 출석 체크를 찾아 확인·제출할 수 있습니다.

출석 체크 페이지에서 학생이 출석 체크 날짜를 선택하면, 당일 출석 체크 남은 시간 또는 추가 체크 마감 시각을 확인할 수 있습니다. "지금 체크하기" 또는 "추가 체크"를 탭한 후 출석 체크 내용을 작성합니다. 출석 체크 내용에는 이미지, 녹음, 동영상, 개인 클라우드 드라이브 내 파일, 로컬 파일, 링크 등의 첨부파일을 업로드할 수 있습니다. 파일 개수 제한: 이미지 첨부파일 15장, 녹음 첨부파일 15개, 동영상 첨부파일 15개이며, 로컬 파일·클라우드 드라이브 파일·링크의 합계는 15개를 초과할 수 없고, 각 동영상 또는 파일 크기는 500MB 이내여야 합니다. 컴퓨터에서 출석 체크 첨부파일을 업로드할 때는 이미지와 파일을 출석 체크 내용으로 드래그 앤 드롭할 수 있습니다.

출석 체크 내용을 작성한 후, 학생은 "출석 체크 제출"을 탭할 수 있습니다.

1. 생성된 코스로 들어갑니다.
2. 출석 체크 페이지로 이동합니다.
