## 백엔드 관리자

### 대상
- "관리자 백엔드" 마스터 계정
- "권한 관리" 권한이 있는 하위 계정

### 사용 설명
관리자 백엔드는 학교의 수업, 교사, 학생 등의 정보를 관리하는 시스템입니다. 마스터 계정 교사는 관리자 백엔드에서 관리자(하위 계정)를 추가하여 로그인시키고 서로 다른 권한을 부여할 수 있습니다. 권한별로 관리 가능한 백엔드 영역은 다음과 같습니다:

| 섹션 | 영역 | 관리자가 할 수 있는 일 |
| --- | --- | --- |
| 수업 센터 | 클래스 관리/수업 관리 | 클래스 생성, 수정, 종료, 학생 추가. 수업 생성, 수정, 삭제. |
| | 공개 수업 | 공개 수업 생성, 수정, 삭제, 학생 추가. |
| 저장소 관리 | 교사 관리 | 교사 추가, 수정, 비활성화/활성화, 권한 및 태그 설정. |
| | 학생 관리 | 학생 추가, 수정, 숨기기/표시, 삭제, 권한 및 태그 설정. |
| | 데이터 개요 | 백엔드 저장소 현황 확인. |
| | 조직 클라우드 드라이브 | 폴더 생성, 자료 업로드, 복사·이동. 삭제, 다운로드, 멤버 관리의 3개 하위 옵션을 개별 설정 가능. |
| | 문제 은행 | 조직 문제 은행의 문제·시험지 추가, 수정, 삭제. |
| | 수업 리소스 | 각 수업의 【녹화 영상】【모니터링 이미지】【판서 자료】 저장 용량 확인, 잠금(오삭제 방지), 수동 삭제. |
| | 클래스 리소스 | 클래스의 【클래스 파일】【수업 첨부파일】【공동 작성 문서】 저장 용량 확인, 잠금, 수동 삭제. |
| | 리소스 센터 | 리소스 상품 추가 및 리소스 주문 관리, 마스터 계정이 획득한 리소스 확인. |
| 교육 관리 | 라이브/재생 | 웹 라이브 및 재생 개인화 설정 확인·수정. |
| | 교육 데이터 | 수업 후 평가 수정, 교육 보고서, 학습 보고서, 수업 데이터 내 강의 분석·학습 분석 확인. |
| | 과제 관리 | 과제 데이터 확인/다운로드. |
| | 퀴즈 관리 | 퀴즈 데이터 확인/다운로드. |
| 교무 관리 | 모니터링 관리/계정 조회 | 진행 중인 수업 참관, 교사·학생 출석 확인, 수업 중 네트워크·기기 상태 확인. |
| 재무 센터 | 재무 센터 | 요금 규칙, 주문 상세, 청구서 등 확인. |
| 마이 스쿨 | 마이 스쿨 | 기관의 개인화 설정 확인·수정. |
| | 권한 관리 | 학교 백엔드에 관리자 추가, 기존 관리자 수정·삭제. |
| 클라이언트 권한 | 공개 수업/클래스 생성 | ClassIn 앱에서 직접 공개 수업이나 클래스 생성. |

### 유의사항
- 관리자 정보 수정 시 계정이나 이메일은 변경할 수 없으며, 표시 이름과 권한만 수정 가능합니다.

### 조작 방법

**(1) 관리자 추가**
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "권한 관리"로 이동
3. 오른쪽의 "하위 계정 추가" 클릭
4. 하위 계정의 기본 정보 입력
5. 하위 계정의 관리 권한 설정
6. "확인" 클릭

**(2) 관리자 권한 수정**
1. 왼쪽 상단에서 관리자 검색
2. 관리자 오른쪽의 "편집" 클릭

**(3) 관리자 삭제**
1. 오른쪽 상단에서 관리자 검색
2. 관리자 오른쪽의 "삭제" 클릭

## 관리자 백엔드 로그인/로그아웃

### 대상
- "관리자 백엔드" 마스터 계정
- "관리자 백엔드" 하위 계정

### 이런 경우에
ClassIn을 사용하는 각 학교에는 전용 관리자 백엔드가 있습니다. 교무 담당자는 여기서 수업 편성, 설정, 클래스·수업 모니터링, 교육 데이터 및 청구 정보 확인 등을 수행하며, 이러한 작업은 앱 내 클래스, 교사, 학생 및 관련 기능에 직접 영향을 줍니다. 편성이나 설정 작업을 하려면 먼저 관리자 백엔드에 로그인해야 합니다.

### 사용 설명
각 학교의 관리자 백엔드에는 모든 권한을 가진 마스터 계정이 하나 있습니다. 여러 교무 담당자가 함께 사용해야 하는 경우, 마스터 계정은 여러 하위 계정을 추가하고 각각 다른 권한을 설정할 수 있어 다인 협업이 용이합니다.

관리자 백엔드는 영어, 중국어 간체, 한국어, 베트남어, 일본어, 아랍어 표시를 지원합니다. 백엔드 홈 화면 오른쪽 상단에서 언어를 전환할 수 있습니다.

교사가 여러 학교에서 하위 계정 또는 마스터 계정을 가지고 있는 경우, 먼저 관리자 백엔드에 로그인한 후 오른쪽 상단에서 다른 학교의 관리자 백엔드로 전환할 수 있습니다.

### 관련 문서
- "관리자 백엔드에 하위 계정 추가"

### 조작 방법

**(1) 관리자 백엔드 로그인**
1. 브라우저를 연다
2. 주소창에 www.eeo.cn을 입력해 접속
3. 오른쪽 상단의 "관리자 백엔드" 클릭
4. ClassIn 계정/비밀번호 또는 인증코드로 로그인

**(2) 다른 학교의 관리자 백엔드로 전환**
1. 관리자 백엔드에 진입한 후 오른쪽 상단에서 다른 학교의 관리자 백엔드로 전환

**(3) 관리자 백엔드에서 로그아웃**
1. 오른쪽 상단 프로필 사진 클릭
2. "로그아웃" 클릭

## 인증 자료

### 대상
- "관리자 백엔드" 마스터 계정

### 사용 설명
교무 담당자는 관리자 백엔드의 "인증 자료" 화면에서 학교/기업의 인증 정보를 입력하거나 업데이트해야 합니다. 필수 항목은: 학교/기업명, 학교/기업 로고, 주요 업종, 소재 지역, 상세 주소, 학교/기업 담당자의 이름·전화번호·이메일, 인증 방식입니다. 일반적인 인증 방식으로는 사업자등록증, 신분증, 여권 등이 있습니다. 예를 들어 사업자등록증으로 인증하는 경우, 등록증 이미지, 회사명, 법정대표자, 통일사회신용코드가 필요합니다. 인증 자료 제출 후 인증 심사가 진행됩니다.

ClassIn의 클라우드 녹화 기능을 사용하려면 인증 상태가 "인증됨"이어야 합니다.

### 조작 방법
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "인증 자료"로 이동
3. "편집"을 클릭해 인증 정보 수정
4. 수정 완료 후 "확인"을 클릭해 저장
