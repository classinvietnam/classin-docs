## 단원 리포트 설정

### 대상
- "백오피스 관리 시스템" 마스터 계정
- "학교 설정" 권한을 가진 하위 계정

### 사용 설명
"단원 리포트 설정"에는 다음과 같은 구성 모듈이 포함됩니다: 종합 개요, 성적 구성, 능력 분석, 학습 과정, 교사 코멘트, 학교 소개. 이 중 "종합 개요" 모듈은 필수이며 삭제할 수 없지만, 나머지 모듈은 필요에 따라 추가하거나 삭제할 수 있습니다.

### 관련 문서
「백오피스에서 하위 계정 추가」

### 조작 방법
1. 백오피스 관리 시스템에 로그인합니다.
2. 왼쪽 내비게이션에서 "학교 설정"으로 이동합니다.
3. 상단의 "코스 리포트 설정"으로 이동합니다.
4. 하단의 "단원 리포트 설정" 오른쪽의 "템플릿 편집"으로 이동합니다.

## 학습 리포트 스타일 변경

### 대상
- "백오피스 관리 시스템" 마스터 계정
- "학교 설정" 권한을 가진 하위 계정

### 사용 설명
교무 담당자는 백오피스 관리 시스템에서 학습 리포트 템플릿 스타일을 변경할 수 있습니다. 백오피스에는 총 2가지 학습 리포트 스타일이 준비되어 있습니다.

### 관련 문서
「백오피스에서 하위 계정 추가」

### 조작 방법
1. 백오피스 관리 시스템에 로그인합니다.
2. 왼쪽 내비게이션에서 "학교 설정"으로 이동합니다.
3. "활동 리포트 설정"을 엽니다.
4. "템플릿 편집"을 클릭합니다.
5. 활성화할 템플릿을 선택합니다.
6. 템플릿을 클릭합니다.
7. 표시 항목을 설정합니다.

## 수업 후 리포트 메시지 자동 발송

### 대상
- "백오피스 관리 시스템" 마스터 계정
- "학교 설정" 권한을 가진 하위 계정

### 이런 경우에
매 수업이 끝난 후 ClassIn이 자동으로 교사나 학생에게 수업 리포트나 학습 리포트 확인을 알려주기를 원한다면, 교무 담당자는 "백오피스 관리 시스템"에서 알림 자동 발송 기능을 켤 수 있습니다. 이렇게 하면 교사와 학생이 리포트 확인을 잊어버리지 않습니다.

### 사용 설명
교무 담당자는 백오피스 관리 시스템에서 학교 리포트 및 수업 리포트 메시지 알림의 자동 발송 여부를 체크하여 켜거나 끌 수 있습니다. 학생이 사용하는 기기에서도 ClassIn 메시지 알림 기능이 켜져 있다면, 수업 리포트와 학습 리포트가 생성된 후 교사와 학생은 ClassIn 시스템으로부터 리포트 확인 알림을 받게 됩니다.

### 관련 문서
「백오피스에서 하위 계정 추가」

### 조작 방법
1. 백오피스 관리 시스템에 로그인합니다.
2. 왼쪽 내비게이션에서 "학교 설정"으로 이동합니다.
3. "활동 리포트 설정"을 엽니다.
4. "템플릿 편집"을 클릭합니다.
5. "수업 리포트 메시지 알림 설정"에서 "학교 리포트 및 수업 리포트 메시지 알림 자동 발송"을 켜거나 끕니다.
