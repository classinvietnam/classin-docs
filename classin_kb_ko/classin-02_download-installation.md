## 1. Windows에 ClassIn 설치하기

### 1) 다운로드 전 준비

**(1) 컴퓨터 사양 확인하기**

ClassIn을 다운로드하기 전에 컴퓨터의 하드웨어 사양(CPU 모델, 메모리, 운영체제)을 확인하세요. 절차:
1. "내 PC"를 마우스 오른쪽 버튼으로 클릭합니다.
2. "속성"을 선택합니다.
3. "장치 사양"에서 CPU 모델, 메모리, 운영체제를 확인합니다.

### 2) ClassIn 다운로드 및 설치

**2.1 사용 설명**

ClassIn은 Windows 7, Windows 8, Windows 10, Windows 11 이상을 지원합니다. ClassIn 설치 파일을 다운로드할 때는 "Google Chrome" 또는 "Firefox" 사용을 권장합니다. 두 브라우저 모두 파일 다운로드 호환성이 우수합니다.

설치 중 문제를 방지하기 위해, ClassIn 설치 파일을 다운로드하기 전에 컴퓨터에 설치된 백신 프로그램이나 보안 소프트웨어(예: 360 시큐리티, 360 백신, Tencent PC 매니저 등)를 종료하는 것을 권장합니다. 이러한 소프트웨어는 ClassIn의 레지스트리 파일을 위협으로 잘못 인식해 삭제할 수 있으며, 이로 인해 설치 과정에 문제가 생길 수 있습니다.

ClassIn 공식 다운로드 사이트(중국어): https://www.eeo.cn/cn/download
ClassIn 공식 다운로드 사이트(영어): https://www.classin.com/download

**2.2 유의사항**

다음 시스템에서는 ClassIn 설치를 지원하지 않습니다: Windows XP, Windows 8.1 RT, Windows Vista.

**2.3 조작 방법**
1. "브라우저"를 엽니다.
2. 브라우저 주소창에 다음을 입력합니다: www.eeo.cn
3. "다운로드 센터"로 이동합니다.
4. "Windows 버전 다운로드"를 클릭합니다.
5. 다운로드가 완료되면 설치 파일을 실행합니다.
6. 화면 안내에 따라 ClassIn을 설치합니다.

## 2. Mac에 ClassIn 설치하기

**(1) CPU 모델 확인하기**

ClassIn을 다운로드하기 전에 컴퓨터의 CPU 모델을 확인하세요. 절차:
1. "런치패드"를 엽니다.
2. "터미널"을 검색해 엽니다.
3. 터미널 창의 `LeondeMacbook-Air:~ shouhouzhichi$` 오른쪽에 `sysctl machdep.cpu.brand_string`을 입력합니다.
4. 입력 후 엔터 키를 누릅니다.
5. CPU 모델을 확인합니다.

![](https://cofile.eeo.cn/res-store%2F2910229de3e8dc38f748ea122fe95ca3f0016f263bc74ff8c2d4db656ee8251a_2594456?q-sign-algorithm=sha1&q-ak=AKIDJQGsEOK2TfbFdEZifMnxrWx85mpdHj6H&q-sign-time=1773936000;1774540800&q-key-time=1773936000;1774540800&q-header-list=host&q-url-param-list=&q-signature=5e1435815a88a33835581c2ad92b4a33ca67cc6c)

**(2) CPU 칩 종류 확인하기**

Mac의 메모리, 운영체제 버전, CPU 칩 종류를 확인합니다. 절차:
1. 화면 왼쪽 상단의 Apple 메뉴 아이콘에 마우스를 올립니다.
2. "이 Mac에 관하여"를 클릭합니다.
3. "이 Mac에 관하여" 화면의 "프로세서" 항목에서 메모리, 운영체제 버전, CPU 칩 종류를 확인합니다.

**2.2 조작 방법**

**인텔 칩 탑재 Mac에 ClassIn 다운로드 및 설치**
1. 브라우저 주소창에 다음을 입력합니다: www.eeo.cn
2. "macOS 인텔 칩 버전 다운로드"를 클릭합니다.
3. 설치 파일을 실행하고 검증이 완료될 때까지 기다립니다.
4. 왼쪽의 ClassIn 아이콘을 오른쪽의 "응용 프로그램" 폴더로 드래그하고, 복사가 완료될 때까지 기다립니다.
5. "런치패드"를 열고 "Classin"을 검색합니다.
6. "Classin"을 엽니다.
7. 최초 실행 검증을 기다린 후, 표시되는 대화 상자에서 "열기"를 클릭합니다.

## 3. iPhone/iPad에 ClassIn 설치하기

**(1) 기기 모델 확인하기**

"설정" → "일반" → "정보"에서 모델명을 확인합니다.

**(2) 사양 요건표와 비교하기**

보유하신 iPhone 또는 iPad 모델을 아래 권장 기기 목록과 비교해, ClassIn 수업 요건을 충족하는지 확인합니다.

| --- | --- | --- | --- |
| 운영체제 | iOS 11 이상 | iOS 11 이상 | iOS 14 이상 |
| iPad/iPhone 기기 모델 | iPhone 6 이상, iPad 5세대 이상, iPad mini 4세대 이상, iPad Air 3세대 이상, iPad Pro 이상 | iPhone 8 이상, iPad 6세대 이상, iPad Pro 이상 | iPhone XS 이상, iPad 8세대 이상, iPad Pro 2세대 이상, iPad mini 5세대 이상, iPad Air 3세대 이상 |

1. "App Store"를 엽니다.
2. 검색창에 "Classin"을 입력합니다.
3. 오른쪽의 "받기"를 탭합니다.
