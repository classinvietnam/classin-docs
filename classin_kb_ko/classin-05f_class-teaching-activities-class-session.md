## 수업

## 1. "수업"이란?

ClassIn 플랫폼에서 "수업"이란 교사가 학생에게 지식을 전달하는 전용 공간을 말하며, 수업 코마 또는 라이브 강의실이라고도 부릅니다. 수업 중 교사는 설명, 시연, 질문 등의 방식으로 교육 활동을 진행하며, 이를 통해 학생의 학습과 성장을 촉진하는 것을 목표로 합니다. 강의실 환경의 설계와 구성은 교육 효과를 높이고 학생의 적극적인 참여를 이끌어내는 데 매우 중요합니다. 수업 내에서 자주 사용되는 기능으로는 좌석, 칠판, 각종 교육 도구가 있으며, 이를 통해 수업 진행이 원활하게 이루어집니다.

## 2. "수업" 새로 만들기

### 대상
"담임교사"

《교사의 수업 새로 만들기 허용》 기능을 켠 후의 "반 교사"

### 사용 설명
반에서 수업을 만들 때 설정할 수 있는 항목은 다음과 같습니다:

| 설정 | 기능 |
| --- | --- |
| 수업 이름 | 학생과 교사가 쉽게 식별할 수 있도록 수업에 명확한 이름을 붙입니다. |
| 시작 시간과 시간 | 수업의 시작 시간과 수업 시간을 설정합니다. 시작 시간은 가장 빠르게는 현재 시각으로 설정할 수 있으며, 수업 시간은 최소 15분, 최대 23시간 55분까지 설정할 수 있습니다. |
| 발행 대상 | "수업"을 특정 반, 반 내 일부 그룹 구성원 또는 일부 학생에게 발행할 수 있습니다. |
| 담당 교사 | 기본적으로 생성자가 담당 교사가 됩니다. 담임교사는 반 내 다른 교사 신분 구성원을 담당 교사로 지정할 수 있습니다. 하나의 수업에는 담당 교사를 한 명만 설정할 수 있습니다. |
| 조교사 | 반 내 교사를 선택해 조교사로 설정할 수 있습니다. 1회 수업당 최대 6명의 조교사를 추가할 수 있습니다. 조교사 1명이 무대에 올라 카메라 화면을 표시하는 경우 담당 교사나 학생의 좌석을 차지하지 않지만, 조교사 여러 명이 무대에 오르면 학생 좌석을 차지합니다. |
| 코스 선택 | "수업"을 어느 코스에 속하게 할지 선택합니다. 기본값은 현재 코스입니다. |
| 단원 주제 | "수업"을 어느 단원 주제에 속하게 할지 선택합니다. 선택하지 않으면 기본 단원으로 분류됩니다. |
| OMO 스테이션 라이브 | 학생이 교사의 스테이션 라이브 화면을 시청할 수 있도록 설정하며, 학생은 시청 여부를 선택할 수 있습니다. 오프라인과 온라인이 결합된 블렌디드 수업 시나리오에 적합합니다. 이 기능은 백오피스 관리 시스템에서 활성화해야 선택할 수 있습니다. |
| 무대 인원수 | 수업 중 동시에 강의실 최상단 좌석에 나타날 수 있는 인원수를 말합니다. 최소 담당 교사 1명·학생 0명, 최대 담당 교사 1명·학생 12명까지 지원합니다. |
| ClassIn 강의실 녹화 | 클라우드 녹화는 "ClassIn 강의실 녹화"와 "현장 녹화"로 나뉩니다. "ClassIn 강의실 녹화"는 수업의 전체 화면을 녹화합니다. |
| 현장 녹화 | 클라우드 녹화는 "ClassIn 강의실 녹화"와 "현장 녹화"로 나뉩니다. "현장 녹화"는 선택한 담당 교사의 카메라 화면만 녹화하여, 전체 수업 장면을 보여주는 데 사용됩니다. |
| 웹 라이브 및 다시보기 권한 | 클라우드 녹화에 체크한 상태에서, 수업의 웹 라이브 및 다시보기 권한을 설정할 수 있어 반 외부 사용자가 웹을 통해 라이브와 다시보기 콘텐츠를 시청할 수 있는지 결정할 수 있습니다. |
| AI 수업 요약 | 클라우드 녹화에 체크한 상태에서, AI 에이전트가 수업 다시보기 내용을 지능적으로 요약하도록 선택할 수 있으며, 챕터별 요약과 자막 목록이 포함됩니다. |
| 좌석 표시 | 켜면 교사와 학생이 온라인에서 상호작용하는 수업을 진행하기 쉬워지고, 언제든지 소통하고 질의응답을 할 수 있습니다. 끄면 수업이 칠판 중심의 교육에 집중되며, 교사는 강의실 안에서 다시 조정할 수도 있습니다. |
| 학생 자동 무대 등장 | "좌석 표시"가 켜져 있는 경우, 학생이 강의실에 들어올 때 자동으로 무대에 올라 자신의 카메라 화면을 표시할지 설정할 수 있습니다. |
| 학생 간 학습 리포트 상호 열람 허용 | 켜면 학생이 다른 학생의 학습 리포트를 열람할 수 있습니다. |

### 유의사항
반에서 수업을 만들 때 교사는 무대 인원수를 선택할 수 있습니다. 시스템은 기본적으로 현재 기기에서 마지막으로 수업을 만들었을 때의 선택 항목을 사용합니다. 기기를 변경하면 시스템이 이전 선택을 기억하지 않으므로 다시 설정해야 합니다.

수업 코마나 코스를 추가할 수 없는 경우, 현재 코스 아래의 수업 코마 수가 이미 상한에 도달했을 가능성이 있습니다.

수업 코마의 시간 길이와 관계없이, 정식 강의실의 초과 수업 시간은 20분, 임시 강의실의 초과 수업 시간은 2분입니다.

"담임교사"가 곧 "담당 교사"인 경우, 클라이언트에서 수업을 만들 때 담당 교사는 기본적으로 담임교사가 되므로 별도로 담당 교사를 설정할 필요가 없습니다.

"학생이 교사에 의해 반에서 내보내짐", "반이 해산됨", "학생이 스스로 반을 떠남"의 경우, 이미 반을 떠난 학생이 ClassIn에서 녹화 수업 다시보기 영상을 열람할 수 있는지는 반 설정의 "반을 떠난 학생 또는 반 해산 후에도 코스 내용을 열람할 수 있도록 허용" 설정에 따라 결정됩니다.

## 3. "수업" 수정하기

수업 생성 권한을 가진 담당 교사

ClassIn 클라이언트에서 담임교사는 이미 만들어진 모든 수업을 수정할 수 있으며, 수업 생성 권한을 가진 교사는 자신이 담당 교사인 수업만 수정할 수 있습니다.

구체적으로 수정 가능한 정보와 설정에는 수업 이름, 개강일, 개강 시각, 수업 시간, 담당 교사, 조교사, 무대 인원수, 클라우드 녹화, 웹 라이브, 웹 다시보기 등이 포함됩니다. 아래의 관련 규칙과 시간 제한을 준수해 주세요.

개강 20분 전까지 수정할 수 있는 설정: 수업 이름, 개강일, 개강 시각, 수업 시간, 발행 대상 반/구성원, OMO 스테이션 라이브, 무대 인원수, 클라우드 녹화(ClassIn 강의실 녹화, 현장 녹화), 웹 라이브, 웹 다시보기, 좌석 표시, 학생 자동 무대 등장.

수업 종료 전까지 언제든지 수정할 수 있는 설정: 담당 교사 변경, 조교사 추가/변경, 웹 다시보기.

시간 제한 없이 언제든지 수정할 수 있는 설정: AI 수업 요약, 웹 다시보기, 단원 주제, 학생 간 학습 리포트 상호 열람 허용.

정식 개강 전(강의실 사전 입장 시간 포함)이라면 수업은 언제든지 삭제할 수 있습니다. 다만 수업이 정식 수업 시간에 들어가면 더 이상 삭제할 수 없습니다.

종료된 수업은 삭제할 수 없습니다.

1. "홈"으로 이동합니다.
2. 반으로 들어갑니다.
3. 생성된 코스로 들어갑니다.
4. 수업을 찾아 "···"을 클릭하고 "편집"을 선택합니다.

## 6. "조교사" 설정하기

## 1) 수업 생성 시 조교사 추가하기

### 적용 시나리오
수강하는 학생 수가 많은 경우, 담임교사 또는 수업 생성 권한을 가진 교사는 수업에 "조교사"를 추가할 수 있습니다. 조교사는 수업 중 담당 교사가 수업 질서를 유지하는 것을 돕고, 담당 교사의 수업 진행을 지원할 수 있습니다.

수업에 조교사를 추가하기 전에, 담임교사가 먼저 조교사를 반에 추가하고 반 내에서 반 교사 신분으로 설정해야 합니다. 이렇게 해야 담임교사 또는 수업 생성 권한을 가진 교사가 수업을 만들 때 해당 반 교사를 조교사로 추가할 수 있습니다.

1. 왼쪽 내비게이션에서 "홈"으로 이동합니다.
2. 반을 찾아 들어갑니다.
3. 왼쪽 상단에서 새 코스를 만들거나 기존 코스로 들어갑니다.
4. "새로 만들기"를 클릭합니다.
5. "수업"을 만듭니다.
6. 생성 창에서 "펼치기"를 클릭하고 "조교사"를 추가합니다.
