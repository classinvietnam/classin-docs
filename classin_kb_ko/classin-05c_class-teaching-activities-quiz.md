## 시험

## 1. "시험"이란?

ClassIn의 "시험" 기능은 본질적으로 "시험지"이며, 학생이 특정 과목이나 분야에서 지식과 기술을 얼마나 습득했는지 평가하는 것을 목적으로 합니다. 시험은 학생의 학습 성과를 검증하는 중요한 수단일 뿐만 아니라, 학교와 교육 기관이 수업의 질과 커리큘럼 설계의 효과를 평가하는 데도 도움이 됩니다. 또한 시험은 학생이 스스로 학습 진행 상황과 취약점을 점검하는 데도 도움이 됩니다. 시험에 참여함으로써 학생은 각 과목의 습득 정도를 파악하고 부족한 부분을 신속히 발견할 수 있습니다. 이는 학생이 학습의 중점을 명확히 하고, 학습 효율을 높이며, 지식의 공백을 빠르게 메우는 데 도움이 됩니다.

## 2. "시험" 새로 만들기

## 1) 시험 활동 만들기

### 대상
"담임교사"와 "교사"

### 사용 설명
시험의 문제 추가 화면에 들어가면:

교사는 "문제 은행에서 선택"에서 "ClassIn 문제 은행"이 제공하는 문제나 시험지를 추가할 수 있으며, 키워드나 조건으로 문제와 시험지를 필터링할 수 있습니다.

미리 문제를 입력해 둔 경우, "내 문제 은행"에서 미리 입력한 문제와 시험지를 불러올 수 있습니다.

학교가 교사에게 문제·시험지 리소스 사용 권한을 부여한 경우, "조직 문제 은행"에서 권한이 부여된 리소스를 불러올 수 있습니다.

필요한 문제와 시험지를 문제 바구니에 추가하고, 바구니에서 추가된 문제를 삭제할 수도 있습니다. 이를 현재 시험지에 다시 추가하면 문제 선택이 완료됩니다.

교사는 "추가/일괄 추가 문제"에서 수동으로 단일 문제를 추가하거나 문제를 일괄 추가할 수도 있습니다. 일괄 추가 문제는 특정 형식을 따라야 ClassIn이 인식할 수 있으므로, 일괄 추가 시에는 먼저 템플릿을 다운로드하고, 템플릿과 입력 안내에 따라 문제를 추가한 후, 완성된 문제를 저장하고 업로드해야 합니다.

컴퓨터나 태블릿에서는 교사가 교육 목표나 특정 지식 포인트를 기반으로 AI 에이전트가 문제를 출제하도록 할 수 있습니다.

추가된 문제는 배점 설정, 위치 이동, 삭제, 편집, 복제 등의 작업을 지원합니다. 미리보기도 지원되어, 컴퓨터와 휴대폰에서 학생이 시험지를 볼 때의 화면을 확인할 수 있습니다. 시험지 리소스를 내 문제 은행에 저장하는 것도 지원되며, 컴퓨터를 사용하는 경우 시험지를 컴퓨터 로컬로 다운로드할 수도 있습니다.

**"시험" 생성 시 설정할 수 있는 항목:**

| 설정 | 기능 |
| --- | --- |
| 시간 | 시험의 시작 및 마감 시간을 설정합니다. |
| 답안 작성 제한 시간 | 학생이 답안을 작성하는 시간 제한을 설정합니다. |
| 평가 | 시험의 평가 제도를 설정합니다. |
| 발행 대상 | 특정 반, 반 내 일부 그룹 구성원 또는 일부 학생에게 발행하거나, 여러 반에 동시에 발행할 수 있습니다. |

| 학생 간 내용·성적 상호 열람 허용 | 학생끼리 서로의 내용과 성적을 열람할 수 있는지 설정합니다. 시험 제출 후/채점 후/종료 후 중 언제 허용할지 설정할 수 있습니다. |
| 정답과 해설 공개 | 정답과 해설을 공개할지 설정합니다. 시험 제출 후/채점 후/종료 후 중 언제 공개할지 설정할 수 있습니다. |
| 새로 참여한 학생 제출 허용 | 켜면 시험 활동이 끝나기 전에 새로 반에 참여한 학생도 발행된 시험에 참여할 수 있습니다. |
| 잠금 해제 조건 | 완료가 필요한 선행 활동을 추가합니다. 잠금 해제 조건을 추가하면, 학생은 선행 조건을 완료해야 현재 시험 활동을 시작할 수 있습니다. |

8. "문제"를 설정합니다.
9. "시험 설정 항목"을 구성합니다.
10. 바로 "발행"하거나 "초안 저장"합니다.

## 2) 문제 일괄 추가하기

### 이런 경우에
교사가 대량의 문제를 한 번에 ClassIn에 가져와야 할 때는 "문제 일괄 추가" 기능을 사용할 수 있습니다.

"문제 일괄 추가 - 문제 업로드"에서는, 입력 안내에 맞는 로컬 컴퓨터의 Word 또는 Excel 문서 내 문제를 직접 복사해 "문제 일괄 추가" 창에 붙여넣을 수 있습니다. 템플릿에 맞는 로컬 Word 또는 Excel 문서를 이 창으로 드래그 앤 드롭해 사용할 수도 있습니다.

"문제 일괄 추가 - 문제 편집"에서는 문제를 편집·삭제할 수 있으며, 내 문제 은행에 저장하는 것도 지원됩니다.

#### (1) 객관식 문제 형식

**문제 번호 형식:**
- 문제 번호는 아라비아 숫자여야 합니다.
- 문제 번호 뒤에는 반드시 문장부호나 공백을 붙여야 합니다(예: "1." 또는 "1、" 또는 "1 ").

**문제 본문 형식:**
- 텍스트와 이미지를 포함할 수 있으며, 텍스트는 최대 15,000자까지 가능합니다.

**선택지 영역 형식:**
- 선택지 번호는 대문자여야 합니다.
- 각 선택지 뒤에는 반드시 문장부호나 공백을 붙여야 합니다(예: "A." 또는 "A、" 또는 "A ").
- 선택지 수는 2~26개이며, A~Z 순서로 표기합니다.
- 선택지 내용에는 텍스트와 이미지를 포함할 수 있으며, 텍스트는 최대 200자까지 가능합니다.

**정답 영역 형식:**
- 반드시 지정된 형식을 사용해야 합니다(예: "답안: A").

**해설 영역 형식(선택 사항):**
- 반드시 지정된 형식을 사용해야 합니다(예: "해설: A인 이유").
- 해설 내용에는 텍스트와 이미지를 포함할 수 있으며, 텍스트는 최대 15,000자까지 가능합니다.

## 3. "시험" 수정하기

시험 발행 후에는 시험 내 문제와 제목을 수정할 수 없습니다.

초안 및 미시작 시험은 "코스"를 변경할 수 없으며, 나머지 내용과 설정은 모두 변경할 수 있습니다.

진행 중인 시험은 시험 내용과, 설정 항목 중 시작 시간, 답안 작성 제한 시간, 코스, 빈칸 채우기 수동 채점을 변경할 수 없습니다.
