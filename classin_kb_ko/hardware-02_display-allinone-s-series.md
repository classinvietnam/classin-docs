## [대형 디스플레이 일체형] 전원/신호 문제

# 1. 전원을 켠 후 신호가 없어 Windows 데스크톱에 들어갈 수 없음

**증상 설명:** 대형 디스플레이 일체형 기기 전원을 켠 후, 화면에 계속 "신호 연결 중", "신호 없음", "NO SIGNAL" 상태가 표시되며 Windows 시스템 데스크톱에 들어갈 수 없습니다.

**해결 방법:** 아래 방법 중 하나를 시도해 이 문제를 해결해 보세요.

**OPS 호스트가 정상적으로 전원이 연결되어 있는지 확인:**

일체형 기기 뒷면 OPS 호스트의 "POWER" 표시등을 확인해 판단합니다: "POWER" 표시등이 켜져 있다면 컴퓨터가 정상적으로 전원이 연결되어 켜진 상태임을 나타냅니다. "POWER" 표시등이 켜져 있지 않다면 아래의 POWER 버튼을 클릭해 전원을 켜 주세요(아래 그림 참고)

**OPS 전환 시도:**

일체형 기기 오른쪽의 전원 버튼을 클릭해 신호 소스를 선택하고, 내장 컴퓨터로 조정합니다

**OPS 호스트 재시작:**

일체형 기기 뒷면 OPS 호스트에서 POWER 버튼을 찾습니다

POWER 버튼을 길게 눌러 OPS 호스트가 완전히 종료될 때까지 기다립니다

다시 POWER 버튼을 눌러 OPS 호스트를 재시작합니다

# 2. 시스템에 블루스크린 발생

**증상 설명:** Windows 시스템에 들어갈 수 없고, 화면에 블루스크린 오류가 표시됩니다(아래 그림 참고).

**해결 방법:** 다음 단계에 따라 시도해 보세요.

시스템을 재시작해 해결되는지 확인합니다

오른쪽의 전원 키를 클릭해 안드로이드 메뉴로 들어갑니다

"설정"을 탭한 후 "본 기기 정보"를 탭합니다

"Windows 시스템 복원"을 선택합니다

## [대형 디스플레이 일체형] 오디오/비디오 문제

# 1. 대형 디스플레이 일체형 기기에서 소리가 나지 않음

**증상 설명:** 대형 디스플레이 일체형 기기 사용 시 어떤 소리도 들리지 않습니다.

**해결 방법:** 아래 방법 중 하나를 시도해 이 문제를 해결해 보세요.

대형 디스플레이 일체형 기기의 안드로이드 메뉴에서 소리 설정이 꺼져 있는지 확인합니다

**Windows 시스템 음량이 음소거되어 있는지 확인:**

Windows 시스템 데스크톱 오른쪽 하단의 "화살표" 아이콘을 클릭합니다

"스피커" 아이콘을 클릭합니다

좌우로 드래그해 시스템 음량을 조절합니다(아래 그림 참고)

**Windows 시스템 소리 설정에서 "86(XX) Monitor" 기기가 비활성화되어 있는지 확인:**

"스피커" 아이콘을 마우스 오른쪽 버튼으로 클릭해 "소리"를 선택합니다

"재생" 탭으로 이동합니다

"86 Monitor" 기기가 비활성화되어 있다면 해당 기기를 마우스 오른쪽 버튼으로 클릭해 "사용"을 선택합니다

아래의 "확인" 버튼을 클릭합니다(아래 그림 참고)

위 방법으로 해결되지 않으면, 대형 디스플레이 일체형 기기를 재시작하고 360 드라이버 마스터나 드라이버 지니어스 도구로 오디오 드라이버를 다시 설치하는 것을 권장합니다

## [대형 디스플레이 일체형] 디스플레이 문제

# 1. 화면 밝기 조절하기

**증상 설명:** 대형 디스플레이 일체형 기기 사용 시 화면 밝기가 적절하지 않습니다.

**해결 방법:** 다음 단계에 따라 화면 밝기를 조절해 주세요.

일체형 기기의 전원 버튼을 클릭합니다

안드로이드 팝업 창에서 백라이트 밝기를 수동으로 조절합니다

# 2. 화면에 튀는 점/물결무늬 발생

**증상 설명:** 사용자가 대형 디스플레이 일체형 기기를 사용할 때, 터치스크린에 튀는 점이나 물결무늬 현상이 발생합니다(아래 그림 참고).

**해결 방법:** 이는 일체형 기기 화면이 바깥쪽으로 튀어나와 터치 모듈 신호가 이상해지는 것이 원인입니다. 아래 수리 방법을 참고해 조작해 주세요.

주먹으로 화면 유리 중앙 부분을 가볍게 여러 번 눌러, 화면이 평평해지도록 시도해 보세요

조건이 허락한다면, 일체형 기기 바닥을 살짝 들어 올려 화면이 일정한 각도로 위쪽을 향하도록 하면 정상적인 터치 기능 회복에 도움이 될 수 있습니다

위 방법으로도 문제가 해결되지 않으면 Classin A/S에 연락해 수리를 요청하는 것을 권장합니다

# 3. 화면에 선이나 화면 깜빡임 발생

**증상 설명:** 대형 디스플레이 일체형 기기 화면에 선이 나타나거나 화면이 깜빡이는 현상이 발생합니다(아래 그림 참고).

**해결 방법:** 이 문제는 보통 화면의 OC(구동 회로)나 TCON(타이밍 제어 회로) 기판 고장으로 인해 발생합니다. Classin A/S에 연락해 공장 수리를 요청하는 것을 권장합니다.

# 4. 일체형 기기 화면 깜빡임 발생

**증상 설명:** 전원을 켠 후 화면이 깜빡여 정상적으로 사용할 수 없습니다.

**해결 방법:** 360 드라이버 마스터/드라이버 지니어스 등을 다운로드해 그래픽 드라이버를 업그레이드해 주세요.

# 5. 일체형 기기 화면 멈춤/검은 화면

**증상 설명:** 일체형 기기 전원을 켜면 ClassIn 로고 화면에서 계속 멈춰 있거나, 계속 검은 화면 상태로 시스템 화면에 들어가지 못합니다.

**해결 방법:** 이런 문제는 전원 보드/메인보드 고장일 가능성이 높으므로, Classin A/S에 연락해 수리를 요청하는 것을 권장합니다.

## [대형 디스플레이 일체형] 케이블 연결 및 화면 투사 문제

# 1. 대형 디스플레이 일체형 기기 무선 화면 투사

**증상 설명:** 대형 디스플레이 일체형 기기 사용 시 무선 화면 투사가 필요합니다.

**해결 방법:** 다음 방식으로 시도해 보세요.

**안드로이드 화면 투사 사용 방법**

대형 디스플레이의 전원 버튼을 클릭합니다

안드로이드 메뉴가 팝업으로 표시되면 "화면 투사"를 선택합니다

화면 안내에 따라 Wi-Fi에 연결하고 비밀번호를 입력하면 화면 투사가 가능합니다. 비밀번호: 88887777

**ClassIn X 소프트웨어로 화면 투사하는 방법**

대형 디스플레이에서 ClassIn X 소프트웨어에 들어가 계정에 로그인한 후 "ClassIn 화면 투사"를 선택합니다

컴퓨터에서 ClassIn 소프트웨어에 로그인해 왼쪽의 "화면 투사"를 선택하고, 해당 Wi-Fi를 선택한 후 투사 코드를 입력하면 투사가 시작됩니다

# 2. 대형 디스플레이 일체형 기기 유선 화면 투사

각종 연결 방법은 아래를 참고해 주세요:

HDMI 케이블로 노트북과 대형 디스플레이 일체형 기기를 연결합니다(대형 디스플레이 일체형 기기에는 3개의 HDMI 입력 포트가 있으며, 각각 전면 패널과 왼쪽 후면 패널의 HDMI1, HDMI2에 있고 모두 사용 가능합니다)

USB A-B 터치 케이블로 노트북과 대형 디스플레이 일체형 기기를 연결합니다(대형 디스플레이 일체형 기기에는 2개의 터치 포트가 있으며, 각각 전면 패널과 왼쪽 후면 패널의 TOUCH-USB 포트에 있고 모두 사용 가능합니다)

화면이 표시되지 않으면 대형 디스플레이 일체형 기기의 다른 HDMI 포트로 교체해 보세요

위와 같은 유선 방식으로 대형 디스플레이와 노트북을 연결할 때는, 마이크와 카메라를 노트북에 연결하고 대형 디스플레이 일체형 기기에는 연결하지 않도록 주의해 주세요

## [대형 디스플레이 일체형] 입력·터치·필기 문제

# 1. 소프트웨어 키보드가 팝업되지 않음

**증상 설명:** 일체형 기기 사용 시, 시스템 데스크톱 오른쪽 하단의 "키보드" 아이콘을 클릭해도 소프트웨어 키보드가 팝업되지 않아 소프트웨어 키보드로 입력할 수 없습니다.

**해결 방법:** 다음 단계에 따라 설정해 주세요.

데스크톱 왼쪽 하단의 "Windows" 아이콘을 클릭해 "설정"으로 들어갑니다

"설정" 화면에서 "장치" 옵션을 선택합니다

"입력"을 선택해 "태블릿 모드가 아니고 키보드가 연결되지 않은 경우 터치 키보드 표시" 옵션을 찾아 켭니다(기본적으로 켜져 있는 상태라면 한 번 껐다가 다시 켠 후 컴퓨터를 재시작해 주세요)

# 2. 필기 시 버벅거림

**증상 설명:** 대형 디스플레이 일체형 기기에서 ClassIn으로 녹화 수업을 진행할 때, 강의실 펜 도구로 칠판에 필기할 때 버벅거림이 발생합니다.

**해결 방법:** 아래 방법 중 하나를 시도해 이 문제를 해결해 보세요.

**해상도와 표시 비율 조정:**

일체형 기기의 Windows 시스템 데스크톱 해상도를 1920×1080으로 설정합니다

표시 비율을 150%로 조정합니다

**ClassIn 캐시 정리:**

ClassIn 메인 화면을 열고 왼쪽 하단의 설정 옵션을 클릭합니다

"시스템 설정" 화면으로 들어갑니다

"캐시 정리" 버튼을 클릭합니다
