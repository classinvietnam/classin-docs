## [기타] 하드웨어 사용 문제

# 1. 페이지 넘김 펜과 수신기 재페어링하기

**증상 설명:** 페이지 넘김 펜을 사용할 수 없어 재페어링이 필요합니다.

**해결 방법:** 페어링: 버튼 1을 길게 눌러 놓은 채로, 버튼 2를 연속으로 5번 클릭합니다. 표시등이 깜빡이며 페어링 모드로 진입합니다. 버튼 1을 놓으면 페어링이 완료됩니다.

# 2. 페이지 넘김 펜의 넘김 거리가 충분하지 않음

**증상 설명:** 페이지 넘김 펜의 넘김 거리가 너무 짧아 사용이 불편합니다.

**해결 방법:** 페이지 넘김 펜의 수신기는 가능한 한 대형 디스플레이 측면 USB 포트에 꽂아, 수신기가 가려지지 않도록 해 주세요.

## [필기 패드] 하드웨어 사용 문제

# 1. 필기 이상

**증상 설명:** 필기 패드에서 필기가 정상적으로 되지 않습니다.

**해결 방법:** 아래 방법 중 하나를 시도해 이 문제를 해결해 보세요.

**드라이버 설치 확인:** classintablet 드라이버가 올바르게 설치되었는지 확인해 주세요. 드라이버 다운로드 주소: https://www.eeo.cn/cn/download (설치 완료 후 드라이버 프로그램이 백그라운드에서 최소화된 상태로 계속 실행되도록 해 주세요. 절대 종료하지 마세요)

**드라이버 충돌 확인:** 컴퓨터에 가오몬(Gaomon), 와콤(Wacom) 등 다른 필기 패드 드라이버가 설치되어 있지 않은지 확인해 주세요. 설치되어 있다면 충돌을 피하기 위해 해당 드라이버를 제거해 주세요

**데이터 케이블 확인:** 정품 데이터 케이블이나 호환되는 화웨이 휴대폰 데이터 케이블을 사용해 연결해 주세요(충전 전용 케이블은 사용할 수 없습니다)

# 2. 필기 펜 심 교체하기

**증상 설명:** 필기 펜의 심이 심하게 마모되어 정상적인 사용에 영향을 줄 때, 새 심으로 교체해야 합니다.

**해결 방법:** 아래 그림의 방법을 시도해 이 문제를 해결해 보세요.

# 3. 드라이버에 연결되지 않음으로 표시됨

**증상 설명:** 필기 패드 드라이버에 연결되지 않음으로 표시됩니다.

다른 USB 포트로 교체해 연결을 시도해 보세요

다른 USB 데이터 케이블로 교체해 연결을 시도해 보세요

Mac 컴퓨터를 사용하는 경우, 다른 확장 독으로 교체해 연결을 시도해 보세요

# 4. 필기 시 버벅거림

**증상 설명:** 필기 패드로 글을 쓰는 과정에서 버벅거림 현상이 발생합니다.

**해결 방법:** 360 드라이버 마스터를 다운로드해 설치하고, 이 도구로 그래픽 드라이버를 업데이트해 필기 패드의 필기 경험을 개선해 주세요.

# 5. 펜이 패드에 닿지 않았는데도 필기가 됨

**증상 설명:** 필기 펜이 패드에 닿지 않은 상태에서도 필기가 됩니다.

**해결 방법:** 이런 경우는 보통 필기 펜의 고장으로 인한 것이므로, ClassIn A/S에 연락해 새 필기 펜으로 교체하는 것을 권장합니다.

## [무선 마이크] 하드웨어 사용 문제

# 1. 충전 케이스가 충전되지 않음(맘모스 LARK150)

**증상 설명:** 맘모스 LARK150 무선 마이크(핀 마이크) 충전 케이스가 충전되지 않습니다.

**해결 방법:** 다음 단계에 따라 리셋 작업을 진행해 주세요.

충전 케이스를 충전기에 연결합니다

핀 형태의 물체로 충전 케이스, 마이크, 수신기의 리셋 구멍을 각각 5초간 길게 눌러 줍니다

마이크와 수신기를 충전 케이스에서 꺼낸 후, 충전 케이스만 단독으로 30분간 충전합니다

30분 후, 마이크와 수신기를 다시 충전 케이스에 넣으면 기기의 배터리 표시를 확인할 수 있으며, 충전 케이스가 정상적인 충전 기능을 회복합니다

# 2. 연결 방법은?(맘모스 LARK150, M1, 로드)

**증상 설명:** 마이크 배선 연결 문제.

**해결 방법:** 다음 단계에 따라 조작해 주세요.

**무선 마이크와 대형 디스플레이 일체형 기기 연결(TRS-TRS 케이블 사용)**

한쪽은 무선 마이크(핀 마이크)에 연결

다른 한쪽은 대형 디스플레이 일체형 기기의 OPS 호스트에 있는 빨간색 마이크 오디오 잭에 연결

**무선 마이크와 노트북 연결(TRS-TRRS 케이블 사용)**

TRS 쪽은 무선 마이크(핀 마이크)에 연결

TRRS 쪽은 노트북의 3.5mm 오디오 잭에 연결

**무선 마이크와 휴대폰 또는 태블릿 연결(TRS-Type-C 케이블 사용)**

다른 한쪽은 휴대폰이나 태블릿의 Type-C 포트에 연결

**무선 마이크와 USB 사운드 카드 연결(TRS-TRS 케이블 사용)**

다른 한쪽은 USB 사운드 카드의 빨간색 마이크 오디오 잭에 연결

# 3. 표시등 상태(맘모스 M1)

| 기기 상태 | 표시등 상태 |
| --- | --- |
| 정상 대기 | 파란색 등 켜짐 |
| 영상 스트림 켜짐 | 초록색 등 켜짐 |
| 트래킹 켜짐 | 초록색 등 켜짐(저휘도) |
| 화이트보드 모드 | 노란색 등 켜짐 |
| 제스처 인식 성공 | 파란색 빠른 점멸 |
| 제스처 사용 불가 | 주황색 빠른 점멸 |
| 업그레이드 모드 | 흰색 등 켜짐 |
| 펌웨어 업그레이드 중 | 파란색 느린 점멸 |
| 고장 | 빨간색 등 켜짐 |
| 개인정보 보호 대기 | 등 꺼짐 |

더 많은 정보는 다음을 참고해 주세요: https://www.insta360.com/support/supportdetail?name=link

# 4. 소리가 잘 안 들림(맘모스 LARK150, 맘모스 M1, 로드)

**증상 설명:** 맘모스 LARK150, 맘모스 M1 또는 로드 무선 마이크(핀 마이크) 사용 시 소리가 작아 잘 안 들립니다.

**해결 방법:** 아래 방법 중 하나를 시도해 이 문제를 해결해 보세요.

**기기 자체 음량 조절:** 먼저 무선 마이크 기기 자체의 음량 설정을 확인하고 높여 주세요. 기기 음량이 적절한 수준인지 확인해 주세요

**ClassIn 강의실 마이크 음량 조절:** ClassIn 강의실에 들어간 후 마이크 음량 설정을 찾아 적절히 음량을 높여, 소리가 명확하게 들리도록 해 주세요

**ClassIn 강의실 배경 소음 감소 끄기:** ClassIn 강의실에서 배경 소음 감소 기능을 끕니다. 이는 마이크의 음량과 음질을 높여 소리를 더 명확하게 만드는 데 도움이 됩니다

# 5. 배터리 지속 시간

**증상 설명:** 맘모스 M1의 송신기, 수신기, 충전 케이스의 배터리 지속 시간을 알고 싶습니다.

**답변:**

**맘모스 M1 무선 마이크:**

송신기와 수신기 모두 완전 충전 시 8시간 연속 사용 가능합니다

함께 제공되는 충전 케이스는 송신기와 수신기를 각각 두 번씩 완전 충전할 수 있어, 장시간 사용 요구를 충족합니다

**맘모스 LARK150 무선 마이크:**

송신기는 완전 충전 상태에서 4시간 연속 사용 가능합니다

수신기는 완전 충전 상태에서 7시간 연속 사용 가능합니다

충전 케이스는 완전 충전 후 송신기 2개와 수신기 1개를 2.5회 충전할 수 있습니다

참고: 휴대폰과 마찬가지로 저온 환경에서 사용 시 기기의 배터리 지속 시간이 짧아질 수 있습니다. 또한 사용 거리에 따라서도 송신기와 수신기의 배터리 지속 시간이 달라질 수 있습니다

# 6. 세 가지 작동 모드(맘모스 LARK150)

맘모스 LARK150 수신 측 왼쪽 버튼을 길게 누르면 다음 세 가지 작동 모드 사이를 순환하며 전환할 수 있습니다: 모노 모드, 스테레오 모드, 세이프티 트랙 모드.

# 7. 세 가지 작동 모드의 효과는?(맘모스 LARK150)

맘모스 LARK150에는 세 가지 작동 모드가 있으며, 각 모드의 효과는 다음과 같습니다:

**스테레오 모드:** 두 개의 마이크(MIC1과 MIC2)로 오디오를 수집할 때, 수신 측은 MIC1의 오디오를 왼쪽 채널로, MIC2의 오디오를 오른쪽 채널로 출력합니다. 이렇게 하면 사용자는 두 마이크가 각각 수집한 서로 다른 소리를 명확하게 구분할 수 있습니다.

**모노 모드:** 이 모드에서는 두 마이크(MIC1과 MIC2)가 수집한 오디오가 합쳐지며, 수신 측은 합쳐진 오디오를 좌우 채널에 모두 출력합니다. 이렇게 하면 좌우 채널의 오디오 내용이 완전히 동일해, 모노 오디오가 형성됩니다.

**세이프티 트랙 모드:** 이 모드에서는 수신 측이 MIC1과 MIC2의 오디오를 합쳐서 처리하지만, 왼쪽 채널과 오른쪽 채널의 음량이 다릅니다. 왼쪽 채널은 정상 음량이고, 오른쪽 채널의 음량은 왼쪽 채널보다 6dB 낮습니다. 이렇게 하면 녹음 과정에서 백업 트랙을 제공할 수 있어, 음량이 과도해 발생하는 오디오 왜곡을 방지하고 오디오 품질과 사용자 개인정보 보호를 동시에 보장할 수 있습니다.

# 8. 세이프티 트랙 모드는 어떤 용도인가요?

현장 녹음 시 갑자기 음량이 커지는 상황이 발생할 수 있으며, 이렇게 지나치게 큰 소리는 녹음 파일의 왜곡이나 사용 불가를 초래할 수 있습니다. 이러한 상황에 대응하기 위해 맘모스 LARK150의 세이프티 트랙 모드를 사용할 수 있습니다. 이 모드는 녹음 시 2채널 오디오를 생성하며, 왼쪽 채널은 정상 음량의 오디오를, 오른쪽 채널은 더 낮은 음량의 오디오를 녹음합니다. 이렇게 하면 왼쪽 채널의 오디오에서 소리가 튀거나 왜곡이 발생하더라도, 오른쪽 채널의 오디오를 백업으로 사용할 수 있어 녹음 자료가 완전히 사용 불가능한 상태가 되는 것을 방지할 수 있습니다.

# 9. 송신기와 수신기 페어링하기

**송신기 페어링 모드 시작:** 송신기의 노란색 버튼을 약 3초간 길게 눌러, 파란색 표시등이 빠르게 깜빡일 때까지 기다립니다.

**수신기 페어링 모드 시작:** 수신기의 "+" 버튼을 약 3초간 길게 눌러, 파란색 표시등이 빠르게 깜빡일 때까지 기다립니다.

**페어링 완료 대기:** 송신기와 수신기의 파란색 표시등이 계속 켜진 상태가 되면 페어링이 성공한 것입니다.

**맘모스 LARK150 무선 마이크:**

맘모스 LARK150으로 페어링할 때는 송신기와 수신기를 충전 케이스에 넣고 전원을 켜기만 하면 자동으로 페어링이 완료되며, 별도의 추가 조작이 필요하지 않습니다.

# 10. WP1 무선 마이크의 주파수 잠금 및 잠금 해제 방법

**증상 설명:** WP1 마이크의 주파수 잠금 상태를 조정해야 합니다.

**답변:** 다음 방식으로 조작해 주세요.

**핸드헬드 마이크 잠금:**

핸드헬드 마이크와 수신기가 페어링된 후, 핸드헬드 측에서 "페이지 업"+"페이지 다운"을 동시에 눌렀다 놓으면 화면에 채널이 깜빡이며 표시되고, "볼륨 업"을 눌렀다 놓으면 조작이 완료됩니다. 잠금에 성공하면 화면 상단에 작은 자물쇠 아이콘이 표시됩니다

**핸드헬드 마이크 잠금 해제:**

"페이지 업"+"페이지 다운"을 동시에 눌렀다 놓으면 화면에 채널이 깜빡이며 표시되고, "볼륨 다운"을 눌렀다 놓으면 조작이 완료됩니다

**수신기 잠금:**

수신기와 핸드헬드 마이크가 자동으로 페어링된 후, 수신기의 세 개 "채널" 딥 스위치를 ON 위치로 전환하면 조작이 완료됩니다

**수신기 잠금 해제:**

수신기의 "채널" 딥 스위치를 조정해, 세 개의 딥 스위치가 모두 ON 위치에 있지 않도록 합니다

참고: 주파수 잠금 설정은 핸드헬드 마이크와 수신기 모두 주파수 잠금 모드로 설정해야 하며, 그렇지 않으면 연결·페어링할 수 없습니다.

## [짐벌 카메라] 하드웨어 사용 문제

# 1. 카메라 화면 흐림

**증상 설명:** 컴퓨터를 카메라에 연결한 후 표시되는 카메라 화면이 흐립니다.

**해결 방법:** 아래 방법 중 하나를 시도해 이 문제를 해결해 보세요.

렌즈에 먼지나 다른 이물질이 있는지 확인하고, 있다면 청소해 주세요

리모컨이나 카메라 소프트웨어로 초점을 조절해 보세요

리모컨이나 카메라 전용 소프트웨어를 사용해 카메라 초점을 조절합니다. 선명도를 확인할 때는 ClassIn 칠판 화면에서 카메라를 열어 확인하지 않는 것을 권장합니다. 화면이 압축될 수 있기 때문입니다. ClassIn의 보조 카메라 기능이나 Windows 기본 카메라 앱을 사용해 카메라의 실제 선명도를 확인해 주세요

컴퓨터에 iSmart CMS 소프트웨어를 설치해, 초점 기능(초점 +/-)을 조절해 화면 선명도를 조정합니다

# 2. 카메라 화면에 물결무늬(플리커) 발생

**증상 설명:** 컴퓨터/대형 디스플레이 일체형 기기를 카메라에 연결한 후, 표시되는 카메라 화면에 물결무늬 현상이 발생합니다.

**리모컨 사용:**

리모컨으로 메뉴에 들어갑니다

"영상" > "노출" > "플리커 방지" 순서로 선택합니다

플리커 방지 매개변수를 50Hz 또는 60Hz로 변경합니다

**디스플레이 유형에 따라:**

대형 디스플레이가 ClassinX 브랜드가 아니고, 도트 매트릭스 화면이거나 PWM(펄스폭 변조) 조광 기술을 사용하는 화면인 경우, 물결무늬 현상이 완전히 해소되지 않을 수 있습니다

화면 밝기를 높이거나 카메라의 노출 매개변수를 조정해 물결무늬 효과를 개선해 보세요

# 3. 인물 트래킹 기능 끄기(CAM35/CAM36)

**증상 설명:** 컴퓨터/대형 디스플레이 일체형 기기를 카메라에 연결한 후, 인물 트래킹 기능을 꺼야 합니다.

컴퓨터에 iSmart CMS 소프트웨어를 설치하고, 카메라와 컴퓨터가 같은 로컬 네트워크에 연결되어 있는지 확인합니다

iSmart CMS 소프트웨어를 열고 "온라인 기기" 옵션을 클릭한 후 "검색 시작" 버튼을 클릭해 로컬 네트워크 내 카메라 기기를 스캔합니다(아래 그림 참고)

검색 결과에서 설정을 변경하려는 카메라 기기를 선택하고 "관리에 추가" 버튼을 클릭해 기기가 "관리 대상 기기" 목록에 표시되도록 합니다(아래 그림 참고)

"메인 미리보기" 화면으로 들어가 해당 카메라 기기를 선택해 트래킹 설정 조작을 진행합니다(아래 그림 참고)

"매개변수 설정" 옵션을 클릭해 "기본 2" 설정 화면으로 들어갑니다. 이 화면에서 "전원 켤 때 기본 상태"를 "트래킹 없음"으로 변경한 후 "저장" 버튼을 클릭해 설정을 완료합니다(아래 그림 참고)

# 4. 프리셋 위치 설정하기

**증상 설명:** 카메라 설치 완료 후, 카메라의 위치, 초점 거리, 화면 등의 매개변수를 미리 설정하는 프리셋 위치 설정이 필요합니다.

**해결 방법:** 아래 방법을 시도해 보세요.

**CAM34 카메라:**

프리셋 위치 설정: 숫자 키를 누른 후 "프리셋 설정" 키를 누릅니다

프리셋 위치 불러오기: 해당 숫자 키+"CALL" 키를 누릅니다

프리셋 위치 지우기: 해당 숫자 키+"CLEAR" 키를 누릅니다

**CAM37 카메라:**

프리셋 위치 설정: 숫자 키를 누른 후 "SET" 키를 누릅니다

**P1 카메라:**

프리셋 위치 설정: 숫자 키를 길게 눌러, 카메라 표시등이 한 번 깜빡이면 설정이 완료됩니다

# 5. 전원 연결 후 전원 표시등이 켜지지 않음

**증상 설명:** 카메라 전원 연결 후 전원 표시등이 켜지지 않습니다.

**해결 방법:** 카메라가 전원 연결 후 반응이 없고 전원 표시등도 켜지지 않는다면 하드웨어 고장일 수 있으므로, Classin 하드웨어 A/S에 연락해 수리나 교체를 요청해 주세요.

# 6. 프리셋 위치 재설정하기

**증상 설명:** 카메라 프리셋 위치를 조정해야 합니다.

**해결 방법:** 아래 방법 중 하나를 시도해 이 문제를 해결해 보세요.

해당 숫자 키를 바로 누르면 카메라가 프리셋 위치로 돌아갑니다

먼저 해당 숫자 키를 누른 후 CALL 키를 누르면 카메라가 프리셋 위치로 돌아갑니다

# 7. 화면이 표시되지 않음(CAM34)

**증상 설명:** CAM34 카메라의 파란색 POWER 등과 초록색 STANDBY 등이 동시에 켜져 있지만, 화면이 표시되지 않습니다.

**해결 방법:** CAM34 카메라의 파란색 POWER 등과 초록색 STANDBY 등이 동시에 켜지면, 카메라가 시작 중임을 나타냅니다. 약 20초간 인내심을 가지고 기다려, 파란색 POWER 등만 켜질 때까지 기다려 주세요. 이는 카메라가 정상적으로 시작되었음을 나타냅니다. 이때가 되어야 화면이 정상적으로 표시됩니다.

# 8. 화면 노이즈(CAM37)

**증상 설명:** CAM37 카메라 화면에 노이즈 현상이 발생합니다.

먼저 카메라와 컴퓨터 사이의 연결선 종류(보통 HDMI 케이블 또는 SDI 케이블)를 확인해 주세요

HDMI 케이블이나 SDI 케이블을 사용 중이라면, 새 HDMI 케이블이나 SDI 케이블로 교체해 보세요

케이블을 교체해도 문제가 계속되면, 카메라에 함께 제공된 Mini USB 케이블로 연결하는 것을 권장합니다

# 9. 화면이 표시되지 않음(CAM37)

**증상 설명:** CAM37 카메라 연결 후 화면이 표시되지 않습니다.

**해결 방법:** 아래 방법 중 하나를 시도해 이 문제를 해결해 보세요

**연결선 확인:** CAM37 카메라와 컴퓨터 사이의 연결선이 올바르고 확실하게 연결되었는지 확인해 주세요. 데이터 케이블이 손상되거나 느슨하지 않은지 확인해 주세요

**전원 연결 확인:** CAM37 카메라의 전원이 올바르게 연결되었고, 전원 표시등이 정상적으로 켜져 있는지 확인해 주세요

**재시작 시도:** 리모컨의 전원 버튼으로 카메라 재시작을 시도해 보세요

# 10. 화면이 표시되지 않음(CAMP1)

**증상 설명:** CAMP1 카메라의 초록색 등과 빨간색 등이 동시에 켜져 있지만, 화면이 표시되지 않습니다.

**해결 방법:** CAMP1 카메라의 초록색 등과 빨간색 등이 동시에 켜지면, 카메라가 시작 중임을 나타냅니다. 약 20초간 인내심을 가지고 기다려, 빨간색 등이 꺼질 때까지 기다려 주세요. 이는 카메라가 정상적으로 시작되었음을 나타냅니다. 이때가 되어야 화면이 정상적으로 표시됩니다.

# 11. 자동 줌 끄기

**증상 설명:** 카메라의 자동 줌 기능을 꺼야 합니다.

카메라의 리모컨을 찾습니다

리모컨의 "수동" 버튼을 누릅니다

# 12. 카메라 밝기 조절하기(CAM34)

**증상 설명:** 카메라의 화면 밝기를 조절해야 합니다.

**해결 방법:** CAM34 카메라의 밝기를 조절하려면 다음 단계에 따라 조작해 주세요.

CAM34 카메라 리모컨의 "메뉴" 버튼을 누릅니다

컴퓨터 화면에 카메라 설정 화면이 팝업으로 표시됩니다

설정 화면에서 "노출" 항목을 선택해 들어갑니다

"노출" 항목 내에서 "밝기 보정" 옵션을 찾아, 만족스러운 밝기 효과가 될 때까지 조절합니다

# 13. 카메라 초점 거리 조절하기

**증상 설명:** 카메라의 초점 거리 값을 조절해야 합니다.

리모컨의 "-" 키나 "+" 키로 초점 거리를 조절합니다

# 13. USB 카메라가 인식되지 않음

**증상 설명:** 카메라 설치 후, 대형 디스플레이가 이 하드웨어를 인식하지 못합니다.

컴퓨터 쪽 USB 포트를 다시 뽑았다 꽂아 보세요

카메라를 재시작합니다(가능하면 전원을 끈 후 카메라를 재시작해 주세요)

컴퓨터의 장치 관리자를 열어 "알 수 없는 USB 장치"를 제거한 후 다시 로드해 설치합니다

위 방법으로도 해결되지 않으면, USB 케이블 자체의 고장 가능성을 고려해 보세요
