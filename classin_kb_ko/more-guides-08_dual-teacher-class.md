## 반 간 연계 수업 사용 설명(듀얼 티처 수업)

# 1. 듀얼 티처 수업이란?

듀얼 티처 수업은 ClassIn 플랫폼을 통해 서로 다른 반의 학생들을 통합해 함께 학습에 참여시키는 혁신적인 교육 모델입니다. 이 방식은 전통적인 반의 경계를 뛰어넘을 뿐만 아니라, 교육과 학습의 효율과 효과를 크게 높일 수 있습니다. 공간의 제약을 없앰으로써 듀얼 티처 수업은 우수한 교사의 수업을 무한히 복제할 수 있어, 더 많은 학생이 우수한 교육 자원의 혜택을 받을 수 있게 합니다.

# 2. 적용 시나리오

**교육 관리:** 우수한 교사가 여러 소규모 반을 동시에 대상으로 라이브 수업을 진행할 수 있어, 우수 교사의 효과를 크게 높이는 동시에 우수한 교육 자원을 온전히 보존할 수 있습니다.

**수업 효과:** 각 소규모 반의 조교사는 반 내에서 학생과 상호작용할 수 있을 뿐 아니라, 수업 전후로 과제를 채점하고 자료를 배포해 맞춤형 관리를 실현할 수 있습니다.

**서비스 운영:** 학부모가 수업을 더 세밀하게 확인하고 학생의 학습 행동을 관리하고자 하는 요구를 충족시키며, 교육 시스템은 전체 학생의 수행 데이터와 발전 상황을 전 과정에 걸쳐 기록합니다.

**모집·재등록:** 대규모 반의 규모와 가격으로 소규모 반의 경험과 효과를 제공해, 기관이 차별화된 경쟁력을 확립하고 평판을 쌓으며 수익을 배가하는 데 도움을 줍니다.

# 3. 사용 설명

**듀얼 티처 강의실:** 하나의 메인 강의실과 여러 개의 하위 강의실로 구성됩니다. 메인 강의실 하나에는 최대 100개의 하위 강의실을 연결할 수 있습니다.

**영상과 음성:** 수업 진행 중, 메인 강의실의 "담당 교사"와 "통화 연결된 학생"의 영상과 음성은 모든 강의실로 전송됩니다. 그 외에는, 하위 강의실 내 학생과 조교사는 메인 강의실 내 다른 인원(조교사 포함)의 영상과 음성을 보거나 들을 수 없으며, 다른 하위 강의실 내 학생과 조교사의 영상과 음성도 보거나 들을 수 없습니다. 마찬가지로 메인 강의실의 담당 교사, 조교사, 학생도 다른 하위 강의실 내 학생과 조교사의 영상과 음성을 보거나 들을 수 없습니다.

**텍스트 채팅:** 메인 강의실에서는 모든 교사와 학생이 채팅 도구를 통해 모든 하위 강의실의 조교사나 학생이 보낸 텍스트 메시지를 확인할 수 있습니다. 반면 하위 강의실에서는 조교사와 학생이 자신의 강의실 내 구성원이 보낸 텍스트 메시지와 메인 강의실 "담당 교사"의 텍스트 정보만 볼 수 있으며, 다른 하위 강의실의 메시지는 볼 수 없고, 메인 강의실의 "담당 교사" 외 다른 인원(조교사 포함)이 보낸 텍스트 메시지도 볼 수 없습니다.

**원클릭 초기화 기능:** 수업 시작 전, 하위 강의실의 학생에게 칠판에 필기하고 그림을 그릴 권한이 부여되어 있을 수 있습니다. 메인 강의실과 하위 강의실의 내용 일관성을 확보하기 위해, "담당 교사"는 메인 강의실에 들어간 후 강의 시작 전에 "원클릭 초기화" 기능을 사용할 수 있습니다. 구체적인 조작 방법: 오른쪽 상단의 점 4개 아이콘을 클릭한 후 "초기화" 옵션을 선택합니다. 이 기능은 다음 작업을 수행합니다: 모든 강의실의 판서 내용 지우기, 모든 교재와 도구 닫기, 모든 강의실의 조교사와 학생을 전원 무대 아래로 내리기, 모든 학생의 권한 부여 상태 지우기, 트로피 수와 학생 무대 등장 횟수 초기화. 이를 통해 수업 시작 시 모든 강의실의 상태가 일치하도록 보장해, 교육 활동이 원활하게 진행되도록 합니다.

**메인 강의실에서 사용 가능한 교육 도구:** 마우스 모드, 선택/이동 도구, 펜, 지우개, 텍스트 입력, 스크린샷, 레이저 포인터, 클라우드 드라이브, 수업 노트, 채팅 도구, 출석부, 로컬 파일 열기, 판서 저장/공유, 투사 도구, 화면 공유, 주사위, 타이머, 카운트다운 타이머, 브라우저, 물리/화학 실험, 보상 순위표(메인 강의실 순위표만 표시), 교육 자료실, 보조 카메라, 드래그식 레이저 포인터, 자·컴퍼스 도구, 기하 도형, 듀얼 티처 답안 클리커, 통화 연결, 1개 계정 2개 기기(PC/iPad만 지원, PC를 메인 기기로 사용하는 것을 권장).

**메인 강의실에서 비활성화된 도구와 기능:** LMS, 소형 칠판, 그룹 토론, VNC, 라이브 채팅, 무작위 지명, 부저, 비디오 월(메인 강의실 학생만 시청하는 것과 모든 하위 강의실 학생을 시청하는 것 모두 포함), 학생 화면 공유, 협업 텍스트, 다방향 브라우저.

정식 개강 전에는 시간표 편성, 수업 준비, 수업 진행, 수업 질서 유지, 녹화, 학생의 수업 후 복습을 포함한 모든 단계를 아우르는 종합적인 리허설을 진행해야 합니다. 각 단계에 문제가 없음을 확인한 후에야 정식으로 개강해 주세요.

# 4. 교무 담당자 필독

## 1) 듀얼 티처 수업 서비스 개통 방법

듀얼 티처 수업 서비스 개통이 필요하면 전담 고객 매니저에게 문의해 주세요.

## 2) 백오피스에서 수업 만들기

참고: 듀얼 티처 수업은 별도로 반을 새로 만들 필요 없이 기존 반을 사용해 수업을 진행할 수 있습니다. 새 반 생성이 정말 필요하다면 일반 반 생성 절차에 따라 만들면 됩니다.

### 2.1 메인 수업 만들기

메인 반에서 특정 수업(주의: 반 전체가 아님)을 선택해, 이를 메인 수업의 기반으로 삼아 하위 수업을 만듭니다. 반에 아직 수업이 추가되지 않았다면 아래 그림을 참고해 만들어 주세요. (생성 경로: 백오피스 관리 로그인 > 반 관리 > 반으로 이동 > 수업 추가)

### 2.2 하위 수업 추가하기

반으로 이동해, 이미 만든 수업에 메인 수업으로 체크한 후 【일괄로 하위 수업 새로 만들기】를 클릭합니다. 하위 수업을 추가하는 과정에서, 하위 수업이 속할 반을 지정해야 합니다. 아래 그림을 참고해 만들어 주세요. (소속 반을 선택할 때, 위쪽 검색창에서 반 이름을 검색하거나 태그로 검색하면 효율이 높아집니다.)

유의사항:

**(1)** 메인 수업 하나당 최대 100개의 하위 수업을 만들 수 있습니다. (한 번에 최대 50개 생성 가능, 50개를 초과하면 2회에 나눠 생성해야 함)

**(2)** 메인 수업의 개강 시각까지 5분 미만이거나 이미 개강 시각이 지난 경우, 하위 수업을 만들 수 없습니다.

**(3)** 모든 하위 수업에 일괄로 조교사를 추가하거나, 각 하위 수업에 개별적으로 조교사를 추가할 수 있습니다. (조교사는 선택 사항이며 필수가 아닙니다. 실수로 잘못 추가한 경우 "전체 제거" 기능으로 조교사를 제거할 수 있습니다)

**(4)** 조교사가 수업 중 여러 반의 채팅 상황을 동시에 확인해야 한다면, 해당 조교사를 메인 수업과 여러 하위 수업의 조교사로 배정해, 조교사가 메인 수업에서 전체 채팅 영역을 확인하기 편리하게 할 수 있습니다.

**(5)** 생성 완료 후, 하위 수업의 비공개 부분 정보는 해당 반에서 수정할 수 있습니다.

**(6)** 녹화 수업 방식은 【메인 수업의 녹화 다시보기 사용】 또는 【클라우드 녹화 수업(각 하위 수업이 개별적으로 녹화)】 중 선택할 수 있습니다. 하위 수업의 클라우드 녹화 수업을 선택하는 경우, 녹화를 진행하는 각 하위 강의실마다 조교사 1명이 들어가 전 과정을 녹화해야 한다는 점에 유의해 주세요.

### 2.3 편집 및 삭제

ClassIn 앱(클라이언트)과 백오피스 화면 모두에서 메인 수업을 편집·삭제할 수 있으며, 하위 수업의 관련 내용도 자동으로 동기화 업데이트됩니다. (소프트웨어에서 수업 수정) (백오피스 관리에서 메인 수업 수정)

ClassIn 앱(클라이언트)에서는 하위 수업을 직접 편집하거나 삭제할 수 없으며, 사용자는 백오피스에서만 관련 조작을 할 수 있습니다. 사용자는 하위 수업에 해당하는 반으로 들어가 일반적인 편집·삭제 조작(하위 수업 수정 또는 삭제)을 하거나, 메인 수업 맨 오른쪽의 "조작" 버튼을 클릭해 "온라인 듀얼 티처"를 선택한 후 삭제 조작을 할 수도 있습니다.

## 3) 수업 후 서비스 자료 다운로드

**(1)** 교사가 메인 강의실 답안 클리커에서 찍은 스크린샷은 조교사와의 소통 자료로 활용할 수 있습니다. 이 스크린샷은 백오피스-수업 관리-수업 데이터(메인 수업)-수업 분석-답안 클리커 데이터에 보관됩니다.

**(2)** 이미지 확인을 클릭하면 해당 수업의 모든 답안 클리커 스크린샷을 확인할 수 있으며, 오른쪽 상단의 "이미지 다운로드"로 모든 이미지를 일괄 다운로드할 수 있어, 수업 후 서비스 담당 교사가 학생/학부모와 소통하기 편리합니다.

**(3)** 일부 기관에서는 조교사에게 백오피스 권한이 없는 경우, 교무 교사가 일괄로 다운로드를 지원해야 합니다.

**(4)** 수업 후 서비스 담당 교사는 이러한 답안 클리커 스크린샷과 학생의 답안 데이터를 통해 학생에게 맞춤형 지도를 제공할 수 있습니다.

# 5. 교사 필독

## 1) 주강 교사 기기

주강 교사는 컴퓨터와 아이패드로만 수업을 진행할 수 있으며(기능이 더 완전하므로 컴퓨터 사용을 우선 권장), 휴대폰과 안드로이드 패드로는 수업을 진행할 수 없습니다.

## 2) 강의실 핵심 도구

**통화 연결**

통화 연결은 주강 교사와 학생이 소통하는 중요한 채널입니다.

**(1)** 듀얼 티처 수업의 메인 강의실에서, 주강 교사는 "교육 도구에서 통화 연결 열기" 또는 "채팅 메시지 마우스 오른쪽 버튼 클릭"을 통해 특정 학생 한 명을 선택해 통화 연결을 할 수 있습니다(동시에 통화 연결 가능한 인원은 1명뿐). 통화 연결된 학생의 음성/영상은 메인 반과 모든 하위 반에 동기화됩니다.

**(2)** 통화 연결이 끝난 후, 마우스를 영상 창에 올려 "통화 연결 종료"를 선택하거나, "통화 연결 목록 열기"를 선택해 다른 학생과 통화 연결을 할 수 있습니다.

**(3)** 통화 연결 영상 창은 자유로운 크기 조절과 이동을 지원하며, 화질은 학생 좌석의 화질과 동일합니다. 표시 로직은 학생 좌석과 무관하므로, 통화 연결과 좌석에서 동시에 같은 학생이 표시될 수 있습니다.

**(4)** 주강 교사의 컴퓨터와 아이패드는 통화 연결 기능을 지원합니다.

**채팅**

채팅 영역은 주강 교사와 하위 강의실 학생이 소통하는 중요한 채널입니다(하위 강의실 학생에게 권한 부여, 트로피 지급 등의 기능은 지원하지 않습니다).

**(1)** 하위 강의실 학생의 발언에는 이름 앞에 반 이름이 붙습니다.

**(2)** 메인 강의실의 채팅 도구는 상단에서 【전체 강의실 채팅】 또는 【특정 하위 강의실 채팅】을 선택해 확인할 수 있습니다.

**(3)** 메인 강의실과 하위 강의실의 채팅 영역은 【질문】 기능을 지원하지 않습니다. 학생에게 질문이 있으면 【채팅】 창에서 질문할 수 있습니다.

**(6)** 참고: 채팅 영역은 다시보기에서 교재를 가릴 수 있습니다. 하위 강의실 학생은 녹화 수업 다시보기를 통해 자기 반과 무관한 다른 반의 채팅 내용도 보게 됩니다. 교사는 녹화 전에 수동으로 "채팅창을 강의실 밖으로 이동" 버튼을 클릭해 채팅 영역이 녹화되지 않도록 할 수 있습니다.

**듀얼 티처 답안 클리커**

답안 클리커는 주강 교사가 학습 상황 데이터를 수집하는 주요 수단입니다.

**(1)** 듀얼 티처 강의실에서 답안 클리커를 보내는 조작은 일반 답안 클리커와 동일합니다.

**(2)** 답안 작성 과정에서 교사는 모든 반의 정답률과 각 선택지의 선택 인원 수를 확인할 수 있습니다.

**(3)** 답안 클리커 상단에서 반을 필터링해 특정 반의 답안 현황을 확인할 수 있습니다.

**(4)** 답안 작성이 끝난 후, 정답을 맞힌 학생이나 참여한 학생에게 트로피를 지급할 수 있습니다. 이는 주강 교사가 하위 강의실 학생에게 트로피를 지급할 수 있는 유일한 방법입니다.

**(5)** 답안 작성 과정 중 언제든지, 교사는 답안 클리커 내 스크린샷 도구로 스크린샷을 찍을 수 있습니다(보통 설명 후 풀이 과정이 담긴 화면을 캡처). 이 스크린샷은 백오피스에 저장되어 조교사가 수업 후 소통할 때 사용하는 자료가 됩니다.

**(6)** 답안 작성이 끝난 후, 하위 강의실 학생은 자기 반의 답안 상세 내역만 확인할 수 있습니다. (교무가 "하위 강의실이 메인 강의실의 녹화 수업 다시보기를 사용"하도록 설정한 경우, 하위 강의실 학생은 다시보기에서 모든 반의 답안 데이터를 확인할 수 있습니다)

**원클릭 초기화 기능**

수업 시작 전, 하위 강의실 학생은 상황에 따라 칠판에 필기하고 그림을 그리는 등의 권한이 부여되어 있을 수 있습니다. 메인 강의실과 하위 강의실의 내용 일관성을 확보하기 위해, 주강 교사는 강의실에 들어간 후 강의 시작 전 강의실 초기화 기능(오른쪽 상단 점 4개-초기화)을 사용할 수 있습니다:

모든 강의실의 판서 지우기

모든 교재와 도구 닫기

모든 강의실의 조교사와 학생을 전원 무대 아래로 내리기

모든 학생의 권한 부여 상태, 트로피 수, 무대 등장 횟수 지우기

**수업 종료 기능**

**(1)** 하위 강의실의 조교사에게는 전체 수업 종료 기능이 없습니다.

**(2)** 메인 강의실에서 전체 수업 종료 기능을 사용하면, 모든 하위 강의실이 메인 강의실과 함께 전체 수업 종료됩니다.

# 6. 조교사 필독

## 1) 조교사 기본 직무

수업 중:

1. 백오피스의 수업 감독 관리 페이지에서 결석 학생을 확인하고 학생에게 연락해 출석을 독려합니다

2. 수업 질서를 유지하며, 강의실 채팅 영역에 부적절한 내용이 있을 때 해당 하위 강의실에서 즉시 제지하거나 삭제합니다

3. 하위 강의실의 비디오 월을 통해 학생의 학습 상태를 실시간으로 확인하고 학생에게 알립니다

4. 학생의 소프트웨어 사용 문제를 해결합니다

5. 주강 교사의 수업 내용 외에, 각자 담당 반에 보충 지도를 진행합니다

금지 사항:

1. 메인 강의실의 조교사는 교재와 판서를 임의로 조작하지 마세요. 조작 결과는 하위 강의실에 동기화되지 않습니다(향후 버전에서 개선 예정)

2. 하위 강의실의 조교사는 주강 교사와 동시에 같은 기능(판서, 교재, 교육 도구)을 조작하지 마세요. 그렇지 않으면 메인 강의실과 각 하위 강의실 간 동기화가 어긋날 수 있습니다

수업 후:

1. 과제, 시험 등 수업 전후 활동을 채점합니다

2. 가정과의 소통. 교사가 수업 중 찍은 답안 클리커 스크린샷 등을 활용해 충실한 맞춤형 학습 상황 분석과 지도를 진행합니다

## 2) 채팅 영역 사용하기

시간표 편성 시, 교무 교사는 조교사(조교사)를 메인 수업과 자신이 담당하는 모든 하위 수업에 동시에 배정합니다.

조교사는 기본적으로 메인 강의실에 있으면서 채팅 영역의 학생 메시지를 확인합니다. 만약 이상 상황(예: 학생의 부적절한 발언이나 질문 등)을 발견하면, 조교사는 발언자의 반 정보에 따라 해당 하위 강의실로 들어가 채팅 영역을 열어 처리합니다. 메시지 삭제, 채팅 금지, 또는 직접 답변이 가능합니다.

현재는 조교사가 메인 강의실에서 직접 이상 상황을 처리하는 것을 지원하지 않지만, 향후 지원할 예정입니다.

하위 강의실의 학생은 자기 반의 채팅 내용과 주강 교사가 메인 강의실에서 발신한 채팅 정보만 확인할 수 있습니다.

## 3) 수업 후 소통 자료

과제, 시험 등 일반적인 소통 내용 외에도, 주강 교사가 메인 강의실 답안 클리커에서 찍은 스크린샷도 조교사의 소통 자료로 활용할 수 있습니다. 이 스크린샷은 백오피스-코스 관리-수업 데이터-답안 클리커 데이터에 보관됩니다.

이미지 확인을 클릭하면 해당 수업의 모든 답안 클리커 스크린샷을 일괄 다운로드할 수 있습니다.

백오피스 권한이 없는 조교사는 교무 교사에게 일괄 다운로드를 요청할 수 있습니다.
