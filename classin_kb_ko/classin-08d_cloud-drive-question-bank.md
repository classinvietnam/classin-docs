## 문제 은행 센터

## 1. 문제 은행 센터란?

문제 은행 센터는 개인 문제 은행, 조직 문제 은행, ClassIn 공식 문제 은행을 포함한 풍부한 문제 리소스를 사용자에게 제공합니다. 사용자는 필요에 따라 객관식(단일 선택), 복수 선택, 참/거짓, 빈칸 채우기, 서술형, 종합 문제 등 다양한 유형의 문제를 선택해 추가할 수 있습니다. 종합 문제에는 여러 개의 소문제를 포함할 수 있으며, 소문제 유형에는 단일 선택, 복수 선택, 참/거짓, 빈칸 채우기, 서술형이 포함됩니다.

사용자는 문제를 하나씩 추가할 수도 있고 일괄로 추가할 수도 있어 조작이 편리합니다. 문제 추가가 완료된 후, 사용자는 시험지를 만들어 이미 추가된 문제를 시험지에 넣거나, 시험지 만드는 과정에서 문제를 추가할 수도 있습니다.

기관/학교 교사 관리에서 교사가 ClassIn 앱 스페이스의 문제 은행 센터에서 조직 문제 은행을 표시할 수 있는지, 조직 문제 은행 내 내용을 확인·사용할 수 있는지는 학교급·과목의 구성원 관리 권한에 따라 결정됩니다.

개인 학습이든 조직 연수든, 문제 은행 센터는 사용자의 다양한 요구를 충족할 수 있어, 효율적이고 편리한 문제 관리와 시험지 작성 서비스를 제공합니다.

## 2. 내 문제 은행

## 1) 학교급·과목 추가하기

### 대상
전체 사용자

### 사용 설명
사용자는 컴퓨터와 태블릿에서 내 문제 은행에 학교급·과목을 설정할 수 있으며, 이렇게 하면 이후 문제를 추가할 때 특정 학교급·과목으로 문제를 편리하게 분류할 수 있습니다.

### 구체적인 조작 방법

#### 컴퓨터/태블릿
1. "스페이스"로 이동합니다.
2. "문제 은행 센터"로 이동합니다.
3. "내 문제 은행"으로 이동합니다.
4. "학교급/과목"을 추가합니다.

## 2) 문제 추가하기

내 문제 은행에서 문제를 추가할 때, 사용자는 필요에 따라 지식 포인트나 챕터를 설정한 후, 해당 지식 포인트나 챕터 아래에 문제를 추가할 수 있습니다. 컴퓨터나 태블릿으로 문제를 추가할 때, 사용자는 여러 유형의 문제를 추가할 수 있습니다: 단일 선택, 복수 선택, 참/거짓, 빈칸 채우기, 서술형, 종합 문제(종합 문제에는 여러 소문제를 포함할 수 있으며, 지원되는 유형은 단일 선택, 복수 선택, 참/거짓, 빈칸 채우기, 서술형입니다). 휴대폰으로 문제를 추가할 때는 단일 선택, 복수 선택, 참/거짓만 지원됩니다. 문제 추가가 완료되면, 사용자는 이미 추가된 문제를 삭제, 복제, 전달, 다른 과목으로 이동 등의 조작을 할 수 있습니다. 조직 문제 은행 권한을 가진 교사는 권한이 있는 조직 문제 은행에도 문제를 추가할 수 있습니다.

여러 문제를 한 번에 추가해야 할 때는 컴퓨터의 일괄 문제 추가 기능을 사용할 수 있습니다. 먼저 일괄 추가 창에서 Excel 템플릿이나 Word 템플릿을 다운로드한 후, 템플릿 형식에 따라 문제를 추가합니다. 완료 후, 작성한 템플릿을 일괄 추가 창에 다시 업로드합니다. 일괄 추가 형식에 익숙하다면, 형식에 맞는 문제를 일괄 추가 창의 원본 문제 입력 영역에 직접 복사해 붙여넣을 수도 있습니다.

#### 컴퓨터
1. "학교급/과목"과 "문제"를 선택합니다.
2. "+문제 추가" / "일괄 문제 추가"를 클릭합니다.

#### 태블릿
1. "+문제 추가"를 클릭합니다.

## 3) 시험지 추가하기

사용자는 내 문제 은행에서 시험지를 추가할 수 있습니다. 시험지를 만들 때, 내 문제 은행에서 문제를 선택해 시험지에 넣을 수도 있고, 시험지 추가 시 바로 새 문제를 추가할 수도 있습니다. 컴퓨터를 사용하는 경우 일괄 문제 추가도 지원합니다. 이미 추가된 시험지는 복제, 전달, 다른 학교급이나 과목으로 이동을 지원하며, 컴퓨터를 사용하는 경우 컴퓨터 로컬로 다운로드할 수도 있습니다. 조직 문제 은행 권한을 가진 교사는 해당 조직 문제 은행에도 시험지를 추가할 수 있습니다.

1. "학교급/과목"을 선택합니다.
2. "시험지"를 선택합니다.
3. "시험지 추가"를 클릭합니다.

"+시험지 추가"를 클릭합니다.

"+"를 클릭해 시험지를 추가합니다.

## 4) 문제와 시험지 편집/삭제하기

이미 추가된 문제는 편집, 삭제, 복제, ClassIn 반이나 친구에게 전달, 다른 과목으로 이동, 조직 문제 은행에 추가할 수 있습니다.

이미 추가된 시험지는 편집, 복제, 다운로드, 삭제, ClassIn 반이나 친구에게 전달, 다른 학교급으로 이동, 시험을 만들어 다른 반에 발행, 또는 시험지 내 문제를 조직 문제 은행에 추가할 수 있습니다.

### 유의사항
휴대폰은 단일 선택, 복수 선택, 참/거짓 편집만 지원합니다.

휴대폰과 태블릿 모두 시험지 다운로드를 지원하지 않습니다.

1. "학교급/과목", "문제" 또는 "시험지"를 선택합니다.
2. 문제나 시험지를 찾아 "편집"을 클릭하거나 "···"을 클릭해 삭제를 조작합니다.

## 5) 문제/시험지를 조직 문제 은행에 추가하기

학교/기관 마스터 계정, "문제 은행 센터" 권한을 가진 학교/기관 관리자, 조직 문제 은행의 해당 학교급·과목에 "조작 가능" 또는 "관리 가능" 권한을 가진 교사

권한을 가진 교사는 내 문제 은행의 문제나 시험지를 조직 문제 은행에 추가할 수 있습니다.

1. 문제나 시험지를 찾아 "조직 문제 은행에 추가"를 클릭합니다.

## 6) 시험지 편집·다운로드 및 새 시험 만들기

전체 사용자 또는 반 교사

"내 문제 은행"의 문제와 시험지는 문제 바구니에 추가하는 것을 지원하며, 문제 바구니에서 확인, 삭제, 문제 순서 조정을 할 수 있고, 시험지 편집·다운로드와 새 시험 만들기도 할 수 있습니다.

**시험지 편집·다운로드:** 시험지 페이지로 이동해 시험지 저장을 지원하며, 컴퓨터를 사용하는 경우 시험지를 로컬로 다운로드할 수도 있습니다.

**새 시험 만들기:** 새 시험 페이지로 이동해, 교사는 반에 발행하기, 내 문제 은행에 시험지 저장을 지원하며, 컴퓨터를 사용하는 경우 시험지를 로컬로 다운로드할 수도 있습니다.

또한 교사는 "내 문제 은행 - 시험지"에서 직접 시험지 내용을 다운로드해 시험을 만들 수도 있습니다.

휴대폰은 시험지 편집·다운로드와 시험 만들기를 지원하지 않습니다.

태블릿은 시험 만들기와 "내 문제 은행" 아래 "시험지" 항목에 시험지를 저장하는 것을 지원하지만, 시험지 내용 다운로드는 지원하지 않습니다.

1. 문제나 시험지를 찾아 "문제 바구니에 추가"를 클릭하거나 시험지 옆의 "···"을 클릭합니다.
2. "시험지 편집·다운로드" 또는 "새 시험 만들기".

## 3. 조직 문제 은행

학교/기관 마스터 계정, "문제 은행 센터" 권한을 가진 학교/기관 관리자

권한을 가진 교사는 학교급과 과목을 추가할 수 있으며, 이렇게 하면 이후 문제를 추가할 때 특정 학교급이나 과목으로 문제를 편리하게 분류할 수 있습니다.

휴대폰은 조직 문제 은행 아래 학교급·과목 생성·설정을 지원하지 않습니다.

1. "조직 문제 은행"으로 이동합니다.
2. "학교/기관"을 선택합니다.

## 2) 학교급·과목 삭제하기

특정 학교급·과목의 문제 은행이 완전히 사용되지 않게 되면 삭제할 수 있습니다. 삭제 후, 해당 문제 은행 내 문제와 시험지도 완전히 삭제되며, 다른 사용자가 시험을 만들 때 해당 학교급이나 과목의 문제와 시험지를 불러올 수 없게 됩니다. 삭제 후에는 복구할 수 없습니다.

휴대폰은 삭제를 지원하지 않습니다.

1. "관리"로 이동합니다.
2. 학교급·과목을 삭제합니다.

## 3) 학교급·과목 활성화/비활성화하기

학교/기관 마스터 계정, "문제 은행 센터" 권한을 가진 학교/기관 관리자

조직 문제 은행 내 특정 학교급·과목의 문제 은행이 일시적으로 사용되지 않을 때, 권한을 가진 교사는 이를 비활성화할 수 있습니다. 비활성화 후에도 문제 은행 내 문제와 시험지 데이터는 손실되지 않지만, 확인·사용은 할 수 없게 됩니다.

휴대폰은 활성화·비활성화를 지원하지 않습니다.

1. 문제 은행을 "활성화" 또는 "비활성화"합니다.

## 4) 구성원과 권한 설정하기

학교/기관 마스터 계정, "조직 클라우드 드라이브" 권한을 가진 학교/기관 관리자, 해당 학교급·과목에 "관리 가능" 권한을 가진 교사

권한을 가진 교사는 조직 문제 은행 내 학교급·과목에 구성원을 추가·설정하고 권한을 관리할 수 있습니다. 구성원 및 관리 권한 설명은 다음과 같습니다:

| 권한 | 설명 |
| --- | --- |
| 관리 가능 | 구성원 관리와 문제·시험지의 추가·삭제·수정이 가능합니다.<br><br>문제: 확인, 추가, 내 문제 은행에 추가, 편집, 이동, 복제, 전달, 삭제, 문제 바구니에 추가.<br><br>시험지: 확인, 추가, 내 문제 은행에 추가, 편집, 이동, 복제, 다운로드, 전달, 삭제, 문제 바구니에 추가, 새 시험 만들기. |
| 조작 가능 | 문제·시험지의 추가·삭제·수정이 가능합니다.<br><br>문제: 확인, 추가, 편집, 삭제, 문제 바구니에 추가.<br><br>시험지: 확인, 추가, 편집, 삭제, 문제 바구니에 추가, 새 시험 만들기. |
| 확인만 가능 | 문제와 시험지 사용만 가능합니다.<br><br>문제: 확인, 문제 바구니에 추가.<br><br>시험지: 확인, 문제 바구니에 추가, 새 시험 만들기. |
| 표시 안 함 | 조직 문제 은행 아래 내용을 확인할 수 없습니다. |

**슈퍼 관리자:** "문제 은행 센터" 권한을 가진 백오피스 학교/기관 관리자를 말합니다.

휴대폰은 구성원과 권한 설정을 지원하지 않습니다.

1. "구성원 관리"로 이동합니다.
2. 구성원을 추가하거나 구성원 권한을 수정합니다.

## 5) 문제 추가하기

학교/기관 마스터 계정

"조직 문제 은행" 권한을 가진 학교/기관 관리자

해당 학교급·과목에 "관리 가능" 또는 "조작 가능" 권한을 가진 교사

내 문제 은행에서 문제를 추가할 때, 사용자는 필요에 따라 지식 포인트나 챕터를 설정한 후, 해당 지식 포인트나 챕터 아래에 문제를 추가할 수 있습니다. 컴퓨터나 태블릿으로 문제를 추가할 때, 사용자는 여러 유형의 문제를 추가할 수 있습니다: 단일 선택, 복수 선택, 참/거짓, 빈칸 채우기, 서술형, 종합 문제(종합 문제에는 여러 소문제를 포함할 수 있으며, 지원되는 유형은 단일 선택, 복수 선택, 참/거짓, 빈칸 채우기, 서술형입니다). 휴대폰으로 문제를 추가할 때는 단일 선택, 복수 선택, 참/거짓만 지원됩니다. 문제 추가가 완료되면, 사용자는 이미 추가된 문제를 삭제, 복제, 전달, 다른 과목으로 이동 등의 조작을 할 수 있습니다. 마스터 계정, 조직 문제 은행 권한의 관리자, 그리고 해당 학교급·과목에 "관리 가능" 권한을 가진 교사는 내 문제 은행에도 문제를 추가할 수 있습니다.

1. "학교/기관"을 선택합니다.

## 6) 시험지 추가하기

"관리 가능", "조작 가능" 권한을 가진 조직 문제 은행 구성원

사용자는 조직 문제 은행에서 시험지를 추가할 수 있습니다. 시험지를 만들 때, 내 문제 은행과 조직 문제 은행 모두에서 문제를 선택해 시험지에 넣을 수도 있고, 시험지 추가 시 바로 새 문제를 추가할 수도 있습니다. 컴퓨터를 사용하는 경우 일괄 문제 추가도 지원합니다. 이미 추가된 시험지는 복제, 전달, 삭제, 다른 학교급이나 과목으로 이동을 지원하며, 시험 만들기도 지원합니다. 컴퓨터를 사용하는 경우 시험지를 로컬로 다운로드할 수도 있습니다. 마스터 계정, 조직 문제 은행 권한의 관리자, 그리고 해당 학교급·과목에 "관리 가능" 권한을 가진 교사는 내 문제 은행에도 문제를 추가할 수 있습니다.

1. "학교급/과목"과 "시험지"를 선택합니다.
