## 비밀번호 찾기

### 이런 경우에
ClassIn 로그인 비밀번호를 잊어버렸을 때는, ClassIn의 "비밀번호 찾기" 기능으로 로그인 비밀번호를 재설정할 수 있습니다.

### 유의사항
SMS, 이메일 인증코드, 음성 인증코드는 하루 합계 10건까지만 받을 수 있습니다. 이 건수를 초과하면 그날은 더 이상 인증코드를 받을 수 없습니다.

### 조작 방법

**컴퓨터/태블릿**
1. Classin을 엽니다.
2. "비밀번호 찾기"를 클릭합니다.
3. 휴대폰 번호 또는 이메일을 입력한 후 "인증코드 받기"를 클릭하고, 새 비밀번호를 설정합니다.

2. "비밀번호 찾기"를 탭합니다.

## 계정 등록

### 사전 조건
ClassIn에 가입하기 전, 인증코드를 정상적으로 수신할 수 있는 휴대폰이나 이메일을 준비해 주세요. 가입 시 인증코드를 확실히 받기 위함입니다.

### 사용 설명
ClassIn 계정 가입 시 SMS 인증코드를 받지 못한 경우, 60초를 기다린 후 "음성 인증코드" 받기를 탭할 수 있습니다.

중국 외 국가의 휴대폰 번호로도 ClassIn 계정을 등록할 수 있습니다. 등록 시 올바른 국가 코드를 선택해야 합니다. 예를 들어 미국 휴대폰 번호로 등록한다면 국가 코드에서 "+1"을 선택해야 합니다.

음성 인증코드는 중국 본토 휴대폰 번호(+86 국가 코드)만 지원합니다.

중국 국내 사용자가 이메일로 가입한 경우, 휴대폰 번호 인증도 추가로 필요합니다.

SMS, 이메일 인증코드, 음성 인증코드는 하루 합계 10건까지만 받을 수 있습니다. 이 건수를 초과하면 그날은 더 이상 인증코드를 받을 수 없습니다.

### 조작 방법

**컴퓨터/태블릿**
1. Classin을 엽니다.
2. "지금 가입하기"를 클릭합니다.
3. 휴대폰 번호 또는 이메일을 입력한 후 "인증코드 받기"를 클릭하고, 로그인 비밀번호를 설정합니다.

## Classin 로그인(계정/비밀번호, 원탭, QR코드, 인증코드, 위챗 또는 Apple)

## 1. 계정/비밀번호로 로그인

### 관련 문서
「계정 등록」
「비밀번호 찾기」

## 2. 휴대폰 원탭 로그인

### 사전 조건
"본인 번호로 원탭 로그인" 기능을 사용하려면 휴대폰에 정상적으로 사용 가능한 SIM 카드가 꽂혀 있어야 합니다.

### 유의사항
컴퓨터와 태블릿 사용자는 "본인 번호로 원탭 로그인" 기능을 사용할 수 없습니다.

"본인 번호로 원탭 로그인"을 탭하면 바로 ClassIn에 로그인됩니다.

## 3. QR코드 로그인

### 사용 설명
먼저 휴대폰이나 태블릿에 ClassIn을 설치해 로그인해 두거나, ClassIn과 위챗 연동을 완료해 둡니다. 그런 다음 컴퓨터에서 ClassIn을 열고, 휴대폰이나 태블릿의 ClassIn 또는 위챗 앱의 "스캔" 기능을 사용해 컴퓨터 ClassIn 로그인 화면에 표시된 QR코드를 스캔하면 로그인이 완료됩니다.

1. 컴퓨터에서 ClassIn을 열고 "QR코드 로그인"을 클릭합니다.
2. 휴대폰/태블릿에서 ClassIn 또는 위챗을 열고 로그인합니다.
3. 휴대폰/태블릿의 ClassIn 또는 위챗 오른쪽 상단의 "+" 아이콘을 탭하고 "스캔"을 선택합니다.
4. 컴퓨터 ClassIn에 표시된 QR코드를 스캔합니다.

![](https://cofile.eeo.cn/res-store%2Fc931b1bc2dc51f63d0c3713a2b3b81a8c2b42a20c6fdaf279d16c53017a50f95_271344?q-sign-algorithm=sha1&q-ak=AKIDJQGsEOK2TfbFdEZifMnxrWx85mpdHj6H&q-sign-time=1773936000;1774540800&q-key-time=1773936000;1774540800&q-header-list=host&q-url-param-list=&q-signature=d8e76c71acd14efd75575af761b982959874be8c)

## 4. 인증코드 로그인

인증코드 로그인 기능을 사용하려면 휴대폰이나 이메일로 SMS 또는 메일을 정상적으로 수신할 수 있어야 합니다.

SMS, 이메일 인증코드, 음성 인증코드는 하루 합계 10건까지만 받을 수 있습니다. 이 건수를 초과하면 그날은 더 이상 인증코드를 받을 수 없습니다.

1. Classin을 엽니다.
2. "다른 로그인 방법"을 탭합니다.
3. "인증코드 로그인"을 탭합니다.
4. 휴대폰 번호 또는 이메일을 입력한 후 인증코드를 받습니다.

![](https://cofile.eeo.cn/res-store%2F71953d3e3359fed4d7a58fea6948377b39aac2c29b4695e6a440b189f291f8d3_1032011?q-sign-algorithm=sha1&q-ak=AKIDJQGsEOK2TfbFdEZifMnxrWx85mpdHj6H&q-sign-time=1773936000;1774540800&q-key-time=1773936000;1774540800&q-header-list=host&q-url-param-list=&q-signature=12f6209f2658558664bad3afbd1ba59e6e433a43)

## 5. 위챗 또는 Apple 로그인

휴대폰이나 태블릿에서 ClassIn과 위챗 또는 Apple ID 연동을 완료하면, 위챗 또는 Apple로 로그인해 사용할 수 있습니다.

1. 휴대폰 또는 태블릿에서 Classin을 열고 "다른 로그인 방법"을 탭합니다.
2. "위챗 로그인" 또는 "Apple 로그인"을 탭합니다.
3. 연동 인증을 완료하면 로그인됩니다.
