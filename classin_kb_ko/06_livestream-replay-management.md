## 웹 라이브/재생 설정: 로그인하지 않은 사용자도 좋아요 가능

### 대상
- "백오피스 관리 시스템" 마스터 계정
- "라이브/재생" 권한을 가진 하위 계정

### 이런 경우에
웹 라이브를 시청하는 사용자가 부적절한 발언을 하는 것을 방지하기 위해, 백오피스 관리 시스템에서는 웹 라이브 설정의 "로그인하지 않은 사용자의 채팅 및 좋아요 참여 허용" 기능이 기본적으로 꺼져 있습니다. 교무 담당자가 웹 라이브로 수업을 시청하는 모든 사용자가 자유롭게 채팅하고 좋아요를 누를 수 있도록 하려면, "백오피스 관리 시스템"에서 "로그인하지 않은 사용자의 채팅 및 좋아요 참여 허용" 기능을 켤 수 있습니다. 이 기능을 켜면 ClassIn 계정 로그인 여부와 관계없이 웹 라이브를 시청하는 모든 사용자가 자유롭게 채팅하고 좋아요를 누를 수 있습니다.

### 사용 설명
이 설정은 변경 대상이 된 "수업(課節)"의 웹 라이브에만 적용됩니다.

### 관련 문서
「백오피스에서 하위 계정 추가」

### 조작 방법
1. 백오피스 관리 시스템에 로그인합니다.
2. 왼쪽 내비게이션에서 "라이브/재생"으로 이동합니다.
3. 해당 수업을 찾아 오른쪽의 "관리"를 클릭합니다.
4. "라이브 설정"으로 이동합니다.
5. "로그인하지 않은 사용자의 채팅 및 좋아요 참여 허용"을 켜거나 끕니다.
6. "저장"을 클릭합니다.

3. 해당 수업을 찾습니다.
4. "전체 채팅 금지"를 켜거나 끕니다.

## 라이브/재생 "안내 문구"

### 대상
- "백오피스 관리 시스템" 마스터 계정
- "학교 설정" 권한을 가진 하위 계정

### 사용 설명
교무 담당자는 백오피스 관리 시스템에서 웹 라이브 진행 시 표시되는 커스텀 안내 문구를 설정할 수 있습니다. 주로 세 가지 모드로 나뉩니다. 첫 번째는 교사가 아직 강의실에 입장하지 않았거나 녹화를 시작하지 않았을 때의 안내 문구이며, 두 번째는 교사가 수업 도중 강의실을 나갔을 때의 안내 문구, 세 번째는 해당 수업에 웹 라이브 권한이 켜져 있지 않을 때의 안내 문구입니다. 각 안내 문구 유형에는 기본 문구와 커스텀 문구가 있으며, 커스텀 문구를 설정하려면 해당 유형 아래의 "편집"을 클릭한 뒤 새 문구를 입력하고 저장한 다음, 새로 추가한 커스텀 문구에 체크하면 됩니다.

### 관련 문서
「백오피스에서 하위 계정 추가」

### 조작 방법
1. 백오피스 관리 시스템에 로그인합니다.
2. 왼쪽 내비게이션에서 "학교 설정"으로 이동합니다.
3. 상단의 "웹 라이브/재생"으로 이동합니다.
4. "웹 라이브/재생 안내 문구 커스텀 설정"에서 커스텀 안내 문구를 설정합니다.

## 라이브/재생 데이터

### 대상
- "백오피스 관리 시스템" 마스터 계정
- "수업 관리" 및 "라이브/재생" 권한을 가진 하위 계정

### 이런 경우에
교무 담당자는 백오피스 관리 시스템의 "라이브 관리 및 데이터" 페이지에서 특정 수업의 웹 라이브 데이터와 웹 재생 데이터를 조회하거나 다운로드할 수 있습니다.

"라이브 관리 및 데이터" 페이지 상단에는 해당 수업의 전체 웹 라이브 데이터가 표시됩니다. 여기에는 웹 라이브 시청 총 인원수, 웹 라이브 시청 총 횟수, 현재 웹 라이브 접속 중인 인원수, 웹 라이브 최대 동시 접속자 수, 웹 라이브 예약 인원수, 예약 후 실제로 시청한 인원수, 로그인한 상태로 시청한 인원수, 좋아요에 참여한 인원수, 채팅에 참여한 인원수, 채팅 메시지 총 개수, 1인당 평균 채팅 메시지 수, 채팅 금지된 인원수, 라이브 커머스 상품을 클릭한 시청자 총 인원수가 포함됩니다.

"라이브 관리 및 데이터" 페이지 하단에는 웹 라이브 또는 재생을 시청한 각 사용자의 상세 정보가 표시됩니다. 여기에는 시청자의 계정(로그인하지 않은 경우 임의의 문자열로 표시), 시청자의 닉네임(로그인하지 않은 경우 동일하게 임의의 문자열로 표시), 웹 라이브 예약 여부, 시청 시 ClassIn 계정 로그인 여부, 해당 웹 라이브를 시청한 총 횟수, 총 시청 시간, 라이브를 실시간으로 시청했는지 아니면 종료 후 재생을 시청했는지, 매 시청 시각, 매 시청 진입 시각, 매 시청 시 시청 시간, 매 시청 시 IP 주소, 매 시청 시 사용한 기기 종류, 라이브 시청 중 좋아요 참여 여부, 시청 중 보낸 채팅 메시지 수, 채팅 메시지의 구체적인 내용, 시청 중 채팅 금지를 당한 적이 있는지 여부, 시청 중 라이브 커머스 상품을 클릭했는지 여부, 클릭했다면 구체적으로 어떤 상품을 클릭했는지가 포함됩니다.

### 유의사항
수업 생성 시 "웹 라이브" 또는 "웹 재생"을 선택하지 않은 경우, 백오피스 관리 시스템의 "라이브/재생" 항목에서 해당 수업을 찾을 수 없습니다.

### 관련 문서
「백오피스에서 하위 계정 추가」

### 조작 방법
1. 백오피스 관리 시스템에 로그인합니다.
2. 왼쪽 내비게이션에서 "라이브/재생"으로 이동합니다.
3. 해당 수업을 찾아 오른쪽의 "관리"를 클릭합니다.
4. "라이브 관리 및 데이터"로 이동해 데이터를 확인합니다(오른쪽의 "표 다운로드"를 클릭하면 데이터를 로컬 컴퓨터로 다운로드할 수 있습니다).

## 웹 라이브/재생 설정: 표지/소개/공지사항/상품

- "백오피스 관리 시스템" 마스터 계정

### 사용 설명
**표지 설정:**
- 업로드한 이미지는 고정 비율 자르기를 지원하며, 권장 이미지 비율은 1920px x 1080px입니다.
- 업로드하는 이미지 크기는 500KB를 초과하지 않아야 페이지 로딩 속도에 영향을 주지 않습니다.
- 변경한 표지 이미지는 설정 대상인 "수업(課堂/課節)"에만 적용됩니다.

**공지사항:**
- "백오피스 관리 시스템"의 웹 라이브/재생 공지사항에는 "이미지", "링크", "텍스트" 콘텐츠를 추가할 수 있습니다.

- 학교에 수업과 관련된 굿즈(예: 도서 등)가 있는 경우, 웹 라이브/재생의 상품 기능을 활용해 이러한 상품을 홍보하고 판매할 수 있습니다.
