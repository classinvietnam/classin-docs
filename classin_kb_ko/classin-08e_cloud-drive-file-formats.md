## 3. ClassIn 파일 소개

### 1) edb 파일

#### (1) edb 소개

edb 판서 파일은 ClassIn만의 고유한, 이미지와 텍스트로 구성된 파일로, 교재 내용에 드래그, 그리기 등의 조작을 할 수 있습니다.

#### (2) edb 판서 파일 제작하기

**방법 1(새 edb 판서 파일 만들기):** 스페이스-내 클라우드 드라이브-새 판서

**방법 2(edb 판서 파일 편집):** 스페이스-내 클라우드 드라이브-edb 판서 파일 열기-편집

**방법 3:** 칠판(수업 스케줄 불필요)이나 강의실에 들어가기-edb 판서 파일 제작/편집-판서 저장

**a. 칠판이나 강의실에서 edb 파일을 만드는 방법**

강의실 미니 도구 사용: 이동/펜/타이핑/지우개/스크린샷/로컬 이미지 불러오기 등을 선택합니다.

일반 단축키로 이미지를 빠르게 복사·붙여넣기 할 수 있습니다: 복사: Ctrl+C; 붙여넣기: Ctrl+V.

**b. 칠판이나 강의실에서 edb 파일을 저장하는 방법**

교사가 방금 편집한 판서를 저장해야 할 때, 도구함의 "판서 저장/공유"를 클릭해 저장하거나 친구에게 공유합니다.

판서 저장 시 배경색을 변경할 수 있습니다(투명색 지원).

판서 저장 시 edb/png/pdf 3가지 형식 중 선택할 수 있으며, 로컬 저장 시에는 여러 개 선택 가능하고, 클라우드 드라이브 저장 시에는 하나만 선택 가능합니다.

### 2) edoc 파일

#### (1) edoc 소개

edoc은 ClassIn이 사용자에게 제공하는, ClassIn 내에서 협업 편집을 하기 위한 문서 형식입니다. 교육 연구 수업 준비 단계에서 사용하거나 정보 수집에도 사용할 수 있습니다. 강의실에서 edoc 문서를 열면 펜과 텍스트 도구로 표시하는 것은 지원하지 않습니다.

#### (2) edoc 제작 경로

**방법 1(새 협업 문서 만들기):** 스페이스-내 클라우드 드라이브-새로 만들기-협업 문서. 내 클라우드 드라이브에서 찾을 수 있으며, ClassIn 친구나 반에 공유할 수 있습니다.

**방법 2(새 협업 문서 만들기):** 강의실 내-도구함-협업-문서. 이 방법으로도 edoc을 만들 수 있으며, 학생에게 권한을 부여해 임시로 협업 편집 권한을 추가할 수 있습니다.

**방법 3(협업 문서 온라인 편집):** 스페이스-내 클라우드 드라이브-word 열기-온라인 편집 클릭

#### (3) edoc 내 주석 추가하기

edoc 내에서 문서 안의 "+"를 클릭하면 주석을 추가할 수 있습니다.

### 3) eppt 파일

#### (1) eppt 소개

eppt는 ClassIn이 사용자에게 제공하는, ClassIn 내에서 편집하는 ppt 형식입니다. 교육 연구 수업 준비 단계에서 사용할 수 있습니다.

#### (2) eppt 제작 경로

**방법 1(새 온라인 PPT 만들기):** 스페이스-내 클라우드 드라이브-새로 만들기-온라인 PPT. 내 클라우드 드라이브에서 찾을 수 있으며, ClassIn 친구나 반에 공유할 수 있습니다.

**방법 2(업로드한 PPT 수정):** 스페이스-내 클라우드 드라이브-ppt 열기-온라인 편집 클릭

### 4) eda 파일

#### (1) eda 소개

eda는 ClassIn이 개발한 강의실 내 확장 도구의 일종으로, 공용 리소스로 사용자에게 제공됩니다. 현재 4가지가 포함되어 있습니다: 바둑, 지뢰 찾기, 줄다리기, 스도쿠. 학생에게 권한을 부여하면 학생이 조작할 수 있습니다.

#### (2) eda 열기 경로

스페이스-내 클라우드 드라이브-오른쪽 하단 "?"-ClassIn 사용 가이드-강의실 내 기타 확장 도구

### 5) edlink 파일

#### (1) edlink 소개

edlink는 웹페이지 링크입니다. 브라우저에 링크를 저장하는 것과 비교해, edlink는 클라우드 드라이브 업로드와 전달이 가능합니다. 강의실에서는 교사 신분만 조작할 수 있으며, 조교 신분과 학생 신분은 조작 과정을 볼 수 있습니다.

#### (2) edlink 제작 방법

Windows 로컬에서 새 txt 텍스트 파일(메모장 파일 형식)을 만듭니다.

txt 파일을 열고 웹 주소를 붙여넣습니다(웹 주소만 입력하면 됩니다).

txt 텍스트를 다른 이름으로 저장하고, 저장 유형에서 "모든 파일"을 선택하며, 파일명 확장자에 ".edlink"를 입력합니다.

로컬에서 파일을 찾은 후 마우스 오른쪽 버튼으로 속성을 클릭해, 파일 유형이 edlink로 표시되면 올바른 것입니다.

로컬의 edlink 파일을 ClassIn 스페이스-내 클라우드 드라이브에 업로드하면 열 수 있습니다.

### 6) edu 파일

#### (1) edu 소개

edu 파일은 웹사이트 주소를 포함하는 특수한 파일입니다. 교사가 수업 중 edu 파일을 열면, 교사 본인과 강의실 내 모든 학생이 각자의 브라우저를 통해 독립적으로 해당 웹사이트 주소를 엽니다. 이렇게 하면 각 학생이 독립적으로 해당 웹사이트를 탐색·사용할 수 있어 서로 방해하지 않습니다. edu 파일은 보통 다음과 같은 시나리오에서 사용됩니다:

**설문 조사:** 교사는 각 학생에게 설문지나 시험지를 배포하고 각 학생의 응답 상황을 수집할 수 있습니다.

**자기주도 연습:** 학생은 자기 테스트 연습 웹사이트를 사용해 스스로 연습할 수 있습니다. edu 파일은 음성 기능을 지원해, 학생이 말하기와 듣기 연습을 할 수 있습니다.

#### (2) edu 제작 방법

**1단계:**

수업에서 사용할 웹사이트 주소를 얻습니다.

NoBook을 예로 들어 주소 획득 방법을 설명합니다:

a. "NoBook" 공식 사이트에 접속합니다: https://www.nobook.com/index.html. 새 계정을 등록하거나 기존 계정으로 로그인합니다.

b. 프리미엄 실험 중에서 수업 중 학생이 직접 조작해야 하는 실험을 선택합니다.

참고: 유료 버전 NoBook 계정이 없는 학생이 일부 있다면, 학생이 열 권한이 없는 상황을 피하기 위해 무료 버전 실험을 선택해 주세요.

c. 선택한 실험을 클릭하고, 공유 버튼을 통해 해당 NoBook 실험의 공유 주소를 얻을 수 있습니다.

d. 브라우저에서 공유 주소를 열면 브라우저가 이동하며, 해당 실험의 웹사이트 주소를 얻을 수 있습니다.

참고: 웹사이트 주소가 edu에서 열리지 않는다면, 주소 맨 끝의 "=" 기호를 제거한 후 다시 edu로 열어보세요.

원쥐안싱(설문 도구)을 예로 들어 주소 획득 방법을 설명합니다:

a. "원쥐안싱" 공식 사이트 www.wjx.cn에 접속해 새 계정을 등록하거나 기존 계정으로 로그인합니다.

b. 로그인 후 설문 작성을 시작합니다.

c. 필요한 옵션을 클릭해 문제를 출제하거나, 오른쪽의 "시험 문제 일괄 추가"를 클릭합니다.

d. 시험지 편집을 완료한 후 "편집 완료"를 클릭합니다.

e. 시험지 편집 완료 후 "설문 배포"를 클릭합니다.

f. "복사" 버튼을 클릭해 링크를 복사하면 원쥐안싱의 웹사이트 주소를 얻을 수 있습니다.

**2단계:**

새 edu 파일을 만들고, 파일의 이름과 웹사이트 주소를 입력합니다.

참고: 만든 후에는 "ClassIn 강의실-스페이스-내 클라우드 드라이브"에서 해당 파일을 열어 웹사이트 주소가 올바른지 확인하세요.

**3단계:**

정식 수업 중 교사는 클라우드 드라이브에서 해당 edu 파일을 열 수 있으며, 각 학생의 기기에서 각자 독립적으로 해당 웹사이트 주소가 열려 자기주도 연습을 진행합니다.

참고: 해당 웹사이트가 연습을 위해 로그인이 필요하다면, 체험 수업을 한 번 진행해 학생들에게 충분한 로그인 시간을 확보해 주세요. 한 번 로그인한 후에는 해당 기기에서 이후 다시 로그인할 필요가 없습니다.

**4단계:**

학생들이 자기주도 연습을 하는 동안 서로 영향을 주지 않으며, 독립적으로 자신의 과제를 완료할 수 있습니다.

교사는 ClassIn 강의실에서 학생의 완료 상황을 확인할 수 없습니다. 해당 웹사이트에 자체 데이터 통계 기능(예: 설문 통계)이 있다면, 해당 웹사이트의 백오피스에서 직접 데이터를 확인할 수 있습니다.

### 7) edv 파일

#### (1) edv 소개

edv는 강의실 내에서 여는 교재 형식의 일종으로, 다른 형식의 교재와 달리 edv는 교사에게만 보이며 학생 측에는 보이지 않습니다(창과 내용 모두 보이지 않음).

#### (2) edv 사용 설명

교사가 edv 파일을 스페이스-내 클라우드 드라이브에 업로드하고 열면 확인할 수 있습니다.

### 8) edx 파일

edx 파일은 웹사이트 주소를 포함하는 특수한 파일입니다. 교사가 수업 중 edx 파일을 열면 다방향 브라우저가 실행되어 파일 내 URL을 열게 됩니다. 학생 측과 교사 측의 상호작용 방식은 교사가 다방향 브라우저 도구를 직접 열었을 때와 동일합니다.

#### (2) edx 제작 방법

수업에서 사용할 웹사이트 주소를 얻습니다: 예를 들어 주소가 www.eeo.cn이라고 가정합니다.

새 edx 파일을 만들고, 파일의 이름과 웹사이트 주소를 입력합니다.

참고: 만든 후에는 바로 열어 미리보기로 웹페이지가 올바르게 표시되는지 확인할 수 있습니다.

정식 수업 중 교사는 스페이스-내 클라우드 드라이브에서 해당 edx 파일을 열 수 있습니다. 열면 다방향 브라우저 사용 방식대로 완전히 수업을 진행할 수 있습니다.

참고: 이 유형의 파일은 강의실 내에서 교사만 열 수 있는 권한이 있으며, 다른 역할은 열 권한이 없습니다. 강의실 밖에서는 제한이 없어 정상적으로 미리볼 수 있습니다.

### 9) edt 파일

#### (1) edt 소개

edt는 ClassIn 강의실의 스킨 배경에 사용되며, 1280×720 픽셀, 투명 채널이 없는 jpg 또는 jpeg 형식 이미지만 지원하고, edt 형식으로 저장할 수 있습니다.

#### (2) edt 제작 방법

1280×720 픽셀, 투명 채널이 없는 jpg 또는 jpeg 형식 이미지를 이미지 편집 도구로 엽니다.

다른 이름으로 저장하며, 저장 유형은 JPEG를 선택하고 파일명 확장자에 ".edt"를 입력합니다.

로컬에서 파일을 찾은 후 마우스 오른쪽 버튼으로 속성을 클릭해, 파일 유형이 edt로 표시되면 올바른 것입니다.

로컬의 edt 파일을 ClassIn 스페이스-내 클라우드 드라이브에 업로드하면 강의실에서 열 수 있습니다.
