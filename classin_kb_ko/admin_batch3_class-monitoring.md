## 교실 도움 요청 수신 및 답변

### 1. 도움 요청 수신

**대상**
- "관리자 백엔드" 마스터 계정
- "모니터링 관리" 권한이 있는 하위 계정

**이런 경우에**
교실 내 교사나 학생이 도움이 필요할 때, 교실의 도움 요청 기능을 통해 "관리자 백엔드"로 요청을 보낼 수 있습니다. 교무 담당자는 관리자 백엔드에 로그인해 "모니터링 관리" 페이지에서 해당 세션을 찾고, 세션 아래의 문제 알림을 클릭해 교실에서 제기된 문제를 확인할 수 있습니다. 교무 담당자는 이러한 문제에 답변하여 도움을 줄 수 있습니다.

**관련 문서**
- "관리자 백엔드에 하위 계정 추가"

**조작 방법**
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "모니터링 관리"로 이동
3. 세션을 찾는다
4. 세션 왼쪽 하단에서 "도움 요청 메시지" 확인

### 2. 교실에 메시지 보내기
"백엔드 관리 시스템" 마스터 계정이 필요합니다.

교무 담당자가 수업을 모니터링할 때는 참관자 신분이므로 교실 내 누구와도 상호작용할 수 없습니다. 교실 내 특정 사용자에게 이상이 발견되면, 교무 담당자는 백엔드 관리 시스템에서 해당 사용자에게 텍스트 메시지를 보내 문제 해결 방법을 안내할 수 있습니다.

**조작 방법**
1. 세션 아래의 "연락" 클릭
2. "교사에게 연락" 또는 "학생에게 연락" 선택
3. 연락 대상을 체크하고 "문제 설명"에 내용을 입력한 후 "전송" 클릭

## 모니터링 이미지 확인

### 대상
- "관리자 백엔드" 마스터 계정
- "모니터링 관리" 권한이 있는 하위 계정

### 사용 설명
교무 담당자는 모니터링 상세 페이지에 들어가면 교실 내 모니터링 이미지를 확인할 수 있습니다. 모니터링 이미지는 ClassIn 시스템이 담당 교사의 시점에서 자동으로 촬영한 스크린샷으로, 1분마다 자동으로 저장됩니다.

### 유의사항
- 모니터링 관리에서는 최대 1000장까지 표시됩니다.

### 관련 문서
- "모니터링 교실 입장"
- "관리자 백엔드에 하위 계정 추가"

### 조작 방법
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "모니터링 관리"로 이동
3. 세션을 찾는다
4. 이미지를 클릭해 상세로 진입, 모니터링 이미지 확인

## 계정 조회(사용자의 수업 기기 사용 현황 확인)

### 대상
- "관리자 백엔드" 마스터 계정
- "계정 조회" 권한이 있는 하위 계정

### 이런 경우에
교실 내 교사나 학생이 네트워크 불안정이나 수업 버벅임을 알려온 경우, 교무 담당자는 "관리자 백엔드"에서 해당 사용자의 수업 중 네트워크 및 기기 상태를 확인할 수 있습니다.

### 사용 설명
교무 담당자는 "관리자 백엔드 - 계정 조회"에서 사용자의 "전화번호"나 "이메일", "수업 시간" 정보를 통해 사용자의 수업 중 네트워크 상태와 기기 사용 현황을 조회할 수 있습니다. 확인 가능한 정보로는 세션명, 수업명, 시작 시간, 세션 시간, 무대 인원수, 사용자의 교실 내 역할, 사용자의 수업 중 각 시간대별 네트워크 사용 현황과 기기 CPU 사용률, 사용자의 교실 입장 시간, 퇴장 시간 및 퇴장 사유, 사용자가 녹화 기능을 켰는지 여부와 녹화가 정상적으로 진행되었는지 여부 등이 포함됩니다. 기기 정보란의 해당 기기 아이콘에 마우스를 올리면 사용자가 교실에서 사용한 카메라, 마이크, 스피커의 사용 상태(비활성화 여부, 기기 인식 실패 여부, 여러 기기가 있을 경우 선택한 기기 등)를 확인할 수 있습니다. 또한 사용자가 수업 시 사용한 기기의 OS 버전, 연결된 서버 이름, 기기의 CPU 모델, ClassIn 버전, 무선/유선 네트워크 여부도 조회할 수 있습니다.

### 관련 문서
- "관리자 백엔드에 하위 계정 추가"

### 조작 방법
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "계정 조회"로 이동
3. 상단에서 날짜를 선택하고 ClassIn 계정 입력
4. 하단에서 수업 시 네트워크 및 기기 사용 현황 확인

## 모니터링 교실 입장

### 대상
- "관리자 백엔드" 마스터 계정
- "모니터링 관리" 권한이 있는 하위 계정

### 이런 경우에
- 교무 담당자가 학교 내 특정 교사의 수업을 참관하고 싶을 때, 백엔드 관리 시스템의 모니터링 관리 페이지에서 해당 교실로 입장해 참관할 수 있습니다.
- 교실 내 담당 교사가 네트워크 불안정이나 기기 문제로 클라우드 녹화가 중단되어 정상적으로 계속 녹화할 수 없고, 해당 수업에 공동 교사가 없는 경우, 교무 담당자는 백엔드 관리 시스템의 모니터링 관리 페이지에서 해당 교실로 입장해 로컬 녹화를 진행할 수 있습니다.

### 사용 설명
교무 담당자가 모니터링을 진행하려면 "관리자 백엔드"의 "모니터링 관리" 페이지에서 "교실 입장" 버튼을 클릭해야 합니다. 이때 관련 앱을 실행할지 확인하는 메시지가 브라우저에 표시되며, 교무 담당자는 "허용" 또는 "ClassIn 열기" 등의 버튼을 클릭해야 모니터링 교실에 정상적으로 입장할 수 있습니다. 이 절차를 따라도 ClassIn 소프트웨어가 정상적으로 실행되지 않으면, PC의 백신 프로그램을 종료한 후 ClassIn 소프트웨어 설정에서 레지스트리를 복구하세요. 복구 완료 후 다시 실행을 시도하면 됩니다. 참고로 교무 담당자가 백엔드 관리 시스템에서 교실에 입장해 모니터링하는 것은 무료이며 비용이 발생하지 않습니다.

교무 담당자가 교실에 입장해 모니터링할 때는 "투명 인간" 신분으로 입장합니다. 이때 교실 내 교사와 학생은 교무 담당자의 존재를 인식하지 못하며, 교무 담당자도 교실 내 누구와도 상호작용할 수 없습니다. 다만 유의할 점은, 교무 담당자가 사용하는 백엔드 관리 시스템 계정이 해당 교실에서 공동 교사나 학생 신분을 가지고 있는 경우, 교무 담당자가 모니터링을 위해 교실에 입장하면 자동으로 해당 신분으로 전환됩니다. 이 경우 교무 담당자는 교실 내 구성원과 상호작용할 수 있고, 구성원들도 교무 담당자의 존재를 인식할 수 있습니다. 교무 담당자가 "투명 인간" 신분이 아닌 상태로 입장하면, 일반적인 교실 이용과 동일하게 백엔드 관리 시스템의 요금이 부과됩니다.

### 유의사항
- 모니터링 관리에서는 최대 1000개 교실까지 표시됩니다.
