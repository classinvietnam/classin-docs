## ClassInX 기타 자주 사용하는 설정

# 1. 터치 반응 크기

## 대상
전체 사용자

## 사용 설명
사용자가 대형 디스플레이에서 ClassInX를 사용할 때, 지우개 도구가 선택되지 않은 상태에서 한 손가락 조작이나 두 손가락 스와이프가 지우개로 잘못 인식될 수 있습니다.

이런 경우, 강의실 화면 하단의 dock 바에서 ClassIn으로 들어가 왼쪽 하단 아바타를 클릭해 강의실 설정으로 이동한 후, 【터치 반응 크기】를 찾아 크기(실제 대형 디스플레이 크기 대비)를 조금 줄이는 것을 권장합니다.

## 구체적인 조작 방법
1. 화면 하단 중앙을 탭하거나 위로 스와이프해 dock 바로 들어갑니다.
2. "ClassIn"을 클릭합니다.
3. 왼쪽 하단의 "아바타"를 클릭합니다.
4. "강의실 설정"을 클릭합니다.
5. "터치 반응 크기"로 이동해 크기를 조절합니다.

# 2. 시작 시 자동 실행

대형 디스플레이를 켤 때마다 ClassInX 소프트웨어가 자동으로 열리게 하고 싶다면, 강의실 화면 하단의 dock 바에서 ClassIn으로 들어가 왼쪽 하단 아바타를 클릭해 시스템 설정으로 이동한 후, 【시작 시 자동 실행】을 찾아 켜는 것을 권장합니다. 반대로 끄고 싶다면 꺼 주세요.

1. "시스템 설정"을 클릭합니다.
2. "시작 시 자동 실행"을 켜거나 끕니다.

# 3. 터치스크린 소프트웨어 키보드 자동 실행

사용자가 대형 디스플레이에서 ClassInX를 사용해 칠판이나 강의실에 들어갔을 때, 시스템에 내장된 소프트웨어 키보드로 입력하고 싶다면, 화면 하단의 dock 바에서 ClassIn으로 들어가 왼쪽 하단 아바타를 클릭해 시스템 설정으로 이동한 후, 【터치스크린 소프트웨어 키보드 자동 실행】을 찾아 켜는 것을 권장합니다.

1. "시스템 설정"을 클릭합니다.
2. "터치스크린 소프트웨어 키보드 자동 실행"을 켜거나 끕니다.

# 4. ClassInX 소프트웨어 로그 보고

사용자가 ClassInX 소프트웨어 사용 중 스스로 해결할 수 없는 문제를 겪을 때, ClassIn 고객센터에 문제 설명, 문제가 발생한 계정, 발생 시각 등의 정보를 제공할 수 있으며, 화면 하단의 dock 바에서 ClassIn으로 들어가 왼쪽 하단 아바타를 클릭해 시스템 설정으로 이동한 후, 【소프트웨어 로그 보고】에서 "보고"를 클릭하면 기술 담당자가 효율적이고 신속하게 문제를 파악할 수 있습니다.

1. "소프트웨어 로그 보고" 옆의 "보고"를 클릭합니다.

# 5. 음성 어시스턴트 녹음 보고

사용자가 ClassInX 2.0 대형 디스플레이 사용 시, 다커(大可) 음성 어시스턴트에서 음성 인식 이상 등의 문제를 겪을 때, ClassIn 고객센터에 문제 설명, 문제가 발생한 계정, 발생 시각 등의 정보를 제공할 수 있으며, 화면 하단의 dock 바에서 ClassIn으로 들어가 왼쪽 하단 아바타를 클릭해 시스템 설정으로 이동한 후, 【음성 어시스턴트 녹음 보고】에서 "보고"를 클릭하면 기술 담당자가 효율적이고 신속하게 문제를 파악할 수 있습니다.

1. "음성 어시스턴트 녹음 보고" 옆의 "보고"를 클릭합니다.

# 6. ClassInX 캐시 파일 정리

사용자가 ClassInX에서 특정 기능 페이지를 열었을 때 로딩 시간이 너무 길어 콘텐츠가 정상적으로 표시되지 않는다면, 화면 하단의 dock 바에서 ClassIn으로 들어가 왼쪽 하단 아바타를 클릭해 파일 전송으로 이동한 후, 【캐시 파일】 옆의 "정리"를 클릭하고, 정리 완료 후 "지금 재시작"을 클릭해 주세요.

1. "파일 전송"을 클릭합니다.
2. "캐시 파일" 옆의 "정리"를 클릭합니다.
3. "지금 재시작"을 클릭합니다.

# 7. ClassInX 데이터 파일 정리

사용자가 ClassInX에서 시간표가 정상이고 올바른 계정으로 로그인했음을 확인했는데도 강의실 입구를 확인할 수 없다면, 화면 하단의 dock 바에서 ClassIn으로 들어가 왼쪽 하단 아바타를 클릭해 파일 전송으로 이동한 후, 【데이터 파일】 옆의 "정리"를 클릭하고, 정리 완료 후 "지금 재시작"을 클릭해 주세요.

1. "데이터 파일" 옆의 "정리"를 클릭합니다.
2. "지금 소프트웨어 재시작"을 클릭합니다.

## ClassInX 확장 디스플레이 사용 가이드

### 1. 확장 보조 디스플레이

대형 디스플레이 2대가 연결된 경우, ClassIn X 2.0 대형 디스플레이에서 ClassIn X 소프트웨어에 들어가 탭하거나 위로 스와이프해 더 많은 도구를 확인한 후, 확장 디스플레이의 투사 설정을 클릭하고 "확장"을 선택하면, 보조 디스플레이를 확장 디스플레이로 사용할 수 있습니다.

### 2. 확장 칠판(듀얼 디스플레이 연동)

확장 디스플레이를 칠판 판서 표시에 사용해야 한다면, ClassInX의 확장 디스플레이에서 "확장 칠판"을 선택할 수 있습니다.

(1) ClassIn X에 들어가 탭하거나 위로 스와이프해 더 많은 도구를 확인한 후, 확장 디스플레이를 클릭해 "확장 칠판"을 선택하거나 추가합니다.

(2) 확장 칠판은 기본적으로 "듀얼 디스플레이 연동" 기능이 켜져 있습니다. 확장 디스플레이 설정 패널 오른쪽 하단에서, 확장 디스플레이에 표시되는 판서 내용을 메인 화면의 "이전 페이지", "다음 페이지" 또는 "같은 페이지"로 설정할 수 있습니다. 설정 후, 한쪽 화면에서 페이지를 넘기면 다른 쪽 화면도 함께 넘어갑니다. 양쪽 화면 모두 필기가 가능하며, 필기한 내용은 다른 쪽 화면에도 동기화됩니다.

(3) 확장 디스플레이 설정 패널 오른쪽 상단에서는 확장 디스플레이의 배경 설정도 지원합니다.

(4) 강의실에서 확장 칠판을 선택한 경우, 강의실의 담당 교사가 설정을 마치면, 강의실 내 학생은 강의실 오른쪽 하단의 확장 디스플레이 제어 버튼으로 메인 화면과 확장 디스플레이 표시를 전환할 수 있습니다.

### 3. 확장 칠판(듀얼 디스플레이 비연동)

확장 디스플레이 설정 패널 왼쪽 하단에서 "듀얼 디스플레이 연동"을 끄면, 두 칠판은 같은 판서 내용을 표시하지만 각각 독립적으로 페이지를 넘길 수 있습니다.

### 4. 확장 파일

확장 디스플레이를 클라우드 드라이브(스페이스) 내 파일 표시에 사용해야 한다면, ClassInX의 확장 디스플레이에서 "파일"을 선택할 수 있습니다.

(1) ClassIn X에 들어가 탭하거나 위로 스와이프해 더 많은 도구를 확인한 후, 확장 디스플레이를 클릭해 "파일"을 선택하거나 추가하면, 클라우드 드라이브 스페이스 화면으로 이동합니다. 파일(PDF, PPT, DOC, EXCEL 형식만 지원)을 선택하면, 선택한 파일이 확장 디스플레이에 표시됩니다. 확장 디스플레이의 파일에는 필기와 주석을 달 수 있습니다.

(2) 확장 디스플레이에서는 동영상을 재생할 수 없습니다. ppt에 동영상이 있으면 해당 동영상은 자동으로 메인 화면으로 이동해 재생됩니다.

(3) 확장 디스플레이는 최대 2개의 파일 표시를 지원합니다. 사용자는 확장 디스플레이 설정 창에서 "추가"를 클릭해 다른 파일을 선택할 수 있으며, 파일을 전환해 확장 디스플레이의 표시 내용을 조정할 수 있습니다.

(4) 강의실에서 확장 파일을 선택한 경우, 강의실의 담당 교사는 확장 디스플레이 창 패널에서 "학생 자유 열람 허용" 권한을 설정할 수 있습니다. 이 설정을 켜면, 강의실 내 학생은 강의실 오른쪽 하단에서 확장 디스플레이 파일을 확인하면서 파일을 자유롭게 넘겨 볼 수 있습니다.

### 5. 확장 디스플레이에서 비디오 월 표시하기

확장 디스플레이는 칠판이나 파일 콘텐츠 표시 외에도 비디오 월 화면 표시도 지원합니다. 사용자는 화면 중앙 하단의 dock 바에서 도구함으로 들어가 비디오 월 도구를 열면, 비디오 월 화면이 자동으로 확장 디스플레이에 표시됩니다.

## ClassInX 강의실 조작 제스처

# 1. 도형 그리기 단축키

ClassInX는 직선, 원형, 타원형, 직사각형, 정사각형, 마름모 등 도형을 그리는 단축 기능을 제공합니다. 교사는 펜 도구를 선택하고 칠판에 자유롭게 도형을 그린 후, 손가락을 칠판 위에 1초간 멈추기만 하면, 아래 그림처럼 보정된 표준 도형을 얻을 수 있습니다

# 2. 한 손가락 조작

## 교재 이동하기

사용자는 양손 중 아무 손가락이나 교재 테두리 부분에 놓고, ppt, pdf, word, 오디오, 동영상 등의 교재를 이동시킬 수 있습니다.

## 칠판의 텍스트, 선, 도형 이동하기

사용자는 먼저 원형 도구판에서 "선택 및 이동 도구"를 선택한 후, 한 손가락으로 이동하려는 텍스트/이미지/도형/선에 손가락을 대고 드래그해 필요한 위치로 이동시킵니다.

## PPT 내 애니메이션 효과나 동영상 재생하기

사용자는 먼저 원형 도구판에서 "선택 및 이동 도구"를 선택한 후, 한 손가락으로 ppt 페이지를 탭하면 현재 페이지의 애니메이션 효과를 실행하거나 현재 페이지 내 동영상을 재생할 수 있습니다.

## PPT 교재 앞뒤 페이지 넘기기

사용자는 먼저 원형 도구판에서 "선택 및 이동 도구"를 선택한 후, 한 손가락으로 ppt 페이지를 탭하고 ppt 화면을 앞뒤로 스와이프하면 앞뒤 페이지 넘기기가 가능합니다

# 3. 두 손가락 조작

## 칠판 위아래로 스와이프하기

대형 디스플레이에서 두 손가락으로 스와이프하면 큰 칠판의 페이지 넘기기 조작을 할 수 있습니다

## 판서 전체 페이지 넘기기

두 손가락을 왼쪽이나 오른쪽으로 스와이프하면 판서 전체 페이지 넘기기가 가능합니다

## 확대/축소

이미지, 교재, 동영상에 두 손가락을 놓고 서로 가까워지거나 멀어지게 스와이프하면 확대/축소가 가능합니다

## 두 손가락 선택

두 손가락을 동시에 칠판의 특정 요소에 놓으면 해당 요소를 선택할 수 있으며, 이동, 삭제, 복제 등의 조작을 할 수 있습니다. 두 손가락으로 선택할 수 있는 요소로는 이미지, 텍스트, 도형, 선 등이 있습니다.

# 4. 네 손가락 조작

## 도구판 불러오기

강의실 칠판에서, 교사가 네 손가락으로 대형 디스플레이의 임의의 위치를 터치하기만 하면 도구판이 해당 위치로 이동해, 교사가 언제든지 편리하게 도구판의 기능을 선택할 수 있게 됩니다.

# 5. 손등·손바닥 조작

## 지우개

지우개를 불러오는 원리는 손을 최대한 넓은 면적으로 칠판에 접촉시키는 것입니다. 손바닥, 손등, 손의 측면 이 세 부위는 손에서 가장 면적이 넓은 부위이므로, 이 세 부위 중 어느 하나를 칠판에 대면 지우개가 불러와져 칠판 내용을 지울 수 있습니다. 참고로 지우개를 확실히 불러오려면 칠판에서 최대한 1초 정도 머문 후, 지우개 모양이 나타나면 이동해 지워 주세요. 지우는 동안 손은 칠판에서 떨어지면 안 됩니다.
