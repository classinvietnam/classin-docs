## 캐시 삭제

### 대상
전체 사용자

### 이런 경우에
ClassIn 사용 중 다음과 같은 문제가 발생할 수 있습니다.
- 과제 또는 퀴즈 페이지를 열면 내용 없이 빈 화면이 표시됨
- 교실에서 수업 자료를 열면 화면이 완전히 검게 또는 하얗게 표시되어 원래 내용이 보이지 않음
- 교실에서 클라우드 드라이브 도구를 열면 계속 "로딩 중"으로 표시되며 자료가 정상적으로 표시되지 않음

위와 같은 문제가 발생하면 앱 설정의 "캐시 삭제" 기능을 시도해 보세요.

### 조작 방법

**PC**
1. 왼쪽 하단 프로필 사진 클릭
2. "파일 전송"으로 이동
3. "캐시 삭제" 클릭

**휴대폰**
1. 하단 내비게이션에서 "홈" 진입
2. 왼쪽 상단 프로필 사진 탭
3. "앱 설정"으로 이동

**태블릿**
1. 왼쪽 하단 프로필 사진 탭

## 레지스트리 복구

### 대상
전체 사용자

### 이런 경우에
교사가 "관리자 백엔드"에서 모니터링 기능을 사용할 때 브라우저를 통해 ClassIn 앱을 정상적으로 실행할 수 없다면, ClassIn 설정의 "레지스트리 복구" 기능을 시도해 보세요.

### 유의사항
- "레지스트리 복구" 기능은 Windows PC에서만 사용 가능합니다.

### 조작 방법

**PC(Windows)**
1. 왼쪽 하단 프로필 사진 클릭
2. "시스템 설정"으로 이동
3. "레지스트리 복구"를 찾아 오른쪽의 "복구" 클릭

### 유의사항
- 휴대폰과 태블릿에서는 "소프트웨어 종료 방식"을 설정할 수 없습니다.

**PC**

## 눈 보호 모드

### 대상
전체 사용자

### 이런 경우에
ClassIn 사용 중 화면 블루라이트로 인한 눈 부담을 줄이기 위해 ClassIn 설정에서 "눈 보호 모드"를 켤 수 있습니다. 활성화하면 화면이 부드러운 노란빛 톤으로 조정되어 블루라이트 자극을 줄이고 눈의 피로와 건조함을 완화합니다. 끄면 화면 색온도가 정상으로 돌아옵니다.

### 유의사항
- PC에서 눈 보호 모드를 켜면 화면 전체에 효과가 적용되며, ClassIn 앱을 종료하면 색온도가 정상으로 돌아옵니다.
- 휴대폰/태블릿에서는 ClassIn 화면에서만 효과가 적용됩니다.

### 조작 방법

**PC**
1. 왼쪽 하단 프로필 사진 클릭
2. "시스템 설정"으로 이동
3. "눈 보호" 켜기/끄기

**휴대폰**
1. 하단 내비게이션에서 "홈" 진입
2. 왼쪽 상단 프로필 사진 탭

4. "눈 보호 모드" 전환

## 장비 점검(오디오/비디오)

### 이런 경우에
"장비 점검" 기능은 수업 전 PC의 오디오/비디오 장비를 종합적으로 점검하여 고장이나 설정 문제를 미리 파악하고, 수업 중 마이크·스피커·카메라가 정상 작동하도록 돕는 기능입니다.

### 사용 방법
장비 점검 페이지에서 다음 4단계를 완료하면 수업 중 장비 문제로 인한 지장을 방지할 수 있습니다.
- **시스템 점검**: OS, CPU 모델, 네트워크 지연, 패킷 손실률 등을 빠르게 확인
- **카메라 점검**: 카메라 작동 여부 확인. 화면이 나오지 않으면 이 페이지에서 카메라를 전환하거나 복구 도우미로 드라이버를 복구할 수 있습니다.
- **스피커 점검**: 스피커 작동 여부 확인. 재생을 클릭하면 소리가 나며, 들린 소리 종류에 체크합니다. 소리가 나지 않으면 이 페이지에서 스피커를 전환하거나 복구 도우미로 사운드 드라이버를 복구할 수 있습니다.
- **마이크 점검**: 마이크 작동 여부 확인. 녹음을 클릭하면 음성에 따라 파형 바가 움직입니다. 움직이지 않으면 이 페이지에서 마이크를 전환하거나 복구 도우미로 사운드 드라이버를 복구할 수 있습니다.

### 유의사항
- 휴대폰과 태블릿에는 장비 점검 기능이 없습니다.

### 조작 방법

**PC**
1. 왼쪽 하단 프로필 사진 클릭
2. "장비 점검"으로 이동
3. 오른쪽에서 점검할 항목(시스템, 네트워크 상태, 마이크, 카메라, 스피커) 클릭

## 소프트웨어 단축키

### 대상
전체 사용자

### 이런 경우에
ClassIn 앱 설정에서 PC 사용자는 자주 쓰는 단축키(앱 열기, 화면 캡처, 메시지 보내기 등)를 변경할 수 있습니다.

### 유의사항
- 휴대폰과 태블릿에서는 단축키를 설정할 수 없습니다.

### 조작 방법

**PC**
1. 왼쪽 하단 프로필 사진 클릭
2. "시스템 설정"으로 이동
3. "단축키 설정"으로 이동하여 단축키 변경

## 소프트웨어 로그 제출

### 대상
전체 사용자

### 이런 경우에
ClassIn 사용 중 스스로 해결할 수 없는 문제가 발생하면, 문제 설명, 관련 계정, 발생 시각 등의 정보를 ClassIn 고객지원팀에 제공할 수 있습니다.

PC를 사용하는 경우, 시스템 설정에서 소프트웨어 로그 기능을 찾아 "제출"을 클릭하세요. 이렇게 하면 기술 지원팀이 문제를 더 빠르게 파악할 수 있습니다.

휴대폰이나 태블릿을 사용하는 경우, ClassIn 고객지원팀의 안내(앱 재로그인 등)에 따라 조작하세요.

### 조작 방법

**PC**
1. 왼쪽 하단 프로필 사진 클릭
2. "시스템 설정"으로 이동
3. "소프트웨어 로그 제출"을 찾아 오른쪽의 "제출" 클릭

## 청소년 모드

### 1. 청소년 모드 켜기

**대상**: 학생

**이런 경우에**: 청소년 모드는 학생에게 안전한 학습 환경을 제공하고 학부모가 자녀의 온라인 활동을 효과적으로 관리할 수 있도록 하는 ClassIn의 보호 기능입니다. 활성화 시 비밀번호를 설정해야 하며, 이후 비밀번호 입력으로 수정하거나 끌 수 있습니다. 활성화 후 다음 기능을 켜거나 꺼서 학생의 이용을 제한할 수 있습니다.

- **클래스 생성 금지**: 학생이 스스로 새 클래스를 만들 수 없도록 하여 학습 환경의 질서를 유지합니다.
- **공개 수업 생성 금지**: 학생이 스스로 공개 수업을 만들 수 없도록 하여 학습 환경의 질서를 유지합니다.
- **친구 추가 금지**: 학생이 반 친구를 포함해 누구에게도 먼저 친구 신청을 할 수 없습니다(다른 사람이 먼저 신청하는 것은 가능).
- **브라우저 열기 금지**: 학생이 유해 사이트에 접근하지 못하도록 하여 인터넷 안전을 보장합니다.
- **자발적 로그아웃 금지**: 학생이 ClassIn에서 로그아웃을 눌러도 로그아웃되지 않습니다.
- **자발적 클래스 참여 금지**: 학생이 클래스 번호나 In 코드 검색으로 스스로 클래스에 참여할 수 없습니다.

**조작 방법**

PC: 왼쪽 하단 프로필 사진 → 시스템 설정 → 스크롤하여 청소년 모드 진입 → "청소년 모드 켜기" 클릭 → 비밀번호 입력 후 "다음" → 각 권한 켜기/끄기

휴대폰: 하단 내비게이션에서 홈 → 왼쪽 상단 프로필 사진 → 앱 설정 → 청소년 모드 → "청소년 모드 켜기" 클릭 → 비밀번호 설정 후 "청소년 모드 켜기" 클릭

태블릿: 왼쪽 하단 프로필 사진 → 비밀번호 입력 후 "청소년 모드 켜기" 클릭

### 2. 청소년 모드 편집 또는 끄기

청소년 모드를 켠 후, 학생이 제한된 기능을 사용해야 한다면 비밀번호를 입력해 청소년 모드에 진입한 뒤 필요한 기능을 수정할 수 있으며, 청소년 모드 자체를 끄는 것도 가능합니다.

### 3. 비밀번호를 잊은 경우 - 청소년 모드

청소년 모드 비밀번호를 잊은 경우, "비밀번호 찾기" 기능을 눌러 이메일로 전송된 안내에 따라 비밀번호 재설정을 신청할 수 있습니다.

### 4. 비밀번호 변경 - 청소년 모드

청소년 모드에서 "비밀번호 변경"을 누르고, 기존 비밀번호를 입력한 후 새 비밀번호를 두 번 입력하면 변경이 완료됩니다.

## 고해상도 디스플레이(High DPI)

### 대상
전체 사용자

### 이런 경우에
Windows PC에서 ClassIn 로그인 후 메인 화면 창이나 글자가 너무 작게 보인다면, ClassIn 설정에서 "고해상도 디스플레이" 모드를 켜서 해결할 수 있습니다.

### 유의사항
- Windows PC에서만 사용 가능한 기능입니다.
- "고해상도 디스플레이" 모드는 단일 모니터 환경에서만 지원됩니다.

### 조작 방법

**PC(Windows)**
1. 왼쪽 하단 프로필 사진 클릭
2. "시스템 설정"으로 이동
3. "고해상도 디스플레이" 켜기/끄기

## 기본 파일 저장 위치

### 대상
전체 사용자

### 이런 경우에
이 기능은 교실 내 저장된 이미지, 교실 내 판서, 로컬 녹화 영상, 클래스 그룹에서 다운로드한 파일 등 ClassIn 파일의 기본 저장 경로를 설정합니다. 관련 파일을 더 효율적으로 관리하고 활용하는 데 도움이 됩니다.

### 유의사항
- 휴대폰과 태블릿에는 이 기능이 없습니다.

### 조작 방법

**PC**
1. 왼쪽 하단 프로필 사진 클릭
2. "파일 전송"으로 이동
3. 기본 파일 저장 경로 변경
