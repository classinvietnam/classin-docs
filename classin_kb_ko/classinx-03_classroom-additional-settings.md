## ClassInX 강의실 추가 설정

# 1. 좌석 영역 표시/숨기기

## 사용 설명
좌석 영역은 칠판 맨 위의 한 줄 영역을 말하며, 이 영역은 교사·학생의 카메라 화면을 표시하는 용도로만 사용되고 필기는 지원하지 않습니다.

수업 생성 시 좌석 영역 표시 여부를 설정하는 것 외에도, 강의실에 들어간 후에도 담당 교사나 조교사는 강의실의 추가 설정에서 좌석 영역을 표시하거나 숨길 수 있습니다.

또한 좌석 영역이 표시되어 있을 때만 교사가 설정한 좌석 로테이션이 적용됩니다. 교사가 전체 화면으로 필기해야 한다면 좌석 영역을 숨길 수 있습니다.

## 구체적인 조작 방법
1. 화면 하단 중앙을 클릭하거나 위로 스와이프해 dock 바로 들어갑니다.
2. 맨 오른쪽의 "설정"을 클릭합니다.
3. "추가 설정"을 클릭합니다.
4. "일반"을 클릭합니다.
5. 좌석 영역 "표시" 또는 "숨기기"를 선택합니다.

# 2. 집중 모드

## 대상
담당 교사, 조교사

수업 중 학생이 산만해지지 않도록 집중 모드 기능 사용을 권장합니다. 백오피스 관리자는 【집중 모드 활성화】 기능에 체크한 스킨을 반에 적용할 수 있으며, 해당 반의 정식 강의실은 기본적으로 집중 모드가 활성화됩니다. 이 외에도 담당 교사나 조교사가 강의실에 들어간 후, 강의실의 추가 설정에서 집중 모드를 켜거나 끌 수 있습니다.

집중 모드를 켜면: 학생이 Windows 컴퓨터로 강의실에 들어갈 경우, 강의실 창은 항상 최대화되고 최상단에 고정되어 다른 창에 가려지지 않습니다. 학생이 휴대폰이나 태블릿으로 강의실에 들어갈 경우, 다른 앱으로 전환하면 자동으로 강의실에서 나가게 됩니다.

담당 교사나 조교사가 강의실 내에서 설정한 집중 모드는 현재 강의실에만 적용됩니다.

## 유의사항
집중 모드는 Mac OS 기기를 사용하는 학생에게는 적용되지 않습니다.

집중 모드는 참관생에게는 적용되지 않습니다.

학생의 기기가 화면 분할이나 유사한 기능을 지원하는 경우, 집중 모드가 적용되지 않을 수도 있습니다.

1. "집중 모드"를 켜거나 끕니다.

# 3. 손들기 소리 알림

## 적용 시나리오
학생이 강의실에서 손을 들면, 교사 기기에서 자동으로 손들기 알림음이 재생되어, 교사가 수업에 집중하거나 판서를 하거나 파일을 확인하는 중에도 학생의 손들기 요청을 제때 알아차려 수업 상호작용을 놓치지 않을 수 있습니다.

강의실에 들어간 후, 담당 교사와 조교사는 각자 자신의 손들기 알림음을 설정할 수 있으며, 설정은 서로 영향을 주지 않습니다.

손들기 알림음 설정에서 교사는 알림음 없음을 선택하거나, 딩동/똑딱/딩동벨 소리 중 하나를 알림음으로 선택할 수 있습니다.

알림음은 교사 본인에게만 들리며, 강의실 내 학생에게는 들리지 않습니다.

1. "손들기 알림음"을 선택합니다.

# 4. 입퇴장 알림

강의실에 들어간 후, 교사가 강의실의 추가 설정에서 입퇴장 알림을 켜면, 강의실의 학생이 입장하거나 퇴장할 때마다 교사의 화면 하단에 알림 팝업이 표시되어, 교사가 실시간으로 학생의 출석 상황을 파악할 수 있습니다.

담당 교사와 조교사는 각자 자신의 입퇴장 알림을 설정할 수 있으며, 설정은 서로 영향을 주지 않습니다.

담당 교사가 이 기능을 켜둔 경우, 조교사의 입장이나 퇴장에 대해서도 담당 교사가 알림을 받습니다.

1. "입퇴장 알림"을 켜거나 끕니다.

# 5. 강의실 배경

강의실 배경은 미리 백오피스 관리 시스템에서 설정할 수 있으며, 강의실에 들어간 후에는 교사도 강의실의 추가 설정에서 직접 설정할 수 있습니다. 교사가 강의실에서 배경을 변경하면, 새로 변경한 강의실 배경이 즉시 적용됩니다.

교사는 시스템 기본 배경 이미지를 선택하거나, 로컬 이미지를 강의실 배경으로 업로드할 수 있습니다. 업로드하는 이미지는 JPG 형식이어야 하며 크기는 1MB를 초과할 수 없습니다.

교사가 강의실의 추가 설정에서 변경한 강의실 배경은 현재 강의실에만 적용됩니다.

1. "강의실 배경"을 클릭합니다.
2. 강의실 배경 이미지를 "선택"하거나 "업로드"합니다.

# 6. 강의실 창 레이아웃

카메라, 교재, 소형 도구를 미리 설정된 위치로 드래그해 자동으로 크기를 조절하면, 교사가 강의실 칠판 화면을 빠르게 정리하고 교육 장면을 효율적으로 전환하며 수업과 상호작용에 더 집중할 수 있습니다.

강의실에 들어간 후, 교사는 강의실 추가 설정 > 기타 > 창 레이아웃 경로로 기존 레이아웃 템플릿을 선택할 수 있습니다. 사용자 정의 레이아웃 템플릿 추가도 지원하며, 레이아웃 템플릿 추가 시 타일 모드(칸의 크기와 위치가 고정되어 자유롭게 조절할 수 없음) 또는 자유 칸 모드(칸의 크기와 위치를 자유롭게 조절 가능)를 추가할 수 있습니다.

템플릿을 선택한 후, 교사가 대형 디스플레이를 사용하는 경우 한 손가락으로 카메라, 교재, 소형 도구를 드래그해 0.5초간 멈추면 레이아웃 모드로 진입할 수 있습니다. 컴퓨터를 사용하는 경우, 마우스로 드래그하면서 키보드의 Shift 키를 누르고 있으면 레이아웃 모드로 진입할 수 있습니다.

1. "기타"를 클릭합니다.
2. 레이아웃 설정 아래에서 "창 레이아웃"을 클릭합니다.
3. 레이아웃 템플릿을 "선택"하거나 "추가"합니다.
4. 한 손가락으로 카메라/교재/소형 도구를 드래그해 0.5초간 멈추면 레이아웃 모드로 진입합니다.
(컴퓨터를 사용하는 경우, 드래그하면서 Shift 키를 누르고 있어야 합니다.)

# 7. 강의실 도움 요청

담당 교사, 조교사, 수업 학생(참관생 제외)

강의실 내 교사나 학생이 스스로 해결할 수 없는 문제에 부딪혔을 때, 백오피스 교무 관리 교사에게 지원을 요청할 수 있습니다.

강의실에 들어간 후, 교사는 강의실 추가 설정 > 기타 > 도움 요청 경로로 도움 요청 창에 들어갈 수 있습니다. 도움 요청 창에서 문제가 있는 사용자를 선택하고 문제를 설명한 후 "확인"을 클릭하면 됩니다. 백오피스 교무 관리 교사는 www.eeo.cn의 교무 관리 > 수업 감독 관리에서 수업 도움 요청 정보를 확인할 수 있으며, 정보에는 문제 설명과 시스템이 그 시점에 캡처한 강의실 내 모든 사용자의 강의실 스크린샷이 포함됩니다. 교무 교사가 답변하면 강의실 내 교사 화면에 답변 창이 자동으로 팝업으로 표시됩니다.

백오피스 관리자가 【학생이 학교 백오피스로 도움 요청 메시지를 보내는 것을 허용】 기능에 체크한 스킨을 반에 적용한 경우, 학생은 컴퓨터나 아이패드로 해당 반 아래의 강의실에 들어간 후 도움 요청 기능을 사용할 수 있게 됩니다. 도움 요청 창에서 학생은 문제를 설명한 후 "확인"을 클릭하면 됩니다. 백오피스 교무 관리 교사는 www.eeo.cn의 교무 관리 > 수업 감독 관리에서 수업 도움 요청 정보를 확인할 수 있으며, 정보에는 문제 설명과 시스템이 해당 학생에 대해 캡처한 강의실 스크린샷이 포함됩니다. 교무 교사가 답변하면 강의실 내 해당 학생 화면에 답변 창이 자동으로 팝업으로 표시됩니다.

학생(참관생 제외)은 컴퓨터나 아이패드로 ClassIn 앱을 통해, 【학생이 학교 백오피스로 도움 요청 메시지를 보내는 것을 허용】 기능이 체크된 강의실에 들어간 경우에만 도움 요청 기능을 사용할 수 있습니다.

1. "빠른 도움 요청" 아래에서 "도움 요청"을 클릭합니다.
2. 교사: 문제가 있는 사용자를 선택하고 문제를 설명한 후 "확인"을 클릭합니다.
(학생: 문제를 설명한 후 "확인"을 클릭합니다.)

# 8. ClassInX 소프트웨어 업그레이드

전체 사용자

더 원활한 사용을 위해 ClassInX 소프트웨어를 최신 버전으로 업그레이드하는 것을 권장합니다.

계정에 로그인하지 않은 사용자는 화면 하단의 dock 바 > 설정 > 추가 설정 > 소프트웨어 정보에서 현재 ClassInX 소프트웨어 버전을 확인하거나 소프트웨어를 업그레이드할 수 있습니다.

계정에 로그인한 사용자는 위 위치 외에도, 화면 하단의 dock 바 > ClassIn > 왼쪽 하단 아바타 > 소프트웨어 정보에서도 현재 ClassInX 소프트웨어 버전을 확인하거나 소프트웨어를 업그레이드할 수 있습니다.

1. "소프트웨어 정보"를 클릭합니다.
2. 현재 ClassInX 소프트웨어 버전을 확인하거나 "업그레이드"를 클릭합니다.

# 9. 강의실 필기 펜 설정

ClassInX에서 필기 펜으로 칠판에 필기할 때, 필기 펜을 필기 전용으로 사용하려면, 화면 하단의 dock 바 > 설정 > 추가 설정 > 하드웨어에서 【필기 펜을 필기 전용으로 사용】 기능을 켜는 것을 권장합니다.

활성화하면 필기 펜은 필기 전용으로 사용되며, 손가락 조작은 원형 도구판에서 선택된 도구와 일치하는 동작이 됩니다(펜촉을 기울이면 손가락으로 인식될 수 있습니다).

1. "하드웨어"를 클릭합니다.
2. "필기 펜을 필기 전용으로 사용"을 켜거나 끕니다.

# 10. 강의실 터치 잠금 설정

오프라인 학생이 대형 디스플레이 화면을 실수로 터치하는 것을 방지하기 위해, 교사는 쉬는 시간에 ClassInX 소프트웨어의 화면 하단 dock 바 > 설정 > 추가 설정 > 하드웨어에서 【화면 터치 잠금 기능】을 켤 수 있습니다.

터치 잠금이 켜진 상태에서, 사용자는 화면 하단의 터치 잠금 버튼을 탭하거나 페이지 넘김 펜의 "이전 페이지" 버튼을 길게 눌러 터치 잠금을 해제할 수 있습니다.

터치 잠금이 꺼진 상태에서도, 페이지 넘김 펜의 "이전 페이지" 버튼을 길게 눌러 터치 잠금을 켤 수 있습니다.

1. "화면 터치 잠금 기능"을 켜거나 끕니다.

# 11. 다커(大可) 음성 어시스턴트

다커 음성 어시스턴트는 사용자가 음성 명령을 통해 ClassInX 2.0 대형 디스플레이에서 ClassIn 관련 조작을 더 편리하게 완료할 수 있도록 돕습니다.

음성 어시스턴트 기능은 ClassInX 2.0 대형 디스플레이 기기에서만 지원되며, 사용 시 ClassInX 소프트웨어에서 마이크 권한을 켜야 합니다.

ClassInX 소프트웨어의 화면 하단 dock 바 > 설정 > 음성 어시스턴트에서 【다커 음성 어시스턴트】 기능을 켜거나 끌 수 있습니다.

다커 음성 어시스턴트를 켜면, 【웨이크프리】(별도로 "다커 다커"라고 부를 필요 없이 바로 명령을 말할 수 있음), 【텍스트 피드백】(음성 인식 결과가 대형 디스플레이에 텍스트로 표시됨), 【효과음 피드백】(다커가 딩동 소리로 응답함) 기능도 켜거나 끌 수 있으며, 이러한 기능은 강의실이나 칠판 오른쪽 하단의 다커 아이콘을 탭해서도 켜거나 끌 수 있습니다.

또한 정식 강의실에서는 조건을 충족하는 경우 담당 교사, 조교사, 그룹장도 다커 음성 어시스턴트 기능을 사용할 수 있지만, 조건을 충족하는 학생에게는 이 기능 사용 권한이 없습니다.

1. "음성 어시스턴트"를 클릭합니다.
2. "다커 음성 어시스턴트"를 켜거나 끕니다.
