## 백오피스에서 교사·학생 정보 수정하기

### 1. 백오피스에서 교사 정보 수정하기

#### 대상
- "백오피스 관리 시스템" 마스터 계정
- "교사 관리" 권한을 가진 하위 계정

#### 사용 설명
교무 담당자는 이미 "백오피스 관리 시스템"에 등록된 교사의 프로필을 수정할 수 있습니다. 수정 가능한 항목은 교사 이름, 교사 사진, 교사 태그, 교사 소개입니다.

주의: 교사의 휴대폰 번호와 이메일은 여기서 수정할 수 없습니다. 휴대폰 번호를 변경하려면 앱 내의 "ClassIn 휴대폰 번호 변경" 기능을 이용하세요.

#### 관련 문서
「백오피스 관리 시스템에서 하위 계정 추가」

#### 조작 방법
1. 백오피스 관리 시스템에 로그인합니다.
2. 왼쪽 내비게이션에서 "교사 관리"로 이동합니다.
3. 교사를 검색합니다.
4. 오른쪽의 "보기"를 클릭합니다.
5. 왼쪽 상단의 "편집"을 클릭합니다.

## 백오피스에서 교사·학생 추가하기

### 1. 백오피스에서 교사 추가하기

#### 대상
- "백오피스 관리 시스템" 마스터 계정
- "교사 관리" 권한을 가진 하위 계정

#### 사용 설명
"백오피스 관리 시스템"에 교사를 추가하려면 다음 기본 정보를 입력해야 합니다: 교사의 휴대폰 번호 또는 이메일(둘 중 하나만 입력해도 됨), 교사의 이름. 이 외에도 교사 사진을 업로드하거나, 태그를 지정하거나, 공용 교재 사용 허용 여부를 결정하거나, 교사 소개(입력하지 않아도 됨)를 작성할 수 있습니다. 마지막으로 "확인" 버튼을 클릭하면 추가가 완료됩니다.

추가하려는 교사가 아직 ClassIn 계정을 등록하지 않은 경우, 추가 시 "신규 교사 대리 등록" 옵션을 체크해야 합니다. 그러면 시스템이 해당 교사의 계정을 자동으로 등록하고 임의의 비밀번호를 SMS로 발송하여, 교사가 휴대폰 번호와 비밀번호로 시스템에 로그인할 수 있게 됩니다.

#### 관련 문서
「교사 정보 수정」
「교사 이용 정지」
「백오피스 관리 시스템에서 하위 계정 추가」

#### 조작 방법
1. 백오피스 관리 시스템에 로그인합니다.
2. 왼쪽 내비게이션에서 "교사 관리"로 이동합니다.

### 2. 백오피스에서 학생 추가하기

"학생 관리" 권한을 가진 하위 계정.

#### 이런 경우에
교무 담당자가 코스에 학생을 추가하려는 경우, 현재 "백오피스 관리 시스템"에 이미 등록된 학생 중에서만 선택할 수 있습니다. 추가하려는 학생이 현재 "백오피스 관리 시스템"에 없다면, 먼저 "학생 관리"에서 해당 학생을 추가하고 현재 "백오피스 관리 시스템"의 학생 신분으로 등록한 뒤에야 해당 코스에 추가할 수 있습니다.

"백오피스 관리 시스템"에 학생을 추가하려면 다음 기본 정보를 입력해야 합니다: 학생의 휴대폰 번호 또는 이메일(둘 중 하나만 입력해도 됨), 학생의 이름. 추가하려는 학생이 아직 ClassIn 계정을 등록하지 않은 경우, 추가 시 "신규 학생 대리 등록" 옵션을 체크해야 합니다. 그러면 시스템이 해당 학생의 계정을 자동으로 등록하고 임의의 비밀번호를 SMS로 발송하여, 학생이 휴대폰 번호 또는 이메일과 비밀번호로 시스템에 로그인할 수 있게 됩니다.

## 교사·학생 이용 정지, 숨기기 및 복원

### 대상
- "백오피스 관리 시스템" 마스터 계정
- "교사 관리" 또는 "학생 관리" 권한을 가진 하위 계정

### 이런 경우에
**교사 이용 정지:** 교사가 퇴사한 경우, 교무 담당자는 "백오피스 관리 시스템"의 "교사 관리" 항목에서 해당 교사를 이용 정지할 수 있습니다. 이용 정지되면 해당 교사는 수업 편성 시 선택 가능한 교사 목록에 나타나지 않습니다.

**이용 정지된 교사 복원하기:** 이용 정지된 교사를 다시 수업 편성 시 선택 가능하게 하려면, "백오피스 관리 시스템"에 로그인한 뒤 "교사 관리" 항목으로 이동합니다. "교사 관리" 항목에서 이용 정지된 교사를 찾아 정지 상태를 해제하면, 해당 교사가 다시 수업 편성 시 선택 가능한 교사 목록에 나타납니다. 이는 주로 교사가 복직했을 때 다시 수업을 배정할 수 있는 대상으로 포함시킬 때 사용됩니다.

**학생 숨기기:** 교무 담당자는 "백오피스 관리 시스템"의 "학생 관리" 항목에서 특정 학생을 숨길 수 있습니다. 숨기면 해당 학생은 수업 편성 시 선택 가능한 학생 목록에 나타나지 않습니다.

**숨겨진 학생 복원하기:** 숨겨진 학생을 다시 수업 편성 시 표시되도록 하려면, "백오피스 관리 시스템"에 로그인한 뒤 "학생 관리" 항목으로 이동합니다. "학생 관리" 항목에서 숨겨진 학생을 찾아 숨김 상태를 해제하면, 해당 학생이 다시 수업 편성 시 선택 가능한 학생 목록에 나타납니다.

### 유의사항
이용 정지하려는 교사가 "백오피스 관리 시스템"의 하위 계정 신분을 가지고 있는 경우, 그대로는 이용 정지할 수 없습니다. "권한 관리"에서 먼저 해당 교사의 하위 계정 신분을 삭제한 후 이용 정지 작업을 진행해야 합니다.

이용 정지하려는 교사에게 아직 끝나지 않은 수업이나 진행 중인 수업이 있는 경우, 해당 교사를 이용 정지할 수 없습니다.
