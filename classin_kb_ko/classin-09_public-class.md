## 공개 수업 만들기

### "공개 수업"이란?
ClassIn 플랫폼에서 "공개 수업"은 간편하게 수업을 만드는 방식입니다. 일반 반과 달리 "공개 수업"에는 반 그룹이 없으며, 만들면 즉시 독립적인 수업이 생성됩니다. 학생은 두 가지 방법으로 "공개 수업"에 등록해 참여할 수 있습니다: 공개 수업 QR코드를 스캔하거나 공개 수업 In 암호를 입력하는 방법입니다. 이 때문에 "공개 수업"은 학부모 상담회, 일회성 보충 수업, 취미반, 각종 강연 등의 시나리오에 특히 적합합니다.

### 대상
학교/기관 마스터 계정

"클라이언트-공개 수업, 반 만들기" 권한을 가진 백오피스 학교/기관 관리자

## 사용 설명
권한을 가진 교사는 ClassIn 앱 홈 화면 상단에서 공개 수업을 만들 수 있으며, 담당 교사는 기본적으로 만든 사람이 됩니다.

### 관련 문서
「공개 수업에 학생 추가하기」

### 구체적인 조작 방법

#### 컴퓨터/태블릿
1. "홈"으로 이동합니다.
2. "공개 수업 만들기"를 클릭합니다.
3. 관련 매개변수를 설정합니다.

#### 휴대폰

## 공개 수업에 학생 추가하기

### 대상
공개 수업의 담당 교사 또는 조교사

### 사용 설명
공개 수업에서 교사는 자신의 ClassIn 친구를 공개 수업 학생으로 직접 추가할 수 없습니다. 교사가 "공개 수업 QR코드"와 "공개 수업 In 암호"를 참여가 필요한 학생에게 공유하면, 학생이 스스로 등록해 공개 수업에 참여하는 방식입니다.

### 구체적인 조작 방법

#### 컴퓨터/태블릿
1. "시간표"로 이동합니다.
2. "날짜"를 선택합니다.
3. "공개 수업"을 클릭합니다.
4. 학생 추가 방식을 선택합니다: QR코드 공유, In 암호, 이메일 초대.

#### 휴대폰
1. "학생 초대"를 클릭합니다.

## 공개 수업 수정하기

### 대상
공개 수업의 담당 교사

### 사용 설명
ClassIn 클라이언트에서 공개 수업의 담당 교사는 이미 만든 공개 수업을 수정할 수 있습니다. 구체적으로 수정 가능한 정보와 설정에는 공개 수업 이름, 개강일, 개강 시각, 공개 수업 시간, 조교사, 무대 인원수, 클라우드 녹화 수업, 웹 라이브, 웹 다시보기 등이 포함됩니다. 아래의 관련 규칙과 시간 제한을 준수해 주세요.

개강 20분 전까지 수정할 수 있는 설정: 공개 수업 이름, 개강 시각과 시간, 조교사, OMO 스테이션 라이브, 무대 인원수, 클라우드 녹화 수업(ClassIn 강의실 녹화, 현장 녹화), 웹 라이브, 웹 다시보기, 좌석 표시, 학생 자동 무대 등장.

수업 종료 전까지 언제든지 수정할 수 있는 설정: 조교사 추가/변경, 웹 다시보기.

시간 제한 없이 언제든지 수정할 수 있는 설정: 웹 다시보기.

### 유의사항
정식 개강 전(강의실 사전 입장 시간 포함)이라면 공개 수업은 언제든지 삭제할 수 있습니다. 다만 공개 수업이 정식 수업 시간에 들어가면 더 이상 삭제할 수 없습니다.

종료된 공개 수업은 삭제할 수 없습니다.

### 구체적인 조작 방법

#### 컴퓨터/태블릿
1. "시간표"로 이동합니다.
2. "날짜"를 선택합니다.
3. "공개 수업"을 클릭합니다.
4. "편집"을 클릭합니다.

#### 휴대폰
1. "···"을 클릭합니다.

## 공개 수업 삭제하기

### 대상
공개 수업의 담당 교사

### 사용 설명
ClassIn 클라이언트에서 공개 수업의 담당 교사는 정식 개강 전까지 이미 만든 공개 수업을 삭제할 수 있습니다.

### 유의사항
정식 개강 전(강의실 사전 입장 시간 포함)이라면 공개 수업은 언제든지 삭제할 수 있습니다. 다만 공개 수업이 정식 수업 시간에 들어가면 더 이상 삭제할 수 없습니다.

삭제된 공개 수업은 복구할 수 없습니다. 신중하게 조작해 주세요.

종료된 공개 수업은 삭제할 수 없습니다.

### 구체적인 조작 방법

#### 컴퓨터/태블릿
1. "시간표"로 이동합니다.
2. "날짜"를 선택합니다.
3. "공개 수업"을 클릭합니다.
4. "삭제"를 클릭합니다.

#### 휴대폰
1. "···"을 클릭합니다.
