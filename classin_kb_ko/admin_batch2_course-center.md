## 수강 제외 학생 관리

### 1. 수강 제외 학생이란?
수강 제외 학생이란 특정 클래스 내에서 교사가 특정 수업에 참여하지 못하도록 제한한 학생을 말합니다. 제외된 학생은 해당 수업 교실에는 입장할 수 없지만, 그 클래스의 다른 수업에는 정상적으로 참여할 수 있습니다.

### 2. 수강 제외 학생 설정

**대상**
- "관리자 백엔드" 마스터 계정
- "클래스 관리" 권한이 있는 하위 계정

**사용 설명**
클래스 학생이 조기에 수강을 취소하거나 교무 담당자가 특정 학생의 특정 수업 참여를 제한하려는 경우, 교무 담당자는 클래스 내 학생을 해당 수업의 제외 학생으로 설정할 수 있습니다. 제외 학생으로 설정되면 해당 학생은 제한된 수업에 참여할 수 없으며, 해당 수업의 녹화 재생도 시청할 수 없습니다.

**관련 문서**
- "관리자 백엔드에 하위 계정 추가"

**조작 방법**
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "클래스 관리"로 이동
3. 클래스를 찾아 진입
4. "시간표"로 이동
5. 수업을 찾아 오른쪽 "수강 제외 학생" 항목의 "추가" 버튼 클릭
6. 제외 학생 추가

### 3. 수강 제외 학생 삭제
"권한 관리" 권한이 있는 하위 계정이 필요합니다.

수업을 찾아 오른쪽의 수강 제외 학생 위치에 마우스를 올리면 연필 아이콘이 나타나며, 클릭하여 삭제할 수 있습니다. 전체 일괄 삭제 또는 개별 삭제를 지원합니다.

## 청강생 관리

### 1. 청강생이란?
청강생이란 교실에 입장하여 수업을 청강할 수 있는 학생을 말합니다. 청강생은 교실 내에서 정상적으로 수업을 들을 수 있지만, 교사와 다른 학생에게는 보이지 않으며 명단에도 이름이 표시되지 않습니다. 즉, 청강생은 수업 중 투명 상태와 같습니다. 그럼에도 누적 출석 시간이 10분에 도달하면 유효한 출석으로 기록됩니다. 다만 청강생은 교실 내에서 어떠한 도구도 사용할 수 없으며 수업 청취에만 집중할 수 있습니다. 청강생을 추가하면 클래스 학생 명단에는 나타나지만 수업 녹화 재생은 시청할 수 없습니다.

### 2. 청강생 추가

**대상**
- "관리자 백엔드" 마스터 계정
- "클래스 관리" 권한이 있는 하위 계정

**이런 경우에**
각 클래스에는 최대 20명까지 청강생을 추가할 수 있습니다. 이 기능은 주로 교무 담당자가 클래스에 체험 수강 자리를 추가할 수 있도록 하기 위한 것입니다. 이를 통해 학생이 해당 수업을 미리 체험할 수 있습니다. 청강생은 클래스 그룹에 가입해 다른 학생 및 교사와 교류할 수 있지만, 교실 내 다른 사람은 청강생을 볼 수 없습니다. 즉, 청강생이 교실에 입장하면 투명 상태로 수업을 듣게 됩니다. 이 기능은 관심 있는 수업을 고려 중인 학생이 특정 수업을 체험한 후 정식 등록 여부를 결정하는 데 적합합니다.

**관련 문서**
- "관리자 백엔드에 하위 계정 추가"

**조작 방법**
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "클래스 관리"로 이동
3. 클래스를 찾아 진입
4. "멤버"로 이동
5. "청강생"으로 이동
6. "청강생 설정" 클릭

### 3. 청강생 삭제
"권한 관리" 권한이 있는 하위 계정이 필요합니다.

청강생 삭제.

## 편입 학생 관리

### 1. 편입 학생이란?
편입 학생이란 클래스에 소속되지 않은 학생으로, 교무 담당자에 의해 특정 클래스의 특정 수업에 참여하도록 배정된 학생을 말합니다.

### 2. 편입 학생 추가

**대상**
- "관리자 백엔드" 마스터 계정
- "클래스 관리" 권한이 있는 하위 계정

**이런 경우에**
교사가 학생에게 특정 수업을 체험시키고 싶고, 교실 내에서 교사 및 다른 학생과 교류할 수 있도록 하고 싶지만 실제 클래스에는 추가하고 싶지 않을 때, 해당 학생을 그 수업의 편입 학생으로 추가할 수 있습니다.

**사용 설명**
"편입 학생"이란 클래스에 소속되지 않은 학생으로, 교무 담당자에 의해 특정 클래스의 특정 수업에 참여하도록 배정된 학생을 말합니다. 편입 학생은 클래스 그룹이 없어 클라이언트의 클래스 그룹에서 교사가 내는 과제, 퀴즈, 채팅에 참여할 수 없습니다. 다만 편입 학생은 편입된 수업의 교실에는 입장할 수 있으며, 교실 내에서는 다른 학생과 동일한 권한(무대 발언, 교사의 도구 사용 권한 부여, 교실 내 채팅 참여 등)을 가집니다.

**유의사항**
- 이미 클래스에 정식 소속된 학생은 해당 클래스 내 어떤 수업에도 편입 학생으로 추가될 수 없습니다.
- 편입 학생과 클래스 학생은 동일한 클래스 인원 상한을 공유합니다.

**관련 문서**
- "관리자 백엔드에 하위 계정 추가"

**조작 방법**
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "클래스 관리"로 이동
3. 클래스를 찾아 진입
4. "시간표"로 이동
5. 수업을 찾아 오른쪽 "편입 학생" 항목의 "추가" 버튼 클릭
6. 자교 내 학생·교사 또는 타교 인원을 편입 학생으로 추가 가능

### 3. 편입 학생 삭제
수업을 찾아 오른쪽의 편입 학생 위치에 마우스를 올리면 연필 아이콘이 나타나며, 클릭하여 삭제할 수 있습니다. 일괄 삭제 또는 개별 삭제를 지원합니다.

## 클래스 학생 관리(백엔드)

### 1. 클래스 학생 추가

**대상**
- "관리자 백엔드" 마스터 계정
- "클래스 관리" 권한이 있는 하위 계정

**사용 설명**
관리자 백엔드에서 교무 담당자는 ClassIn 가입 여부와 관계없이 어떤 학생이든 클래스에 추가할 수 있습니다. 학생이 이미 ClassIn에 가입되어 있고 백엔드 학생 목록에 추가되어 있다면, 교무 담당자는 학생 이름이나 전화번호로 검색해 쉽게 찾아 클래스에 추가할 수 있습니다. 학생이 백엔드 학생 목록에 없거나 아직 ClassIn 계정을 등록하지 않은 경우, 교무 담당자는 대리 등록을 통해 학생을 클래스에 추가하고 ClassIn 계정 등록을 대신 완료할 수 있습니다.

**관련 문서**
- "청강생 관리"
- "편입 학생 관리"
- "관리자 백엔드에 하위 계정 추가"

**조작 방법**
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "클래스 관리"로 이동
3. 클래스를 찾아 클래스 이름을 클릭해 진입
4. "멤버"로 이동
5. "클래스 학생 설정" 클릭

### 2. 다른 클래스의 학생 복사

**대상 및 이런 경우에**
관리자 백엔드에서 어떤 클래스의 수업 수가 상한에 도달해 교사가 계속 수업을 추가해야 하는 경우, 새 클래스를 생성해야 합니다. 새로 생성한 클래스에서 모든 학생을 다시 수동으로 추가하는 수고를 덜기 위해, 시스템은 기존 클래스의 모든 학생을 새 클래스로 직접 복사하는 기능을 제공하여 시간과 노력을 절약하고 업무 효율을 높입니다.

**유의사항**
- 클래스에 이미 학생이 있는 경우, 다른 클래스의 학생 명단을 복사하면 현재 클래스의 기존 학생 전원이 교체됩니다. 조작 시 각별히 주의하세요.

**조작 방법**
1. "클래스 학생 복사" 클릭

### 3. 클래스 학생 수정
교무 담당자가 클래스 내 학생 구성원을 변경해야 할 때는 클래스 학생 목록에서 직접 수정할 수 있습니다.
- 오른쪽 상단에서 학생 추가 또는 삭제

### 4. 클래스 학생 삭제
학생 개별 삭제 또는 여러 명 선택 후 일괄 작업에서 일괄 삭제를 선택합니다.

## 공개 수업 생성/수정/삭제(백엔드)

### 1. 공개 수업 생성

**대상**
- "관리자 백엔드" 마스터 계정
- "공개 수업" 권한이 있는 하위 계정

**이런 경우에**
클래스에 속하지 않는 수업(학급 회의, 학부모 상담, 명강사 특강, 교사 세미나 등)을 만들고 싶다면 공개 수업 생성을 고려해 보세요. 다양한 교육 시나리오에 더 유연하게 대응할 수 있습니다.

**사용 설명**
관리자 백엔드에서 공개 수업을 생성하면 소프트웨어에도 대응하는 공개 수업이 자동으로 생성됩니다. 마찬가지로 소프트웨어에서 공개 수업을 생성하면 관리자 백엔드에도 대응하는 공개 수업 코스가 생성됩니다. 두 공개 수업은 완전히 동일하며 차이가 없습니다.

**조작 방법**
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "공개 수업"으로 이동
3. "공개 수업 생성" 클릭
4. 파라미터 설정

### 2. 공개 수업 수정
"클래스 관리" 권한이 있는 하위 계정이 필요합니다.
1. 공개 수업을 찾는다
2. 수정하려는 파라미터에 마우스를 올려 오른쪽에 연필 아이콘이 나타나면 클릭해 해당 항목 수정

### 3. 공개 수업 삭제
1. 오른쪽의 "작업" 클릭 후 "공개 수업 삭제" 선택

## 태그 관리

### 대상
- "관리자 백엔드" 마스터 계정
- "권한 관리" 권한이 있는 하위 계정

### 이런 경우에
관리자 백엔드에서 태그의 주요 역할은 교무 담당자가 수업, 세션, 교사/학생 멤버를 더 편리하게 관리할 수 있도록 돕는 것입니다. 태그를 사용하면 교무 담당자는 태그를 기준으로 수업, 세션, 멤버를 분류하고 찾아 더 빠르게 검색할 수 있습니다. 이는 관리 업무의 효율성과 편의성을 높여줍니다.

### 사용 설명
관리자 백엔드에서 태그 총 개수 상한은 2000개이며, 각 수업과 세션, 각 교사와 학생의 개인 태그 수 상한은 각각 10개입니다.

### 관련 문서
- "관리자 백엔드에 하위 계정 추가"

### 조작 방법

**(1) 수업 태그 정보 추가/수정**
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "수업 관리"로 이동
3. 오른쪽의 "수업 생성" 클릭
4. 아래에서 "수업 태그 선택" 클릭
5. 새 태그 생성 또는 기존 태그 선택
6. "확인" 클릭해 저장

**(2) 세션 태그 정보 추가/수정**
1. 수업을 찾아 수업명을 클릭해 세션 상세로 진입
2. "세션 추가" 클릭
3. "세션 태그 선택" 클릭

## 듀얼 티처 수업 생성/수정/삭제

### 1. 듀얼 티처 수업 생성

**대상**
- "관리자 백엔드" 마스터 계정
- "권한 관리" 권한이 있는 하위 계정

**사용 설명**

**방법 1: 새 《클래스》를 생성하고 《메인 세션/서브 세션》 추가**
교무 담당자가 관리자 백엔드에서 듀얼 티처의 메인 세션을 아직 생성하지 않은 경우, 다음과 같이 진행합니다. 먼저 관리자 백엔드에서 새 클래스를 생성합니다. 이어서 해당 클래스에 세션을 하나 추가합니다. 그런 다음 서브 세션을 일괄 추가하고, 새로 만든 세션을 메인 세션으로 설정합니다.

**방법 2: 기존 《세션》을 《메인 세션》으로 설정하고 《서브 세션》 추가**
교무 담당자는 관리자 백엔드에서 클래스에 직접 진입해 "서브 세션 일괄 생성"을 클릭한 후, 기존 세션을 듀얼 티처의 메인 세션으로 설정하고 서브 세션을 추가할 수도 있습니다.

**유의사항**
- 듀얼 티처 기능은 고객 매니저에게 연락해 별도로 활성화해야 합니다.
- 듀얼 티처 메인 세션당 최대 100개의 서브 세션을 생성할 수 있습니다.
- 메인 세션 시작까지 5분 미만이거나 이미 시작 시간이 지난 경우 서브 세션을 생성할 수 없습니다.
- "소프트웨어"와 "관리자 백엔드 시스템" 모두에서 메인 세션 편집/삭제가 가능하며, 변경 사항은 서브 세션에 자동으로 동기화됩니다.
- 서브 세션 설정은 "소프트웨어"에서는 수정할 수 없으며 "관리자 백엔드 시스템"에서만 수정 가능합니다.
- 듀얼 티처 수업은 별도의 클래스를 새로 만들 필요 없이 기존 클래스로도 진행할 수 있습니다.
- 메인 세션과 서브 세션은 동일한 클래스 내에 존재할 수 없습니다.

**관련 문서**
- "관리자 백엔드에 하위 계정 추가"

**조작 방법**

**"메인 세션" 신규 생성**
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "클래스 관리"로 이동
3. 클래스를 찾아 진입
4. "시간표"로 이동
5. "신규" 클릭
6. "세션 생성" 선택

**"서브 세션" 추가**
1. 세션 선택(선택된 세션은 자동으로 메인 세션이 됨)
2. "서브 세션 일괄 추가" 클릭
3. 서브 세션의 관련 파라미터 설정(서브 세션을 담을 빈 클래스를 미리 생성해 두어야 하며, 서브 세션 생성 시 이 미리 생성한 빈 클래스에 귀속시킴)

### 2. 듀얼 티처 수업 수정
서브 세션 수정 시 시작일, 시작 시간, 세션 길이, 담당 교사는 수정할 수 없습니다.
- 서브 세션은 "관리자 백엔드"에서만 수정 가능합니다.
- 메인 세션은 "관리자 백엔드"와 "소프트웨어" 모두에서 수정 가능합니다.

**"메인 세션" 또는 "서브 세션" 수정**
1. 메인 세션 또는 서브 세션이 속한 클래스를 찾아 진입
2. 세션 수정

### 3. 듀얼 티처 수업 삭제
교무 담당자는 관리자 백엔드에서 메인 세션과 서브 세션을 삭제할 수 있습니다. 먼저 해당 메인 세션을 찾습니다. 메인 세션의 온라인 듀얼 티처 페이지에서 서브 세션을 삭제합니다. 메인 세션을 삭제하면 모든 서브 세션이 자동으로 삭제됩니다. 특정 서브 세션만 삭제하려면 해당 서브 세션만 삭제하면 다른 서브 세션에는 영향이 없습니다.

메인 세션을 삭제하면 해당 메인 세션과 연결된 모든 서브 세션도 자동으로 삭제됩니다.

1. 왼쪽 내비게이션에서 "수업 관리"로 이동
2. 메인 세션이 속한 클래스를 찾아 진입
3. 메인 세션 오른쪽의 "작업" 클릭 후 "온라인 듀얼 티처" 선택
4. 메인 세션 또는 서브 세션 삭제

| 클래스 교실 설정 | 클래스 전용 커스텀 교실 설정 선택. 이 설정은 클래스 내 모든 "세션"에 적용됨. 미선택 시 학교가 설정한 "기본 커스텀 교실 설정"이 적용됨 |
| 클래스 태그 | 클래스에 태그를 추가해 관리와 검색을 용이하게 함 |
| 클래스 만료일 | 클래스 만료일 설정. 만료일 도달 시 해당 클래스에 시작 전이거나 진행 중인 "세션"이 없으면 시스템이 자동으로 해당 클래스를 종료함.<br><br>참고: 수업은 기본적으로 무기한으로 설정됩니다. 자동 종료가 필요한 경우, 마지막 세션 종료 후 며칠(최소 1일, 최대 365일)을 종료 시점으로 설정할 수 있습니다. |
| 클래스 재생 시청 제한 | 학생이 녹화 재생을 시청할 수 있는 횟수 설정(최소 1회, 최대 20회. 영상 전체 재생 시간의 75% 이상을 시청하면 1회의 유효 시청으로 간주) |
| 고급 설정 | "학생의 자발적 클래스 참여 허용", "클래스 멤버 간 친구 추가 허용", "교사의 세션/수업 추가 허용", "학생의 클래스 닉네임 수정 허용", "클래스 탈퇴 후 또는 클래스 해산 후에도 클래스 내용 열람 허용", "클래스 멤버의 임시 교실 시작 허용" 등의 기능을 켜거나 끌 수 있음. 담임교사도 ClassIn 소프트웨어 내 클래스에서 이를 설정 가능 |

**유의사항**

- "세션 추가"

### 2. 클래스 수정

**대상**
- "관리자 백엔드" 마스터 계정
- "클래스 관리" 권한이 있는 하위 계정

**사용 설명**
사용자는 ClassIn "관리자 백엔드"에서 이미 생성된 클래스를 수정할 수 있습니다. 수정 가능한 내용에는 클래스 이름, 클래스 커버, 클래스 소개, 담임교사, 클래스 클라우드 드라이브 리소스, 클래스 교실 설정, 클래스 태그, 클래스 만료일, 클래스 재생 시청 제한, 고급 설정이 포함됩니다. 고급 설정에는 학생의 자발적 클래스 참여 허용 여부, 클래스 멤버 간 친구 추가 허용 여부, 교사의 세션 추가 허용 여부, 학생의 클래스 닉네임 수정 허용 여부, 탈퇴/해산 후 클래스 내용 열람 허용, 클래스 멤버의 임시 교실 시작 허용 등의 옵션이 포함됩니다. 담임교사도 ClassIn 소프트웨어에서 이러한 옵션을 수정할 수 있습니다.

참조: "종료"

**조작 방법**
1. 관리자 백엔드에 로그인
2. "클래스 관리"로 이동
3. 클래스를 찾아 진입
4. "설정"으로 이동해 클래스 수정

### 3. 클래스 종료

**"종료"란?**
"종료"란 교무 담당자가 ClassIn 관리자 백엔드 시스템에서 특정 클래스를 종료 처리하는 것을 말하며, 이에 대응하는 ClassIn 소프트웨어 내 클래스도 동시에 해산됩니다. 반대로 ClassIn 소프트웨어에서 클래스가 해산되면 시스템은 자동으로 관리자 백엔드 시스템 내 대응 수업을 종료 처리합니다. 따라서 "종료"와 "클래스 해산"은 같은 의미이며, 하나는 백엔드 관리 시스템에서, 다른 하나는 ClassIn 소프트웨어에서 수행하는 조작입니다.

**이런 경우에**
교무 담당자가 ClassIn 소프트웨어에서 클래스를 해산하고 싶지만 해당 클래스의 담임교사가 아닌 경우, 소프트웨어 내에서 조작할 수 없습니다. 이 경우 교무 담당자는 "관리자 백엔드 시스템"에 로그인해 해당 클래스를 찾아 종료할 수 있습니다. 클래스가 종료되면 대응하는 ClassIn 소프트웨어 내 클래스도 해산됩니다.

"관리자 백엔드"의 "종료"와 소프트웨어의 "클래스 해산"은 동일한 것을 의미합니다. "관리자 백엔드"에서 "종료" 작업을 하면 소프트웨어 내 대응 클래스도 "해산"됩니다. 반대로 소프트웨어에서 클래스가 "해산"되면 "관리자 백엔드"의 대응 클래스도 "종료"됩니다. 다만 수업 내에 아직 시작하지 않았거나 종료되지 않은 세션이 있는 경우 "종료" 작업을 할 수 없습니다. 클래스가 종료되면 클래스 내 학생과 교사는 클래스 그룹을 통한 소통을 할 수 없게 됩니다. 다만 이는 클래스 내 녹화 재생 시청에는 영향을 주지 않습니다.

종료 후에도 학생이 클래스 내 과거 재생 영상을 계속 시청할 수 있게 하려면 《클래스 탈퇴 후 또는 클래스 해산 후에도 클래스 내용 열람 허용 설정》 기능을 활성화하세요.

클래스는 삭제할 수 없으며 종료만 가능합니다.

**(1) 단일 클래스 종료**
1. 왼쪽 내비게이션에서 "클래스 관리"로 이동
2. 클래스를 찾아 오른쪽 "종료" 클릭

**(2) 일괄 종료**
1. 여러 클래스를 선택하고 "일괄 작업" 클릭 후 "일괄 종료" 선택
