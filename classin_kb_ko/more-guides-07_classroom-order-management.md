## 수업 질서 관리

## 1. 학교 관리 방안

### 1) 학교 관리(관리자)

#### 1.1 불법 녹화 방지 기능 켜기

1.1.1 사용자 지정 강의실 수정하기

ClassIn 백오피스에 로그인해 왼쪽에서 "시스템 설정"으로 이동하고 "강의실 설정"을 선택한 후, 아래의 "사용자 지정 강의실 설정" 항목에서 이미 활성화된 사용자 지정 강의실을 수정하거나 새 사용자 지정 강의실을 만듭니다.

1.1.2 전광판 켜기

사용자 지정 강의실 설정을 연 후 "스위치 설정"으로 이동해 7번째 항목 "학생·참관생 강의실 전광판 설정"을 찾아, "학생이 강의실에 입장한 후, 해당 학생의 닉네임과 전화번호가 강의실 내에서 무작위로 움직입니다"에 체크합니다.

팁: 이는 불법 녹화·유출 방지 억제책입니다. 닉네임과 전화번호가 움직이면 수업 내용을 화면 녹화나 스크린샷으로 무단 촬영하기 어려워지며, 설령 촬영되더라도 어느 학생에 의한 것인지 추적하기 쉬워집니다.

#### 1.2 강의실 채팅창 숨기기

1.2.1 사용자 지정 강의실 수정하기: ClassIn 백오피스에 로그인해 왼쪽에서 "시스템 설정"으로 이동하고 "강의실 설정"을 선택한 후, 아래의 "사용자 지정 강의실 설정" 항목에서 이미 활성화된 사용자 지정 강의실을 수정하거나 새 사용자 지정 강의실을 만듭니다.

1.2.2 채팅창 숨기기: 사용자 지정 강의실 설정을 연 후 "스위치 설정"으로 이동해 2번째 항목 "채팅창 설정"을 찾아 "채팅 버튼 숨기기"에 체크합니다. 팁: 학교 전체에서 채팅창을 비활성화하면 수업 중 학생의 무질서한 텍스트 발언이나 채팅을 효과적으로 방지할 수 있습니다. 학교 전체 규모의 회의나 행사에 적합합니다.

### 2) 반 관리(담임교사)

#### 2.1 반 참여 입구 닫기

반에 들어가 반 그룹 오른쪽 상단에서 반 설정으로 이동한 후, "반 관리"로 이동해 "반 가입 개방"과 "공유 페이지에 반 참여 입구 표시" 기능을 끕니다.

#### 2.2 반 그룹 발언 관리하기

2.2.1 특정 학생 채팅 금지하기

반에 들어가 반 그룹 오른쪽 상단에서 반 설정으로 이동해, "반 구성원"에서 채팅을 금지하려는 학생을 마우스 오른쪽 버튼으로 클릭해 "채팅 금지"를 선택합니다.

2.2.2 전체 학생 채팅 금지하기

반에 들어가 반 그룹 오른쪽 상단에서 반 설정으로 이동해 "전체 학생 채팅 금지"에 체크합니다.

#### 2.3 반 그룹 메시지 숨기기

반에 들어가 숨기려는 메시지를 마우스 오른쪽 버튼으로 클릭해 "숨기기"를 선택합니다.

#### 2.4 반 학생 실명제

반에 들어가 반 그룹 오른쪽 상단에서 반 설정으로 이동해, "반 구성원"에서 학생을 마우스 오른쪽 버튼으로 클릭해 "반 닉네임 수정"을 선택합니다.

#### 2.5 반에서 학생 삭제하기

반에 들어가 반 그룹 오른쪽 상단에서 반 설정으로 이동해, "반 구성원"에서 학생을 마우스 오른쪽 버튼으로 클릭해 "구성원 삭제"를 선택합니다.
