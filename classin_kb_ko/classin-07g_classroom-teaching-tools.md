## 교육 도구

## 1. 클릭 도구

### 클릭 도구란?
"클릭 도구"는 마우스 모드라고도 하며, 강의실 도구 중 자주 사용되는 도구 중 하나입니다. 교사는 클릭 도구를 이용해 PPT 교재의 애니메이션 효과를 실행하거나, PPT 교재에 삽입된 오디오와 동영상을 재생하거나, 브라우저 내 웹페이지 콘텐츠를 클릭할 수 있습니다. 또한 클릭 도구는 가상 "화학 실험실"과 "물리 실험실" 내 장비 조작에도 사용됩니다. 교사가 "학생 화면 공유" 도구를 사용할 때, 클릭 도구로 학생 바탕화면의 파일 조작을 제어할 수도 있습니다. 클릭 도구를 사용하면 교사는 더 유연하고 효율적으로 수업을 진행할 수 있어, 교육 효과를 높일 수 있습니다.

### 대상
담당 교사, 조교사, 권한 부여된 학생.

## 2. 선택/이동

### 선택/이동 도구란?
"선택/이동" 도구는 강의실 도구 중 자주 사용되는 도구 중 하나입니다. 사용자는 이 도구를 이용해 칠판 위 다양한 요소(이미지, 도형, 텍스트 등)에 대해 단일 선택, 다중 선택, 이동 작업을 할 수 있습니다. 칠판 요소를 선택하면 해당 요소 아래에 "2차 편집" 기능 바가 팝업됩니다. 사용자는 이 기능 바의 단축키를 이용해 선택된 요소를 수정·조정할 수 있습니다.

### 사용 설명
"선택/이동" 도구를 사용할 때, 강의실 내 이미지, 텍스트, 도형 등의 요소를 단일 선택하거나 다중 선택할 수 있으며, 이 요소들에 대한 2차 편집도 지원합니다. 【영역 선택 모드】는 칠판에 사각형을 그려 그 안의 모든 요소를 선택할 수 있습니다. 【자유 선택 모드】는 자유롭게 불규칙한 올가미를 그려 그 안의 요소를 선택할 수 있습니다.

"선택/이동" 도구의 "2차 편집" 기능을 사용할 때는 먼저 칠판의 요소를 클릭하면, 선택된 요소 아래에 선택된 요소를 2차 수정할 수 있는 기능 바가 나타납니다. 사용자는 이 기능 바에서 제공하는 기능을 이용해 현재 선택된 요소를 2차 수정·편집할 수 있습니다.

칠판의 여러 요소를 동시에 선택한 경우, 여러 요소의 색상을 동시에 변경할 수도 있습니다.

**(1) 이미지 요소에서 지원하는 2차 수정:**

| 기능 | 설명 |
| --- | --- |
| 배경 제거 | 2차 편집 기능 내 배경 제거 기능을 통해, 이미지 속 대상 물체를 원본 이미지에서 분리해 배경을 투명하게 만듭니다. |
| 이미지 위치 잠금 | 칠판 내 이미지를 특정 위치에 고정해, 실수로 드래그되거나 삭제되는 것을 방지합니다. 잠금 해제 후에야 잠긴 이미지를 이동·수정·삭제할 수 있습니다. |
| 이미지 크기 조절 | 칠판 내 이미지의 크기를 변경합니다. |
| 이미지 레이어 조절 | 칠판 내 이미지의 표시 레이어를 조절합니다. 여러 이미지, 도형, 텍스트가 칠판의 같은 위치에 있을 때, 레이어가 높은 이미지가 맨 앞에 표시되어 다른 요소에 가려지지 않습니다. |
| 이미지 복제 | 칠판 내 이미지를 여러 개 복사해 칠판에 배치합니다. |
| 이미지 삭제 | 칠판 내 이미지를 칠판에서 삭제하는 것을 말합니다. |

**(2) 도형 요소에서 지원하는 2차 수정:**

| 기능 | 설명 |
| --- | --- |
| 도형 테두리 색상 수정 | 도형의 테두리 색상을 변경해 다른 요소와 구분되어 눈에 띄도록 합니다. |
| 도형 채우기 색상 추가·수정 | 칠판에서 채우기 색상이 설정되지 않은 도형에 채우기 색상을 추가합니다. 이미 채우기 색상이 설정된 도형의 색상 수정도 포함됩니다. |
| 도형 위치 잠금 | 칠판 내 도형을 특정 위치에 고정해, 실수로 드래그되거나 삭제되는 것을 방지합니다. 잠금 해제 후에야 잠긴 도형을 이동·수정·삭제할 수 있습니다. |
| 도형 크기 조절 | 칠판 내 도형의 크기를 변경합니다. |
| 도형 레이어 조절 | 칠판 내 도형의 표시 레이어를 조절합니다. 레이어가 높은 도형이 맨 앞에 표시되어 다른 요소에 가려지지 않습니다. |
| 도형 복제 | 칠판 내 도형을 여러 개 복사해 칠판에 배치합니다. |
| 도형 삭제 | 칠판 내 도형을 칠판에서 삭제합니다. |

**(3) 텍스트 요소에서 지원하는 2차 수정:**

| 기능 | 설명 |
| --- | --- |
| 텍스트 크기 수정 | 칠판 내 텍스트의 글자 크기를 수정합니다. |
| 텍스트 색상 수정 | 칠판에 이미 입력된 텍스트의 색상을 변경합니다. |
| 텍스트 위치 잠금 | 칠판 내 텍스트를 특정 위치에 고정해, 실수로 드래그되거나 삭제되는 것을 방지합니다. 잠금 해제 후에야 잠긴 텍스트를 이동·수정·삭제할 수 있습니다. |
| 텍스트 레이어 조절 | 칠판 내 텍스트의 표시 레이어를 조절합니다. 여러 이미지, 도형, 텍스트가 칠판의 같은 위치에 있을 때, 레이어가 높은 텍스트가 맨 앞에 표시되어 다른 요소에 가려지지 않습니다. |
| 텍스트 복제 | 칠판 내 텍스트를 여러 개 복사해 칠판에 배치합니다. |
| 텍스트 삭제 | 칠판 내 텍스트를 칠판에서 삭제합니다. |

2. 칠판 내 요소를 "단일 선택" 또는 "다중 선택"합니다.
3. 요소 선택 후 요소를 "이동"하거나 "2차 수정"할 수 있습니다.

## 3. 펜

### 이런 경우에
펜 도구는 강의실에서 자주 사용되는 교육 도구 중 하나로, 기능이 풍부해 사용자가 칠판, 교재, 이미지에 표시, 필기, 그림을 그릴 수 있게 해줍니다. 정원, 타원, 정사각형, 직사각형, 불규칙 삼각형, 정삼각형, 직선, 곡선 등 다양한 도형 그리기와 텍스트 작성을 지원합니다.

사용자는 일반 펜이나 형광펜을 선택해 사용할 수 있습니다. 일반 펜은 분필과 비슷한 효과를 내며, 형광펜은 반투명 효과를 내 텍스트, 교재, 이미지의 핵심 부분을 표시하기에 적합합니다. 또한 사용자는 실선이나 점선 효과도 선택할 수 있습니다.

펜 도구는 사용자가 색상과 굵기를 자유롭게 조절하는 것도 지원해, 다양한 그리기와 표시 요구를 충족합니다. 사용자에게 펜 도구는 수업 상호작용과 효과를 크게 높여줍니다.

사용자가 "곡선" 모드를 선택하고 칠판에 불규칙한 도형(원형, 사각형, 가로세로선, 삼각형 등)을 그리면, 시스템은 사용자가 그리기를 마치고 약 1.5초 후 자동으로 도형을 인식합니다. 인식에 성공하면 시스템은 사용자가 그린 불규칙한 도형을 정형 도형으로 변환합니다.

**(1) 펜 모드와 단축키:**

**곡선 모드:** Shift 키를 누른 채로 직선을 그릴 수 있습니다.

**직선 모드:** Shift 키를 누른 채로 수평 직선을 그릴 수 있습니다.

**사각형 모드:** Shift 키를 누른 채로 정사각형을 그릴 수 있습니다.

**원형 모드:**
- Shift 키를 누른 채로 정원을 그릴 수 있습니다.
- Ctrl 키를 누른 채로 펜을 내린 지점을 중심으로 원을 그릴 수 있습니다.
- Shift+Ctrl 키를 누른 채로 펜을 내린 지점을 중심으로 정원을 그릴 수 있습니다.

**단축키:**

Alt 키를 누른 채로 숫자 키패드의 "1", "2", "3", "4"를 누르면 각각 펜을 "곡선", "직선", "원형", "사각형" 모드로 전환할 수 있습니다.

Alt 키를 누른 채로 알파벳 키 "q", "w", "e", "r", "a", "s", "d", "f", "z", "x", "c", "v"를 누르면 펜 색상을 변경할 수 있습니다.

Ctrl 키를 누른 채로 Z 키를 누르면 직전 그리기 동작을 취소할 수 있습니다.

참고: 서로 다른 소프트웨어와 운영체제에서는 단축키와 설정 방법이 다를 수 있습니다. 위 조작은 일반적인 경우만을 설명한 것이며, 실제 조작 시에는 사용 중인 소프트웨어와 운영체제의 요구 사항에 따라 진행해 주세요. (Windows 컴퓨터의 "Ctrl" 키는 Mac 컴퓨터의 "Command" 키에, Windows 컴퓨터의 "Alt" 키는 Mac 컴퓨터의 "Option" 키에 대응합니다.)

형광펜 모드에서는 펜이 기본적으로 실선이며 점선으로 전환할 수 없습니다. 펜 모양은 기본적으로 곡선이며 선택하거나 변경할 수 없습니다.

이미 칠판에 그려진 도형은 단축키로 색상을 수정할 수 없으며, 2차 편집 기능으로만 색상을 수정할 수 있습니다.

자동으로 정형 도형으로 변환된 도형은 Ctrl+Z로 이전 상태로 되돌릴 수 없습니다.

교사나 학생이 강의실에서 펜 도구를 사용해 그리거나 필기할 때, 강의실 내 모든 사람이 그 과정을 실시간으로 볼 수 있습니다.

## 9. LMS

## 대상
## 이런 경우에
강의실의 학습 관리 시스템(LMS)은 강의실에서 자주 사용되는 도구 중 하나입니다. LMS를 통해 교사는 수업 중 과제, 시험, 답안지를 배포하고 학생이 제출한 내용을 제때 채점할 수 있습니다. 또한 강의실 내 과제, 시험, 답안지 데이터는 반 외부 데이터와도 매끄럽게 연동되어 교육 관리 편의성이 높아집니다. 교사는 LMS를 이용해 방과 후 과제를 배포하고 수업 과정에서 즉시 채점해 실시간 피드백을 제공할 수도 있습니다. 이 기능은 교육 효율과 학생의 학습 경험을 크게 향상시킵니다.

## 유의사항
아이폰, 안드로이드 휴대폰, 안드로이드 태블릿에는 강의실 내 LMS 기능이 없습니다.

## 10. 수업 노트

전체 사용자.

수업 노트는 강의실에서 자주 사용되는 도구 중 하나로, 수업 노트의 주요 기능은 스크린샷을 통해 수업 중 중요한 노트와 하이라이트 순간을 기록하는 것입니다. 강의실 내 교재(PDF, PPT, Word 등)의 주석과 해설 저장을 지원하며, 이미 저장된 이미지를 2차 편집하거나 텍스트 설명을 추가할 수도 있어, 핵심 지식 포인트를 더 명확하게 표현하고 기록할 수 있습니다. 동시에 수업 노트 도구는 강의실에서 노트 이미지를 로컬로 다운로드해 저장하고 공유하는 것도 지원합니다.

각 노트 간 추가 간격은 10초입니다.

휴대폰과 태블릿에는 "수업 노트" 기능이 없습니다.

각 사용자는 동시에 최대 100장의 노트를 기록할 수 있습니다.

## 11. 채팅 도구

채팅 도구는 강의실에서 자주 사용되는 교육 도구 중 하나입니다. 채팅 도구에는 두 가지 주요 모듈이 있습니다: 채팅 모듈과 질문 모듈입니다. 채팅 모듈에서 교사와 학생은 자유롭게 텍스트를 입력해 발언할 수 있으며, 양측 모두 자신이 이미 보낸 메시지를 취소할 수 있습니다. 상대방 메시지의 번역도 지원됩니다. 또한 교사는 학생의 메시지 전송을 금지하거나, 학생이 이미 보낸 메시지를 삭제할 수 있는 권한도 있습니다. 질문 모듈에서 학생은 교사에게 질문할 수 있고, 교사는 학생의 질문을 확인하고 그에 맞는 답변을 할 수 있습니다.

수업이 끝나고 강의실을 나가면, 강의실 내 채팅창의 기록도 삭제되며 저장할 수 없습니다.

## 12. 출석부

#### 반 학생 영역
**무대 등장/퇴장:** 교사가 학생을 조작해 무대에 올려 카메라를 표시하게 하거나, 무대 아래로 내려 수업만 듣고 카메라를 표시하지 않게 합니다.

**권한 부여:** 학생에게 교육 도구 사용 권한을 부여하거나, 학생의 교육 도구 사용 권한을 해제합니다.

**채팅 금지:** 학생이 채팅창에서 타이핑으로 발언하는 것을 금지합니다.

**마이크:** 학생의 마이크를 음소거하거나 해제합니다.

**카메라:** 학생의 카메라 상태를 확인합니다.

**보상:** 학생에게 트로피를 지급합니다.

**손들기:** 학생의 손들기 상태를 확인합니다.

**개인 채팅:** 교사와 학생이 1V1 카메라 개인 채팅 강의실에 들어갑니다.

**내보내기:** 학생을 강의실에서 내보냅니다.

**다른 기기 확인:** 학생이 수업에 사용 중인 기기 유형을 확인합니다.

**로테이션:** 학생의 카메라를 순서대로 표시합니다.

#### 조교사 영역
**조교사 무대 등장/퇴장:** 담당 교사가 조교사를 초대해 무대에 올려 카메라를 표시하게 하거나, 무대 아래로 내려 카메라를 표시하지 않게 합니다(조교사 본인도 자신의 카메라 무대 등장/퇴장을 조작할 수 있습니다).
