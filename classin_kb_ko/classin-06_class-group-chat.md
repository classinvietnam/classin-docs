## 반 그룹 채팅

## 1. 반 메시지 보내기

### 대상
전체 반 구성원

### 이런 경우에
반 내 "채팅" 영역은 학생들이 강의실 밖에서 소통, 토론, 공유를 할 수 있는 공간입니다. 이곳에서 학생들은 코스와 관련된 주제, 학술적 질문, 개인적인 관심사에 대해 대화할 수 있고, 서로의 학습 경험과 자료를 공유할 수 있습니다. 이 영역의 목적은 학생들 간의 소통과 협력을 촉진해 학습과 개인의 성장을 돕는 것입니다.

### 사용 설명
반 내에서 구성원들은 반 채팅 그룹에서 다음과 같은 다양한 방식으로 소통할 수 있습니다:

**텍스트 메시지:** 교사와 학생이 텍스트를 입력해 반 그룹에서 소통하고 생각을 표현합니다.

**음성 메시지:** 교사와 학생은 휴대폰 ClassIn에서 음성으로 소통할 수 있어, 더 편리하고 빠릅니다.

**이미지 공유:** 교사와 학생은 반 그룹에 이미지를 보내 보여주거나 공유할 수 있습니다.

**파일 공유:** 교사와 학생은 컴퓨터나 휴대폰의 로컬 파일 또는 자신의 ClassIn 클라우드 드라이브 내 파일을 반 그룹으로 보낼 수 있어, 다른 반 구성원이 확인하고 다운로드하기 편리합니다.

**이모티콘:** 교사와 학생은 이모티콘을 사용해 반 그룹에서 감정을 표현하고 전달할 수 있어 소통에 감성적인 색채를 더할 수 있습니다.

### 유의사항
컴퓨터에서는 음성 메시지 보내기를 지원하지 않습니다.

새로 반에 참여한 사용자는 이전 채팅 기록을 볼 수 있습니다.

### 조작 방법

**컴퓨터**
1. 왼쪽 내비게이션에서 "메시지"로 이동합니다.
2. 메시지 목록에서 반을 찾아 들어갑니다.
3. 오른쪽의 "반 채팅 영역"으로 이동합니다.
4. 아래쪽에서 텍스트, 이모티콘, 다른 구성원 @멘션, 스크린샷 보내기, 파일 보내기, 친구 명함 보내기, 임시 강의실 개설을 할 수 있습니다.

## 2. 반 메시지 취소하기

대상: 전체 반 구성원

반 채팅 그룹에서 사용자가 잘못된 메시지를 보낸 경우, 메시지 취소 기능을 사용할 수 있습니다. 메시지 취소란, 일정 시간 내에 사용자가 이미 보낸 메시지를 취소해 반 채팅 그룹에 더 이상 표시되지 않도록 하는 것을 말합니다. 이 기능은 부정확하거나 부적절한 내용을 수정할 수 있는 편리한 수단을 제공합니다.

반 채팅 그룹 내 "담임교사"와 "교사"는 시간 제한 없이 언제든지 자신이 보낸 메시지를 취소할 수 있습니다.

반 채팅 그룹 내 학생은 24시간 이내에 자신이 보낸 메시지만 취소할 수 있으며, 이 시간을 초과하면 더 이상 취소할 수 없습니다.

1. 자신이 보낸 메시지를 마우스 오른쪽 버튼으로 클릭한 후 "취소"를 선택합니다.

## 3. 반 그룹 내 파일 전달·저장하기

반 채팅에서 자신 또는 다른 사람이 반으로 보낸 파일을 친구나 다른 반으로 전달하고 싶다면, 다중 선택 기능을 사용할 수 있습니다. 반 채팅 그룹에서 파일을 마우스 오른쪽 버튼으로 클릭하고 "다중 선택"을 선택한 후, 전달하고 싶은 항목에 체크하고 마지막으로 "하나씩 전달"을 클릭하면 됩니다. 반 내 여러 파일을 저장하고 싶다면, 다중 선택 기능을 사용해 저장하고 싶은 파일에 체크한 후 컴퓨터 로컬이나 개인 클라우드 드라이브에 저장할 수 있습니다.

컴퓨터 로컬이나 개인 클라우드 드라이브에 저장할 수 있는 것은 이미지, 동영상, 파일뿐입니다.

휴대폰이나 태블릿에서는 현재 채팅 그룹 내 파일의 다중 선택을 지원하지 않습니다.

1. 왼쪽 내비게이션에서 "메시지"로 이동합니다.
2. 전달하거나 저장하려는 이미지/파일을 마우스 오른쪽 버튼으로 클릭합니다.
3. "전달" 또는 "다른 이름으로 저장"을 선택합니다.

## 4. 반에서 학생 채팅 금지하기

대상: "담임교사"와 "교사"

이 기능은 주로 일부 학생이 반 내에서 부적절한 발언이나 이미지를 게시하거나, 학생이 반 내에서 임시 강의실을 만들어 반 질서를 어지럽히는 것을 방지하기 위해 사용되며, 반 질서의 정상적인 운영을 보장합니다. 부적절한 정보의 확산을 막기 위해, 교사는 반 설정에서 학생을 채팅 금지할 수 있습니다.

교사는 학생을 채팅 금지로 설정할 수 있으며, 채팅 금지된 학생은 반 그룹에 콘텐츠를 보낼 수 없습니다.

1. 구성원을 마우스 오른쪽 버튼으로 클릭합니다.
2. "채팅 금지"를 선택합니다.

## 5. 반 전체 학생 채팅 금지하기

반 내에서 학생의 부적절한 발언, 부적절한 주제 단체 발송 등의 행동이 발생하거나, 학생이 반에서 임의로 임시 강의실을 만들어 수업 질서를 파괴하는 경우, 반 교사는 반 설정에서 "반 전체 채팅 금지" 기능을 켜서 부적절한 발언의 확산을 막고 반 질서와 좋은 학습 분위기를 유지할 수 있습니다. 이 조치는 교사가 반 규율을 유지하고 학생의 학습 권익을 보장하는 데 도움이 됩니다.

교사는 특정 학생 한 명을 채팅 금지할 수도 있고, 반 전체 학생을 채팅 금지할 수도 있습니다. 채팅 금지된 학생은 반 그룹에 콘텐츠를 보낼 수 없습니다.

1. 왼쪽 내비게이션에서 "홈"을 클릭합니다.
2. 반을 찾아 들어갑니다.
3. 왼쪽 상단의 "반 이름"을 클릭합니다.
4. 반 설정에서 "반 관리"로 이동합니다.
5. "전체 학생 채팅 금지"를 켜거나 끕니다.

## 6. 반 채팅 기록

반 채팅의 여러 메시지를 친구나 다른 반으로 전달하고 싶다면, 다중 선택 기능을 사용할 수 있습니다. 반 채팅 그룹에서 메시지를 마우스 오른쪽 버튼으로 클릭해 "다중 선택"을 선택한 후, 전달하고 싶은 메시지에 체크하고 마지막으로 "하나씩 전달"을 클릭하면 됩니다.

채팅 기록은 저장할 수 없으며 전달만 가능합니다.

휴대폰이나 태블릿에서는 현재 채팅 그룹 내 채팅 기록의 다중 선택을 지원하지 않습니다.

1. "메시지"로 이동합니다.
2. "반 그룹"으로 이동합니다.
3. 메시지를 마우스 오른쪽 버튼으로 클릭합니다.
4. "다중 선택"을 선택합니다.
5. 메시지를 다중 선택한 후,
6. "전달", "다른 이름으로 저장", "클라우드 드라이브에 저장"을 클릭합니다.

## 7. 반 임시 강의실

반 임시 강의실은 임시 회의, 코스 토론, 보충 수업, 방과 후 소통 등 다양한 구체적인 요구를 충족할 수 있습니다.

반의 모든 구성원(교사와 학생 모두 포함)은 반 채팅 영역에서 임시 강의실을 만들 권한이 있습니다. 임시 강의실을 만든 교사나 학생은 해당 임시 강의실에서 담당 교사 역할을 맡으며, 다른 반 구성원(교사와 학생 모두 포함)은 학생 신분으로 임시 강의실에 참여해 수업을 듣습니다. 반 임시 강의실은 1대6 교육 모드만 지원하며, 담당 교사 1명과 학생 6명이 동시에 좌석에서 카메라 영상을 표시하고, 나머지 학생은 좌석 아래에서 수업을 듣습니다.

반 교사와 학생 모두 임시 강의실을 개설할 수 있습니다. 반 학생이 임의로 임시 강의실을 만드는 것을 금지해야 한다면, 반 교사는 반 설정에서 학생에게 《개별 채팅 금지》 또는 《전체 채팅 금지》 작업을 할 수 있으며, 채팅 금지된 학생은 반 채팅 영역에서 어떤 메시지도 보낼 수 없고 임시 강의실도 만들 수 없게 됩니다.

임시 강의실에는 "수업 노트" 기능이 없습니다.

임시 강의실의 초과 시간은 1~2분이며, 같은 사람이 임시 강의실을 만든 후에는 초과 시간이 끝날 때까지 기다려야 다시 임시 강의실을 만들 수 있습니다.
