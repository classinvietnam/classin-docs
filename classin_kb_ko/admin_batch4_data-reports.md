## 백엔드에서 AI 수업 분석 보고서 확인/다운로드

### 대상
- "관리자 백엔드" 마스터 계정
- "교사 개발" 권한이 있는 하위 계정

### 사용 설명
관리자 백엔드의 "부가가치 서비스"에서 AI 수업 분석 기능을 활성화한 후, 교무 담당자가 백엔드의 클래스에서 세션을 편성할 때 녹화(ClassIn 교실 녹화 또는 현장 녹화)와 AI 수업 분석을 체크하고, 담당 교사가 정상적으로 음성이 포함된 녹화를 진행하면 수업 후 해당 교사의 AI 수업 분석 보고서가 자동 생성됩니다.

담당 교사는 ClassIn에서 자신의 AI 수업 분석 보고서를 확인하고 다운로드할 수 있습니다.

관리자 백엔드의 교무 담당자는 "관리자 백엔드 - 교육 관리 - 교사 개발" 모듈에서 담당 교사의 수업 성과(전체 점수 및 유의해야 할 항목 포함)를 확인할 수 있으며, 각 세션의 상세 보고서를 확인·다운로드할 수 있습니다.

또한 백엔드에서는 이 보고서의 삭제도 지원하지만, 삭제 후에는 복구할 수 없습니다. 삭제 후 담당 교사는 ClassIn 수업 재생에서 AI 수업 분석 섹션을 볼 수 없게 되며, 교무가 백엔드의 "교사 개발"에서 AI 수업 분석 점수와 유의 항목을 확인하려 하면 "보고서가 삭제되었습니다"라고 표시됩니다.

### 관련 문서
- "관리자 백엔드에 하위 계정 추가"

### 조작 방법
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "교사 개발"로 이동
3. 세션을 찾는다
4. 오른쪽의 "작업" 클릭 후 "보고서 보기" 또는 "보고서 다운로드" 선택

## 백엔드에서 세션 데이터 내보내기

### "세션 데이터"란?
"세션 데이터"란 교실 내 교육 도구 사용과 상호작용에서 생성되는 각종 데이터 통계를 말하며, 교사와 학생의 출석 현황 및 행동 분석을 포함합니다. "세션 데이터"는 두 섹션으로 나뉘며, "강의 분석" 섹션은 교사의 수업 중 성과 데이터를, "학습 분석" 섹션은 학생의 수업 중 학습 행동 데이터를 통계합니다.

### 대상
- "관리자 백엔드" 마스터 계정
- "권한 관리" 권한이 있는 하위 계정

### 이런 경우에
교사가 수업 출석 및 행동 데이터 통계를 PC에 다운로드하고 싶을 때, 세션 데이터에서 필요한 데이터를 필터링해 Excel 표로 내보낼 수 있습니다.

### 사용 설명

**강의 분석**

"세션 데이터"의 "강의 분석" 페이지에서는 특정 교사나 수업 시간의 데이터를 분석할 수 있습니다. 이 데이터에는 교사의 출석 현황, 자료 사용 평균 수량 및 시간, 평균 보상 횟수, 손들기 횟수, 권한 부여 횟수, 기타 교육 도구 사용 횟수 등이 포함됩니다. 또한 다양한 기능의 사용 횟수와 누적 시간을 꺾은선 그래프로 표시할 수 있습니다. "수량/횟수"와 "누적 시간"은 꺾은선 그래프 왼쪽 상단의 "그래프 커스텀 가이드"에서 수동으로 전환할 수 있습니다.

각 수업의 데이터를 확인·다운로드하고 싶다면 "강의 분석" 페이지 맨 아래에서 구체적인 데이터를 확인·다운로드할 수 있습니다. 포함되는 데이터: 각 세션별 교사의 누적 수업 시간, 각 세션별 교사의 출석 현황, 각 세션별 교실 내 학생 출석 현황(청강생 제외), 각 세션별 학생의 담당 교사 평가 및 코멘트, 교사의 각 세션별 학생 평가 및 코멘트, ClassIn 소프트웨어에서 수업 재생을 시청한 학생 총수, 전체 학생의 ClassIn 수업 재생 평균 시청 시간, 각 세션의 재생 영상 총 시간, 각 세션별 교사의 텍스트 자료(Word, PowerPoint, PDF 및 각종 문서) 사용 수량·시간 통계, 각 세션별 교사의 음성·영상 자료 사용 수량·시간 통계, 각 세션별 교사의 전체 음소거 횟수·시간 통계, 각 세션별 교사의 학생 퇴장 조치 횟수·인원수 통계, 각 세션별 교사의 학생 보상 횟수·인원수 통계, 각 세션별 학생 손들기 횟수·인원수 통계, 각 세션별 권한이 부여된 학생의 도구 사용 횟수·인원수·시간 통계, 각 세션별 교사의 "화면 공유" 도구 사용 횟수·시간 통계, 각 세션별 교사의 "타이머" 도구 사용 횟수 통계, 각 세션별 교사의 "주사위" 도구 사용 횟수 통계, 각 세션별 교사의 "빨리 누르기" 도구 사용 횟수 통계, 각 세션별 교사의 "응답기" 도구 사용 횟수·정답률·상세 통계, 각 세션별 교사의 "미니 칠판" 도구 사용 횟수·시간·상세 통계, 각 세션별 교사의 "텍스트 협업" 도구 사용 횟수·시간 통계, 각 세션별 교사의 "다중 화면 공유" 도구 사용 횟수·시간 통계, 각 세션별 교사의 "브라우저" 도구 사용 횟수·시간 통계, 각 세션별 교사의 "과제" 도구 사용 횟수 통계, 각 세션별 교사의 "카운트다운 타이머" 사용 횟수 통계, 각 세션별 교사의 "무작위 지목" 사용 횟수 통계, 각 세션별 교사의 "EDB 자료" 이름·연 시간·출처 통계, 각 세션별 교사의 "그룹 토론" 사용 횟수·시간·상세 통계, 각 세션별 교사의 "보조 카메라" 사용 횟수·시간 통계, 각 세션별 교사의 "비디오 월" 사용 횟수·시간 통계.

**학습 분석**

"세션 데이터"에서 교사와 관리자는 "학습 분석" 페이지를 통해 학생 데이터를 분석하여 학생의 학습 상황을 더 잘 이해할 수 있습니다. 이 데이터에는 학생의 각 세션별 누적 수업 시간, 출석 기록, 담당 교사의 학생 평가 및 코멘트, 학생이 수업 재생을 시청한 횟수와 시간 등이 포함됩니다. 또한 학생의 수업 중 발언, 무대 등장, 손들기, 퇴장 조치, 보상 받은 횟수와 시간, 교사의 빨리 누르기 및 응답기 사용 현황도 통계할 수 있습니다. 학생이 각 세션에서 카메라를 켠 총 시간도 통계됩니다. 이러한 데이터를 통해 교사와 관리자는 학생의 학습 성과를 더 잘 이해하고, 학습 효과 향상을 위한 맞춤형 조치를 취할 수 있습니다.

### 조작 방법
1. 관리자 백엔드에 로그인
2. 왼쪽 내비게이션에서 "클래스 관리"로 이동
3. 클래스를 찾아 오른쪽의 "세션 데이터" 클릭
4. 왼쪽 상단에서 "강의 분석" 또는 "학습 분석"으로 이동
5. 데이터 필터링
6. 맨 아래의 "표 다운로드" 클릭
