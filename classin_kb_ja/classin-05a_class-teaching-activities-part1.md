## WeChat公式アカウント通知

## 一、WeChat公式アカウントを連携する

### 対象
全員

### こんな時に使う
ClassInのWeChat公式アカウントを連携すると、ClassInアプリにログインしていない場合や、ClassInアプリの通知をオンにしていない場合でも、WeChatを通じて授業通知やクラス内のLMS学習アクティビティ通知を受け取ることができ、重要な情報を見逃すことがなくなります。

### 使用方法
連携すると、ClassInは授業開始前にWeChat公式アカウントを通じて教師・生徒にリマインドメッセージを送信します。具体的な配信タイミングは以下の通りです：

**（1）有料版ClassIn授業通知：**
- 教師：授業開始20分前に授業通知を受け取ります。
- 生徒：授業開始10分前に授業通知を受け取ります。

**（2）LMSアクティビティ通知：**
- 教師がLMS学習アクティビティを発行した場合、または生徒が既に提出したLMS学習アクティビティを採点・催促・訂正操作した場合、生徒はWeChatメッセージのプッシュ通知を受け取ります。
- 生徒がLMS学習アクティビティを提出した場合、教師はWeChatメッセージのプッシュ通知を受け取ります。

これらの精緻な通知配信により、ClassInはすべての教師と生徒が重要な授業・学習アクティビティ情報を確実にタイムリーに取得できるようにします。

### 注意事項
無料版教室では、教師・副教師・生徒・聴講生はいずれも授業開始5分前に通知されます。

WeChat公式アカウントは1日最大100万回まで配信でき、これを超えると配信がブロックされます。

コースまたは授業コマの名前が24文字を超える場合も配信がブロックされます。

### 操作手順
1. WeChatの右上にある虫眼鏡アイコンをタップします。
2. 検索欄に「ClassIn服务号」と入力し、検索結果から「ClassIn服务号」をタップします。
3. ClassIn公式アカウントに入ります。
4. 「フォロー」をタップします。
5. 「アカウント連携」をタップします。
6. 「連携を確認」をタップします。
7. 電話番号、メールアドレス、またはClassInアカウント・パスワードを入力して連携します。
8. 授業やLMSアクティビティのリマインドがある場合、WeChat公式アカウントに表示されます。

## 学習資料

## 一、「学習資料」とは？

授業実践では、教師は予習・復習用の資料を「学習資料」欄にアップロードでき、生徒は授業前の予習や授業後の復習に活用できます。これにより授業内容が充実し、教育効果が高まるとともに、生徒により完全で体系的な学習リソースを提供できます。

## 二、「学習資料」を新規作成する

### 対象
「担任教師」および「教師」

### 使用方法
教師はクラスページに入った後、コース欄で学習資料を配布できます。学習資料では複数種類の添付ファイルを追加でき、画像、音声、クラウドドライブファイル、ローカルファイル、Webサイトリンクに対応しています。ファイル数の上限は、画像添付ファイル15枚、録音添付ファイル15件、動画添付ファイル15個で、ローカルファイル・クラウドドライブファイル・リンクの合計は50個までです。各動画・ファイルのサイズは500MB以内です。パソコンから学習資料の添付ファイルをアップロードする際は、画像やファイルをドラッグ＆ドロップで直接学習資料に追加できます。

**（1）「学習資料」作成時に設定できるパラメーター：**

| 設定 | 機能 |
| --- | --- |
| 時間 | 「学習資料」の開始時刻と締切時刻を設定します。 |
| 発行先 | 特定のクラス、クラス内の一部グループメンバーや一部の生徒に発行することも、複数のクラスに同時に発行することもできます。 |
| 教師 | 担当教師を指定し、関連通知を受け取ります。 |
| コース | 「学習資料」をどのコースに属させるかを選択します。デフォルトは現在のコースです。 |
| ユニットテーマ | 「学習資料」をどのユニットテーマに属させるかを選択します。選択しない場合はデフォルトのユニットに分類されます。 |
| 生徒による添付ファイルのダウンロードを許可 | オンにすると、生徒は「学習資料」の添付ファイルをダウンロードできます。 |
| 新しく参加した生徒の閲覧を許可 | オンにすると、学習資料アクティビティ終了前に新しくクラスに参加した生徒も「学習資料」を閲覧できます。 |
| ロック解除条件 | 完了が必要な前提アクティビティを追加します。ロック解除条件を追加した場合、生徒は前提条件を完了しないと現在の学習資料アクティビティを開始できません。 |

### 注意事項
「生徒が教師によってクラスから除外された」「クラスが解散された」「生徒が自らクラスを離れた」場合、既にクラスを離れた生徒が学習資料内のファイル添付を閲覧できるかどうかは、クラス設定の「クラスを離れた生徒やクラス解散後もコース内容を閲覧できる」設定によって決まります。

### 操作手順

**パソコン／タブレット**
1. 左側のナビゲーションから「ホーム」に進みます。
2. 左上で新規コースを作成するか、既存のコースに入ります。
3. 「新規作成」をクリックします。
4. 「学習資料」を作成します。

## 三、「学習資料」を修正する

学習資料は編集に対応していますが、状態によって編集可能な内容は異なります。

草稿および未開始の学習資料は、「コース」は変更できませんが、他の内容・設定はすべて変更できます。

進行中の学習資料は、内容の変更は可能ですが、設定項目の「開始時刻」と「コース」は変更できません。

終了済みの学習資料は、内容は変更できず、設定項目の時間、発行先、教師、コース、新規参加生徒の閲覧許可、ロック解除条件のいくつかの項目は変更できません。

1. クラスを検索して入ります。
2. 左上からコースに入ります。
3. 学習資料を見つけ、右側の「···」をクリックします。
4. 「編集」を選択します。

## ユニットテーマ

## 一、「ユニットテーマ」とは？

コース設計では、テーマを中心に教育内容を統合し、互いに関連する一連の教育アクティビティを形成することがよくあります。これらのアクティビティは通常、複数の授業コマを経て完全な形になるもので、これを「ユニット」と呼びます。ここでの「ユニット」は従来の教科書の「章節」とは完全に一致するものではなく、「テーマ」も教科書のユニットや章のタイトルに限られるものではありません。

## 二、「ユニットテーマ」を新規作成する

### 対象
「担任教師」および「教師」

### 使用方法
1つのユニットテーマには、授業、録画授業、課題、テスト（試験用紙）、解答用紙、打刻（チェックイン）、ディスカッション、学習資料、AI音声カードなど、さまざまな教育／学習アクティビティを含めることができます。これらの多様なアクティビティを通じて、生徒は一貫したテーマの枠組みの中で関連知識を全面的に理解・習得できます。

### 操作手順

**パソコン／タブレット**
1. 「ホーム」に進みます。
2. クラスに入ります。
3. 新規コースを作成するか、既存のコースに入ります。
4. 「新規作成」をクリックします。
5. 「ユニットテーマ」を選択します。
6. ユニットテーマのタイトルと紹介を追加します。
7. そのまま「発行」するか、「下書き保存」します。

## 三、「ユニットテーマ」を修正する

### 対象
### 使用方法
教師はユニットテーマ作成後、いつでも修正して内容の正確性と適合性を確保できます。

### 操作手順

1. 左側のナビゲーションから「ホーム」に進みます。
2. 左上からコースに入ります。
3. ユニットテーマを見つけます。

## 七、アクティビティの絞り込み

学習アクティビティの絞り込みには、異なるニーズや要件に対応するため、3つの方式があります：

**条件絞り込み：** 特定の条件で絞り込みます。例えば、教師は自分に関連するすべての教育アクティビティを絞り込んだり、生徒は特定の教師名義のすべての教育アクティビティを絞り込んだり、あるいは未開始・進行中・終了済みの教育アクティビティを絞り込んだりできます。また生徒はこの機能を使って自分の未完了の学習アクティビティを絞り込んだり、「ユニットテーマ」や「能力・資質」などの条件で絞り込んだりできます。複数の条件を組み合わせて絞り込むことで、より正確に必要な学習アクティビティを特定できます。

**種別絞り込み：** アクティビティの種別で絞り込みます。例えば：授業（授業コマ、ライブ授業）、録画授業、課題、打刻、テスト（試験用紙）、解答用紙、ディスカッション、学習資料、AI音声カードなど。この絞り込み方式は、ユーザーが特定の種別の教育／学習アクティビティをより早く見つけるのに役立ちます。

**キーワード検索：** キーワードを入力して教育／学習アクティビティを検索し、関連アクティビティを素早く見つけられます。

## ディスカッション

## 一、「ディスカッション」とは？

「ディスカッション」とは、クラス内にディスカッショングループを作成することを指します。このグループでは、クラス内のすべての生徒と教師が自由に質問し、意見や見解を共有し、概念を説明したり感想を発表したりできます。このようなディスカッショングループは、開放的で寛容な雰囲気を作り出し、生徒が主体的に考え、表現することを促すとともに、教師にとっても生徒の思考方法や学習ニーズを理解する重要な機会となります。さらに生徒同士が交流することで、互いの知識や経験を共有し、共同学習を促進できます。このような交流と協働は、生徒の学習意欲とモチベーションを高め、批判的思考力と問題解決能力を育むのに役立ちます。

## 二、「ディスカッション」と「グループディスカッション」の違いは？

ClassInには2つのディスカッション機能があります。1つは教室外のクラス内にあるディスカッション機能で、作成後はクラスの教師・生徒が参加できます。もう1つは教室内の機能で「グループディスカッション」といい、生徒をグループ分けして複数のグループで教室内でディスカッションを行う機能です。教師が各グループの生徒のディスカッションに参加することもできます。

## 三、「ディスカッション」を新規作成する

### 対象
「担任教師」および「教師」

### 使用方法
新しいディスカッションを作成する際、教師はディスカッション内容にテキストを入力し、画像、録音、クラウドドライブファイルまたはローカルファイル、リンクなど各種添付ファイルをアップロードできます。ファイル数の上限は、画像添付ファイル15枚、録音添付ファイル15件で、ローカルファイル・クラウドドライブファイル・リンクの合計は15個までです。各ファイルのサイズは500MB以内です。

パソコンからディスカッションの添付ファイルをアップロードする際は、画像やファイルをドラッグ＆ドロップでディスカッションに直接追加できます。

| 設定 | 機能 |
| --- | --- |

## 九、生徒が「ディスカッション」に参加する

対象：「生徒」

生徒は待ち事項またはクラス内でディスカッションを確認・参加できます。

コメント欄は「最も注目」と「最新」の2つのタブに分かれています。コメント欄では以下に対応しています：

いいね、コメントの投稿・返信（自分または他人へ）に対応しており、コメントにはテキスト入力、画像・録音・音声動画ファイルのアップロードが可能です。ファイル数の上限は、画像添付ファイル9枚、録音添付ファイル9件で、音声動画ファイルの合計も9個までです。各ファイルのサイズは500MB以内で、生徒がパソコンを使用する場合は画像ファイルをコメントにドラッグ＆ドロップすることもできます。

自分または他人のコメント後に「自分のみ表示」または「この人のみ表示」をタップでき、自分が返信・投稿したコメントの削除にも対応しています。スマートフォンではコメントのコピーにも対応しています。

生徒が教師にミュート操作された場合、返信コメントを投稿しようとするとミュート中であることが表示されます。ミュート状態では、いいねやコメントの投稿・返信はできません。

生徒欄では、生徒は自分のコメント、返信、獲得したいいね数、成績を確認できます。パソコンやタブレットを使用している場合は、自分のディスカッションレポートを共有することもできます。教師が「生徒同士の成績相互閲覧を許可」を設定している場合、生徒は他の生徒のディスカッション状況も確認できます。

ディスカッション終了後、生徒は返信の投稿、いいね、コメント削除ができなくなります。

## 十、教師が「ディスカッション」に参加する

教師は、待ち事項またはクラス内で進行中または終了済みのディスカッションを見つけ、確認・参加・評価を行うことができます。

いいね、コメントの投稿・返信（自分または他人へ）に対応しており、コメントにはテキスト入力、画像・録音・音声動画ファイルのアップロードが可能です。ファイル数の上限は、画像添付ファイル9枚、録音添付ファイル9件で、音声動画ファイルの合計も9個までです。各ファイルのサイズは500MB以内で、パソコン使用時は画像ファイルをコメントにドラッグ＆ドロップすることもできます。

自分または他人のコメント後に「自分のみ表示」または「この人のみ表示」をタップできます。担任教師はすべての人のコメントを削除でき、クラス教師は自分と生徒のコメントを削除できます（担任教師のコメントは削除できません）。スマートフォンではコメントのコピーにも対応しています。

生徒のミュートに対応しています。教師にミュートされた生徒は、返信コメントを投稿しようとするとミュート中であることが表示され、ミュート状態では、いいねやコメントの投稿・返信ができません。

生徒欄では、教師は対応する生徒のコメント、返信、獲得したいいね数、成績を確認できます。パソコンやタブレットを使用している場合は、対応する生徒のディスカッションレポートを共有することもでき、パソコンではディスカッション内容のダウンロードにも対応しています。

ディスカッションに評価が設定されている場合、教師はディスカッション欄の生徒コメント後、および生徒欄の両方でその評価を行うことができます。
