## テスト

## 一、「テスト」とは？

ClassInの「テスト」機能は、本質的には「試験用紙」であり、生徒が特定の科目や分野における知識・スキルの習得状況を評価することを目的としています。試験は生徒の学習成果を検証する重要な手段であるだけでなく、学校や教育機関が授業の質やカリキュラム設計の有効性を評価するのにも役立ちます。さらに、テストは生徒自身が学習の進み具合や弱点を確認するのにも役立ちます。テストを受けることで、生徒は各科目の習得度を把握し、不足している部分を素早く発見できます。これにより、生徒は学習の重点を明確にし、学習効率を高め、知識の不足を迅速に補うことができます。

## 二、「テスト」を新規作成する

## 1、テストアクティビティを作成する

### 対象
「担任教師」および「教師」

### 使用方法
テストの試験問題追加画面に入ると：

教師は「問題バンクから選択」から「ClassIn問題バンク」が提供する試験問題や試験用紙を追加でき、キーワードや条件で問題・試験用紙を絞り込んで検索できます。

事前に試験問題を入力している場合は、「マイ問題バンク」で事前に入力した試験問題や試験用紙を呼び出せます。

学校が教師に試験問題・試験用紙リソースの利用権限を付与している場合は、「組織問題バンク」で権限付与されたリソースを呼び出せます。

必要な試験問題や試験用紙を試験問題バスケットに追加し、バスケット内で追加済みの試験問題を削除することもできます。それを現在の試験用紙に再度追加すれば選題完了です。

教師は「追加／一括追加試験問題」で手動で単一の問題を追加したり、一括で試験問題を追加したりすることもできます。一括追加試験問題は特定の書式に従う必要があり、ClassInが認識できる形式でなければならないため、一括追加時にはまずテンプレートをダウンロードし、テンプレートと入力説明に従って試験問題を追加し、追加が完了した試験問題を保存してからアップロードする必要があります。

パソコンやタブレットでは、教師が教育目標や特定の知識ポイントに基づいて、AIエージェントに出題させることもできます。

追加済みの試験問題は、配点の設定、位置の移動、削除、編集、複製などの操作に対応しています。プレビューにも対応しており、パソコン版とスマートフォン版で生徒が試験用紙を見た際の表示を確認できます。試験用紙リソースをマイ問題バンクに保存することにも対応しており、パソコンを使用する場合は試験用紙をパソコンのローカルにダウンロードすることもできます。

**「テスト」作成時に設定できるパラメーター：**

| 設定 | 機能 |
| --- | --- |
| 時間 | テストの開始時刻と締切時刻を設定します。 |
| 解答時間制限 | 生徒が解答する時間の制限を設定します。 |
| 評価 | テストの評価制度を設定します。 |
| 発行先 | 特定のクラス、クラス内の一部グループメンバーや一部の生徒に発行することも、複数のクラスに同時に発行することもできます。 |
| 教師 | 担当教師を指定し、関連通知を受け取ります。 |
| コース | 「テスト」をどのコースに属させるかを選択します。デフォルトは現在のコースです。 |
| ユニットテーマ | 「テスト」をどのユニットテーマに分類するかを選択します。選択しない場合はデフォルトのユニットに分類されます。 |
| 穴埋め問題の手動採点 | オンにすると、生徒の穴埋め問題の解答が正解と一致しない場合、自動的に手動採点に切り替わります。 |
| アクティビティ終了後の補充提出を許可 | オンにすると、生徒が期限内にテストを完了できなかった場合、アクティビティ終了後でも提出できます。 |
| 生徒同士の内容・成績相互閲覧を許可 | 生徒同士がお互いの内容と成績を閲覧できるかどうかを設定します。テスト提出後／採点後／終了後のいずれで許可するかを設定できます。 |
| 解答と解説を公開 | 解答と解説を公開するかどうかを設定します。テスト提出後／採点後／終了後のいずれで公開するかを設定できます。 |
| 新しく参加した生徒の提出を許可 | オンにすると、テストアクティビティ終了前に新しくクラスに参加した生徒も、発行済みのテストに参加できます。 |
| ロック解除条件 | 完了が必要な前提アクティビティを追加します。ロック解除条件を追加した場合、生徒は前提条件を完了しないと現在のテストアクティビティを開始できません。 |

### 操作手順

**パソコン／タブレット**
1. 「ホーム」に進みます。
2. クラスに入ります。
3. 新規コースを作成するか、既存のコースに入ります。
4. 「新規作成」をクリックします。
5. 「テスト」を選択します。
6. 「試験タイトル」を追加します。
7. 「試験問題」を追加します。
8. 「試験問題」を設定します。
9. 「テストパラメーター」を設定します。
10. そのまま「発行」するか、「下書き保存」します。

## 2、試験問題を一括追加する

### こんな時に使う
教師が大量の試験問題を一度にClassInにインポートする必要がある場合、「試験問題を一括追加」機能を使用できます。

「試験問題の一括追加－試験問題のアップロード」では、入力説明に沿ったパソコン内のWordまたはExcelファイルの試験問題を、直接コピー＆ペーストで「試験問題の一括追加」ウィンドウに貼り付けることができます。テンプレートに沿ったパソコン内のWordまたはExcelファイルをこのウィンドウにドラッグ＆ドロップして使用することもできます。

「試験問題の一括追加－試験問題の編集」では、試験問題の編集・削除に対応しており、マイ問題バンクへの保存にも対応しています。

#### （1）単一選択問題の書式

**題番号の書式：**
- 題番号はアラビア数字である必要があります。
- 題番号の後には句読点またはスペースを付ける必要があります（例：「1.」「1、」「1 」）。

**題幹（問題文）の書式：**
- 文字と画像を含めることができ、文字は最大15,000文字まで。

**選択肢欄の書式：**
- 選択肢の番号は大文字アルファベットである必要があります。
- 各選択肢の後には句読点またはスペースを付ける必要があります（例：「A.」「A、」「A 」）。
- 選択肢の数は2～26個で、A～Zの順に表記します。
- 選択肢の内容には文字と画像を含めることができ、文字は最大200文字まで。

**解答欄の書式：**
- 右記の書式を必ず使用します（例：「答案：A」）。

**解説欄の書式（任意）：**
- 右記の書式を必ず使用します（例：「解析：なぜAなのか」）。
- 解説内容には文字と画像を含めることができ、文字は最大15,000文字まで。

#### （2）複数選択問題の書式

複数選択問題の題番号、題幹、選択肢欄の書式は単一選択問題と同様です。

**解答欄の書式：**
- 右記の書式を必ず使用します（例：「答案：A」）。
- 複数の解答選択肢を設定した場合にのみ、システムが自動的に複数選択問題として認識します。

**解説欄の書式（任意）：** 単一選択問題と同様です。

#### （3）正誤判断問題の書式

**題番号の書式：**
- 題番号はアラビア数字である必要があります。
- 題番号の後には句読点またはスペースを付ける必要があります（例：「1.」「1、」「1 」）。

**正誤判断の解答欄：**
- 右記の書式を必ず使用します（例：「答案：A」）。
- 正誤判断問題の答案は「正確／错误／T／F」のいずれかでなければならず、正確／Tは「正しい」、错误／Fは「誤り」を表します。

**解説欄（任意）。**

#### （4）穴埋め問題の書式

**題番号の書式・題幹の書式：**
- 各穴埋め箇所は下線3本以上とします。
- 複数箇所の穴埋めがある場合、穴埋め数と解答数を一致させる必要があり、穴埋め数は1～40個です。

**穴埋め問題の解答欄：**
- 複数の解答がある場合は、解答同士を「｜」で区切ります。
- 解答には文字を含み、最大500文字まで。

**解説欄（任意）。**

注：キーボードでShiftキーと、大キーボードの数字0の右にある「-」キーを同時に押すことで、下線「_」を入力できます（半角英数モードで操作する必要があります）。

#### （5）記述問題の書式

**題番号の書式：**
- 題番号は必ずアラビア数字を使用します。

**解答欄（任意）：**
- システムが自動的に記述問題として認識し、記述問題は人手による採点が必要です。
- 解答には文字と画像を含めることができ、文字は最大15,000文字まで。

**解説欄（任意）。**

#### （6）総合問題の書式

総合問題本体の**題番号の書式・題幹の書式**。

**小問の題番号の書式：**
- アラビア数字＋括弧を必ず使用します（例：「（1）」「（2）」「（3）」）。
- 小問の数は1～50個です。

**小問の書式：**
- 上記各種問題形式（単一選択問題、複数選択問題、正誤判断問題、穴埋め問題、記述問題）の書式要件に従ってください。

## 三、「テスト」を修正する

テスト発行後は、テスト内の試験問題とタイトルを修正できません。

草稿および未開始のテストは、「コース」は変更できませんが、他の内容・設定はすべて変更できます。

進行中のテストは、テスト内容と、設定項目の開始時刻、解答時間制限、コース、穴埋め問題の手動採点を変更できません。

終了済みのテストは、テスト内容と、設定項目の時間、解答時間制限、発行先、教師、コース、穴埋め問題の手動採点、新規参加生徒の提出許可、ロック解除条件のいくつかの項目を変更できません。

草稿・進行中・終了済みのいずれのテストも、試験用紙リソースをマイ問題バンクに保存することには対応しています。

1. 「ホーム」に進みます。
2. クラスに入ります。
3. コースに進みます。
4. テストを見つけて「···」をクリックし、「編集」を選択します。

教師は、テスト発行後、締切前であれば手動でテストを終了させる権限があります。設定で「補充提出を許可」機能をオンにしていない場合、テスト終了後、生徒は未完了のテストを提出できなくなります。

1. テストを見つけて「···」をクリックし、「今すぐ終了」を選択します。

## 六、「テスト」を複製する

草稿、未開始、進行中、終了済みのいずれのテストアクティビティも、本クラスや他のクラスに複製できます。複製後のテストは、開始時刻と締切時刻を除き、内容とパラメーターがデフォルトで元のテストと一致します。

1. テストを見つけて「···」をクリックし、「アクティビティを複製」を選択します。

## 七、「テスト」を共有する

教師は、生徒がClassInにログインしていない場合やClassIn通知機能をオンにしていない場合でも、配布したテストをWeChatや他のプラットフォームに共有でき、教師がタイムリーに生徒の学習を促すのに役立ちます。

教師がパソコンでテストを共有する場合、ClassInのクラスや友達に共有したり、リンクをコピーして共有したり、スマートフォンでWeChatのQRコードスキャンを通じてWeChatの友達やグループに共有したりできます。

教師がスマートフォンやタブレットでテストを共有する場合、ClassInのクラスや友達に共有したり、WeChatの友達・グループ・モーメンツ、Weibo、QQの友達に共有したりでき、リンクのコピーによる共有にも対応しています。

ClassInアプリ以外で共有されたテストを確認する場合、試験用紙の構成などのみが表示され、具体的な問題内容は確認できません。生徒が解答に参加するには、ClassInを起動してクラスに入る必要があります。

1. テストに入ります。
2. 「共有」ボタンをクリックし、共有方法を選択します。

## 八、生徒が「テスト」を解答する

**テストを見つける：** クラス内のコース欄で、教師が布置したテストを見つけます。

**解答画面に入る：** テスト右側の「解答を開始」ボタンをタップすると、解答画面に入ります。この画面の上部で、生徒は問題数と合計点数を確認できます。同時に画面左下には解答の残り時間も表示されます。これらの情報は生徒が解答や時間配分を行う上で重要です。

**解答の流れ：** 生徒はここから解答を開始できます。試験問題に従い、正しい解答を選択または入力します。1問完了するたびに、システムは右側の答案カードで自動的に解答済みの問題をマークし、解答済み・未解答の問題を追跡しやすくします。右側の答案カード内の問題もクリックで選択でき、対応する問題へ素早くジャンプできます。

**テストを提出する：** 生徒が解答を終えたら、画面右下の「テストを提出」ボタンをタップします。これで解答プロセスが終了したことになり、試験用紙は自動的に回収されます。

生徒がテストを提出した後は、解答内容を修正できませんので、提出前に解答を十分に確認してください。

制限時間付きのテストの場合、途中で退出しても計時は継続され、残り時間が終了すると自動的に提出されます。

1. 「待ち事項」に進みます。
2. 「未処理」に進みます。
3. 検索や条件絞り込みでテストを見つけます。
4. 「解答へ」をタップし、「解答を開始」をタップします。

## 九、「テスト」を採点する

「テストを採点する」とは、教師が生徒のテスト用紙を評価・採点するプロセスを指します。生徒が実際にはオフラインでテストを完了した場合でも、教師は採点できます。採点時、教師はテストの問題要件と模範解答に基づいて、生徒の解答を詳細に分析・評価します。教師は生徒の理解力・問題解決能力、正確性と完全性、言語表現や論理的推論などを考慮した上で、対応する点数や評価を付与します。

生徒がテストを提出すると、教師はクラスページのコース欄で対応するテストを見つけ、右側の「採点へ」ボタンをタップします。これにより教師は「未採点」欄に入り、各問題について正誤を1つずつ判断できます。正誤に加えて、複数選択問題と記述問題は「一部正解」にも対応しています。教師は生徒の解答と試験問題の解答解説を照らし合わせ、自動採点をベースに人手での判断を加えることができます。システムが既に自動採点した正誤判断問題や選択問題などの客観問題についても、教師は採点結果を修正できます。また、右側の答案カードからも問題を選んで対応する問題へ素早くジャンプできます。

採点が完了したら、教師は「完了」または「保存して次を採点」をクリックすることで、現在の生徒の採点を終えるか、次の生徒の採点に進むことができます。「保存して次を採点」を選択すると、システムは自動的に次の生徒の解答ページに切り替わります。

生徒が提出したテストは教師が複数回採点し直すことができ、途中の採点記録は保存されず、最終記録のみが有効となります。

検索や条件絞り込みで探すこともできます。

1. テストを見つけて「採点へ」をクリックします。

## 十、「テストデータ」を確認・ダウンロードする

バックオフィス管理システムでは、教師はテストデータをダウンロードできます。また、ソフトウェア上でも、教師はテストデータを直接確認またはダウンロードできます。教師はこれらのデータを基に、生徒の学習状況を分析・評価し、個別指導や的確なフィードバックを提供できます。

テストデータを確認する際は、各問題ごとに確認でき、問題形式でも絞り込みできます。特定の問題をクリックすると、その問題の正解、正答率、全体正答率、各選択肢の選択人数と選択比率などの詳細情報を確認できます。

パソコンで生徒のテスト明細データをエクスポートすると、データはExcel形式でローカルコンピューターに保存されます。表に含まれる生徒情報は次の通りです：生徒のクラスニックネーム、テストを提出したかどうか、補充提出をしたかどうか、提出時刻、解答時間、テストが採点済みかどうか、テストの得点、正答率、正解した問題数、誤答した問題数、部分正解の問題数、未解答の問題数、各問題の得点、各問題で選択した解答。これらのデータは生徒ごとに区分されます。さらに以下の情報も付加されます：クラスID、クラス名、テストタイトル、ユニットID、ユニット名、問題数、テストの満点、採点者。

スマートフォンとタブレットではテストデータの確認のみで、生徒のテスト明細データのエクスポートには対応していません。

1. 「データ統計」を確認するか、「エクスポート」をクリックします。
