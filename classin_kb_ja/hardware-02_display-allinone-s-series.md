## 【大画面一体型マシン】電源・信号問題

# 1. 電源オン後、信号がなくWindowsデスクトップに入れない

**症状：** 大画面一体型マシンの電源をオンにした後、画面がずっと「信号接続中」「信号なし」「NO SIGNAL」状態を表示し、Windowsシステムデスクトップに入れません。

**解決方法：** 以下のいずれかの方法をお試しください。

**OPSホストが正常に通電しているか確認：**

一体型マシン背面のOPSホストの「POWER」インジケーターランプを確認して判断してください：「POWER」インジケーターランプが点灯している場合、パソコンは正常に通電し起動状態にあることを示します。「POWER」インジケーターランプが点灯していない場合は、下部のPOWERボタンをクリックして起動操作を行ってください（下図参照）

**OPSの切り替えを試す：**

一体型マシン右側の起動ボタンをクリックし、信号源を選択し、内蔵パソコンに調整します

**OPSホストを再起動する：**

一体型マシン背面のOPSホストにあるPOWERボタンを見つけます

POWERボタンを長押しし、OPSホストが完全にシャットダウンするまで待ちます

再度POWERボタンを押し、OPSホストを再起動します

# 2. システムにブルースクリーンが表示される

**症状：** Windowsシステムに入れず、画面にブルースクリーンエラーが表示されます（下図参照）。

**解決方法：** 以下の手順でお試しください。

システムを再起動して解決するか確認します

右側の電源ボタンをクリックしてAndroidメニューに入ります

「設定」をタップし、「本機について」をタップします

「Windowsシステム復元」を選択します

## 【大画面一体型マシン】音声・映像問題

# 1. 大画面一体型マシンで音が出ない

**症状：** 大画面一体型マシン使用時、いかなる音声も聞こえません。

**解決方法：** 以下のいずれかの方法をお試しください。

大画面一体型マシンのAndroidメニュー内の音声設定がオフになっていないか確認します

**Windowsシステムの音量がミュートになっていないか確認：**

Windowsシステムデスクトップ右下の「矢印」アイコンをクリックします

「スピーカー」アイコンをクリックします

左右にドラッグしてシステム音量を調整します（下図参照）

**Windowsシステムの音声設定内で「86（XX）Monitor」デバイスが無効化されていないか確認：**

「スピーカー」アイコンを右クリックし「サウンド」を選択します

「再生」タブに入ります

「86 Monitor」デバイスが無効化されている場合、そのデバイスを右クリックし「有効化」を選択します

下部の「確定」ボタンをクリックします（下図参照）

以上の方法で解決しない場合、大画面一体型マシンを再起動し、360ドライバーマスターまたは驱动精灵ツールでオーディオドライバーを再インストールすることをおすすめします

## 【大画面一体型マシン】表示問題

# 1. 画面輝度を調整する

**症状：** 大画面一体型マシン使用時、画面輝度が適切ではありません。

**解決方法：** 以下の手順で画面輝度を調整してください。

一体型マシンの電源ボタンをクリックします

Androidポップアップ画面で、バックライト輝度を手動で調整します

# 2. 画面にジャンプ点／波紋点が発生する

**症状：** ユーザーが大画面一体型マシンを使用する際、タッチスクリーンにジャンプ点や波紋点現象が発生します（下図参照）。

**解決方法：** これは一体型マシンの画面が外側に膨らみ、タッチモジュールの信号が異常になることが原因です。下記の修復方法を参考に操作してください。

拳で画面ガラスの中央部分を軽く押し、これを複数回繰り返し、画面が平らに戻るよう試みてください

条件が許せば、一体型マシンの底部を少し持ち上げ、一体型マシンの画面がある程度の斜め角度で上を向くようにすると、正常なタッチ機能の回復に役立つ場合があります

以上の方法でも問題が解決しない場合、Classinアフターサービスに連絡して修理を依頼することをおすすめします

# 3. 画面に線や画面のちらつきが発生する

**症状：** 大画面一体型マシンの画面に線が現れたり、画面がちらついたりする現象が発生します（下図参照）。

**解決方法：** この問題は通常、画面のOC（駆動回路）やTCON（タイミング制御回路）基板の故障によって引き起こされます。Classinアフターサービスに連絡して工場修理を依頼することをおすすめします。

# 4. 一体型マシンの画面にちらつきが発生する

**症状：** 電源オン後、画面がちらつき、正常に使用できません。

**解決方法：** 360ドライバーマスター／驱动精灵などをダウンロードして、グラフィックドライバーをアップグレードしてください。

# 5. 一体型マシンの画面がフリーズして黒画面になる

**症状：** 一体型マシンの電源をオンにするとClassInロゴ画面でずっとフリーズしたまま、または黒画面のままでシステム画面に入れません。

**解決方法：** このような問題は電源基板／マザーボードの故障である可能性が高いため、Classinアフターサービスに連絡して修理を依頼することをおすすめします。

## 【大画面一体型マシン】配線接続と画面投影問題

# 1. 大画面一体型マシンの無線画面投影

**症状：** 大画面一体型マシン使用時、無線画面投影が必要です。

**解決方法：** 以下の方法でお試しください。

**Android画面投影を使用する方法**

大画面の電源ボタンをクリックします

Androidメニューがポップアップ表示されるので、「画面投影」を選択します

画面の指示に従いWiFiに接続してパスワードを入力すると画面投影できます。パスワード：88887777

**ClassIn Xソフトウェアで画面投影する方法**

大画面でClassIn Xソフトウェアに入り、アカウントにログイン後、「ClassIn画面投影」を選択します

パソコンでClassInソフトウェアにログインし、左側の「画面投影」を選択し、対応するWiFiを選択して投影コードを入力すると投影が開始されます

# 2. 大画面一体型マシンの有線画面投影

各種接続方法は以下をご参照ください：

HDMIケーブルでノートパソコンと大画面一体型マシンを接続します（大画面一体型マシンには3つのHDMI入力ポートがあり、それぞれ前面パネル、左後面パネルのHDMI1とHDMI2にあり、いずれも使用可能です）

USB A-Bタッチケーブルでノートパソコンと大画面一体型マシンを接続します（大画面一体型マシンには2つのタッチポートがあり、それぞれ前面パネルと左後面パネルのTOUCH-USBポートにあり、いずれも使用可能です）

画像が表示されない場合は、大画面一体型マシン上の別のHDMIポートに変更してみてください

上記の有線方式で大画面とノートパソコンを接続する場合、マイクとカメラはノートパソコンに接続し、大画面一体型マシンには接続しないようご注意ください

## 【大画面一体型マシン】入力・タッチ・手書き問題

# 1. ソフトウェアキーボードがポップアップしない

**症状：** 一体型マシン使用時、システムデスクトップ右下の「キーボード」アイコンをクリックしてもソフトウェアキーボードがポップアップせず、ソフトウェアキーボードで入力できません。

**解決方法：** 以下の手順で設定してください。

デスクトップ左下の「Windows」アイコンをクリックし、「設定」に入ります

「設定」画面で「デバイス」オプションを選択します

「入力」を選択し、「タブレットモードでなくキーボードが接続されていない場合にタッチキーボードを表示する」オプションを見つけてオンにします（デフォルトでオン状態の場合は、一度オフにしてから再度オンにし、パソコンを再起動してください）

# 2. 書き込み時のカクツキ

**症状：** 大画面一体型マシンでClassInを使って録画授業をする際、教室のペンツールで黒板に書き込む際にカクツキが発生します。

**解決方法：** 以下のいずれかの方法をお試しください。

**解像度と表示比率を調整する：**

一体型マシンのWindowsシステムデスクトップ解像度を1920×1080に設定します

表示比率を150%に調整します

**ClassInキャッシュをクリアする：**

ClassInメイン画面を開き、左下の設定オプションをクリックします

「システム設定」画面に入ります

「キャッシュをクリア」ボタンをクリックします
