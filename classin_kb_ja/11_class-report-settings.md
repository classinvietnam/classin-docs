# 11. 授業レポート設定

## ユニットレポート設定

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### 使用方法
「ユニットレポート設定」には、以下のコンポーネントモジュールが含まれます：総合概要、成績構成、能力分析、学習プロセス、教師コメント、学校紹介。このうち「総合概要」モジュールは必須項目で削除できませんが、その他のモジュールは必要に応じて追加・削除が可能です。

### 関連記事
「バックオフィスでのサブアカウント追加」

### 操作手順
1. バックオフィス管理システムにログインします。
2. 左側のナビゲーションから「学校設定」に進みます。
3. 上部の「コースレポート設定」に進みます。
4. 下部の「ユニットレポート設定」の右側にある「テンプレートを編集」に進みます。

## 学習レポートのスタイルを変更する

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### 使用方法
教務担当者は、バックオフィス管理システムで学習レポートのテンプレートスタイルを変更できます。バックオフィスには合計2種類の学習レポートスタイルが用意されています。

### 関連記事
「バックオフィスでのサブアカウント追加」

### 操作手順
1. バックオフィス管理システムにログインします。
2. 左側のナビゲーションから「学校設定」に進みます。
3. 「アクティビティレポート設定」を開きます。
4. 「テンプレートを編集」をクリックします。
5. 有効にするテンプレートを選択します。
6. テンプレートをクリックします。
7. 表示項目を設定します。

## 授業後レポートメッセージの自動配信

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### こんな時に使う
授業が終わるたびに、ClassInが自動的に教師や生徒に授業レポートや学習レポートの確認を促してほしい場合、教務担当者は「バックオフィス管理システム」で通知の自動配信機能をオンにできます。これにより、教師や生徒がレポートの確認を忘れることを防げます。

### 使用方法
教務担当者はバックオフィス管理システムで、学校レポートおよび授業レポートのメッセージ通知の自動配信をオン／オフにできます。生徒が使用するClassInの端末でもClassInのメッセージ通知機能がオンになっている場合、授業レポートおよび学習レポートが生成された後、教師と生徒はClassInシステムからレポート確認の通知を受け取ります。

### 関連記事
「バックオフィスでのサブアカウント追加」

### 操作手順
1. バックオフィス管理システムにログインします。
2. 左側のナビゲーションから「学校設定」に進みます。
3. 「アクティビティレポート設定」を開きます。
4. 「テンプレートを編集」をクリックします。
5. 「授業レポートメッセージ通知設定」で「学校レポートおよび授業レポートのメッセージ通知を自動配信」をオン／オフにします。
