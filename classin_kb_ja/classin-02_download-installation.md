## ClassInのダウンロードとインストール

## 一、WindowsへのClassInインストール

### 1. ダウンロード前の準備

**（1）パソコンのスペックを確認する**

ClassInをダウンロードする前に、パソコンのハードウェアスペック（CPUモデル、メモリ、OS）を確認してください。手順：
1. 「PC」を右クリックします。
2. 「プロパティ」を選択します。
3. 「デバイスの仕様」でCPUモデル、メモリ、OSを確認します。

![](https://cofile.eeo.cn/res-store%2F6c0ba30a2c29f907481639d7fcac2d07657379063c7731a076f9d9feb5e90b35_892437?q-sign-algorithm=sha1&q-ak=AKIDJQGsEOK2TfbFdEZifMnxrWx85mpdHj6H&q-sign-time=1773936000;1774540800&q-key-time=1773936000;1774540800&q-header-list=host&q-url-param-list=&q-signature=261155599535c516d948cf4dc5ad3db01c21b67f)

**（2）動作要件表と照合する**

確認したCPUモデル、メモリ、OSを、下表の推奨スペックと照らし合わせ、ClassInでの受講要件を満たしているか確認します。

| | 最低動作要件（生徒／録画しない教師） | 最低動作要件（録画教師） | 推奨動作要件（教師／生徒） |
| --- | --- | --- | --- |
| プロセッサ | Intel Core i3 第8世代以上、AMD Ryzen 3 第2世代以上 | Intel Core i5 第8世代以上、AMD Ryzen 5 第1世代以上 | Intel Core i7 第9世代以上、AMD Ryzen 7 第2世代以上 |
| メモリ | Windows：8GB RAM以上 | Windows：16GB RAM以上 | Windows：16GB RAM以上 |
| OS | Windows 7以上 | Windows 7以上 | Windows 10以上 |
| 画面解像度 | 1280×720以上 | 1280×720以上 | 1920×1080以上 |
| ネットワーク帯域幅 | 2Mbps以上 | 4Mbps以上 | 6Mbps以上 |

### 2. ClassInのダウンロードとインストール

**2.1 使用方法**

ClassInはWindows 7、Windows 8、Windows 10、Windows 11以降に対応しています。ClassInインストーラーのダウンロードには「Google Chrome」または「Firefox」の使用をおすすめします。この2つのブラウザは、ファイルダウンロードの互換性に優れています。

インストール時のトラブルを避けるため、ClassInインストーラーをダウンロードする前に、パソコン上のウイルス対策ソフトやセキュリティソフト（360セーフガード、360アンチウイルス、Tencent PCマネージャーなど）を終了しておくことをおすすめします。これらのソフトが、ClassInのレジストリファイルを誤って脅威と判定し削除してしまうことがあり、インストールが正常に進まなくなる場合があります。

ClassIn公式ダウンロードサイト（中国語版）：https://www.eeo.cn/cn/download
ClassIn公式ダウンロードサイト（英語版）：https://www.classin.com/download

**2.2 注意事項**

以下のシステムではClassInのインストールに対応していません：Windows XP、Windows 8.1 RT、Windows Vista。

**2.3 操作手順**
1. 「ブラウザ」を開きます。
2. ブラウザのアドレスバーに次を入力します：www.eeo.cn
3. 「ダウンロードセンター」に進みます。
4. 「Windows版ダウンロード」をクリックします。
5. ダウンロード完了後、インストーラーを実行します。
6. 画面の指示に従ってClassInをインストールします。

## 二、MacへのClassInインストール

**（1）CPUモデルを確認する**

ClassInをダウンロードする前に、パソコンのCPUモデルを確認してください。手順：
1. 「Launchpad」を開きます。
2. 「ターミナル」を検索して開きます。
3. ターミナル内の `LeondeMacbook-Air:~ shouhouzhichi$` の右側に `sysctl machdep.cpu.brand_string` と入力します。
4. 入力後、Enterキーを押します。
5. CPUモデルを確認します。

![](https://cofile.eeo.cn/res-store%2F2910229de3e8dc38f748ea122fe95ca3f0016f263bc74ff8c2d4db656ee8251a_2594456?q-sign-algorithm=sha1&q-ak=AKIDJQGsEOK2TfbFdEZifMnxrWx85mpdHj6H&q-sign-time=1773936000;1774540800&q-key-time=1773936000;1774540800&q-header-list=host&q-url-param-list=&q-signature=5e1435815a88a33835581c2ad92b4a33ca67cc6c)

**（2）CPUチップの種類を確認する**

Macのメモリ、OSバージョン、CPUチップの種類を確認します。手順：
1. 画面左上の「Appleメニュー」アイコンにマウスを合わせます。
2. 「このMacについて」をクリックします。
3. 「このMacについて」画面の「プロセッサ」欄で、メモリ、OSバージョン、CPUチップの種類を確認します。

![](https://cofile.eeo.cn/res-store%2F2d253d122ed30a5098760d26b6d726c5958bd20605c7d3e4d37e2c7f0750154e_468319?q-sign-algorithm=sha1&q-ak=AKIDJQGsEOK2TfbFdEZifMnxrWx85mpdHj6H&q-sign-time=1773936000;1774540800&q-key-time=1773936000;1774540800&q-header-list=host&q-url-param-list=&q-signature=cc5b23d83f80bba938b0e61308228aae61a848d2)

**（3）動作要件表と照合する**

| | 最低動作要件（生徒／録画しない教師） | 最低動作要件（録画教師） | 推奨動作要件（教師／生徒） |
| --- | --- | --- | --- |
| プロセッサ | Intel Core i3 第8世代以上 | Intel Core i5 第8世代以上 | Intel Core i7 第9世代以上 |
| メモリ | Mac：4GB RAM以上 | Mac：4GB RAM以上 | Mac：8GB RAM以上 |
| OS | macOS 10.13以上 | macOS 10.13以上 | macOS 12以上 |
| 画面解像度 | 1280×720以上 | 1280×720以上 | 1920×1080以上 |
| ネットワーク帯域幅 | 2Mbps以上 | 4Mbps以上 | 6Mbps以上 |

macOS 10.13以降でClassInをダウンロードできます。現在市販されているMacにはIntelチップとAppleチップの2種類のCPUチップがあるため、確認したCPUチップの種類に応じて、www.eeo.cn で対応するバージョンのClassInインストーラーをダウンロードしてください。

ClassIn公式ダウンロードサイト（中国語版）：https://www.eeo.cn/cn/download
ClassIn公式ダウンロードサイト（英語版）：https://www.classin.com/download

**2.2 操作手順**

**Intelチップ搭載MacへのClassInダウンロード・インストール**
1. ブラウザのアドレスバーに次を入力します：www.eeo.cn
2. 「macOS Intelチップ版ダウンロード」をクリックします。
3. インストーラーを実行し、検証が完了するまで待ちます。
4. 左側のClassInアイコンを右側の「アプリケーション」フォルダにドラッグし、コピーが完了するまで待ちます。
5. 「Launchpad」を開き、「Classin」を検索します。
6. 「Classin」を開きます。
7. 初回起動時の検証を待ち、表示されるダイアログで「開く」をクリックします。

**Appleシリコン搭載MacへのClassInダウンロード・インストール**
1. 「macOS Appleチップ版ダウンロード」をクリックします。
2. 左側のClassInアイコンを右側の「アプリケーション」フォルダにドラッグし、コピーが完了するまで待ちます。

## 三、iPhone/iPadへのClassInインストール

**（1）端末機種を確認する**

「設定」→「一般」→「情報」で機種名を確認します。

**（2）動作要件表と照合する**

お使いのiPhoneまたはiPadの機種を下表の推奨機種と照らし合わせ、ClassInでの受講要件を満たしているか確認します。

| | 最低動作要件（生徒／録画しない教師） | 最低動作要件（録画教師） | 推奨動作要件（教師／生徒） |
| --- | --- | --- | --- |
| OS | iOS：11以上 | iOS：11以上 | iOS：14以上 |
| iPad/iPhone機種 | iPhone 6以降、iPad 5以降、iPad mini 4以降、iPad Air 3以降、iPad Pro以降 | iPhone 8以降、iPad 6以降、iPad Pro以降 | iPhone XS以降、iPad 8以降、iPad Pro 2以降、iPad mini 5以降、iPad Air 3以降 |
| ネットワーク帯域幅 | 2Mbps以上 | 4Mbps以上 | 6Mbps以上 |

iPhoneまたはiPadをお使いの方は、ClassInをダウンロードする前に、iOSのバージョンがiOS 11以上であることを確認してください。その後、App StoreからClassInをダウンロードします。手順：
1. 「App Store」を開きます。
2. 検索欄に「Classin」と入力します。
3. 右側の「入手」をタップします。

**Huawei端末：** 「設定」を開く → 一番下までスクロールして「端末情報」に進む → 「プロセッサ」欄でCPUモデル、「実行メモリ」欄でメモリを確認します。

**Xiaomi端末：** 「設定」を開く → 「デバイス情報」に進む → 「プロセッサ」欄でCPUモデル、「実行メモリ」欄でメモリを確認します。

**OPPO端末：** 「設定」を開く → 一番下までスクロールして「端末情報」に進む → 「プロセッサ」欄でCPUモデル、「実行メモリ」欄でメモリを確認します。

**vivo端末：** 「設定」を開く → 一番下までスクロールして「端末情報」に進む → 「プロセッサ」欄でCPUモデル、「実行メモリ」欄でメモリを確認します。
