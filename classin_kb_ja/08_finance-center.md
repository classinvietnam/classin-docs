## チャージ

### 対象
- 「バックオフィス管理システム」主アカウント
- 「財務センター」権限を持つサブアカウント

### 使用方法
ClassInでは2種類のチャージ方法を提供しています：オンライン決済と銀行振込です。「オンライン決済」には、WeChat Pay、Alipay、PayPal、Stripeの4つの決済方法があります。チャージ可能な金額の範囲は2,000元〜100万元です。すぐに入金を反映させたい場合は、オンライン決済をご利用ください。「銀行振込」の振込先情報については、「バックオフィス管理システム」→「財務総覧」→「チャージ」→「銀行振込」ページをご確認ください。

### 関連記事
「控除ルール」
「請求書の発行」
「バックオフィス管理システムでのサブアカウント追加」

### 操作手順
1. バックオフィス管理システムにログインします。
2. 左側のナビゲーションから「財務総覧」に進みます。
3. 右上の「チャージ」をクリックします。

## 請求書管理

### 対象
- 「バックオフィス管理システム」主アカウント
- 「財務センター」権限を持つサブアカウント

### 使用方法
教務担当者は「請求書管理」ページで、以下の情報を使って請求書を絞り込んで検索できます：申請日時（請求書発行を申請した日時）、請求書の種類（普通請求書と専用請求書）、請求書の進捗状況（発行中、要修正、発行済み、クローズ済みなど）、金額範囲（請求書の発行金額範囲）、また申請番号、団体名または氏名、税番号での検索も可能です。教務担当者は「バックオフィス管理システム」からClassInチャージの請求書を発行できます。発行手続き中はいつでも発行操作を取り消すことができ、発行済みの請求書はローカルにダウンロードすることもできます。

## ストレージ消費統計

### 対象
- 「バックオフィス管理システム」主アカウント
- 「財務センター」権限を持つサブアカウント

### こんな時に使う
教務担当者が特定の期間内のバックオフィス管理システムにおけるストレージ消費統計を確認したい場合、バックオフィス管理システムの「統計ダウンロード」モジュールから、ストレージ消費統計を表形式でローカルにダウンロードできます。表から取得できる情報は、取引期間、取引日時、ストレージ消費注文番号、録画動画サイズ（GB）、監課画像枚数（枚）、金額（元）です。

### 使用方法
1回あたり最大6ヶ月分までダウンロード可能です。

複数のダウンロードタスクを同時に実行できます。

申請したダウンロードタスクは「タスクセンター」に表示されます。ユーザーはタスクセンターに移動してダウンロードを完了できます。

### 関連記事
「バックオフィスでのサブアカウント追加」

### 操作手順
1. バックオフィス管理システムにログインします。
2. 左側のナビゲーションから「統計ダウンロード」に進みます。
3. 日付を絞り込みます。
4. 「ストレージ消費」の右側の「ダウンロード」をクリックします。
5. 左側のナビゲーションから「タスクセンター」に進みます。
6. 生成されたタスクを見つけ、右側の「ファイルをダウンロード」をクリックします。

## 控除ルール

### 控除ルールとは？
控除ルールとは、学校や企業がClassInを利用する過程で、特定の機能を使用した際に一定の費用が差し引かれるルールのことです。これらのルールはClassInが定める基準に基づいており、サービスの種類や利用方法によって異なります。

### 対象
- 「バックオフィス管理システム」主アカウント
- 「財務センター」権限を持つサブアカウント

### 使用方法
ClassInの課金はプリペイド方式（事前チャージ）に基づいています。学校や企業はあらかじめClassInバックオフィス管理システムのアカウントにチャージを行い、ユーザーが各種ClassIn機能を利用するたびに、その学校・企業のClassInアカウントから該当する費用が差し引かれます。すべての費用は学校・企業のClassInアカウント残高から差し引かれる点にご注意ください。ClassInが個々の教師や生徒に直接課金することはありません。

| 項目名 | 控除ルール |
| --- | --- |
| 授業（授業コマ） | 1回の授業の控除総額 = 学生控除額 + 副教師控除額（いない場合は無視） + 録画費用（ない場合は無視） |
| 学生 | 学生機能の控除計算式：学生控除額 = 登壇人数の1時間あたり単価 × 有効出席の学生・聴講生数 × 授業コマ時間<br><br>（1）登壇人数の1時間あたり単価：授業コマ作成時に設定した登壇人数に基づいて計算されます。具体的な単価は、バックオフィスの「財務総覧」ページ右上の「控除ルール」で確認できます。<br><br>（2）有効出席の学生・聴講生数：授業の学生・聴講生が教室内で累計10分以上受講した場合に、有効出席と認定されます。<br><br>（3）授業コマ時間：授業コマ作成時に設定した時間に基づいて計算されます。授業コマが予定より早く終了した場合、実際の受講時間に基づいて計算されます。 |
| 副教師 | 副教師の控除計算式：副教師の実際控除額 = 副教師単価 × 授業コマ時間<br><br>（1）副教師単価：副教師の具体的な単価は、バックオフィスの「財務総覧」ページ右上の「控除ルール」で確認できます。「登壇人数」の異なる授業コマでは、教室内の副教師単価も異なります。（副教師の教室内累計受講時間が10分に達すると控除が始まります。10分未満の場合は控除されません。）<br><br>（2）授業コマ時間：授業コマ作成時に設定した時間に基づいて計算されます。授業コマが予定より早く終了した場合、実際の受講時間に基づいて計算されます。（注意：課金の最小単位は30分で、30分未満の場合は30分として計算されます。） |
| 録画 | 録画の控除計算式：録画の実際控除額 = 録画1時間あたり単価 × 録画時間<br><br>（1）録画1時間あたり単価：バックオフィスの「財務総覧」ページ右上の「控除ルール」で確認できます。<br><br>（2）録画時間：実際に生成された再生動画の時間を基準とします（最小単位は分で、1分未満は1分として計算されます）。「再生動画の時間」が「授業コマ消費の課金時間」より短い場合は再生動画の時間で計算されます。「再生動画の時間」が「授業コマ消費の課金時間」より長い場合は授業コマ消費の課金時間で計算されます。 |
| ウェブライブ配信 | ウェブライブ配信トラフィックの控除計算式：ウェブライブ配信トラフィックの実際控除額 = トラフィック単価 × ライブ配信トラフィック<br><br>（1）トラフィック単価：1GBあたりの単価は、バックオフィスの「財務総覧」ページ右上の「控除ルール」で確認できます。<br><br>（2）ウェブライブ配信トラフィック：1授業コマあたり100MB以内のライブ配信トラフィックは無料です。 |
| ウェブ再生 | ウェブ再生トラフィックの控除計算式：ウェブ再生トラフィックの実際控除額 = トラフィック単価 × 再生トラフィック<br><br>（1）トラフィック単価：1GBあたりの単価は、バックオフィスの「財務総覧」ページ右上の「控除ルール」で確認できます。<br><br>（2）ウェブ再生トラフィック：ユーザーがウェブ再生を視聴した際にバックエンドで発生するトラフィック、および授業コマの録画動画をダウンロードする際にバックエンドで発生するトラフィックです。<br><br>（3）注意：毎月1日に前月分の再生トラフィックが控除されます。 |
| ストレージ費用 | ストレージの控除計算式：ストレージの実際控除額 = （授業コマリソース + コース添付ファイル + クラスファイル + 有料組織クラウドドライブ + 教育プラン − ストレージ上限） × ストレージ単価<br><br>（1）毎月1日にストレージ費用が控除されます。実際のストレージ使用量が組織のストレージ上限内であれば課金されず、超過分はストレージ単価で課金されます。実際の課金項目は契約内容によります。<br><br>（2）授業コマリソースには、有料の録画動画、有料の監課画像、板書教材が含まれます。システムが生成する録画動画と監課画像は最初の3ヶ月間は無料ですが、3ヶ月を超えて保存を続ける場合はストレージ費用が発生します。3ヶ月以内に削除した場合、それ以降の課金はありません。アップロードされた授業コマ動画は3ヶ月間の無料特典の対象外で、当月末にストレージ費用が集計されます。<br><br>（3）監課画像のストレージは1枚あたり200KBで換算し、1GB（約5,242枚）を1課金単位とします。1GB未満の部分は課金されません。<br><br>（4）コース添付ファイルは3ヶ月間の無料特典の対象外で、当月末にストレージ費用が集計されます。<br><br>（5）クラスファイルは3ヶ月間の無料特典の対象外で、当月末にストレージ費用が集計されます。<br><br>（6）組織クラウドドライブは3ヶ月間の無料特典の対象外で、当月末にストレージ費用が集計されます。<br><br>（7）教育プランは3ヶ月間の無料特典の対象外で、当月末にストレージ費用が集計されます。 |
| SMS通知 | SMSの控除計算式：SMSの実際控除額 = 中国本土SMS単価 × 実際に送信した中国本土SMS件数 + 香港・マカオ・台湾および国際SMS単価 × 実際に送信した香港・マカオ・台湾および国際SMS件数<br><br>（1）中国本土SMS単価：バックオフィスの「財務総覧」ページ右上の「控除ルール」で確認できます。<br><br>（2）香港・マカオ・台湾および国際SMS単価：バックオフィスの「財務総覧」ページ右上の「控除ルール」で確認できます。<br><br>（3）実際の送信SMS件数：70文字以内（70文字を含む）は1件として送信され、70文字を超える場合は67文字/件として分割送信されます（中国語・英語の区別なく、漢字・アルファベット・数字・スペース・記号などすべて1文字としてカウントされます）。 |
| 音声通話 | 音声通話の控除計算式：音声通話の実際控除額 = 中国本土音声通話単価 × 中国本土実通話分数<br><br>（1）中国本土音声通話単価：バックオフィスの「財務総覧」ページ右上の「控除ルール」で確認できます。<br><br>（2）中国本土実通話分数：1回の通話時間が1分未満の場合は1分として計算されます。 |
| スマート担任 | （1）「スマート担任」機能の年間費用は、バックオフィスの「財務総覧」ページ右上の「控除ルール」で確認できます。<br><br>（2）「スマート担任」機能をオンにすると、システムはお客様のアカウントから即座に1年分の機能開通費用を差し引きます。<br><br>（3）更新期限最終日の23:59:00までにこの機能をオフにしなかった場合、システムは自動的に1年間延長更新します。継続して利用しない場合は、最終日の23:59:00までにこの機能をオフにしてください。<br><br>（4）注意：「スマート担任」機能を利用するとSMSおよび音声通話の費用が発生し、これらは実際の利用量に応じて個別に精算されます。具体的な費用については「SMSの実際控除額」および「音声通話の実際控除額」の説明をご参照ください。 |
| スーパーカスタマーサポート | スーパーカスタマーサポートの控除計算式：スーパーカスタマーサポート控除額 = 中国本土音声コールバック単価 × 中国本土実通話分数<br><br>（1）中国本土音声コールバック単価：バックオフィスの「財務総覧」ページ右上の「控除ルール」で確認できます。<br><br>（2）中国本土実通話分数：発信者と受信者はそれぞれ実際の通話時間に基づいて個別に課金され、1回の通話時間が1分未満の場合は1分として計算されます。 |

## 注文詳細

### 対象
- 「バックオフィス管理システム」主アカウント
- 「財務センター」権限を持つサブアカウント

### 使用方法
教務担当者は、バックオフィス管理システムの「財務明細」モジュールで、すべての注文情報を確認・ダウンロードできます。絞り込みや分析をしやすくするため、システムでは以下の条件が用意されています：

- **取引日時：** 指定した期間で注文を絞り込みます。
- **資金の流れ：** 収入注文または支出注文を選択して表示します。
- **注文タイプ：**（収入注文：サービスグレードのチャージ、チャージ、贈与、障害補償、スケジュール補償、口座振替入金などの種類を含みます）（支出注文：口座振替出金、授業コマ消費、録画、ライブ配信トラフィック、再生トラフィック、ストレージ、SMS、音声通話、スーパーカスタマーサポート、ClassInサービス料、アップグレード体験ユーザー、口座返金、贈与回収、年間相殺控除、財務手動控除、月額サービス料などの種類を含みます）
- **注文ステータス：** 取引成功または取引失敗の注文のみを表示します。
- **金額範囲：** 収入または支出の金額範囲を設定して注文を絞り込みます。
- **検索：** 注文番号または注文内容で正確に検索します。

教務担当者は上記の条件を使って注文情報を正確に絞り込み、絞り込み後にダウンロード操作を行うことができます。ダウンロードされる注文データには、取引期間、注文数、支出・収入金額、注文番号、注文日時、取引日時、注文タイプ、注文内容、注文ステータスが含まれます。

「財務明細」モジュールを通じて、教務担当者はプラットフォーム上のすべての注文情報を効率的に管理・分析できます。
