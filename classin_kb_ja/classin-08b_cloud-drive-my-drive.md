## マイクラウドドライブ（ファイルアップロードなどの関連操作）

## 一、ファイル（フォルダ）の新規作成／アップロード

## 対象
全員

## 適用場面
教師や生徒は授業前に、自分のパソコンローカルやスマートフォンローカルにあるファイルをClassInの「クラウドドライブ」にアップロードでき、これにより授業中にアップロード済みのファイルを教室内の他のメンバーに見せることができます。

## 使用方法
マイクラウドドライブは新規フォルダの作成に対応しており、備課パック、板書、課題リソース、オンラインPPT、コラボレーション文書などのファイルの新規作成にも対応しています。タブレットはオンラインPPTの新規作成に対応していません。スマートフォンはフォルダ、板書、課題リソース、コラボレーション文書の作成のみに対応しています。フォルダのアップロードに対応しているのはパソコンのみです。

マイクラウドドライブはファイルのアップロードにも対応しており、ppt、word、pdf、画像、音声・動画などのファイルをアップロードできます。

ClassInではアップロードするファイルのサイズに一定の制限があります：パソコンからアップロードする場合、1ファイルあたり500MBを超えることはできません。スマートフォンやタブレットからアップロードする場合、1ファイルあたり100MBを超えることはできません。TXTファイルについては、教室内で正常に使用できるようサイズを1MB以内に抑えることをおすすめします。またスマートフォンやタブレットからアップロードする動画ファイルについては、解像度が720P未満の動画はサイズが100MBを超えることはできず、解像度が720P以上の動画は再生時間が3分を超えることはできません。

## 注意事項
フォルダの総数上限は2000個で、各フォルダ内のファイル数の上限は300個です。

パソコン端では、ファイルやフォルダをドラッグ＆ドロップしてマイクラウドドライブにアップロードできます。

ファイルのアップロード後は変換に一定の時間がかかるため、早めにアップロードすることをおすすめします。

教室内でファイルを使用する必要がある場合は、必ず教室内でクラウドドライブから開く必要があります。

すべての形式のファイルをClassInにアップロードできますが、教室内で正常に開いて使用できるのは以下に記載されているファイル形式のみです。

ClassIn教室内で使用に対応しているファイルタイプは以下の通りです：

| タイプ | 形式 |
| --- | --- |
| ClassIn板書 | edb |
| ClassInファイル | edt；edu；edx；eda；edv |
| PowerPointプレゼンテーション | pptx；ppt；pptm |
| Word文書 | docx；doc |
| Excel表 | xlsx；xls；csv |
| PDF文書 | pdf |
| 画像 | jpeg；jpg；png；bmp |
| 音声 | mp3；wav；wma；aac；flac；m4a；oga |
| 動画 | mp4；3gp；mpg；mpeg；3g2；avi；flv；wmv；h264；m4v；mj2；mov；ogg；ogv；rm；qt；vob；webm |
| テキスト文書 | txt；html；htm；css；js；as；cpp；c；cc；cxx；h；java；md；matlab；pascal；pl；php；py；r；rb；ru；sql；swift；rbx；rs；go |
| 囲碁 | sgf |
| チェス／シャンチー | fen；pgn |

## 具体的な操作手順

#### パソコン／タブレット
1. 左側のナビゲーションから「スペース」に進みます。
2. 「マイクラウドドライブ」に進みます。
3. 上部の「アップロード」または「新規作成」でフォルダとファイルを作成します。

#### スマートフォン
1. 「スペース」に進みます。
2. マイクラウドドライブ内で「＋」をタップします。
3. 「フォルダとファイルを作成」または「ファイルをアップロード」します。

## 二、アップロード済みPPTファイルの修正（オンライン編集）

ClassIn使用時、教師がアップロード済みのPPTを修正する必要がある場合、「スペース」の「マイクラウドドライブ」に入って該当ファイルを見つけ、開いた後「オンライン編集」をクリックすると、PPTはClassIn専用のeppt形式（オンライン編集に対応）に変換され、教師はそのまま修正して保存できます。

スマートフォンやタブレットには「オンライン編集」機能はありません。

オンライン編集で保存されたepptファイルはダウンロードできません。

#### パソコン
1. 左側のナビゲーションから「スペース」に進みます。
2. アップロード済みのPPTファイルを見つけて開きます。
3. 「オンライン編集」を選択します。

<!-- DOC_BOUNDARY -->
```yaml
title: "ファイルを転送する"
source_title_zh: "转发文件"
```

## 三、ファイルを転送する

マイクラウドドライブ内のファイルは、ClassInのクラスや友達への転送に対応しています。

1. 「マイクラウドドライブ」に進みます。
2. 転送したいファイルにチェックを入れます。
3. 下部の「転送」をクリックします。

<!-- DOC_BOUNDARY -->
```yaml
title: "ファイルをダウンロードする"
source_title_zh: "下载文件"
```

## 四、ファイルをダウンロードする

パソコンはマイクラウドドライブから画像、板書、PPT、PDF、Word文書などのファイルをダウンロードできます。ただし、ClassIn専用のファイル形式（オンラインスライド〈eppt形式〉や文書〈edoc形式〉など）はダウンロードや他のアプリでの開封には対応していません。

スマートフォンやタブレットは画像をローカルアルバムに保存することに対応していますが、PPT、PDFなどのファイルには直接ダウンロードする機能はなく、マイクラウドドライブ内で開いた後、共有機能をタップして他のアプリで開いて確認・使用することができます。

1. ダウンロードしたいファイルにチェックを入れます。
2. 下部の「ダウンロード」をクリックします。

#### タブレット
1. 画像またはファイルを開きます。
2. 画像を長押しして保存する、またはファイルページで共有ボタンをタップして他のアプリで開くことを選択します。

<!-- DOC_BOUNDARY -->
```yaml
title: "ファイルを印刷する"
source_title_zh: "打印文件"
```

## 五、ファイルを印刷する

「マイクラウドドライブ」に保存されている教材ファイルを実物の紙資料に変換する必要がある場合、教師はClassInの印刷機能を使用できます。パソコンは画像、PPT、PDFなどのファイルの印刷に対応しています。

スマートフォンやタブレットには「印刷」機能はありません。

1. ファイルを開きます。
2. ファイル右上角の「印刷」をクリックします。

<!-- DOC_BOUNDARY -->
```yaml
title: "ファイル（フォルダ）を削除する"
source_title_zh: "删除文件（文件夹）"
```

## 六、ファイル（フォルダ）を削除する

マイクラウドドライブ内のファイルとフォルダは削除に対応していますが、削除すると復元できません。

1. ファイルまたはフォルダにチェックを入れます。
2. 下部の「削除」をクリックします。
3. 「削除」をクリックします。

## 七、画像を編集する

マイクラウドドライブの画像は、確認（元画像を含む）、編集、拡大縮小、クラウドドライブ／ローカルアルバムへの保存、ClassInのクラスや友達への転送に対応しています。

パソコンではさらに、画像の画面いっぱい表示／元に戻す、印刷にも対応しています。編集完了後はデフォルトで画像がコピーされ、他のソフトに貼り付けることができます。

1. 画像を開きます。
2. 「編集」をクリックします。
3. 画像を編集後「完了」をクリックします。

画像を長押しして「編集」を選択します。
画像を編集後「完了」をクリックすると、「転送」または「保存」を選択できます。

<!-- DOC_BOUNDARY -->
```yaml
title: "edb板書ファイルを編集する"
source_title_zh: "编辑edb板书文件"
```

## 八、edb板書ファイルを編集する

マイクラウドドライブで開いたedb板書は編集に対応しています。パソコンで開いた板書は、edb、png、pdf形式での保存および別名保存に対応しています。スマートフォンやタブレットで開いた場合はマイクラウドドライブへの保存のみに対応しています。

1. edb板書ファイルを開きます。
2. edbを編集後「保存」するか、「···」をクリックして「別名保存」します。

edbを編集後「保存」をクリックします。

マイクラウドドライブ内のedb板書ファイルを開きます。
