## 極速体験

## ステップ1：ClassInをダウンロード＆インストールする

ClassIn公式サイト（www.eeo.cn）にアクセスし、ダウンロードセンターに入ります

インストーラーをダウンロードし、ガイドに従ってClassInをインストールします

## ステップ2：ClassInにログインする

登録済みのアカウントを入力してClassInにログインします

## ステップ3：個人情報を設定する

ソフトウェア左下のアバターをクリックします

アバターとニックネームを設定します

## ステップ4：デバイス検出

教室に入る前に、ネットワーク環境や音声・映像デバイスの「検出」を行い、正常に授業を受けられることを確認します。ソフトウェア左下のアバターをクリックし、デバイス検出に進み、ガイドに従って検出します

## ステップ5：教材をアップロードする

教師は授業前に左側のナビゲーションから「スペース」に入り、ローカルの教材を「スペース」にアップロードしておくと、授業中に使いやすくなります。（表示する必要のある教材がない場合は、このステップは省略できます）

## ステップ6：授業に入る

ソフトウェア上部で該当する授業を見つけ、「授業を受ける」をクリックして教室に入ります

## ステップ7：身だしなみを確認する

授業を受けるをクリックすると、マイクとカメラを調整する画面に入ります

ここで身だしなみを確認し、確認が完了したら「教室に入る」をクリックします

## ステップ8：よく使う教室ツール

教師が教室に入った後、教室右上でカメラとマイクをコントロールでき、右側にはよく使う教育ツールがあります。生徒のカメラを表示・非表示にする必要がある場合は、右側ツールバー最後のツール「花名簿」で操作できます

生徒が教室に入った後、教室右上でカメラとマイクをコントロールでき、右側にはデフォルトで「授業ノート」「チャットウィンドウ」「花名簿」の3つのツールのみがあります

## ステップ9：授業後に授業回放動画を視聴する

授業で録画授業機能をオンにしていた場合、下課後約30分ほどで課程表に日付ごとにその授業の回放動画を確認できます

## ClassIn簡介

# 一、ClassIn簡介

### 1. 製品コンセプトと対応科目
ClassInは教育における「専門性」を追求し、ユーザーに卓越した教育体験を届けることに専念しています。

対応科目は幅広く、児童英語、語学研修、職業訓練、STEAMなどを含み、乗馬、ダンス、篆刻といった特殊な科目の指導にも活用できます。

### 2. 教育シーン
1対1授業、少人数クラス、大クラス、ライブ配信、ダブルティーチャー（中国人教師と外国人教師）授業など、多様な教育シーンを完璧にサポートし、異なる教育機構やユーザーの教育ニーズに対応します。

### 3. 移動教育とインタラクティブ性
モビリティに優れており、教師はイエローストーン国立公園、プラネタリウム、美術展など様々な現場シーンでClassInを通じてライブ講義を配信でき、生徒もオンライン授業で自分が見聞きしたことを提示・共有できます。

最大16人の同期対面授業に対応しており、教師と生徒はいずれも映像ウィンドウと音声を使ってインタラクションできます。映像ウィンドウは自由にドラッグ・拡大縮小でき、グループ学習、ディスカッション、プレゼンテーションなどのシーンに適しています。

### 4. 個性的な教育ツール
インタラクティブな電子黒板を備え、事前編集、複数ページのスクロール、無制限使用機能を持ち、授権された人員が同時に操作・使用できます。

インタラクティブ小黒板、解答器、計時器、教師画面共有、ビデオウォール、ランダム指名などの数十種類の教育ツールを搭載しており、教師が異なるタイプの授業を進めやすくなっています。

### 5. 教育教材サポート
アニメーション効果付きPPT、動画、音声、Word、pdfなど多種多様なインタラクティブ教材に対応しており、複数教材の組み合わせ授業にも対応しているため、より多くの教育シーンのニーズを満たし、授業内容をより豊かで多様にすることができます。

### 6. 授業の雰囲気とコントロール機能
挙手、早押し、報奨授与、登壇・降壇などの授業コントロール機能を備えており、競争意識のある授業の雰囲気を作り出し、生徒の参加度と積極性を高められます。

リアルタイム学習レポートシステムは、教師と生徒が授業外の時間に交流するのに便利で、教育の質を追跡でき、包括的な学習エコシステムの構築に役立ちます。

### 7. 地域の制限を受けない
グローバル化という大きな背景の中、ClassInは強力な適応性と利便性を発揮しています。世界のどこにいても、ネットワークがカバーされていれば、簡単にClassInを使って学習や授業ができます。

生徒にとっては、賑やかな国際都市にいても、辺鄙で静かな農村にいても、広大なアフリカの草原にいても、寒冷な北極の村にいても、ネットワークに接続できれば、ClassInを開いて世界各地の教師や同級生とインタラクション・交流でき、知識への扉が世界に向かって開かれることを意味します。様々な素晴らしい授業に参加でき、自分の視野を広げ、異なる文化的背景を持つ人々と共に成長できます。

教師にとっては、ClassInのグローバルな特性により、授業が地域の制限を受けなくなります。異なる国や地域から生徒を募集し、自分の専門知識や経験を共有できます。ネットワークという橋の上で、知識の火種を伝え、国境と文化の違いを越えて、真の意味での教育の境界のなさを実現します。

# 二、ClassInは教師に何を実現できるのか？

現代教育において、オンライン授業はもはや欠かせない一部となっています。経験豊富な退職教師であれ、若手教育者であれ、多くの人が評判の良いオンライン教育プラットフォームで授業を選択しています。では、生徒はどのようにより早く自分に合った教師を見つけられるのでしょうか？オンライン教育コースは師弟の距離を縮めるだけでなく、教師のために一連の重要な目標を実現します。

まず、オンライン教育プラットフォームは教師により多くの機会とリソースを提供します。オンライン教育プラットフォームは膨大なユーザー基盤を持っており、教師がより多くの生徒に接触できるようにします。退職教師であれ新任教師であれ、これらのプラットフォームを通じて全国各地の生徒とインタラクション・授業ができます。これにより教師にはより広い舞台が提供され、自身の教育能力と経験を十分に発揮するのに役立ちます。

次に、オンライン教育システムには複数の機能があり、教育効果を効果的に高めます。成熟した教育プラットフォームは教育プロセスをより気軽かつスムーズにします。教師はシステムを通じて教材や資料を直感的に提示でき、板書に大量の時間を費やす必要がありません。さらに教師はプラットフォーム上で課題や試験問題を出題でき、課題や試験問題の確認もより便利になります。これにより教師は教育内容に集中でき、教育効果を高められます。

また、オンライン教育システムはダブルティーチャー指導の設定ができ、教師同士の競争力をさらに高めます。主講教師とアシスタント教師を設定することで、主講教師の教育負担を軽減し、準備授業や教育の質の向上により多くの時間とエネルギーを割けるようにします。ダブルティーチャー指導モデルは教師同士に良好な教育の雰囲気を作り出し、お互いの成長を促進することもできます。これは教育機構にとっても、より優秀な教師を惹きつけ、教育水準全体を高めるのに役立ちます。

以上をまとめると、オンライン教育プラットフォームは教師に多くのメリットをもたらします。これらのプラットフォームを通じて、教師はより多くの生徒に接触でき、教育目標を実現できます。プラットフォームの多様な機能は教育効果を高め、教育プロセスをより気軽でスムーズなものにします。ダブルティーチャー指導モデルは教師同士の競争力と教育水準全体を高めます。したがって、オンライン教育は現代教育の重要な構成要素であるだけでなく、教師が個人的な目標を実現する力強い助力ともなっています。

# 三、ClassInは生徒に何を実現できるのか？

**柔軟な学習方式の提供：** オンライン教育は時間と空間の制限を打ち破り、生徒は自分のスケジュールに応じて学習でき、固定の授業時間に縛られなくなります。これは生徒の学習生活を大いに便利にします。

**学習効率の向上：** オンライン教育プラットフォームは豊富な学習リソースと多様な学習方法を提供します。生徒は自分の習熟度や学習ニーズに応じて適した学習教材や方法を選択できます。さらにオンライン教育はリアルタイムのインタラクションとパーソナライズされた指導機能も備えており、学習効率の向上に役立ちます。

**忙しい社会人層への対応：** 仕事が忙しく学習時間が不定な人々にとって、従来のオフライン教育はそのニーズを満たすことが難しいことがよくあります。一方オンライン教育の柔軟性により、こうした人々は自分のスケジュールに応じて学習でき、仕事と学習をより良くバランスさせられます。

**質の高い教育リソースの共有：** オンライン教育は世界各地の優秀な教師リソースを集約でき、生徒がより広く多様な学習コンテンツに接触できるようにします。オンライン学習プラットフォームを通じて、生徒は他の生徒とも交流・議論でき、学習の感想や経験を共有し、学習過程を豊かにできます。

まとめると、オンライン教育は柔軟な学習方式の提供、学習効率の向上、忙しい層への対応、質の高い教育リソースの共有を通じて、学習者に顕著な助けとなります。ただし、生徒はオンライン教育の利点を十分に活用し、理想の学習効果を得るために、依然として良好な自己管理能力と学習習慣を身につける必要があります。

## ショートカットキー

# 一、教室外

画面のキャプチャ：Ctrl+Alt+C

ソフトウェアを開く：Ctrl+Alt+X

メッセージを送信：Enter

# 二、教室内

### （1）MacパソコンとWindowsパソコンのショートカットキーの違い

Windowsパソコンの「Ctrl」キーはMacパソコンの「Command」キーに対応

Windowsパソコンの「Alt」キーはMacパソコンの「Option」キーに対応

Windowsパソコンの「Pageup/Down」キーはMacパソコンの「Fn+Up/Down」キーに対応

Windowsパソコンの「Home/End」キーはMacパソコンの「Fn+Left/Right」キーに対応

### （2）教室共通のショートカットキー

| 機能 | ショートカットキー |
| --- | --- |
| 全選択 | Ctrl + A |
| コピー | Ctrl + C |
| 貼り付け | Ctrl + V |
| 削除 | Ctrl + D / Delete |

### （3）教室右側のツールバーまたは円盤ツールのショートカットキー

| 機能 | ショートカットキー |
| --- | --- |
| PPTアニメーションクリック（選択後PPTのアニメーション効果を操作可能） | Ctrl + G |
| 選択＆移動 | Ctrl + M |
| ペン | Ctrl + P |
| 消しゴム | Ctrl + E |
| テキストツール | Ctrl + T |
| スクリーンショット | Ctrl + Alt + X |
| レーザーポインター | Ctrl + L |

### （4）ペンおよびテキストツールのショートカットキー

| 機能 | ショートカットキー |
| --- | --- |
| 対応する図形／色を呼び出す | Alt + 対応する数字／文字 |
| 曲線を描く時 | Shiftキーを押しながらだと直線に変わり、Altキーを押しながらだと正円に変わる |
| 直線を描く時 | Shiftキーを押しながらだと45度の折れ線に変わる |
| 円形を描く時 | Shiftキーを押しながらだと正円に変わる |
| 四角形を描く時 | Shiftキーを押しながらだと正方形に変わる |

### （5）大黒板のみ対応のショートカットキー（教材と小黒板は非対応）

| 機能 | ショートカットキー |
| --- | --- |
| 直前の操作を元に戻す（戻る） | Ctrl + Z |
| 直前の操作をやり直す（進む） | Ctrl + Y |
| ワンクリック画面クリア（黒板・教材上の板書、画像を含めてクリア） | Ctrl + N |
| ファイル機能を開く（画像や板書の読み込み） | Ctrl + O |
| 板書の保存／共有機能を呼び出す | Ctrl + S |
| 黒板の中間ページに到達する | Ctrl + Shift + O |
| 前のページ | Page Up |
| 次のページ | Page Down |
| 先頭ページに戻る | Home |
| 最後のページにめくる | End |
| 選択した内容を移動 | Left/Right/Up/Down |

### （6）ローカル黒板と備課室でのみ対応のショートカットキー（教室では非対応）

| 機能 | ショートカットキー |
| --- | --- |

| 1つ下の階層に下げる | Ctrl + Shift + Page Down |
| 最上位階層に置く | Ctrl + Shift + Home |
| 最下位階層に置く | Ctrl + Shift + End |

注意事項：Ctrlキーを押しながらマウス左クリックで黒板上の内容をクリックすると、選択した内容の右上角で階層設定を行うこともできます。
