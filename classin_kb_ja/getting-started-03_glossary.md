## 用語注釈

| ClassIn用語 | 説明 |
| --- | --- |
| IM | Instant Messagingの略称で、インスタントメッセージングエリアを指します。ClassInにログイン後に入るメイン画面がIM画面で、個人アバター、インスタントメッセージリスト、待ち事項、連絡先、スペース、時間割、黒板、設定などのモジュールが含まれます。 |
| 個人アバター | ClassInメイン画面の左上に位置し、クリックすると個人情報（アバター、名前、名刺共有、QRコード共有、電話番号紐付け、メールアドレス紐付け、パスワード修正、性別、生年月日、地域、個性署名など）を設定できます。 |
| インスタントメッセージリスト | ClassInメイン画面内のモジュールの1つで、クラスと友達からのメッセージを受信します。パソコンユーザーは左側のナビゲーションバーから、スマートフォンとタブレットユーザーは下部のナビゲーションバーから入ります。このリストでは、クラスと友達からのメッセージを受信し、上部固定、通知オフ、削除などの操作ができます。 |
| 連絡先 | ユーザーはClassInの左側（パソコン）または下部（スマートフォン、タブレット）ナビゲーションバーから「連絡先」モジュールに入り、友達の追加、クラスと友達リストの確認、友達申請の処理、友達詳細情報の確認と管理などの操作ができます。 |
| 授権リソース | 学校が特定の教師に使用を許可した公共教育リソース（教材、試験問題用紙など）です。授権を通じて、教師は標準化された教育リソースを使用でき、教育内容の統一性と品質を確保できます。 |
| 台上 | 教室内で、教師が「花名簿」ツールを通じて生徒にカメラの表示を招待する位置を「台上」と呼びます。台上の生徒は教師や他の台上生徒と音声で交流でき、すべての教室メンバーがそのカメラ映像を見られます。 |
| 上台（登壇） | 教師が「花名簿」ツールで生徒を「台上」に招待してカメラを表示させる操作です。 |
| 回到台下（降壇） | 教師が生徒のカメラ表示を停止させる操作を「回到台下」と呼びます。 |
| 台下 | 「台上」でカメラを表示していない教室メンバーは、すべて台下で授業を聴いている状態です。 |
| 授権 | 教師が「花名簿」ツールで生徒に教室ツール（ペン、選択／移動ツール、クリックツール、黒板消し、テキスト入力ツール、スクリーンショットツール、クラウドドライブなど）の使用権限を付与することです。 |
| 空白 | ユーザーがClassInの特定の画面を開いた際、画面に何も表示されない状態を「空白」と呼びます。よくあるケースとして、課題、テスト、クラウドドライブ、または教材の画面を開いた後に空白になることが挙げられます。 |
| 白屏（白い画面） | ユーザーがClassInの特定の画面を開いた際、画面に何も表示されない状態を「白屏」と呼びます。よくあるケースは空白と同様です。 |
| 黒屏（黒い画面） | ユーザーがClassInの特定の画面を開いた際、画面に何も表示されず、真っ黒なページのみが表示される状態を「黒屏」と呼びます。よくあるケースとして、クラウドドライブや教材の画面を開いた後に黒屏になることが挙げられます。 |
| 排課（授業スケジュール登録） | ユーザーがClassInメイン画面で「クラスを作成」をクリックし、作成済みのクラス内で「コース」欄に入り、「新規作成」ボタンをクリックし、「授業」を選択して授業スケジュールを登録することです。 |
| 開課（授業開講） | ユーザーがClassInメイン画面で「クラスを作成」をクリックし、作成済みのクラス内で「コース」欄に入り、「新規作成」ボタンをクリックし、「授業」を選択して授業を開講することです。 |
| 建課（授業作成） | ユーザーがClassInメイン画面で「クラスを作成」をクリックし、作成済みのクラス内で「コース」欄に入り、「新規作成」ボタンをクリックし、「授業」を選択して授業を作成することです。 |
| ビデオウォール | 教育ツールの1つで、教師はビデオウォールを通じてクラス内すべての生徒のカメラ映像をリアルタイムで監視でき、生徒の授業状態を観察しやすくします。生徒がカメラをオンにしていない場合、教師はその映像枠のみを見ることになります。 |
| オンライン教室、ローカル教室、臨時教室 | **ローカル教室：** ClassInメイン画面の「黒板」機能で、ユーザーが教室機能に慣れ、板書を作成するためのもので、時間制限はありません。<br>**オンライン教室：** ClassInの「授業」で、教師と生徒がここで授業を行います。<br>**臨時教室：** 教師と生徒がいつでも作成でき、無料で使用できます。 |
| 教育アクティビティ | クラス内のすべての教育を目的・内容とした活動で、授業、録画授業、課題、テスト、チェックイン、答題カード、ディスカッション、学習資料などを含みます。 |
| 複数クラステスト | 教師がテストを作成する際、テスト設定内の「クラス」欄で複数のクラスにチェックを入れ、複数のクラスの生徒がそのテストに参加できるようにすることです。 |
| ハウリング（エコー） | 教室内のスピーカーの音がマイクに拾われて教室に戻され、ハウリングが発生することです。通常、マイクとスピーカーの距離が近すぎることが原因です。 |
| 専注モード | 生徒の授業への集中度を高める機能です。オンにすると、パソコンユーザーの教室画面は全画面表示になり、他の画面に切り替えられなくなります。スマートフォンやタブレットユーザーは、ClassInがバックグラウンドに移行すると自動的に教室を退出します。 |
| ハードウェアドライバー修復 | ClassIn内のハードウェア修復機能で、マイク、スピーカー、カメラなどのデバイスの故障を解決するために使用します。 |
| edb | ClassIn独自の電子板書ファイル形式で、教師が教室で作成した板書を保存し、いつでも使用・共有できるようにするためのものです。 |
| 黒板 | **メイン画面の黒板機能：** ローカル教室を指し、教師と生徒が教室機能に慣れるためのものです。<br>**教室内の黒板：** 教師と生徒が教室内で使用するインタラクティブツールです。<br>**教室ツールボックス内の小黒板ツール：** 授業過程での解答とインタラクションに使用します。 |
| 大画面一体型マシン | ディスプレイとパソコン本体が一体化されたデバイスで、通常展示、デモンストレーション、情報配信に使用されます。 |
| 大画面一体型マシンと大画面モード | **大画面一体型マシン：** ディスプレイと本体が一体化されたデバイスです。<br>**大画面モード：** ClassIn教室内の操作画面モードです。 |
| コース | **ソフトウェア内のクラスの「コース」モジュール：** 単元テーマや学習アクティビティを追加できます。<br>**バックオフィス管理システムの「コース」：** ソフトウェア内の「クラス」と同じ意味です。 |
| バックオフィス管理システム | ClassInの管理プラットフォームで、教務教師はここでコースと課節を作成し、教師と生徒を管理し、授業データを監視し、個別設定などを行えます。 |
| 時間単位 | 30分＝0.5時間、1時間＝60分。 |
| データ容量単位 | 1GB＝1024MB、1MB＝1024KB、1KB＝1024バイト。 |
| スマートフォン | 通話、SMS送信、インターネット閲覧などの機能に対応する携帯型電子通信デバイスで、一般的なシステムにはiOS、Android、HarmonyOSがあります。 |
| タブレット | タッチスクリーンとソフトウェアキーボードを採用した携帯型電子デバイスで、一般的なシステムにはiOS、Android、HarmonyOSがあります。 |
| 授業受講端末 | ClassInクライアントを指します。 |
| ウェブ回放 | 授業終了30分後から共有リンクで視聴できるウェブ版授業回放動画で、クラウド録画授業機能をオンにする必要があります。 |
| アシスタント | 連席教師を指します。 |
| 教室 | 「教室」とは教育活動を行う場所を指し、正式授業、クラス臨時教室、友達臨時教室、ローカル教室を含みます。 |
| スペース | スペースはクラウドドライブとも呼ばれ、オンラインストレージサービスを提供する機能を指します。スペースを使用することで、ユーザーはローカルデバイス内のファイルをクラウドにアップロードでき、ファイルのリモートストレージとアクセスを実現できます。ユーザーは任意のデバイスをインターネットに接続し、ClassInソフトウェアにログインしてスペース欄に入るだけで、自分のファイルをオンラインで確認、共有、ダウンロード、編集できます。<br><br>スペースの利点は、高い信頼性と優れたクロスデバイス性にあります。ユーザーのファイルデータはクラウドサーバーに保存されており、ファイルデータの完全性とセキュリティを保証するだけでなく、ユーザーが任意の場所から任意のデバイスを使ってファイルをリモートでアクセス・管理することを可能にします。同時にクラウドスペースは複数のオンライン編集ツールも提供しており、ユーザーはローカル編集ソフトをダウンロードすることなく、直接オンラインでファイルを編集・処理できます。要するに、クラウドスペースは効率的で便利かつ安全なオンラインファイルストレージ・管理方式であり、ユーザーに大きな利便性と保障をもたらします。<br><br>ClassInでは2つの異なる場所から「スペース」に入ることができます。1つはClassInメイン画面のナビゲーションバーからスペースに入る方法、もう1つは教室内の教育ツール内の「スペース」ツールから「スペース」に入る方法で、この2つの場所の「スペース」内のデータは相互に連動しています。スペースの主な機能は、ユーザーに教材をオンラインで保存する場所を提供することです。ユーザーはスペース内で「リソースセンター」と「授権リソース」の教材を授権使用でき、「ClassIn問題バンク」と「ClassIn試験問題用紙ライブラリ」で試験問題用紙をカスタマイズすることもできます。さらにユーザーはTeacherlnに直接アクセスすることもできます。 |
| クライアント | ClassInクライアントを指します。 |
| 1v1 | 「1v1」とは、授業中に同時にカメラ映像が表示される人数、すなわち教師1人と生徒1人を指します。ClassInプラットフォームは複数の登壇人数構成に対応しており、1v1、1v2、1v3、1v4、1v5、1v6、1v7、1v8、1v9、1v10、1v11、1v12、1v13、1v14、1v15を含みます。 |
