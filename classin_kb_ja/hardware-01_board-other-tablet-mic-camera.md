## 【その他】ハードウェア使用問題

# 1. ページめくりペンと受信機を再ペアリングする

**症状：** ページめくりペンが使用できず、再ペアリングが必要です。

**解決方法：** ペアリング操作：ボタン1を長押ししたまま、ボタン2を連続で5回押します。インジケーターが点滅してペアリングモードに入ります。ボタン1を離すとペアリング完了です。

# 2. ページめくりペンのめくり距離が足りない

**症状：** ページめくりペンのめくり操作距離が近すぎて使いにくいです。

**解決方法：** ページめくりペンの受信機はできるだけ大画面の側面USBポートに挿し、受信機が遮られないようにしてください。

## 【手書きボード】ハードウェア使用問題

# 1. 文字入力異常

**症状：** 手書きボードで文字入力が正常にできません。

**解決方法：** 以下のいずれかの方法をお試しください。

**ドライバーのインストール確認：** ClassInTabletドライバーが正しくインストールされていることを確認してください。ドライバーダウンロードアドレス：https://www.eeo.cn/cn/download （インストール完了後、ドライバープログラムはバックグラウンドで最小化された状態で実行されている必要があります。絶対に終了しないでください）

**ドライバーの競合確認：** パソコンに高漫（Gaomon）、Wacomなど他の手書きボードドライバーがインストールされていないことを確認してください。インストールされている場合は、競合を避けるためこれらのドライバーをアンインストールしてください

**データケーブルの確認：** 純正のデータケーブルまたは互換性のあるHuaweiスマートフォン用データケーブルで接続してください（充電専用ケーブルは使用できません）

# 2. 手書きペンの替え芯を交換する

**症状：** 手書きペンの芯が著しく摩耗し、正常な使用に影響が出ている場合、新しい替え芯への交換が必要です。

**解決方法：** 下図の方法をお試しください。

# 3. ドライバーが未接続と表示される

**症状：** 手書きボードのドライバーが未接続と表示されます。

USBポートを別の場所に変更して接続してみてください

USBデータケーブルを別のものに交換して接続してみてください

Macパソコンを使用しているユーザーは、拡張ドックを別のものに交換して接続してみてください

# 4. 書き込み時のカクツキ

**症状：** 手書きボードで書き込む際にカクツキ現象が発生します。

**解決方法：** 360ドライバーマスターをダウンロード・インストールし、このツールでグラフィックドライバーを更新することで、手書きボードの書き込み体験を改善してください。

# 5. ペン先が触れていないのに文字が書けてしまう

**症状：** 手書きペンがボードに触れていない状態で文字が書けてしまいます。

**解決方法：** これは通常、手書きペンの故障が原因です。ClassInアフターサービスに連絡して新しい手書きペンへの交換を依頼することをおすすめします。

## 【無線マイク】ハードウェア使用問題

# 1. 充電ケースが充電できない（マンモスLARK150）

**症状：** マンモスLARK150無線マイク（ワイヤレスピンマイク）の充電ケースが充電できません。

**解決方法：** 以下の手順でリセット操作を行ってください。

充電ケースを充電器に接続します

ピン状の物で、充電ケース、マイク、受信機それぞれのリセット用小穴を5秒間長押しします

マイクと受信機を充電ケースから取り出し、充電ケース単体で30分間充電します

30分後、マイクと受信機を再度充電ケースに戻すと、デバイスの電量表示が確認でき、充電ケースは正常な充電機能を回復します

# 2. 接続方法は？（マンモスLARK150、M1、Rode）

**症状：** マイクの配線接続に関する問題。

**解決方法：** 以下の手順で操作してください。

**無線マイクと大画面一体型マシンの接続（TRSからTRSへのケーブルを使用）**

片端を無線マイク（ワイヤレスピンマイク）に接続

もう一方の端を大画面一体型マシンのOPSホスト上の赤色マイク音声ポートに接続

**無線マイクとノートパソコンの接続（TRSからTRRSへのケーブルを使用）**

TRS側を無線マイク（ワイヤレスピンマイク）に接続

TRRS側をノートパソコンの3.5mm音声ポートに接続

**無線マイクとスマートフォンまたはタブレットの接続（TRSからType-Cへのケーブルを使用）**

もう一方の端をスマートフォンやタブレットのType-Cポートに接続

**無線マイクとUSBサウンドカードの接続（TRSからTRSへのケーブルを使用）**

もう一方の端をUSBサウンドカードの赤色マイク音声ポートに接続

# 3. インジケーターランプの状態（マンモスM1）

| デバイス状態 | インジケーターランプ状態 |
| --- | --- |
| 通常スタンバイ | 青ランプ点灯 |
| 動画ストリームオン | 緑ランプ点灯 |
| トラッキングオン | 緑ランプ点灯（低輝度） |
| ホワイトボードモード | 黄ランプ点灯 |
| ジェスチャー認識成功 | 青ランプ速い点滅 |
| ジェスチャー使用不可 | オレンジランプ速い点滅 |
| アップグレードモード | 白ランプ点灯 |
| ファームウェア更新中 | 青ランプゆっくり点滅 |
| 故障 | 赤ランプ点灯 |
| プライバシースタンバイ | ランプ消灯 |

詳細情報は以下をご参照ください：https://www.insta360.com/support/supportdetail?name=link

# 4. 音がはっきり聞き取れない（マンモスLARK150、マンモスM1、Rode）

**症状：** マンモスLARK150、マンモスM1、またはRode無線マイク（ワイヤレスピンマイク）使用時、音が小さくはっきり聞き取れません。

**解決方法：** 以下のいずれかの方法をお試しください。

**デバイス自体の音量を調整する：** まず、無線マイクデバイス自体の音量設定を確認し高くしてください。デバイス音量が適切なレベルにあることを確認してください

**ClassIn教室のマイク音量を調整する：** ClassIn教室に入った後、マイク音量設定を見つけ、適宜マイク音量を高くして、音が明確に聞こえるようにしてください

**ClassIn教室の背景音ノイズキャンセリングをオフにする：** ClassIn教室で背景音ノイズキャンセリング機能をオフにします。これによりマイクの音量と音質が向上し、音がより明確になります

# 5. バッテリー持続時間

**症状：** マンモスM1の送信機、受信機、充電ケースのバッテリー持続時間について知りたい。

**回答：**

**マンモスM1無線マイク：**

送信機と受信機はいずれもフル充電後8時間連続使用可能です

付属の充電ケースは送信機と受信機をそれぞれ2回フル充電でき、長時間の使用ニーズを確保します

**マンモスLARK150無線マイク：**

送信機はフル充電状態で4時間連続使用可能です

受信機はフル充電状態で7時間連続使用可能です

充電ケースは満充電後、2つの送信機と1つの受信機を2.5回充電できます

注意：スマートフォンと同様、低温環境下での使用時、デバイスのバッテリー持続時間が短くなる場合があります。また、使用距離の違いも送信機や受信機のバッテリー持続時間に影響します

# 6. 3つの動作モード（マンモスLARK150）

マンモスLARK150受信端左側のボタンを長押しすると、以下の3つの動作モードを順に切り替えられます：モノラルモード、ステレオモード、セーフティトラックモード。

# 7. 3つの動作モードの効果は？（マンモスLARK150）

マンモスLARK150には3つの動作モードがあり、それぞれの効果は以下の通りです：

**ステレオモード：** 2つのマイク（MIC1とMIC2）で音声を収音する場合、受信端はMIC1の音声を左チャンネルに、MIC2の音声を右チャンネルに出力します。これにより、ユーザーは2つのマイクがそれぞれ収音した異なる音声を明確に聞き分けられます。

**モノラルモード：** このモードでは、2つのマイク（MIC1とMIC2）が収音した音声が合成され、受信端は合成後の音声を左右両チャンネルに出力します。これにより、左右チャンネルの音声内容が完全に一致し、モノラル音声が形成されます。

**セーフティトラックモード：** このモードでは、受信端がMIC1とMIC2の音声を合成処理しますが、左チャンネルと右チャンネルの音量が異なります。左チャンネルは通常音量、右チャンネルの音量は左チャンネルより6dB低くなります。これにより録音過程でバックアップトラックを提供でき、音量が過大なことによる音声の歪みを防ぎ、音声品質とユーザーのプライバシーの両方を保護します。

# 8. セーフティトラックモードは何のために使うのか？

現場録音時、突然音量が大きくなる状況に遭遇することがあり、この過大な音は録音ファイルの歪みや使用不能を引き起こす可能性があります。この状況に対応するため、マンモスLARK150のセーフティトラックモードを使用できます。このモードは録音時に2チャンネル音声を生成し、左チャンネルは通常音量の音声を、右チャンネルはより低い音量の音声を録音します。これにより、左チャンネルの音声が音割れや歪みを起こしても、右チャンネルの音声はバックアップとして引き続き使用でき、録音素材が完全に使用不可能になることを防げます。

# 9. 送信機と受信機のペアリング

**送信機のペアリングモードを起動：** 送信機の黄色いボタンを約3秒間長押しし、青いインジケーターランプが速く点滅するまで待ちます。

**受信機のペアリングモードを起動：** 受信機の「+」ボタンを約3秒間長押しし、青いインジケーターランプが速く点滅するまで待ちます。

**ペアリング完了を待つ：** 送信機と受信機の青いインジケーターランプが常時点灯状態になると、ペアリング成功を意味します。

**マンモスLARK150無線マイク：**

マンモスLARK150でペアリングする際は、送信機と受信機を充電ケースに入れて電源を入れるだけで、自動的にペアリングが完了し、追加の操作は必要ありません。

# 10. WP1無線マイクの周波数ロックとロック解除方法

**症状：** WP1マイクの周波数ロック状態を調整する必要がある。

**回答：** 以下の方法で操作してください。

**ハンドヘルドマイクのロック：**

ハンドヘルドマイクと受信機のペアリング後、ハンドヘルド端で「ページアップ」＋「ページダウン」を同時に押して離すと、画面にチャンネルが点滅表示され、「音量アップ」を押して離すと操作完了です。ロック成功後、画面上部に小さな鍵アイコンが表示されます

**ハンドヘルドマイクのロック解除：**

「ページアップ」＋「ページダウン」を同時に押して離すと、画面にチャンネルが点滅表示され、「音量ダウン」を押して離すと操作完了です

**受信機のロック：**

受信機とハンドヘルドマイクの自動ペアリング後、受信機の3つの「チャンネル」ディップスイッチをONの位置に切り替えると操作完了です

**受信機のロック解除：**

受信機の「チャンネル」ディップスイッチを調整し、3つのディップスイッチがすべてONの位置にならないようにします

注意：周波数ロック設定は、ハンドヘルドマイクと受信機の両方を周波数ロックモードに設定する必要があります。そうしないとリンク・ペアリングできません。

## 【雲台カメラ】ハードウェア使用問題

# 1. カメラの映像がぼやける

**症状：** パソコンをカメラに接続後、表示されるカメラ映像がぼやけます。

**解決方法：** 以下のいずれかの方法をお試しください。

レンズにホコリやその他の障害物がないか確認し、あれば清掃します

リモコンまたはカメラソフトでピントを調整します

リモコンまたはカメラ付属のソフトウェアでカメラのピントを調整します。鮮明度を確認する際は、画像が圧縮される可能性があるため、ClassInの黒板画面からカメラを開いて確認しないことをおすすめします。ClassInの補助カメラ機能、またはWindows標準搭載のカメラアプリを使用して、カメラの実際の鮮明度を確認してください

パソコンにiSmart CMSソフトをインストールし、フォーカス機能（フォーカス＋／－）を調整して映像の鮮明度を調整します

# 2. カメラ映像に波紋（フリッカー）が発生する

**症状：** パソコン／大画面一体型マシンをカメラに接続後、表示されるカメラ映像に波紋現象が発生します。

**リモコンを使用する場合：**

リモコンからメニューに入ります

「画像」＞「露出」＞「フリッカー防止」の順に選択します

フリッカー防止パラメーターを50Hzまたは60Hzに変更します

**大画面のタイプについて：**

大画面がClassinXブランドでなく、ドットマトリックス画面またはPWM（パルス幅変調）調光技術を使用している画面の場合、波紋現象を完全に解消できない場合があります

画面の輝度を上げるか、カメラの露出パラメーターを調整して波紋の発生を改善してみてください

# 3. 人物トラッキング機能をオフにする（CAM35/CAM36）

**症状：** パソコン／大画面一体型マシンをカメラに接続後、人物トラッキング機能をオフにする必要があります。

パソコンにiSmart CMSソフトをインストールし、カメラとパソコンが同じLAN内で接続されていることを確認します

iSmart CMSソフトを開き、「オンラインデバイス」オプションをクリックし、続けて「検索開始」ボタンをクリックしてLAN内のカメラデバイスをスキャンします（下図参照）

検索結果から、設定を変更したいカメラデバイスを選択し、「管理に追加」ボタンをクリックして、デバイスを「管理対象デバイス」リストに表示させます（下図参照）

「メインプレビュー」画面に入り、対応するカメラデバイスを選択して、トラッキング設定操作を行います（下図参照）

「パラメーター設定」オプションをクリックし、「基本2」設定画面に入ります。この画面で「起動時のデフォルト状態」を「トラッキングなし」に変更後、「保存」ボタンをクリックして設定を完了します（下図参照）

# 4. プリセット位置を設定する

**症状：** カメラ設置完了後、カメラの位置、焦点距離、画像などのパラメーターを事前設定するプリセット位置の設定が必要です。

**解決方法：** 以下の方法をお試しください。

**CAM34カメラ：**

プリセット位置の設定：数字キーを押した後「プリセット設定」キーを押します

プリセット位置の呼び出し：対応する数字キー＋「CALL」キーを押します

プリセット位置のクリア：対応する数字キー＋「CLEAR」キーを押します

**CAM37カメラ：**

プリセット位置の設定：数字キーを押した後「SET」キーを押します

**P1カメラ：**

プリセット位置の設定：数字キーを長押しし、カメラのインジケーターランプが1回点滅すれば設定完了です

# 5. 通電後、電源インジケーターランプが点灯しない

**症状：** カメラ通電後、電源インジケーターランプが点灯しません。

**解決方法：** カメラが通電後に反応せず、電源インジケーターランプも点灯しない場合、ハードウェアの故障の可能性があるため、Classinハードウェアアフターサービスに連絡して修理または交換を依頼してください。

# 6. プリセット位置をリセットする

**症状：** カメラのプリセット位置を調整する必要があります。

**解決方法：** 以下のいずれかの方法をお試しください。

対応する数字キーを直接押すと、カメラをプリセット位置に戻せます

まず対応する数字キーを押し、続けてCALLキーを押すと、カメラをプリセット位置に戻せます

# 7. 映像が表示されない（CAM34）

**症状：** CAM34カメラの青いPOWERランプと緑のSTANDBYランプが同時に点灯していますが、画面に映像が表示されません。

**解決方法：** CAM34カメラの青いPOWERランプと緑のSTANDBYランプが同時に点灯している場合、カメラが起動中であることを示します。約20秒間お待ちいただき、青いPOWERランプのみが点灯するまで待ってください。これはカメラの起動が正常に完了したことを示します。この時点で映像が正常に表示されます。

# 8. 画面が乱れる（CAM37）

**症状：** CAM37カメラの画面が乱れる現象が発生します。

まずカメラとパソコン間の接続ケーブルの種類（通常はHDMIケーブルまたはSDIケーブル）を確認してください

HDMIケーブルまたはSDIケーブルを使用している場合、新しいHDMIケーブルまたはSDIケーブルに交換してみてください

ケーブルを交換しても問題が解決しない場合、カメラ付属のMini USBケーブルでの接続をおすすめします

# 9. 映像が表示されない（CAM37）

**症状：** CAM37カメラを接続後、映像が表示されません。

**解決方法：** 以下のいずれかの方法をお試しください

**接続ケーブルを確認：** CAM37カメラとパソコン間の接続ケーブルが正しくしっかりと接続されていることを確認してください。データケーブルが破損または緩んでいないことを確認してください

**電源接続を確認：** CAM37カメラの電源が正しく接続され、電源インジケーターランプが正常に点灯していることを確認してください

**再起動を試す：** リモコンの電源ボタンでカメラの再起動を試みてください

# 10. 映像が表示されない（CAMP1）

**症状：** CAMP1カメラの緑ランプと赤ランプが同時に点灯していますが、画面に映像が表示されません。

**解決方法：** CAMP1カメラの緑ランプと赤ランプが同時に点灯している場合、カメラが起動中であることを示します。約20秒間お待ちいただき、赤ランプが消灯するまで待ってください。これはカメラの起動が正常に完了したことを示します。この時点で映像が正常に表示されます。

# 11. オートズームをオフにする

**症状：** カメラのオートズーム機能をオフにする必要があります。

カメラのリモコンを見つけます

リモコンの「手動」ボタンを押します

# 12. カメラの輝度を調整する（CAM34）

**症状：** カメラの画面輝度を調整する必要があります。

**解決方法：** CAM34カメラの輝度を調整するには、以下の手順で操作してください。

CAM34カメラのリモコンの「メニュー」ボタンを押します

パソコン画面にカメラの設定画面がポップアップ表示されます

設定画面で「露出」項目を選択して入ります

「露出」項目内で、「輝度補正」オプションを見つけて、満足のいく輝度効果になるまで調整します

# 13. カメラの焦点距離を調整する

**症状：** カメラの焦点距離を調整する必要があります。

リモコンの「－」キーまたは「＋」キーで焦点距離を調整します

# 13. USBカメラが認識されない

**症状：** カメラ設置後、大画面がこのハードウェアを認識できません。

パソコン側のUSBポートを一度抜いて挿し直します

カメラを再起動します（できれば電源を切ってからカメラを再起動してください）

パソコンのデバイスマネージャーを開き、「不明なUSBデバイス」をアンインストールしてから再度読み込んでインストールします

以上の方法でも解決しない場合、USBケーブル自体の故障の可能性を検討してください
