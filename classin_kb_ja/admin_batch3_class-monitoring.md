## 教室からの救援メッセージの受信と返信

### 一、救援メッセージの受信

**対象者**
- 「管理バックエンド」主アカウント
- 「監課管理」権限を持つ子アカウント

**こんなときに**
教室内の教師や生徒が助けを必要とする場合、教室内の救援機能を使って「管理バックエンド」に救援メッセージを送信できます。教務担当者は管理バックエンドにログインし、「監課管理」ページで該当の授業を見つけ、授業下部の問題情報をクリックして教室から提出された問題を確認できます。教務担当者はこれらの問題に返信し、サポートを提供できます。

**関連記事**
- 「管理バックエンドに子アカウントを追加」

**操作手順**
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「監課管理」に進む
3. 授業を見つける
4. 授業左下の「救援メッセージ」を確認

### 二、教室にメッセージを送信
「バックエンド管理システム」主アカウントが必要です。

教務担当者が教室を監課する際は傍聴者としての立場のため、教室内の誰とも交流できません。教室内のあるユーザーに異常な問題を発見した場合、教務担当者はバックエンド管理システムから教室内の特定のメンバーに文字メッセージを送信し、問題の解決方法を案内できます。

**操作手順**
1. 授業下部の「連絡」をクリック
2. 「教師に連絡」または「生徒に連絡」を選択
3. 連絡対象にチェックを入れ、「問題の説明」に内容を入力し「送信」をクリック

## 監課画像の確認

### 対象者
- 「管理バックエンド」主アカウント
- 「監課管理」権限を持つ子アカウント

### 使用説明
教務担当者は監課詳細ページに入ると、教室内の監課画像を確認できます。監課画像は ClassIn システムが教師視点で自動的にスクリーンショットを撮影したもので、毎分1枚ずつ自動保存されます。

### 注意事項
- 監課管理では最大1000枚まで表示されます。

3. 授業を見つける
4. 画像をクリックして詳細に入り、監課画像を確認

## アカウント速査（ユーザーの授業機器使用状況の確認）

### 対象者
- 「管理バックエンド」主アカウント
- 「アカウント速査」権限を持つ子アカウント

### こんなときに
教室内の教師や生徒からネットワークの不安定さや授業のカクつきについて報告があった場合、教務担当者は「管理バックエンド」でそのユーザーの授業中のネットワークと機器の状況を確認できます。

### 使用説明
教務担当者は「管理バックエンド - アカウント速査」でユーザーの「電話番号」や「メールアドレス」、および「授業時間」の情報から、そのユーザーの授業中のネットワーク状況と機器使用状況を照会できます。確認できる情報には、授業名、コース名、開課時間、授業時間、壇上人数、ユーザーの教室内での身分、ユーザーの授業中の各時間帯でのネットワーク使用状況とデバイスのCPU使用率、ユーザーが教室に入った時間、教室を退出した時間とその理由、ユーザーが録画機能を有効にしていたかどうか、録画が正常に行われていたかどうかなどが含まれます。デバイス情報欄の各デバイスアイコンにカーソルを合わせると、ユーザーが教室内で使用したカメラ、マイク、スピーカーの使用状況（無効化されていたか、機器が認識されなかったか、複数機器がある場合はどの機器を選択したかなど）を確認できます。また、授業時に使用したデバイスのシステムバージョン、接続先サーバー名、デバイスのCPUモデル、ClassIn のバージョン番号、無線か有線かのネットワーク種別も確認できます。

### 関連記事
- 「管理バックエンドに子アカウントを追加」

### 操作手順
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「アカウント速査」に進む
3. 上部で日付を選択し、ClassIn アカウントを入力
4. 下部で授業時のネットワークと機器使用状況を確認

## 監課教室に入る

### 対象者
- 「管理バックエンド」主アカウント
- 「監課管理」権限を持つ子アカウント

### こんなときに
- 教務担当者が学校内のある教師の授業を傍聴したい場合、バックエンド管理システムの監課管理ページから対応する教室に入って傍聴できます。
- 教室内の授業教師がネットワーク不安定や機器の問題によりクラウド録画が中断され、正常に録画を継続できない状況で、かつその授業に共同担当教師がいない場合、教務担当者はバックエンド管理システムの監課管理ページから対応する教室に入り、ローカル録画を行うことができます。

### 使用説明
教務担当者が監課を行う場合、「管理バックエンド」の「監課管理」ページで「教室に入る」ボタンをクリックする必要があります。この時、関連アプリを起動するかどうかの確認がブラウザに表示され、教務担当者は「許可」または「ClassIn を開く」などのボタンをクリックすることで監課教室に正常に入れます。この操作手順に沿ってもClassInソフトウェアが正常に起動しない場合は、パソコンのウイルス対策ソフトを終了し、ClassInソフトウェアの設定内でレジストリを修復してください。修復完了後、再度起動操作を行ってください。なお、教務担当者がバックエンド管理システムから教室に入って監課を行うのは無料であり、費用は発生しません。

教務担当者が教室に入って監課を行う際は「透明人間」の身分で入室します。この時、教室内の教師や生徒は教務担当者の存在に気づくことができず、教務担当者も教室内の誰とも交流できません。ただし注意すべき点として、教務担当者が使用しているバックエンド管理システムのアカウントがその教室内で共同担当教師または生徒の身分を持っている場合、教務担当者が監課のために教室に入る際、その身分に自動的に切り替わります。この場合、教務担当者は教室内のメンバーと交流でき、教室内のメンバーも教務担当者の存在に気づくことができます。教務担当者が「透明人間」以外の身分で入室した場合、通常の教室利用と同様にバックエンド管理システムの料金が発生します。

### 注意事項
- 監課管理では最大1000教室まで表示されます。
