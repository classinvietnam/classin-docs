## 「メンバーによる臨時教室作成を許可」デフォルト状態設定

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### 使用方法
教務担当者は、クラスの利用状況に応じて、クラス作成前に、そのクラス内の教師・生徒がデフォルトで臨時教室を作成できるかどうかをオン／オフにできます。

### 注意事項
この機能をオンにした場合、新しく作成されたコース（クラス）にのみ適用され、既に作成済みのコース（クラス）には影響しません。

### 関連記事
「バックオフィスでのサブアカウント追加」

### 操作手順
1. バックオフィス管理システムにログインします。
2. 左側のナビゲーションから「学校設定」に進みます。
3. 上部の「クラス設定」に進みます。
4. 「デフォルトで臨時教室の開始を許可するメンバー」で、教師・生徒の臨時教室作成権限をオン／オフにします。

## クラスニックネームの同期

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### 使用方法
教務担当者は、バックオフィス管理システムでクラスニックネーム同期機能をオンにできます。この機能をオンにすると、生徒がその学校配下のクラスに参加するたびに、バックオフィス管理システム上の生徒の氏名が、新しく参加したクラスのニックネームとして自動的に同期されます。

なお、この同期は生徒がクラスに初めて参加したときにのみ実行されます。バックオフィス管理システムで生徒の氏名を変更しても、新しい氏名は既に参加済みのクラスには同期されません。また、この機能は自校のクラスにのみ適用されます。生徒が他校のクラスに参加した場合、ニックネームは同期されません。

### 関連記事
「バックオフィスでのサブアカウント追加」

### 操作手順
1. バックオフィス管理システムにログインします。
2. 左側のナビゲーションから「学校設定」に進みます。
3. 上部の「クラス設定」に進みます。
4. 「クラスニックネーム同期設定」で「新しくコースに参加した生徒のバックオフィス氏名をClassInクラスニックネームとして同期する」をオン／オフにします。

## クラスを退出した生徒やクラス解散後も、コース内容を閲覧できる

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### 使用方法
この機能をオンにすると、「教師が生徒をクラスから退出させた」「クラスが解散された」「生徒が自らクラスを退出した」といった状況が発生した場合でも、既にクラスを離れた生徒は引き続き授業／授業コマの再生、板書、録画授業動画、その他の活動添付ファイルを閲覧できます。

この機能をオフにすると、同様の状況が発生した場合、既にクラスを離れた生徒は授業／授業コマの再生、板書、録画授業動画、その他の活動添付ファイルを閲覧できなくなります。

### 注意事項
「クラスを退出した生徒やクラス解散後も、コース内容を閲覧できる設定」機能をオン／オフにした場合、その効果はこの機能の変更後に新しく作成されたコース（クラス）の再生動画にのみ及びます。この機能の変更前に既に作成されていたコース（クラス）の再生動画は影響を受けません。また、この機能の状態を再度変更した場合でも、その時点で既にこの機能の影響を受けていた生徒の再生動画へのアクセス権限は変わりません。

板書、録画授業動画、その他の活動添付ファイルへのアクセス可否は、「クラスを退出した生徒やクラス解散後も、コース内容を閲覧できる設定」機能の現在の状態に応じて調整されます。新規コース（クラス）・既存コース（クラス）を問わず、この設定の影響を受け、状態はいつでも変更可能です。

「バックオフィスでのサブアカウント追加」

### 操作手順
1. バックオフィス管理システムにログインします。
2. 左側のナビゲーションから「学校設定」に進みます。
3. 上部の「クラス設定」に進みます。
4. 「クラスを退出した生徒やクラス解散後も、コース内容を閲覧できる設定」で「クラスの『クラスを退出した生徒やクラス解散後も、コース内容を閲覧できる』設定をデフォルトでオンにする」をオン／オフにします。

## コースのデフォルトカバー画像

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### こんな時に使う
教務担当者は、バックオフィス管理システムで「コース（クラス）」のデフォルトカバー画像を設定できます。学校の教師がクラスを作成する際、「コース（クラス）」のカバー画像をカスタマイズしていない場合、システムはバックオフィス管理システムで設定されたデフォルトの「コース（クラス）」カバー画像を使用します。教師はいつでもカスタムの「コース（クラス）」カバー画像に変更できます。

### 使用方法
教務担当者がアップロードする画像は固定比率でのトリミングに対応しています。推奨する画像比率は900px×900pxで、画像サイズは1MB以内にしてください。

3. 上部の「基本設定」に進みます。
4. 「コースのデフォルトカバー画像（クラスのデフォルトアバター）」で「編集」をクリックし、クラスのデフォルトカバー画像を設定します。
