## 担任教師管理

### 対象者
- 「管理バックエンド」主アカウント
- 「権限管理」権限を持つ子アカウント

### こんなときに
クラスの担任教師を変更する必要がある場合、教務担当者は管理バックエンドで該当のコースを見つけ、現在の担任を別の人に変更できます。

3. クラスを見つけ、クラス名をクリックしてクラスに入る

1. 「クラス管理」に進む
2. 複数のクラスを選択
3. 「一括操作」をクリック
4. 「担任教師を一括設定」を選択

## 受講除外生徒管理

### 一、受講除外生徒とは？
受講除外生徒とは、教師が特定のクラス内で、ある生徒が特定の授業に参加することを禁止した生徒を指します。除外された生徒はその授業の教室に入れませんが、そのクラスの他の授業には引き続き参加できます。

### 二、受講除外生徒の設定

**対象者**
- 「管理バックエンド」主アカウント
- 「クラス管理」権限を持つ子アカウント

**使用説明**
クラスの生徒が早期に退会したり、教務担当者が特定の生徒をある授業への参加禁止としたい場合、教務担当者はクラス内の生徒をその授業の除外生徒として設定できます。除外生徒に設定されると、その生徒は禁止された授業に参加できなくなり、その授業の録画再生も視聴できなくなります。

**関連記事**
- 「管理バックエンドに子アカウントを追加」

**操作手順**
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「クラス管理」に進む
3. クラスを見つけて入る
4. 「時間割」に進む
5. 授業を見つけ、右側の「受講除外生徒」欄の「追加」ボタンをクリック
6. 除外生徒を追加

### 三、受講除外生徒を削除
「権限管理」権限を持つ子アカウントが必要です。

授業を見つけ、右側の受講除外生徒の位置にカーソルを合わせ、鉛筆アイコンが表示されたらクリックして削除。全員一括削除または個別削除に対応。

## 聴講生管理

### 一、聴講生とは？
聴講生とは、教室に入って授業を聴講できる生徒を指します。聴講生は教室内で正常に授業を聞くことができますが、教師や他の生徒には見えず、名簿にも名前が表示されません。つまり、聴講生は授業中「透明」の状態です。それでも、累計出席時間が10分に達すれば有効な出席として記録されます。ただし、聴講生は教室内でツールを一切使用できず、授業を聴くことに専念します。聴講生を追加すると、クラスの生徒名簿には表示されますが、授業の録画再生は視聴できません。

### 二、聴講生の追加

**対象者**
- 「管理バックエンド」主アカウント
- 「クラス管理」権限を持つ子アカウント

**こんなときに**
各クラスには最大20人まで聴講生を追加できます。この機能は主に教務担当者がクラスに体験受講の枠を追加できるようにするためのものです。これにより生徒がそのコースを体験できます。聴講生はクラスグループに参加し、他の生徒や教師と交流できますが、教室内の他の人からは聴講生を見ることができません。つまり、聴講生は教室に入ると透明の状態で受講することになります。この機能は、興味のあるクラスを検討中の生徒がある授業を体験し、評価後に正式に受講するかどうかを決定するのに適しています。

**関連記事**
- 「管理バックエンドに子アカウントを追加」

**操作手順**
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「クラス管理」に進む
3. クラスを見つけて入る
4. 「メンバー」に進む
5. 「聴講生」に進む
6. 「聴講生を設定」をクリック

### 三、聴講生を削除
「権限管理」権限を持つ子アカウントが必要です。

聴講生を削除。

## 編入生管理

### 一、編入生とは？
編入生とは、クラスに所属していない生徒で、教務担当者によって特定のクラスの特定の授業に聴講参加するよう手配された生徒を指します。

### 二、編入生の追加

**対象者**
- 「管理バックエンド」主アカウント
- 「クラス管理」権限を持つ子アカウント

**こんなときに**
教師がある生徒に特定の授業を体験してもらいたい場合、かつその生徒が教室内で教師や他の生徒と交流できるようにしたいが、実際のクラスには追加したくない場合、その生徒をその授業の編入生として追加できます。

**使用説明**
「編入生」とは、クラスに所属していない生徒で、教務担当者によって特定のクラスの特定の授業に聴講参加するよう手配された生徒を指します。編入生にはクラスグループがないため、クライアントのクラスグループ内で教師が出す課題やテスト、チャットには参加できません。ただし編入生は編入先の授業の教室には入ることができ、教室内では他の生徒と同じ権限（壇上での発言、教師によるツール使用権限の付与、教室内チャットへの参加など）を持ちます。

**注意事項**
- すでにクラスに所属している生徒は、そのクラス内のどの授業にも編入生として追加することはできません。
- 編入生とクラス生徒は同じクラス人数上限を共有します。

**関連記事**
- 「管理バックエンドに子アカウントを追加」

**操作手順**
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「クラス管理」に進む
3. クラスを見つけて入る
4. 「時間割」に進む
5. 授業を見つけ、右側の「編入生」欄の「追加」ボタンをクリック
6. 自校内の生徒・教師、または他校の人員を編入生として追加可能

### 三、編入生を削除
授業を見つけ、右側の編入生の位置にカーソルを合わせ、鉛筆アイコンが表示されたらクリックして削除。一括削除または個別削除に対応。

## クラス生徒管理（バックエンド）

### 一、クラス生徒の追加

**対象者**
- 「管理バックエンド」主アカウント
- 「クラス管理」権限を持つ子アカウント

**使用説明**
管理バックエンドでは、教務担当者は ClassIn に登録済みかどうかに関わらず、任意の生徒をクラスに追加できます。生徒がすでに ClassIn に登録済みで管理バックエンドの生徒リストに追加されている場合、教務担当者は生徒の名前や電話番号で検索するだけで簡単に見つけてクラスに追加できます。生徒が管理バックエンドの生徒リストに追加されていない場合や、ClassIn アカウントを未登録の場合は、教務担当者が代理登録を行いながらクラスに追加できます。

**関連記事**
- 「聴講生管理」
- 「編入生管理」
- 「管理バックエンドに子アカウントを追加」

**操作手順**
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「クラス管理」に進む
3. クラスを見つけ、クラス名をクリックしてクラスに入る
4. 「メンバー」に進む
5. 「クラス生徒を設定」をクリック

### 二、他のクラスの生徒をコピー

**対象者・こんなときに**
管理バックエンドで、あるクラスの授業数が上限に達しており、教師が新しい授業を追加する必要がある場合、新しいクラスを作成しなければなりません。新しいクラスで全生徒を再度手動追加する手間を省くため、システムは元のクラスの全生徒を新しいクラスに直接コピーする機能を提供し、時間と労力を節約して業務効率を向上させます。

**注意事項**
- クラスにすでに生徒がいる場合、他のクラスの生徒名簿をコピーすると、現在のクラスの既存の生徒全員が置き換えられます。操作には十分ご注意ください。

**操作手順**
1. 「クラス生徒をコピー」をクリック

### 三、クラス生徒の編集
教務担当者がクラス内の生徒メンバーを変更する必要がある場合、クラス生徒リストから直接編集できます。
- 右上で生徒の追加または削除

### 四、クラス生徒の削除
生徒個別に削除するか、複数選択後に一括操作から一括削除を選択します。

## 公開授業の作成/編集/削除（バックエンド）

### 一、公開授業の作成

**対象者**
- 「管理バックエンド」主アカウント
- 「公開授業」権限を持つ子アカウント

**こんなときに**
クラスに属さない授業（クラス会議、保護者会、著名教師講座、教師研修会など）を作成したい場合、公開授業の作成を検討してください。これにより多様な教育シナリオへの対応がより柔軟になります。

**使用説明**
管理バックエンドで公開授業を作成すると、ソフトウェア側にも対応する公開授業が自動生成されます。逆にソフトウェア側で公開授業を作成した場合も、管理バックエンドに対応する公開授業コースが生成されます。この2つの公開授業に違いはありません。

**操作手順**
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「公開授業」に進む
3. 「公開授業を作成」をクリック
4. パラメータを設定

### 二、公開授業の編集
「クラス管理」権限を持つ子アカウントが必要です。
1. 公開授業を見つける
2. 編集したいパラメータにカーソルを合わせ、右側に鉛筆アイコンが表示されたらクリックしてその項目を編集

### 三、公開授業の削除
1. 右側の「操作」をクリックし、「公開授業を削除」を選択

## タグ管理

### 対象者
- 「管理バックエンド」主アカウント
- 「権限管理」権限を持つ子アカウント

### こんなときに
管理バックエンドでのタグの主な役割は、教務担当者がコース、授業、教師・生徒メンバーをより便利に管理できるようにすることです。タグを使うことで、教務担当者はコース、授業、メンバーをタグに基づいて分類・特定し、より素早く検索できます。これにより管理業務の効率と利便性が向上します。

### 使用説明
管理バックエンドではタグの総数上限は2000個、各コース・各授業、各教師・各生徒の個人タグ数の上限はそれぞれ10個です。

### 関連記事
- 「管理バックエンドに子アカウントを追加」

### 操作手順

**（1）コースタグ情報の追加/編集**
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「コース管理」に進む
3. 右側の「コースを作成」をクリック
4. 下部で「コースタグを選択」をクリック
5. 新規タグを作成、または既存タグを選択
6. 「確定」をクリックして保存

**（2）授業タグ情報の追加/編集**
1. コースを見つけ、コース名をクリックして授業詳細に入る
2. 「授業を追加」をクリック
3. 「授業タグを選択」をクリック

**（3）教師タグ情報の追加/編集**
1. 左側ナビゲーションから「教師管理」に進む
2. 教師を見つけ、右側の「表示」をクリック
3. その後「編集」をクリック
4. タグを選択

**（4）生徒タグ情報の追加/編集**
1. 左側ナビゲーションから「生徒管理」に進む
2. 生徒を見つけ、右側の「表示」をクリック

## 双師授業の作成/編集/削除

### 一、双師授業の作成

**対象者**
- 「管理バックエンド」主アカウント
- 「権限管理」権限を持つ子アカウント

**使用説明**

**方法一：新規《クラス》を作成し《主授業/子授業》を追加**
教務担当者が管理バックエンドで双師授業の主授業をまだ作成していない場合、まず管理バックエンドで新しいクラスを作成します。次にそのクラス内に授業を1つ新規追加します。その後、子授業を一括追加し、新規作成した授業を主授業として設定します。

**方法二：既存《授業》を《主授業》に設定し《子授業》を追加**
教務担当者は管理バックエンド内のクラスに直接入り、「子授業を一括作成」をクリックして、既存の授業を双師授業の主授業として設定し、その後子授業を追加することもできます。

**注意事項**
- 双師授業機能はカスタマーマネージャーに連絡して個別に有効化する必要があります。
- 双師授業の主授業1つにつき、最大100個の子授業を作成できます。
- 主授業の開始時刻まで5分未満、または開始時刻を過ぎている場合は子授業を作成できません。
- 「ソフトウェア」と「管理バックエンドシステム」の両方で主授業の編集/削除に対応しており、変更内容は子授業に自動的に同期されます。
- 子授業の設定は「ソフトウェア」内では変更できず、「管理バックエンドシステム」内でのみ変更可能です。
- 双師授業のために専用のクラスを新設する必要はなく、既存のクラスでも実施できます。
- 主授業と子授業は同じクラス内には存在できません。

**関連記事**
- 「管理バックエンドに子アカウントを追加」

**操作手順**

**「主授業」を新規作成**
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「クラス管理」に進む
3. クラスを見つけて入る
4. 「時間割」に進む
5. 「新規」をクリック
6. 「授業を作成」を選択

**「子授業」を追加**
1. 授業を選択（選択した授業は自動的に主授業になります）
2. 「子授業を一括追加」をクリック
3. 子授業の関連パラメータを設定（事前に子授業を格納する空のクラスを作成しておく必要があります。子授業作成時、その事前作成した空のクラスに紐づけます）

### 二、双師授業の編集
子授業を編集する際、開課日、開課時間、授業時間、担当教師の変更には対応していません。
- 子授業は「管理バックエンド」でのみ編集可能です。
- 主授業は「管理バックエンド」と「ソフトウェア」の両方で編集可能です。

**「主授業」または「子授業」を編集**
1. 主授業または子授業が属するクラスを見つけて入る
2. 授業を編集

### 三、双師授業の削除
教務担当者は管理バックエンドで主授業と子授業を削除できます。まず該当の主授業を見つけます。主授業のオンライン双師ページで子授業を削除します。主授業を削除すると、すべての子授業も自動的に削除されます。特定の子授業のみを削除したい場合は、その子授業のみを削除すれば他の子授業には影響しません。

主授業を削除すると、その主授業に関連するすべての子授業も自動的に削除されます。

1. 左側ナビゲーションから「コース管理」に進む
2. 主授業が属するクラスを見つけて入る
3. 主授業右側の「操作」をクリックし、「オンライン双師」を選択
4. 主授業または子授業を削除

## 授業の作成/編集/削除（バックエンド）

### 一、授業の作成

**対象者**
- 「管理バックエンド」主アカウント
- 「クラス管理」権限を持つ子アカウント

**使用説明**

授業追加時に設定可能なパラメータは以下の通りです：

| 設定 | 説明 |
| --- | --- |
| 授業名 | 最大50文字 |
| 開課日 | 当日または他の日付で授業を作成可能 |
| 開課時間 | 最短で5分後から設定可能 |
| 授業時間 | 最短15分、最長23時間55分に設定可能 |
| 担当教師 | 主講教師を追加（1授業につき1名のみ） |
| 共同担当教師 | 1授業あたり最大6名まで追加可能、0名も可 |
| 教育モード | 「オンライン教室」は純粋なオンライン授業に、「スマート教室」はオンライン・オフライン混合授業に適しています |
| 自動壇上表示 | 有効時、生徒が教室に入るとカメラのオンオフに関わらずカメラ枠が壇上に表示されます。無効時、生徒は壇下で授業を聞く形になり、カメラが自動で壇上に表示されません |
| 壇上人数 | 最小1v0、最大1v12。1v0は壇上に教師のカメラのみ表示（生徒カメラなし）。1v12は教師カメラに加え最大12名の生徒カメラを同時表示可能 |
| 授業クラウドディスクリソース | この授業の教室内でのみ開ける公開教材リソース |
| クラウド録画 | 「教室を録画」と「現場を録画」を同時に有効化可能。単一モードの選択や、いずれの録画モードも有効にしないことも可能 |
| ライブ配信/再生 | 「Webライブ配信」と「Web再生」を同時に有効化可能。「Webライブ配信」権限を有効にすると、教師が共有する「Webライブ配信/再生リンク」でリアルタイム授業配信を視聴できます。「Web再生」機能を有効にすると、共有リンクで授業の録画再生を視聴できます |

**注意事項**

### 一、クラスの作成

**対象者**
- 「バックエンド管理システム」主アカウント
- 「クラス管理」権限を持つ子アカウント

**使用説明**
管理バックエンドで作成したクラスは、より豊富な個別設定に対応しています。例えば、編入生、受講除外生徒、聴講生の追加などの操作が可能です。また、管理バックエンドには担任教師の変更などの機能もあります。そのため、複雑な管理操作が必要な場合は管理バックエンドでクラスを作成・管理することを推奨します。

クラス作成時に設定可能なパラメータは以下の通りです：

| 設定 | 説明 |
| --- | --- |
| クラス名 | 必須項目。わかりやすいクラス名を設定（最大40文字） |
| 担任教師 | クラスの担任教師を指定。担任教師は ClassIn クラス内でメンバー管理や授業の作成/削除などが行えます |
| クラス教師 | クラス内で授業や管理補助を行う教師。クラス作成後、メンバーからも設定可能 |
| クラス生徒 | クラス内でクラス活動や授業に参加する生徒。クラス作成後、メンバーからも設定可能 |

### 三、クラスの結課

**「結課」とは？**
「結課」とは、教務担当者が ClassIn の管理バックエンドシステムであるクラスを結課操作することを指し、これに対応する ClassIn ソフトウェア内のクラスも同期して解散されます。逆に ClassIn ソフトウェア内でクラスが解散されると、システムは自動的にバックエンド管理システム内の対応するコースを結課します。したがって、「結課」と「クラス解散」は同じ意味で、一方はバックエンド管理システムで、もう一方は ClassIn ソフトウェアで行う操作です。

**こんなときに**
教務担当者が ClassIn ソフトウェアであるクラスを解散したいが、そのクラスの担任教師ではない場合、ソフトウェア内で操作できません。この場合、教務担当者は「管理バックエンドシステム」にログインし、該当のクラスを見つけて結課できます。クラスが結課すると、対応する ClassIn ソフトウェア内のクラスも解散されます。

「管理バックエンド」での「結課」とソフトウェアでの「クラス解散」は同じことを指します。「管理バックエンド」で「結課」操作を行うと、ソフトウェア内の対応するクラスも「解散」されます。逆にソフトウェア内でクラスが「解散」されると、「管理バックエンド」内の対応するクラスも「結課」されます。ただし、コース内にまだ開始または終了していない課節がある場合は「結課」操作を行うことができません。クラスが結課すると、クラス内の生徒と教師はクラスグループを通じたやり取りができなくなります。ただし、これはクラス内の録画再生視聴には影響しません。

結課後も生徒がクラス内の過去の録画再生動画を引き続き視聴できるようにしたい場合は、《クラス退会後またはクラス解散後もクラス内容の閲覧を許可する設定》を有効にしてください。

クラスは削除できず、結課のみ可能です。

**（1）単一のクラスを結課**
1. 左側ナビゲーションから「クラス管理」に進む
2. クラスを見つけ、右側の「結課」をクリック

**（2）一括結課**
1. 複数のクラスを選択し、「一括操作」をクリックして「一括結課」を選択
