## ストレージ容量の拡張

### 対象者
- 「管理バックエンド」主アカウント

### こんなときに
バックエンドのストレージ残量が少ない、または不足している場合、バックエンド管理権限を持つ主アカウントは管理バックエンドでストレージ容量を拡張し、授業中に自動保存される板書や教材、クラス内のファイルが正常にバックエンド管理システムに保存され続けられるようにできます。

### 使用説明
ストレージ拡張時に選択できるプランは、100GB/年 と 1000GB/年 の2種類です。支払い方法は WeChat Pay、Alipay、PayPal、Stripe に対応しています。

### 操作手順
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「データ概要」に進む
3. 「拡張」をクリック
4. 拡張プランを選択し、支払いを完了

## ストレージデータ概要

### 「データ概要」とは？
「データ概要」とは、ClassIn バックエンド管理システム内の各種データのストレージ状況を指します。これには学校資料、監課録画記録、クラスファイル、コース添付ファイルなどが含まれます。

### 対象者
- 「管理バックエンド」主アカウント
- 「データ概要」権限を持つ子アカウント

### 使用説明
「管理バックエンド」には「データ概要」というセクションがあり、現在の ClassIn バックエンド管理システム内のすべてのデータのストレージ状況を確認できます。ここでは、学校資料、監課録画、クラスファイルなど、どのようなデータが保存されているか、それぞれが占めるストレージ容量を確認できます。また、これらのデータの使用率も確認でき、バックエンド管理システム内のデータ使用状況をより深く理解するのに役立ちます。

### 操作手順
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「データ概要」に進む

## ストレージリソースの自動削除

### 対象者
- 「管理バックエンド」主アカウント
- 「学校設定」権限を持つ子アカウント

### 使用説明
教務担当者はバックエンド管理システムでストレージリソースの自動削除期間を設定できます。この機能を有効にすると、毎日、削除条件（設定した日数）にちょうど達した「録画動画（授業回放動画）」「監課画像」「コース - 録画授業添付ファイル」「コース - 課題添付ファイル」「コース - 答案用紙添付ファイル」「コース - ディスカッション添付ファイル」「クラスファイル」「コース - 学習資料添付ファイル」「コース - チェックイン添付ファイル」が削除されます。

例えば「3ヶ月経過した録画動画を毎日自動削除」を有効にした場合：10月11日にシステムは7月11日の録画動画を自動削除、10月12日には7月12日の録画動画を自動削除、というように続きます。11月末最終日（30日）には、8月最終数日（30日、31日）の録画動画が自動削除されます。

注意点：
（1）アップロードされた「録画動画（授業回放動画）」は授業の開課日を基準にストレージ期間が計算されます。
（2）保護ロックが有効なリソースは削除されません。
（3）自動削除機能を有効にしても、設定した月数を既に超えているストレージリソースは自動的には削除されません。より古いストレージリソースを削除する場合は、「履歴ストレージリソースの削除」で削除タスクを作成するか、「監課録画」または「コースリソース」で手動削除してください。

### 関連記事
- 「履歴ストレージリソースの削除」
- 「管理バックエンドに子アカウントを追加」

### 操作手順
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「学校設定」に進む
3. 上部の「ストレージ設定」に進む
4. 「ストレージリソースの自動削除設定」で自動削除機能をオン/オフし、自動削除時間を設定

## 公開/個人権限付与リソース

### 一、公開権限付与リソース

**対象者**
- 「管理バックエンド」主アカウント
- 「教師管理」権限を持つ子アカウント

**使用説明**
教師管理に入ると、右上のボタンから公開権限付与リソース機能をオン/オフできます。特定の教師の公開権限付与リソースを個別に管理する場合は、検索でその教師を見つけ、右側でオン/オフを選択できます。これはその教師個人の公開権限付与リソース設定にのみ影響します。また右上には公開権限付与リソースをカスタマイズするオプションがあり、最大40個のフォルダをカスタマイズできます。カスタマイズ完了後にこの機能を有効にすると、利用権限を持つ教師は IM、教室、備課室、黒板などで公開権限付与リソース内のファイルを閲覧・開くことができます。

**注意事項**
- 停止中の教師は学校クラウドディスク内のファイルを一切閲覧できません。

**関連記事**

**操作手順**
1. 教師右側で個人権限付与リソースをカスタマイズ

## クラスファイル・添付ファイル・共同作成管理

### 一、コース添付ファイル・クラスファイルの削除防止

**対象者**
- 「管理バックエンド」主アカウント
- 「クラスリソース」権限を持つ子アカウント

**こんなときに**
教務担当者は「管理バックエンド」で特定のクラスの「コース添付ファイル」「クラスファイル」「クラス共同作成」にロック保護機能を有効にできます。教務担当者が「管理バックエンド」で「削除タスク機能」を作成したり「期間指定削除」を使用したりしても、ロック保護されている「コース添付ファイル」「クラスファイル」「クラス共同作成」は削除できません。これにより、教務担当者の誤操作や管理ミスによる重要な「コース添付ファイル」「クラスファイル」「クラス共同作成」の誤削除を効果的に防止できます。

**操作手順**
1. コースにチェックを入れる
2. リソースを削除

## 履歴ストレージリソースの削除

### 「履歴ストレージリソースの削除」とは？
「履歴ストレージリソースの削除」とは、教務担当者が「管理バックエンド」で期間を指定して削除タスクを作成できる機能です。このタスクは、設定した期間内の「録画動画（授業回放動画）」「監課画像」「コース - 録画授業添付ファイル」「コース - 課題添付ファイル」「コース - 答案用紙添付ファイル」「コース - ディスカッション添付ファイル」「クラスファイル」「コース - 学習資料添付ファイル」「コース - チェックイン添付ファイル」をバックエンド管理システムから完全に削除します。

### 対象者
- 「管理バックエンド」主アカウント
- 「学校設定」権限を持つ子アカウント

### こんなときに
「履歴ストレージリソースの削除」機能は、主に教務担当者が特定の期間内の上記リソースを削除し、不要なストレージ費用や容量の消費を避けるために使用されます。また、この方法で授業データの安全性と機密性を確保することもできます。

### 使用説明
削除タスクは作成後24時間以内に反映されます。タスク履歴から最新状態を確認できます。未実行のタスクはキャンセル可能です。

- 保護ロックが有効なリソースは削除されません。
- 未完了（未開始・実行中）の削除タスクがある場合、新しい削除タスクを作成できません。
- 月末最終日（北京時間）は削除タスクを作成できません。

### 注意事項
- 削除された「録画動画（授業回放動画）」は、教師と生徒がその「授業（課節）」の回放動画を視聴することに影響します。

## 録画動画・監課画像・板書教材の管理

### 一、録画動画・監課画像・板書教材の削除防止

**対象者**
- 「管理バックエンド」主アカウント
- 「クラスリソース」権限を持つ子アカウント

**こんなときに**
教務担当者は「管理バックエンド」で特定の授業の【監課画像】【録画動画】【板書教材】にロック保護機能を有効にできます。教務担当者が「管理バックエンド」で「削除タスク機能」を作成したり「期間指定での回放動画・監課画像削除機能」を使用したりしても、ロック保護されている【監課画像】【録画動画】【板書教材】は削除できません。これにより、教務担当者の誤操作や管理ミスによる重要な監課画像・録画動画・板書教材の誤削除を効果的に防止できます。

**使用説明**
ロックされた【監課画像】【録画動画】【板書教材】が3ヶ月の無料保存期間を超えると、システムは自動的に「管理バックエンド」の残高からストレージ費用を差し引きます。具体的な費用については「財務概要」内の「課金ルール」をご参照ください。

### 二、録画動画・監課画像・板書教材の削除
「課節リソース」権限を持つ子アカウントが必要です。

**注意事項**

1. 左側ナビゲーションから「課節リソース」に進む
2. 課節にチェックを入れる
3. 「画像を削除」「録画動画を削除」「板書教材を削除」をクリック（または「課節リソースを削除」で課節内のすべてのリソースを一括削除）

## 録画動画管理

### 一、回放動画のアップロード

**対象者**
- 「管理バックエンド」主アカウント
- 「クラスリソース」権限を持つ子アカウント

**こんなときに**
担当教師が録画できない場合でも、授業の様子を記録して生徒に視聴させたい場合、教室内の共同担当教師にローカル録画機能を有効にしてもらうことができます。共同担当教師がいない場合は、教務担当者が「管理バックエンド」に入り、監課管理ページから対応する教室に入ってローカル録画機能を有効にできます。授業終了後、共同担当教師または教務担当者が録画したローカル動画を対応する授業の「授業回放動画」保存先にアップロードすれば、回放動画が生成されます。

**注意事項**
- 録画機能が有効になっていない授業には動画をアップロードできません。
- バックエンド管理システムでは H.264 エンコードの MP4 形式動画のみアップロード可能です。エンコードが正しくない場合、音声のみで映像がない状態になることがあります。ファイル形式が MP4 以外の場合、再生できない場合があります。
- バックエンド管理システムでアップロードできる動画の最大解像度は1080Pです。1080Pを超える場合、再生できないことがあります。

**関連記事**
- 「管理バックエンドに子アカウントを追加」

**操作手順**
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「クラスリソース」に進む
3. 条件で授業を検索し、右側の「録画動画」に進む
4. 回放動画をアップロード

### 二、回放動画のダウンロード

**（1）回放動画のダウンロード**

教務担当者は「管理バックエンド」から「授業回放動画」をダウンロードし、パソコンに保存したり他の人に転送して視聴させたりできます。また、先に「授業回放動画」をパソコンにダウンロードしてから「管理バックエンド」内の「授業回放動画」を削除することで、「管理バックエンド」のストレージ費用を節約することもできます。

**操作手順**
1. 回放動画をダウンロード

**（2）回放動画の一括ダウンロード**

1. 以下の拡張機能をダウンロード
2. パソコン内で classin-download-help-2.1.1-chrome の圧縮ファイルを見つける
3. classin-download-help-2.1.1-chrome の圧縮ファイルを右クリックし、「"classin-download-help-2.1.1-chrome"(C) に展開」を選択
4. Google Chrome を開き、右上の「︙」をクリック
5. リンクから「Chrome に追加」をクリックし、「拡張機能を追加」をクリック後、「拡張機能」→「拡張機能を管理」に進む

## バックエンドでの組織クラウドディスク管理

### 一、フォルダの作成/教材のアップロード

**組織クラウドディスクとは？**
「バックエンド管理システム」と ClassIn ソフトウェアの組織クラウドディスク機能は相互に同期しています。ユーザーが ClassIn で組織クラウドディスクを作成し教材をアップロードすると、それらの教材は自動的に学校のバックエンド管理システム内の組織クラウドディスクに同期されます。逆に、教務担当者がバックエンド管理システムで教材をアップロードし組織メンバーを追加すると、メンバーが ClassIn にログインして学校の組織クラウドディスクに入るとこれらの教材を確認できます。

管理者は組織クラウドディスク内でさまざまな《フォルダ》と《サブフォルダ》を作成し、メンバーを追加してメンバーの権限を設定できます。これにより、これらのフォルダは「英語グループ」や「1年生グループ」のような小さな共有・協業スペースになります。この方法によりファイルの共有と管理が容易になるだけでなく、学校や機関のファイル権限付与・管理における効率も向上します。

組織クラウドディスクを通じて、教師はより便利に教育研究資料を共有、協業、管理でき、協働授業のニーズを十分に満たせます。この機能はファイル管理の利便性と教育業務の効率を大幅に向上させます。

**対象者**
- 「管理バックエンド」主アカウント
- 「組織クラウドディスク」権限を持つ子アカウント

**使用説明**

（1）教室内で開けるファイル形式：

- ClassIn 板書形式：edb
- ClassIn ファイル形式：edt、edu、eda、edv
- プレゼンテーション形式：pptx、ppt、pptm、pptippt
- ドキュメント形式：docx、doc
- 表計算形式：xlsx、xls、csv
- PDF形式：pdf
- Epub形式：epub
- 画像形式：jpeg、jpg、png、bmp
- 音声形式：mp3、wav、wma、aac、flac、m4a、oga、opus
- 動画形式：mp4、3gp、mpg、mpeg、3g2、avi、flv、wmv、h264、m4v、mj2、mov、ogg、ogv、rm、qt、vob、webm
- テキスト文書形式：txt、html、htm、css、js、as、cpp、c、cc、cxx、h、java、md、matlab、pascal、pl、php、py、r、rb、ru、sql、swift、rbx、rs、go
- 囲碁形式：sgf
- チェス/将棋形式：fen、pgn

**注意事項**

### 二、メンバーの追加/メンバー権限の編集
「組織クラウドディスク - メンバー管理」権限を持つ子アカウントが必要です。

| 権限 | 説明 |
| --- | --- |
| 管理可能 | メンバーの追加、権限付与、削除が可能。ファイルのアップロード、削除、名前変更、転送、使用などの操作が可能 |
| 操作可能 | ファイルのアップロード、新規作成、使用が可能。削除は不可 |
| 閲覧のみ | ファイルのプレビューと教室での使用が可能。アップロード、新規作成、削除は不可 |
| 非表示 | ファイルを閲覧不可 |

- 「企業版ClassInバックエンド」は自機構内の教師のみ追加できます。
- 「学校版ClassInバックエンド」は自校の教師と生徒を組織フォルダメンバーとして追加できます（生徒は現在「閲覧のみ」権限のみ設定可能）。
- 「バックエンド管理システム」で停止中の教師は、システムが自動的にその教師の組織クラウドディスク権限を解除します。停止中の教師が再度有効化された場合、組織クラウドディスク権限を再取得するには新規メンバー追加の権限付与フローに従って操作してください。

**操作手順**
1. メンバーを追加したいフォルダを見つけ、右側の「···」をクリックし、「メンバー管理」を選択
2. 「メンバーを追加」をクリック
3. メンバー追加完了後、メンバー管理ウィンドウでメンバー権限を編集
