## バックエンド管理者

### 対象者
- 「管理バックエンド」主アカウント
- 「権限管理」権限を持つ子アカウント

### 使用説明
管理バックエンドは学校のコース、教師、生徒などの情報を管理するシステムです。主アカウントの教師は管理バックエンドで管理者（子アカウント）を追加し、ログインさせて異なる権限を付与できます。権限ごとに管理できるバックエンド領域は以下の通りです：

| セクション | 領域 | 管理者ができること |
| --- | --- | --- |
| コースセンター | クラス管理/授業管理 | クラスの作成、編集、終了、生徒の追加。授業の作成、編集、削除。 |
| | 公開授業 | 公開授業の作成、編集、削除、生徒の追加。 |
| ストレージ管理 | 教師管理 | 教師の追加、編集、無効化/有効化、権限とタグの設定。 |
| | 生徒管理 | 生徒の追加、編集、非表示/表示、削除、権限とタグの設定。 |
| | データ概要 | バックエンドのストレージ状況の確認。 |
| | 組織クラウドディスク | フォルダ作成、教材アップロード、コピー・移動。削除、ダウンロード、メンバー管理の3つのサブ権限を個別に設定可能。 |
| | 問題バンク | 組織問題バンクの問題・試験用紙の追加、編集、削除。 |
| | 授業リソース | 各授業の【録画動画】【監視画像】【板書教材】のストレージ確認、ロック（誤削除防止）、手動削除。 |
| | クラスリソース | クラスの【クラスファイル】【コース添付ファイル】【共同作成ドキュメント】のストレージ確認、ロック、手動削除。 |
| | リソースセンター | リソース商品の追加とリソース注文の管理、主アカウントが取得したリソースの確認。 |
| 教学管理 | ライブ配信/再生 | Webライブ配信・再生のパーソナライズ設定の確認・編集。 |
| | 教学データ | 授業後評価の編集、教学レポート、学習レポート、授業データ内の授業分析・学習分析の確認。 |
| | 課題管理 | 課題データの確認/ダウンロード。 |
| | テスト管理 | テストデータの確認/ダウンロード。 |
| 教務管理 | 監課管理/アカウント検索 | 進行中の授業の傍聴、教師・生徒の出席状況確認、授業中のネットワーク・機器状況確認。 |
| 財務センター | 財務センター | 課金ルール、注文詳細、請求書などの確認。 |
| マイスクール | マイスクール | 組織のパーソナライズ設定の確認・編集。 |
| | 権限管理 | 学校バックエンドへの管理者追加、既存管理者の編集・削除。 |
| クライアント権限 | 公開授業/クラスの作成 | ClassIn アプリから直接、公開授業やクラスを作成。 |

### 注意事項
- 管理者情報の編集時、アカウントやメールアドレスは変更できません。表示名と権限のみ変更可能です。

### 操作手順

**（1）管理者を追加**
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「権限管理」に進む
3. 右側の「子アカウントを追加」をクリック
4. 子アカウントの基本情報を入力
5. 子アカウントの管理権限を設定
6. 「確定」をクリック

**（2）管理者の権限を編集**
1. 左上で管理者を検索
2. 管理者右側の「編集」をクリック

**（3）管理者を削除**
1. 右上で管理者を検索
2. 管理者右側の「削除」をクリック

## 管理バックエンドへのログイン/ログアウト

### 対象者
- 「管理バックエンド」主アカウント
- 「管理バックエンド」子アカウント

### こんなときに
ClassIn を利用する各学校には、専用の管理バックエンドが用意されています。教務担当者はここでコースの予約、設定、クラスや授業の監視、教学データや請求情報の確認などを行い、これらの操作はアプリ内のクラス、教師、生徒、その他機能に直接影響します。予約や設定を行うには、まず管理バックエンドにログインする必要があります。

### 使用説明
各学校の管理バックエンドには1つの主アカウントがあり、すべての権限を持ちます。複数の教務担当者が利用する場合、主アカウントは複数の子アカウントを追加し、それぞれに異なる権限を設定できます。これにより複数人での協業が容易になります。

管理バックエンドは英語、簡体字中国語、韓国語、ベトナム語、日本語、アラビア語の表示に対応しています。バックエンドホーム画面右上から言語を切り替えられます。

教師が複数の学校で子アカウントまたは主アカウントを持っている場合、まずいずれかの管理バックエンドにログインし、右上から他の学校の管理バックエンドに切り替えることができます。

### 関連記事
- 「管理バックエンドに子アカウントを追加」

### 操作手順

**（1）管理バックエンドにログイン**
1. ブラウザを開く
2. アドレスバーに www.eeo.cn と入力してアクセス
3. 右上の「管理バックエンド」をクリック
4. ClassIn のアカウント・パスワードまたは認証コードでログイン

**（2）他の学校の管理バックエンドに切り替え**
1. 管理バックエンドに入り、右上から他の学校の管理バックエンドに切り替え

**（3）管理バックエンドからログアウト**
1. 右上のプロフィール写真をクリック
2. 「ログアウト」をクリック

## 認証資料

### 対象者
- 「管理バックエンド」主アカウント

### 使用説明
教務担当者は管理バックエンドの「認証資料」画面で、学校/企業の認証情報を入力または更新する必要があります。必須項目は：学校/企業名、学校/企業ロゴ、主要事業カテゴリ、所在地域、詳細住所、学校/企業責任者の氏名・電話番号・メールアドレス、認証方式です。一般的な認証方式には営業許可証、身分証明書、パスポートなどがあります。例えば営業許可証で認証する場合、許可証の画像、会社名、法定代表者、統一社会信用コードが必要です。認証資料を提出後、認証審査が行われます。

ClassIn のクラウド録画機能を利用するには、認証状態が「認証済み」である必要があります。

### 操作手順
1. 管理バックエンドにログイン
2. 左側ナビゲーションから「認証資料」に進む
3. 「編集」をクリックして認証情報を修正
4. 修正完了後、「確定」をクリックして保存
