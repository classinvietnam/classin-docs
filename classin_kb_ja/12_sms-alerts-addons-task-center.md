## OMOライブ配信

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### 使用方法
教務担当者が「バックオフィス管理システム」でOMOライブ配信機能をオンにすると、教師がバックオフィスまたはアプリで授業コマを作成する際、録画設定でOMOライブ配信機能を有効にできるようになります。

### 関連記事
「バックオフィス管理システムでのサブアカウント追加」

### 操作手順
1. バックオフィス管理システムにログインします。
2. 左側のナビゲーションから「学校設定」に進みます。
3. 上部の「付加サービス」に進みます。
4. 「付加サービス」で「OMOライブ配信」をオン／オフにします。

## タスクセンター

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### 使用方法
複数のダウンロードタスクを一度に作成でき、現在のページで待機する必要はありません。

過去のダウンロードデータを確認できるため、同じデータを重複してダウンロードする必要がありません。

各管理者のダウンロード操作履歴を確認でき、データの安全性確保に役立ちます。

1. **ダウンロードの進捗と結果を確認する。** 完了したダウンロードタスクはファイルとしてダウンロードできます。1ファイルあたり最大10万件のデータをエクスポートでき、これを超える場合は複数ファイルに分割してエクスポートされます。ファイルが1つのみの場合は直接ファイルがダウンロードされ、複数ファイルがある場合は圧縮ファイルとしてダウンロードされます（圧縮ファイル名はダウンロードタスク名と同じ命名規則に従い、内部の各ファイル名の末尾には「_1」「_2」...のように番号が付与されます）。

2. **タスクの命名方式：** タスク種別＋データの起算日 の形式です。例えば「授業コマ出席20240301-20240331」という名前のタスクで生成されるファイルは、2024年3月1日〜3月31日の授業コマ出席データを表します。

3. タスク名、タスク種別、操作日時でこれまでのダウンロードタスクを検索でき、同じデータを重複してダウンロードする必要がありません。

4. 組織の主アカウントは「タスクセンター」ですべての管理者のダウンロードデータを確認できますが、組織のサブアカウントは自分がダウンロードしたデータのみ確認できます。各タスクには操作日時と操作者が記録されるため、システム管理者は各管理者の操作行動を確認でき、不正な操作を早期に発見・防止し、システムの安全性を高めることができます。

### 注意事項
データのダウンロードには一定の遅延があります。例えば19:00にデータをダウンロードする場合、最短でもその日の18:40までのデータしか取得できません。対応策：授業コマ終了後10〜20分ほど待ってからデータをダウンロードすることをおすすめします。

### 関連記事
「バックオフィス管理システムでのサブアカウント追加」

### 操作手順
1. バックオフィス管理システムにログインします。
2. 左側のナビゲーションから「タスクセンター」に進みます。
3. 生成済みのタスクを検索またはダウンロードします。

## 残高・契約期限SMSアラート

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### 使用方法
教務担当者は、バックオフィス管理システムでアカウント残高・契約期限のSMS・電話アラート機能をオン／オフにできます。この機能をオンにすると、教務担当者はアラートのしきい値を設定できます（最大6段階まで設定可能）。残高がしきい値を下回った場合、または契約期限の30日前になった場合、システムはSMSと電話でユーザーに通知します。

### 関連記事
「ストレージ残量アラート」
「バックオフィス管理システムでのサブアカウント追加」

### 操作手順
1. バックオフィス管理システムにログインします。
2. 左側のナビゲーションから「学校設定」に進みます。
3. 上部の「アカウント残高／契約期限アラート」に進みます。
4. 「アカウント残高／契約期限アラート」で「アカウント残高／契約期限SMSアラート」をオン／オフにします（この機能は無料で、SMS料金は発生しません）。下部で複数の通知先電話番号を設定できます。

## ストレージ残量アラート

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### 使用方法
ストレージ残量アラートの通知先電話番号としきい値を設定しておくと、ストレージ残量がこの数値を下回った際に、設定した電話番号にSMSでアラートが届き、正常な利用への影響を未然に防げます。設定したしきい値に加えて、ストレージが上限に達した際にもSMSアラートが送信されます。このアラート機能は無料で、SMS料金は発生しません。

2. 左側のナビゲーションから「学校設定」に進みます。
3. 上部の「残量アラート」に進みます。
4. 「残量アラート」でしきい値を設定し、複数の通知先電話番号を設定します。

## スマート担任

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### 使用方法
教務担当者は、学校のバックオフィス管理システムでスマート担任機能をオン／オフにできます。この機能をオンにすると、教務担当者は2種類のリマインダーを利用できます：1つは授業開始前にSMSまたは電話で生徒に受講準備を促すリマインダー、もう1つは開講後3分以内に未出席の生徒に通知するリマインダーです。

バックオフィス管理システムでは、教務担当者はスマート担任の具体的な機能を設定できます。スマート担任機能には以下の項目が含まれます：

- 授業前日に、電話またはSMSで生徒に翌日の授業があることを通知する。
- 授業開始1時間前に、電話またはSMSで再度生徒に授業を通知する。
- 開講後3分経っても生徒が出席していない場合、電話またはSMSで生徒にすぐに授業に参加するよう通知する。
- 授業前日に、電話またはSMSで教師に翌日の授業があることを通知する。
- 授業開始1時間前に、電話またはSMSで再度教師に授業を通知する。
- 開講後3分経っても教師が現れない場合、電話またはSMSで教師にすぐに授業に参加するよう通知する。

これら6種類のリマインダー機能はすべてまとめてオン／オフにでき、各リマインダー方式では電話またはSMSのいずれか一方のみを選択できます。

## スーパーカスタマーサポート

### 対象
- 「バックオフィス管理システム」主アカウント
- 「学校設定」権限を持つサブアカウント

### 使用方法
教務担当者は、バックオフィス管理システムでスーパーカスタマーサポート機能をオン／オフにできます。この機能をオンにすると、教務担当者はバックオフィス管理システムの監課管理ページから、音声コールバックで教師・副教師・生徒に直接連絡でき、教室内の問題を迅速に解決できます。

バックオフィス管理システムの教務担当者数が多い場合、教師・生徒のプライバシーを保護するため、学校は「電話番号マスキング」機能を有効にできます。有効にすると、監課管理ページとアカウント検索ページで、生徒・教師の電話番号の下4桁がマスキングされ、連絡先の漏洩を防止できます。

ご注意ください：この機能は新疆・チベット・内モンゴルを除く中国本土の電話番号のみに対応しています。発信者・着信者双方に表示される発信番号は中国杭州の番号（0571-57184557）です。

4. 「スーパーカスタマーサポート」で「スーパーカスタマーサポート」と「電話番号マスキング」をオン／オフにします。
