## 授業

## 一、「授業」とは？

ClassInプラットフォームにおいて、「授業」とは教師が生徒に知識を伝える専用の場所であり、授業コマまたはライブ配信教室とも呼ばれます。授業内では、教師が説明、実演、質問などの方法で教育活動を行い、生徒の学習と成長を促進することを目的としています。授業環境の設計と組織は、教育効果の向上と生徒の積極的な参加を促す上で非常に重要です。授業内でよく使われる機能には、座席、黒板、各種教育ツールがあり、授業の円滑な進行を確保します。

## 二、「授業」を新規作成する

### 対象
「担任教師」

《教師による授業新規作成を許可》機能をオンにした後の「クラス教師」

### 使用方法
クラス内で授業を作成する際に設定できる内容は次の通りです：

| 設定 | 機能 |
| --- | --- |
| 授業名 | 生徒と教師が識別しやすいよう、授業に明確な名前を付けます。 |
| 開始時刻と時間 | 授業の開始時刻と授業時間を設定します。開始時刻は最速で現在時刻に設定でき、授業時間は最短15分、最長23時間55分まで設定できます。 |
| 発行先 | 「授業」を特定のクラス、クラス内の一部グループメンバーや一部の生徒に発行できます。 |
| 担当教師 | デフォルトでは作成者が担当教師になります。担任教師はクラス内の他の教師身分のメンバーを担当教師に設定できます。1つの授業には1名のみ担当教師を設定できます。 |
| 副教師 | クラス内の教師を選んで副教師に設定できます。1回の授業につき最大6名の副教師を追加できます。副教師1名が登壇してカメラ映像を表示する場合は、担当教師や生徒の座席を占有しませんが、複数の副教師が登壇する場合は生徒の座席を占有します。 |
| コースを選択 | 「授業」をどのコースに属させるかを選択します。デフォルトは現在のコースです。 |
| ユニットテーマ | 「授業」をどのユニットテーマに属させるかを選択します。選択しない場合はデフォルトのユニットに分類されます。 |
| OMOライブ配信 | 生徒が教師のライブ配信映像を視聴できるようにする設定で、生徒は視聴を選択できます。オフラインとオンラインを組み合わせたブレンド型授業シーンに適しています。この機能はバックオフィス管理システムで有効化しないと選択できません。 |
| 登壇人数 | 授業中、同時に教室最上部の座席に表示できる人数を指します。最小で担当教師1名・生徒0名、最大で担当教師1名・生徒12名までサポートしています。 |
| ClassIn教室を録画 | クラウド録画には「ClassIn教室を録画」と「現場を録画」の2種類があります。「ClassIn教室を録画」は授業内の全画面を録画します。 |
| 現場を録画 | クラウド録画には「ClassIn教室を録画」と「現場を録画」の2種類があります。「現場を録画」は選択した担当教師のカメラ映像のみを録画し、授業全体の様子を表示するために使用します。 |
| ウェブライブ配信・回放権限 | クラウド録画にチェックを入れている場合、授業のウェブライブ配信・回放権限を設定でき、クラス外のユーザーがウェブでライブ配信や回放を視聴できるかどうかを決定できます。 |
| AI授業総括 | クラウド録画にチェックを入れている場合、AIエージェントによる授業回放内容のインテリジェント総括を選択でき、章ごとの要約と字幕リストが含まれます。 |
| 座席の表示 | オンにすると、教師と生徒がオンラインでインタラクティブな授業を行いやすくなり、いつでも交流や質疑応答ができます。オフにすると、授業では黒板を使った教育に集中でき、教師は教室内で再度調整することもできます。 |
| 生徒の自動登壇 | 「座席の表示」がオンになっている場合、生徒が教室に入った際に自動的に登壇してカメラ映像を表示するかどうかを設定できます。 |
| 生徒同士の学習レポート相互閲覧を許可 | オンにすると、生徒は他の生徒の学習レポートを閲覧できます。 |

### 注意事項
クラス内で授業を作成する際、教師は登壇人数を選択できます。システムはデフォルトで現在使用しているデバイスで前回授業を作成した際の選択肢を使用します。デバイスを変更した場合、システムは前回の選択を記録していないため、再設定が必要です。

授業コマやコースを追加できない場合、現在のコース配下の授業コマ数が上限に達している可能性があります。

授業コマの時間の長さにかかわらず、正式教室の延長授業時間は20分、臨時教室の延長授業時間は2分です。

「担任教師」が「担当教師」を兼ねる場合、クライアントで授業を作成する際には担当教師はデフォルトで担任教師となるため、別途担当教師を設定する必要はありません。

「生徒が教師によってクラスから除外された」「クラスが解散された」「生徒が自らクラスを離れた」場合、既にクラスを離れた生徒がClassIn上で録画授業回放動画を閲覧できるかどうかは、クラス設定の「クラスを離れた生徒やクラス解散後もコース内容を閲覧できる」設定によって決まります。

## 三、「授業」を修正する

授業作成権限を持つ担当教師

ClassInクライアントでは、担任教師は作成済みのすべての授業を修正でき、授業作成権限を持つ教師は自分が担当教師である授業のみ修正できます。

具体的に修正可能な情報と設定には、授業名、開講日、開講時刻、授業時間、担当教師、副教師、登壇人数、クラウド録画、ウェブライブ配信、ウェブ回放などが含まれます。以下の関連ルールと時間制限に従ってください。

開講20分前まで修正できる設定：授業名、開講日、開講時刻、授業時間、発行対象のクラス／メンバー、OMOライブ配信、登壇人数、クラウド録画（ClassIn教室を録画、現場を録画）、ウェブライブ配信、ウェブ回放、座席の表示、生徒の自動登壇。

授業終了前まで随時修正できる設定：担当教師の変更、副教師の追加／変更、ウェブ回放。

時間の制限を受けず随時修正できる設定：AI授業総括、ウェブ回放、ユニットテーマ、生徒同士の学習レポート相互閲覧の許可。

正式に開講する前（教室への事前入室時間を含む）であれば、授業はいつでも削除できます。ただし、授業が正式な授業時間に入ると削除できなくなります。

終了済みの授業は削除できません。

1. 「ホーム」に進みます。
2. クラスに入ります。
3. 作成済みのコースに入ります。
4. 授業を見つけて「···」をクリックし、「編集」を選択します。

## 六、「副教師」を設定する

## 1、授業作成時に副教師を追加する

### 適用場面
受講する生徒の人数が多い場合、担任教師または授業作成権限を持つ教師は授業に「副教師」を追加できます。副教師は授業中に担当教師が授業秩序を維持するのを手伝い、担当教師の授業をサポートできます。

授業に副教師を追加する前に、担任教師が先に副教師をクラスに追加し、クラス内でクラス教師身分に設定しておく必要があります。これにより、担任教師または授業作成権限を持つ教師が授業作成時にそのクラス教師を副教師として追加できるようになります。

1. 左側のナビゲーションから「ホーム」に進みます。
2. クラスを検索して入ります。
3. 左上で新規コースを作成するか、既存のコースに入ります。
4. 「新規作成」をクリックします。
5. 「授業」を作成します。
6. 作成ウィンドウで「展開」をクリックし、「副教師」を追加します。

## 七、「担当教師」を変更する

授業が既に始まった後、担当教師に急な用事が入り、一時的に本堂授業の担当教師を交代する必要がある場合、担任教師はその教室の担当教師を一時的に他の人に変更できます。

授業の担当教師を変更する前に、担任教師が先に新しい担当教師をクラスに追加し、新しく参加した教師をクラス内でクラス教師身分に設定しておく必要があります。これにより、担当教師の変更時にその教師を授業の担当教師として設定できるようになります。

1. 教師を選択し、新しい担当教師にチェックを入れて「確定」をクリックします。

## 九、クラスで「録画授業回放動画」を視聴する

### 回放動画とは？
「回放動画」とは、クラス内で授業を作成する際に「ClassIn教室を録画」または「現場を録画」（すなわちクラウド録画）にチェックを入れ、担当教師が正式教室に入って授業全体の過程を録画したものを指します。これらの動画は下課後約30分ほどで自動的に「回放動画」として生成されます。

### 「録画授業回放動画」と「録画授業」の違いは？
「録画授業回放動画」とは、担当教師がClassInのクラウド録画機能を使って、教師の視点から授業全体を録画した動画を指します。これらの動画は授業終了後約30分で自動生成され、回放閲覧できます。一方「録画授業」とは、担任教師または教師がクラス内で作成する特定の教育アクティビティで、教師はパソコンのローカル動画を「録画授業」にアップロードでき、生徒と教師がいつでも視聴・学習できるようになります。

対象：クラス教師、授業の生徒

担当教師が授業内で正常に録画授業を行った場合、下課30分後には、クラス内のすべての教師と授業の生徒がクラス内でその授業を見つけて回放動画を視聴できます。

動画再生時は、録画設定に応じて、録画された動画または録画された現場動画のいずれかを選んで再生でき、回放に複数の動画セグメントが含まれる場合はセグメントを切り替えて視聴できます。

回放動画はウィンドウ表示再生、倍速再生、音量調整に対応しており、進行バーをドラッグして柔軟に回放内容を視聴できます。

授業作成時にAI授業総括の章ごとの要約と字幕リストにチェックを入れていた場合、回放視聴時にもAIが生成したその授業の要約と字幕リストを確認でき、コピーにも対応しています。

授業作成時にClassIn教室を録画／現場を録画とAI授業分析にチェックを入れていた場合、担当教師が録画を完了し音声が正常であれば、授業後に担当教師は授業の回放で本節授業に関するAI授業分析を確認でき、分析をPDFとしてダウンロード保存することもできます。

新しくクラスに参加した生徒にクラスの過去の回放動画の視聴権限を開通させたい場合は、「バックオフィス管理システム」で《新しくコースに参加した生徒に過去の授業コマの回放動画の視聴を許可》機能を有効にし、有効化後に生徒をクラスに追加してください。

## 十、クラスで「板書課件」を確認する

### 「板書課件」とは？
教師が授業中に黒板や教材にテキストを入力したり、描画で注釈を付けたりすると、ClassInは教師の板書や教材を自動的に保存します。自動保存された板書と教材は、授業後の「授業コマ詳細」または「時間割」で確認できます。教師と生徒は授業内容を簡単に振り返り、復習できます。

「板書課件」には「授業板書」と「注釈付き課件」が含まれます。「授業板書」は正式教室内で黒板に書き込まれた板書内容を、「注釈付き課件」は正式教室内で開かれた教材を指します。「授業板書」または「注釈付き課件」のいずれかが生成されれば、授業後に「板書課件」の入口が表示されます。

「板書課件」の生成には一定の条件があります：

まず、www.eeo.cnバックオフィス管理で板書課件の保存機能を有効にしておく必要があります。

次に、正式教室で教師が授業中に、黒板に、または開いたPPT／PDF／Word（docx/doc）／Epub教材（保存が許可された教材を含む）に一定量のテキストを入力した場合、または画筆で10個を超える要素に注釈を付けた場合（PPT教材の場合は1ページで10個を超える画筆注釈要素）、ClassInは授業後、注釈付きの板書全体と教材全体を自動的に保存します。

クラスの教師と授業の生徒は、授業後にクラス内でその授業の「板書課件」を確認でき、さらにその授業の担当教師・副教師・生徒は時間割でもその授業の「板書課件」を確認できます。

その授業の担当教師と副教師は、「板書課件」をClassInのクラス／友達、WeChatに共有でき、スマートフォンやタブレットを使用する場合はWeibo、QQなどにも共有できます。リンクをコピーして他の人に送ることもできます。生成された「授業板書」をjpg画像としてClassInの個人クラウドドライブに保存することにも対応しています。

黒板または教材が保存条件を満たした後、板書に対してCtrl+Nを操作するかワンクリック画面クリアを行うと、クリア前の板書内容が保存されます。

「注釈付き課件」は最終的にPDF形式で保存され、プレビューサムネイルは教材の1ページ目になります。

正式教室が条件を満たした場合にのみ、授業後に「板書課件」が生成されます。

正式教室の担当教師または副教師が正常に出席していれば、授業終了30分後に本堂授業の教師の「教育レポート」が生成され、授業の担当教師・副教師・担任教師はClassInクラス内で「教育レポート」を確認でき、授業の担当教師・副教師は時間割でも確認できます。

「教育レポート」はデフォルトで新版教育レポートが表示され、最上部で旧版レポートへの切り替えにも対応しています。12言語での内容確認にも対応しており、授業情報（担当教師のアバターとクラスニックネーム、授業の開始時刻と授業時間）が表示されます。

「教育レポート」のデータ内容には、出席状況、授業参加率、授業アクティビティ時間分布、授業記録、授業成果の5部分が含まれます。

**出席状況：** 本堂授業の出席・遅刻・早退人数のデータを確認できます。明細を確認すると、生徒個々の具体的な出席状況、授業時間、学習レポートも確認でき、パソコンを使用する場合は出席データをエクスポートすることもできます。

**授業参加率：** 生徒が教室内で解答器、小黒板、インタラクティブメッセージ（教室内のチャットボックスでの会話）、早押しボタンを使用した参加率を表示します。明細を確認すると、生徒の具体的な参加状況を確認でき、パソコンを使用する場合は明細データをエクスポートすることもできます。

**授業アクティビティ時間分布：** 教師が教室内で教育ツールを使用した時間分布を表示します。過程性評価（解答器、小黑板、早押しボタンを含む）、教育インタラクション（ランダム指名、挙手、グループディスカッション、インタラクティブメッセージ、タイマー、カウントダウンなどを含む）、授業激励（生徒へのトロフィー配布）の4部分に分かれます。明細を確認すると、ツールの使用時間や回数をより直感的に確認できます。

**授業記録：** 教室内の授業板書、ハイライトの瞬間（監課画像）、授業ノートが含まれます。

授業板書は黒板に書かれた板書内容で、授業板書画像の生成条件は、黒板上の画筆マーク要素が10個を超えるか、テキスト入力内容が含まれることです。また教師がCtrl+Nやワンクリック画面クリアを操作した場合も、それ以前に生成条件を満たしていた板書画像が保存されます。

ハイライトの瞬間（監課画像）は、教師の教室ウィンドウが自動保存した画像で、教室内で教師が知識を説明する過程を振り返るのに使用できます。

授業ノートは、パソコンを使用する教師が教室内で授業ノート機能を使用した後に保存されたノート画像です。

教師がスマートフォンやタブレットで授業記録内の画像を確認する場合、長押しで画像をローカルのアルバムに保存できます。

**授業成果：** 生徒の解答器（授業内練習）の正答率ランキングと、教師から獲得したトロフィーのランキングデータが含まれます。明細を確認すると生徒のデータ状況が確認でき、パソコンを使用する場合は明細データをエクスポートすることもできます。

## 十四、授業データをエクスポートする

対象：クラス教師、担任教師

授業データは、www.eeo.cnバックオフィス管理でダウンロードできるだけでなく、クラス教師はClassIn内でエクスポートすることもできます。バックオフィス管理では「授業分析」と「学習分析」の2種類のデータをダウンロードできますが、ClassInでは「学習分析」のデータのみダウンロード可能です。

本授業のデータ－学習分析には次の情報が含まれます：授業コマ名、授業コマID、開講時刻、終了時刻、授業コマ時間、生徒氏名、生徒の実際の授業時間、生徒の出席／遅刻／早退の有無、教師評価（教師の生徒への評価）、教師評語（教師の生徒への評語）、生徒評価（生徒の教師への評価）、生徒評語（生徒の教師への評語）、生徒がClassInクライアントで回放を視聴した有効回数／カバー時間、本授業の回放動画の合計時間、生徒の発言時間、生徒の登壇・降壇回数、生徒の登壇・降壇時間、生徒が教師によって教室から除外された回数、生徒が報酬を受け取った回数、生徒の挙手回数、生徒が権限付与された回数と時間、教師の早押しボタン使用回数、生徒の早押し参加回数、生徒の早押し成功回数、生徒の解答器総使用回数、生徒の正解回数、生徒の解答明細、生徒のカメラオン時間。これらのデータは生徒ごとに詳細に区分されます。

スマートフォンとタブレットではClassInクラス内で授業データをエクスポートすることに対応していません。

## 十五、クラスで「AI授業分析」を確認する

ClassIn AI授業分析は、授業の録画授業動画に基づいて、教師の表現やインタラクション状況を分析し、教師の授業過程を再現するとともに、授業内容の複数の側面についてAI評価と採点を行うものです。

eeoバックオフィス管理担当者が「学校設定－付加サービス」でAI授業分析のスイッチをオンにした後、クラスで授業を作成する際にClassIn教室を録画／現場を録画、およびAI授業分析にチェックを入れると、担当教師が録画を完了し音声が正常であれば、授業後に担当教師は授業の回放で本節授業に関するAI授業分析を確認でき、分析をPDFとしてダウンロード保存することもできます。

AI授業分析レポートには、授業概況、授業再現（授業時間配分、時間配分タイムラインチャート、授業キーワードクラウド、授業高頻度語彙表）、授業データ詳細（言語表現効果分析、教育言語論理・構造分析、インタラクション分析）、授業全体のAI評価と最適化提案が含まれます。AI授業分析レポートの内容は中国語のみに対応しており、多言語には対応していません。
