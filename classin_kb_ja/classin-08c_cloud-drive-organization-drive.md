## 組織クラウドドライブ（ファイルアップロードなどの関連操作）

## 一、組織ドライブを新規作成する

## 対象
学校／機関のメインアカウント

「組織クラウドドライブ」権限を持つバックオフィスの学校／機関管理者

## 適用場面
教育研究の過程では、研究グループの複数の教師が教研資料を共有し、協同作業を行う必要がしばしば生じます。このプロセスを促進するために、組織クラウドドライブを使用することで教師のニーズを満たせます。個人クラウドドライブの使用に加え、組織クラウドドライブは複数人での共有・共同構築スペースも提供します。

## 使用方法
学校／機関のメインアカウント、および「組織クラウドドライブ」権限を持つバックオフィスの学校／機関管理者は、ClassInソフトウェアの「スペース」欄内の「組織クラウドドライブ」で組織ドライブを作成できます。組織ドライブを作成した後、初めてクラウドドライブにファイルやサブフォルダを追加できるようになります。

## 注意事項
スマートフォンでは組織クラウドドライブ内で組織ドライブを作成することに対応していません。

## 具体的な操作手順

#### パソコン／タブレット
1. 左側のナビゲーションから「スペース」に進みます。
2. 「組織クラウドドライブ」に進みます。
3. 「学校／機関」を選択します。
4. 「組織ドライブを作成」します。
5. 組織ドライブのフォルダ名を入力します。
6. 「作成」をクリックします。

## 二、ファイル（フォルダ）の新規作成／アップロード

フォルダに操作可能／管理可能な権限を持つ教師

対応する権限を持つ教師、管理者、メインアカウント担当者は、組織ドライブ配下でフォルダとファイルを新規作成／アップロードでき、マイクラウドドライブから組織ドライブにファイルをアップロードすることにも対応しています。

組織ドライブは新規フォルダの作成に対応しており、板書、課題リソース、オンラインPPT、コラボレーション文書などのファイルの新規作成にも対応しています。タブレットはオンラインPPTの新規作成に対応していません。スマートフォンはフォルダ、板書、課題リソース、コラボレーション文書の作成のみに対応しています。フォルダのアップロードに対応しているのはパソコンのみです。

組織ドライブはファイルのアップロードにも対応しており、ppt、word、pdf、画像、音声・動画などのファイルをアップロードできます。

ClassInではアップロードするファイルのサイズに一定の制限があります：パソコンからアップロードする場合、1ファイルあたり500MBを超えることはできません。スマートフォンやタブレットからアップロードする場合、1ファイルあたり100MBを超えることはできません。TXTファイルについては、教室内で正常に使用できるようサイズを1MB以内に抑えることをおすすめします。またスマートフォンやタブレットからアップロードする動画ファイルについては、解像度が720P未満の動画はサイズが100MBを超えることはできず、解像度が720P以上の動画は再生時間が3分を超えることはできません。

フォルダの総数上限は2000個で、各フォルダ内のファイル数の上限は300個です。

パソコン端では、ファイルやフォルダをドラッグ＆ドロップしてマイクラウドドライブにアップロードできます。

ファイルのアップロード後は変換に一定の時間がかかるため、早めにアップロードすることをおすすめします。

教室内でファイルを使用する必要がある場合は、必ず教室内でクラウドドライブから開く必要があります。

すべての形式のファイルをClassInにアップロードできますが、教室内で正常に開いて使用できるのは以下に記載されているファイル形式のみです。

ClassIn教室内で使用に対応しているファイルタイプは以下の通りです：

| タイプ | 形式 |
| --- | --- |
| ClassIn板書 | edb |
| ClassInファイル | edt；edu；edx；eda；edv |
| PowerPointプレゼンテーション | pptx；ppt；pptm |
| Word文書 | docx；doc |
| Excel表 | xlsx；xls；csv |
| PDF文書 | pdf |
| 画像 | jpeg；jpg；png；bmp |
| 音声 | mp3；wav；wma；aac；flac；m4a；oga |
| 動画 | mp4；3gp；mpg；mpeg；3g2；avi；flv；wmv；h264；m4v；mj2；mov；ogg；ogv；rm；qt；vob；webm |
| テキスト文書 | txt；html；htm；css；js；as；cpp；c；cc；cxx；h；java；md；matlab；pascal；pl；php；py；r；rb；ru；sql；swift；rbx；rs；go |
| 囲碁 | sgf |
| チェス／シャンチー | fen；pgn |

1. 「組織ドライブ」に進みます。
2. 上部の「アップロード」または「新規作成」でフォルダとファイルを作成します。

2. 「組織スペース」に進みます。
3. 「＋」をタップします。
4. 「フォルダとファイルを作成」または「ファイルをアップロード」します。

## 三、メンバー権限

「組織クラウドドライブ－メンバー管理」権限を持つバックオフィスの学校／機関管理者

フォルダに管理可能な権限を持つ教師

対応する権限を持つ教師、管理者、メインアカウント担当者は、組織ドライブとその配下のフォルダにメンバーを設定・追加し、権限を管理できます。対応する権限を持つメンバーは組織クラウドドライブ配下のファイルを閲覧・使用できます。

**組織ドライブとその配下のフォルダ－メンバー管理権限の説明：**

| 権限 | 説明 |
| --- | --- |
| 管理可能 | フォルダ対応内容：メンバー管理（メンバーの追加、授権、除外）権限の設定、および組織ドライブ配下のフォルダのアップロード、新規作成、コピー、移動、名前変更、削除。<br><br>ファイル対応内容：閲覧、アップロード、新規作成、転送、ダウンロード、削除、コピー、移動、クラウドドライブへの保存、名前変更、印刷、ppt/edocのオンライン編集操作、およびファイル権限内でのファイル転送保存機能の設定。 |
| 操作可能 | フォルダ対応内容：メンバー管理権限の閲覧、および組織ドライブ配下のフォルダのアップロード、新規作成、コピー、名前変更。<br><br>ファイル対応内容：閲覧、アップロード、新規作成、コピー、名前変更、印刷、ppt/edocのオンライン編集操作。<br><br>自分がアップロードしたファイルや作成したフォルダの削除に対応。 |
| 閲覧のみ | フォルダおよびその配下のファイルの閲覧のみに対応。 |
| 非表示 | フォルダおよびその配下のファイルを閲覧できません。 |

**スーパー管理者：** 「組織クラウドドライブ」権限を持つバックオフィスの学校／機関管理者を指します。バックオフィス管理システムで管理者に「組織クラウドドライブ」権限のみをチェックした場合、バックオフィスおよびClassInソフトウェアの組織クラウドドライブで組織ドライブの閲覧、作成、名前変更、メンバー管理の閲覧ができますが、フォルダの削除やフォルダのメンバー権限設定はできません。ファイルに関しては、閲覧、アップロード、新規作成、転送、コピー、移動、クラウドドライブへの保存、名前変更、印刷、ppt/edocのオンライン編集操作ができますが、ファイルのダウンロードや削除、ファイル転送保存機能の設定はできません。

以下を行うには追加で対応する権限にチェックを入れる必要があります：ファイル／フォルダの削除、ファイル転送保存の設定（「組織クラウドドライブ－削除」）；ファイルのダウンロード（「組織クラウドドライブ－ダウンロード」）；組織ドライブ／フォルダへのメンバー権限設定（「組織クラウドドライブ－メンバー管理」）。

スマートフォンは組織クラウドドライブ内でのメンバー管理（メンバーの追加、授権、除外）権限の閲覧・設定に対応していません。

「企業版ClassIn」は自機構配下の教師のみ追加できます。

「学校版ClassIn」は自校の教師と生徒を組織フォルダのメンバーとして追加できます（生徒は現在「閲覧のみ」と「非表示」権限の設定のみ対応）。

「バックオフィス管理システム」で無効化された教師は、システムが自動的に組織クラウドドライブ権限を解除します。再度有効化した後は、新規メンバーのフローに従って権限を再取得する必要があります。

「小中学校バックオフィス管理システム」を使用する学校の場合、教師が離職／削除された、または生徒が卒業／削除された場合、システムは自動的にその組織クラウドドライブ権限を解除します。離職した教師が復職した場合や、生徒が再入学した場合は、新規メンバーのフローに従って組織クラウドドライブ権限を再取得する必要があります。

1. 権限を付与する必要があるフォルダを見つけ、右側の「···」をクリックします。
2. 「メンバー管理」に進みます。
3. 「メンバーを追加」または「メンバー権限を修正」します。

## 四、ファイル権限

「組織クラウドドライブ－削除」権限を持つバックオフィスの学校／機関管理者

対応する権限を持つ教師、管理者、メインアカウント担当者がファイルに対して「操作可能／閲覧のみメンバーの転送／ダウンロード／個人クラウドドライブへの保存を許可」（転送保存）機能を有効にした場合、「操作可能」または「閲覧のみ」権限を持つメンバーもそのファイルを転送保存できます。

コラボレーション文書edoc、edu、edx、課題リソースなどはファイルへの転送保存権限設定に対応していません。

スマートフォンは組織クラウドドライブ内でのファイル転送保存機能の閲覧・設定に対応していません。

1. フォルダに入ります。
2. ファイルを見つけて「···」をクリックし、「ファイル権限」に進みます。
3. ファイル権限を修正します。

<!-- DOC_BOUNDARY -->
```yaml
title: "ファイルを転送する"
source_title_zh: "转发文件"
```

## 五、ファイルを転送する

ファイル権限で転送保存を許可する設定になっており、かつファイルが所在するフォルダに閲覧可能／操作可能権限を持つ教師が対象です。

対応する権限を持つ教師、管理者、メインアカウント担当者は、ClassInソフトウェアの組織クラウドドライブでファイルを見つけた後、ClassInのクラスや友達に転送できます。

1. ファイルにチェックを入れ、「転送」をクリックします。

## 七、ファイルをダウンロードする

「組織クラウドドライブ－ダウンロード」権限を持つバックオフィスの学校／機関管理者

パソコンは組織クラウドドライブから画像、板書、PPT、PDF、Word文書などのファイルをダウンロードできます。ただし、ClassIn専用のファイル形式（オンラインスライド〈eppt形式〉や文書〈edoc形式〉など）はダウンロードや他のアプリでの開封には対応していません。

スマートフォンやタブレットは画像をローカルアルバムに保存することに対応していますが、PPT、PDFなどのファイルにはダウンロード機能はなく、組織クラウドドライブ内で開いた後、共有機能をタップして他のアプリで開いて確認・使用することができます。

#### パソコン
1. ダウンロードしたいファイルにチェックを入れます。
2. 下部の「ダウンロード」をクリックします。

#### タブレット
1. 画像またはファイルを開きます。
2. 画像を長押しして保存する、またはファイルページで共有ボタンをタップして他のアプリで開くことを選択します。

マイクラウドドライブ内で画像やファイルを開きます。

## 八、ファイルを印刷する

「組織クラウドドライブ」に保存されている教材ファイルを実物の紙資料に変換する必要がある場合、教師はClassInの印刷機能を使用できます。パソコンは画像、PPT、PDFなどのファイルの印刷に対応しています。

スマートフォンやタブレットには「印刷」機能はありません。

1. ファイルを開きます。
2. ファイル右上角の「印刷」をクリックします。

## 九、ファイル（フォルダ）を削除する

対応する権限を持つ教師、管理者、メインアカウント担当者は、ClassInソフトウェアの組織クラウドドライブでファイル（フォルダ）を見つけた後、削除できます。また「操作可能」権限を持つ教師は、自分が作成したフォルダの削除、および自分がアップロードしたファイルの削除にも対応しています。

ファイルとフォルダは削除すると復元できません。

1. 削除したいファイルまたはフォルダを見つけます。
2. 「削除」をクリックします。
