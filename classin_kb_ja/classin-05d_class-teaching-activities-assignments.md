## 課題

## 一、「課題」を新規作成する

### 対象
「担任教師」および「教師」

### こんな時に使う
「課題」機能とは、教師が生徒に一定量の学習タスクや問題を課し、指定された時間内に完了・提出させる機能を指します。教師が課題を課す目的は、生徒が授業内容を定着させ、自主学習能力や問題解決能力を養うのを助けることにあり、同時に生徒の学習状況を評価・フィードバックする手段でもあります。

### 使用方法
教師はクラスページに入った後、コース欄で課題を布置できます。課題には複数種類の添付ファイルを追加でき、画像、音声、クラウドドライブファイル、ローカルファイル、Webサイトリンクに対応しており、生徒が課題内容をより良く理解・習得するのに役立ちます。ファイル数の上限は、画像添付ファイル15枚、録音添付ファイル15件、動画添付ファイル15個で、ローカルファイル・クラウドドライブファイル・リンクの合計は15個までです。各動画・ファイルのサイズは500MB以内です。パソコンから課題の添付ファイルをアップロードする際は、画像やファイルをドラッグ＆ドロップで課題に直接追加できます。

パソコンやタブレットでは、教師は教育目標や特定の知識ポイントに基づいて、AIエージェントによる課題内容の生成・推敲支援を利用できます。

教師は機構が権限付与した課題リソースやマイクラウドドライブ内の課題リソースを選択できます。

教師は課題に模範解答を設定することもでき、解答にも添付ファイルをアップロードできます。解答の公開範囲は、非公開、即時公開、提出後公開、教師採点後公開、課題終了後公開から選択できます。

**「課題」作成時に設定できるパラメーター：**

| 設定 | 機能 |
| --- | --- |
| 時間 | 課題の開始時刻と締切時刻を設定します。 |
| AI採点 | オンにすると、AIエージェントが課題内容に基づいて生徒の解答を採点し、AI採点は草稿として教師の確認待ちとなります。この機能は教師がパソコンまたはタブレットを使用している場合のみ設定できます。 |
| 評価 | 課題の評価制度と配点を設定します。 |
| 発行先 | 特定のクラス、クラス内の一部グループメンバーや一部の生徒に発行することも、複数のクラスに同時に発行することもできます。 |
| 教師 | 担当教師を指定し、関連通知を受け取ります。 |
| コース | 「課題」をどのコースに属させるかを選択します。デフォルトは現在のコースです。 |
| ユニットテーマ | 「課題」をどのユニットテーマに分類するかを選択します。選択しない場合はデフォルトのユニットに分類されます。 |
| アクティビティ終了後の補充提出を許可 | オンにすると、生徒が期限内に課題を完了できなかった場合、アクティビティ終了後でも提出できます。 |
| 生徒同士の課題・成績相互閲覧を許可 | 生徒同士がすべての課題と成績を閲覧できるかを設定します。<br><br>オンにすると、「すべて表示可能」または「優秀な内容と成績のみ表示可能」を選択でき、表示タイミングは「即時表示」「生徒提出後に表示」「採点後に表示」「終了後に表示」から選択できます。 |
| 新しく参加した生徒の提出を許可 | オンにすると、課題アクティビティ終了前に新しくクラスに参加した生徒も、布置済みの課題に参加できます。 |
| 生徒による添付ファイルのダウンロードを許可 | オンにすると、生徒は課題内の教師がアップロードした添付ファイルをダウンロードできます。 |
| ロック解除条件 | 完了が必要な前提アクティビティを追加します。ロック解除条件を追加した場合、生徒は前提条件を完了しないと現在の課題アクティビティを開始できません。 |

### 注意事項
「生徒が教師によってクラスから除外された」「クラスが解散された」「生徒が自らクラスを離れた」場合、既にクラスを離れた生徒が課題内の添付ファイルを閲覧できるかどうかは、クラス設定の「クラスを離れた生徒やクラス解散後もコース内容を閲覧できる」設定によって決まります。

AI採点で「AIによる採点支援」「課題添削・フィードバックアシスタント（課題解答対応版）」「記述問題採点アシスタント（課題解答対応版）」「RE聞き取り採点アシスタント（課題解答対応版）」のいずれか4種類のエージェントを選択した場合、AIは教師が課題にアップロードした模範解答に基づいて採点を行い、採点の精度を高めます。

## 二、「課題」を修正する

課題は編集に対応していますが、状態によって編集可能な内容は異なります。

草稿および未開始の課題は、「コース」は変更できませんが、他の内容・設定はすべて変更できます。

進行中の課題は、内容の変更は可能ですが、設定項目の「開始時刻」と「コース」は変更できません。

終了済みの課題は、内容は変更できず、設定項目の時間、発行先、教師、コース、新規参加生徒の提出許可、ロック解除条件のいくつかの項目は変更できません。

進行中と終了済みの課題は、課題リソースをクラウドドライブに保存でき、以降の利用に役立ちます。

1. コースに進みます。
2. 課題を見つけて「···」をクリックし、「編集」を選択します。

## 六、成績をアップロードする

教師がClassInプラットフォームで課題を発行した後、生徒が実際にはオフラインで課題を完了した場合、教師は課題内の「成績アップロード」機能を使って、生徒がオフラインで完了した課題の成績をClassInにアップロードできます。これにより、後日の成績集計・分析が容易になります。

教師はパソコンを使用して、評価スキームが設定された進行中・終了済みの課題に対して成績をアップロードできます。

ClassInの課題成績アップロード機能では、個々の生徒に手動で成績を追加することも、テンプレートをダウンロードして一括で生徒の成績を追加することもできます。記入した成績をアップロードすると、生徒の既存の成績は上書きされます。

課題成績のアップロードには特定の書式に従った表が必要で、ClassInが認識できる形式でなければならないため、一括アップロード時には、教師はClassInの成績アップロード画面からテンプレートをダウンロードする必要があります。テンプレートの1列目は現在の課題対象の生徒氏名、2列目は得点となっています。作成済みの課題成績Excel表を「成績アップロード」ウィンドウにアップロードすれば完了です。

**パソコン**
1. 課題に入ります。
2. 三点アイコンをクリックし、「成績アップロード」を選択します。

## 七、課題を共有する

教師は進行中または終了済みの課題をWeChatや他のプラットフォームに共有できます。学生がWeChatで教師が共有した課題を開くと、WeChatミニプログラム内で課題を記入することも、ClassInアプリに切り替えてクラス内で課題を記入することもできます。

**パソコン版での課題共有：** ClassInのクラス／友達に共有、リンクのコピー、またはWeChatのQRコードスキャン／ミニプログラムでWeChatの友達／グループに共有できます。

**スマートフォン／タブレット版での課題共有：** ClassInのクラス／友達、WeChat（友達／グループ／モーメンツ）、Weibo、QQの友達に共有でき、課題／課題ミニプログラムの共有やリンクのコピーにも対応しています。

**ClassInアプリ以外での共有課題の確認：** 画像・録音・動画は直接視聴・再生できます。WeChatミニプログラムではPPT・Wordなどのファイルも確認できます。edocなどその他の内容は引き続きClassInを起動してクラスに入る必要があります。

## 九、生徒が「課題」を記入する

## 1、ClassInで課題を記入する

生徒は教師が布置した課題に入った後、まず教師がアップロードした課題添付ファイルを開いて、課題内容を全面的かつ深く理解する必要があります。課題を記入する過程では、システムが対応する機能を使って教師の課題原文を読み込み、その上で自分自身の創造的な思考を十分に発揮し、質の高い解答を作成する必要があります。

生徒は画像、録音、動画、個人クラウドドライブ内のファイル、ローカルファイル、リンクなどの各種添付ファイルをアップロードし、自分の課題内容を充実させることができます。ファイル数の上限は、画像添付ファイル15枚、録音添付ファイル15件、動画添付ファイル15個で、ローカルファイル・クラウドドライブファイル・リンクの合計は15個までです。各動画・ファイルのサイズは500MB以内です。パソコンから課題の添付ファイルをアップロードする際は、画像やファイルを課題にドラッグ＆ドロップできます。

## 十一、「課題」を採点する

「教師が課題を採点する」とは、教師が生徒の提出した課題を評価・採点することを指します。生徒が実際にはオフラインで課題を完了した場合でも、教師は採点できます。教師の課題採点プロセスには通常、課題内容の理解と分析、評価と採点、コメントや提案の記入などが含まれます。課題を採点することで、教師は生徒の学業成績と進歩を把握し、知識や技能の向上に向けた指導を行うことができます。

生徒が課題を提出した後、教師はクラスまたは待ち事項で課題を見つけて採点できます。

パソコンで採点する教師は、課題左側のサイドバーですべての生徒の課題の採点状況を確認でき、未採点の課題を選ぶとその生徒の課題にジャンプして採点を開始できます。

採点の過程で、教師は生徒が提出した課題の添付ファイルを確認・ダウンロードでき、生徒の課題の質をより良く確認・評価するのに役立ちます。さらに教師は、生徒の課題に添付ファイルをアップロードしたり、生徒が既にアップロードした添付ファイルを削除したりする権限もあり、生徒の画像添付ファイルに書き込みをして採点することもできます。

確認と採点が完了したら、教師は生徒の課題に対して評価を行うことができ、テキストコメントと音声コメントの両方に対応しています。

AI採点が設定されている場合、ClassInのAIエージェントは課題の題幹、模範解答、生徒の解答中の添付ファイル（画像、音声、動画、PDF、PPTなど一般的なファイル形式を含む）を認識でき、教師はAIの採点内容を確認できます。

生徒の課題が優れている場合、教師はそれを優秀課題に設定し、生徒の努力と成長を励ますことができます。逆に生徒の課題に問題がある場合、教師は差し戻して訂正させ、生徒が問題点を見つけて改善するのを助けることができます。

教師が「完了」をクリックすると、その生徒の課題採点が完了したことを意味します。「次の生徒を採点」をクリックすると、次の未採点生徒の課題に進みます。教師が現在の生徒の課題を採点中に左側で他の生徒の提出課題に切り替えると、現在の生徒の課題採点は自動的に完了扱いになります。

生徒が提出した課題は教師が複数回採点し直すことができ、その間の採点記録は保存されます。

検索や絞り込み条件で探すこともできます。

## 十四、課題内容をダウンロードする

担任教師またはクラス教師はパソコンを使用して、発行済み課題の詳細から課題内容をダウンロードできます。ダウンロードされる課題内容には、教師が布置した課題内容と、すべての提出済み生徒の課題内容、教師が採点済みの課題の採点後の内容が含まれます。

課題の集計方式は2種類選択できます：1つはデフォルト方式で、1つのフォルダにすべての人の課題添付ファイルを集約し、課題内容が混在します。もう1つは生徒別に集計する方式で、生徒のクラスニックネームごとに2階層目のフォルダを生成し、その生徒のすべての課題内容（教師が採点済みの課題の採点後の内容を含む）をその2階層目フォルダ内に配置します。教師が布置した課題内容も別途2階層目フォルダに保存されます。

パソコンのダウンロード先を選択すると、ClassInのファイル転送機能内に即座にダウンロードタスクが作成され、ダウンロード完了後にローカルで確認できます。

1階層目のフォルダ名は：課題名-クラス名-機構名-ダウンロード時刻となります。

課題内容をローカルにダウンロードした後は次のように変換されます：

**（1）テキスト：** htmlウェブページ形式で表示。
- デフォルト集計：教師の課題内容名 = 課題タイトル、生徒の課題内容名 = 生徒のクラスニックネーム。
- 生徒別集計：教師／生徒の課題内容名はいずれも = 課題タイトル。

**（2）ファイル類（画像／EDB板書／音声動画／通常ファイル）：** 元の形式のまま表示。
（edocファイルはClassIn内でのみ閲覧可能で、ローカル表示・ダウンロードには対応していません。）
- デフォルト集計：教師の添付ファイル名 = 課題タイトル＋ファイル名、生徒の添付ファイル名 = 生徒のクラスニックネーム＋ファイル名。
- 生徒別集計：教師の添付ファイル名 = 課題タイトル＋ファイル名、生徒の添付ファイル名 = ファイル名。

**（3）リンク：** txtファイル形式で表示。
- デフォルト集計：教師のリンクはすべて1つのtxtに保存され、ファイル名は「Webリンク」。生徒のリンクはすべて1つのtxtに保存され、ファイル名は「生徒のクラスニックネーム＋Webリンク」。
- 生徒別集計：リンクはすべて1つのtxtに保存され、ファイル名は「Webリンク」。

1. 課題詳細ページ右上の「その他」に進み、「課題内容をダウンロード」をクリックします。
2. 集計方式「デフォルト」または「生徒別」を選択します。
