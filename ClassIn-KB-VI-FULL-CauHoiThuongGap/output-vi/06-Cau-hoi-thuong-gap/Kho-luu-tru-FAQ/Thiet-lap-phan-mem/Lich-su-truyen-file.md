# Lịch sử truyền file

### Đối tượng áp dụng

Tất cả người dùng

### Trường hợp áp dụng

Nội dung mà người dùng đã tải xuống từ không gian lưu trữ và file đính kèm hoạt động trên máy tính — như ảnh, video, file — có thể xem đường dẫn lưu trong mục Thiết lập - Truyền file. Ngoài ra còn hỗ trợ xóa lịch sử tải xuống.

### Lưu ý

Điện thoại và máy tính bảng không có tính năng này.

### Các bước thực hiện

#### Máy tính

Nhấn vào ảnh đại diện ở góc dưới bên trái

Vào mục Truyền file

Tìm file đã tải, nhấn **···** bên cạnh file, chọn **Mở thư mục** hoặc **Xóa lịch sử**
