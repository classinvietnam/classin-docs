## My Cloud Drive (File Upload and Related Operations)

## I. Creating/Uploading Files (Folders)

## Applies to
Everyone.

## When to use this
Before class, teachers or students can upload files from their local computer or phone to ClassIn's "Cloud Drive Space," so during class they can show files they've already uploaded to everyone else in the classroom.

## Usage Notes
My Cloud Drive supports creating new folders, as well as new lesson packs, whiteboards, assignment resources, online PPTs, collaborative documents, and other file types. Tablet does not support creating a new online PPT. Phone only supports creating folders, whiteboards, assignment resources, and collaborative documents. Only computer supports uploading a folder.

My Cloud Drive also supports uploading files, such as PPT, Word, PDF, images, audio, and video.

ClassIn has certain limits on uploaded file size: when uploading from a computer, a single file cannot exceed 500MB; when uploading from a phone or tablet, a single file cannot exceed 100MB. For TXT files, we recommend a size under 1MB to ensure normal use in the classroom. In addition, for video files uploaded from a phone or tablet: videos below 720p resolution cannot exceed 100MB, and videos above 720p resolution cannot exceed 3 minutes in length.

## Notes
The total folder limit is 2,000, and each folder is limited to 300 files.

On computer, you can drag and drop files and folders to upload them to My Cloud Drive.

Uploaded files need some time to convert — we recommend uploading in advance.

To use a file in the classroom, it must be opened from the cloud drive within the classroom.

Any file format can be uploaded to ClassIn, but only the file formats listed below can be opened and used normally in the classroom.

The file types supported for use in the ClassIn classroom are as follows:

| Type | Formats |
| --- | --- |
| ClassIn Whiteboard | edb |
| ClassIn Files | edt, edu, edx, eda, edv |
| PowerPoint Presentations | pptx, ppt, pptm |
| Word Documents | docx, doc |
| Excel Spreadsheets | xlsx, xls, csv |
| PDF Documents | pdf |
| Images | jpeg, jpg, png, bmp |
| Audio | mp3, wav, wma, aac, flac, m4a, oga |
| Video | mp4, 3gp, mpg, mpeg, 3g2, avi, flv, wmv, h264, m4v, mj2, mov, ogg, ogv, rm, qt, vob, webm |
| Text Documents | txt, html, htm, css, js, as, cpp, c, cc, cxx, h, java, md, matlab, pascal, pl, php, py, r, rb, ru, sql, swift, rbx, rs, go |
| Go (board game) | sgf |
| Chess/Xiangqi | fen, pgn |

## Steps

#### Computer/Tablet
1. Go to Space in the left navigation.
2. Go to My Cloud Drive.
3. Click Upload or New at the top to create a folder or file.

#### Phone
1. Go to Space.
2. In My Cloud Drive, click "+".
3. Create a folder/file, or Upload a file.

## II. Editing an Uploaded PPT File (Online Editing)

While using ClassIn, if a teacher needs to edit an uploaded PPT, they can go to My Cloud Drive under Space, find the file, open it, and click "Online Edit." The PPT converts to ClassIn's proprietary eppt format (which supports online editing), and the teacher can then edit and save it.

Phone and tablet do not have an "Online Edit" feature.

An eppt file that's been saved via online editing cannot be downloaded.

#### Computer
1. Go to Space in the left navigation.
2. Find the uploaded PPT file and open it.
3. Select Online Edit.

## III. Forwarding a File

Files in My Cloud Drive support forwarding to a ClassIn class or friend.

1. Go to My Cloud Drive.
2. Check the file(s) you want to forward.
3. Click Forward below.

## IV. Downloading a File

Computer supports downloading files from My Cloud Drive, such as images, whiteboards, PPTs, PDFs, and Word documents. However, ClassIn's proprietary file formats — such as online slides (eppt format) and documents (edoc format) — cannot be downloaded or opened in other apps.

Phone and tablet support saving images to the local photo album, but for files like PPT and PDF, there's no direct download feature — you can open them in My Cloud Drive, then tap the share feature to open and view them in another app.

1. Check the file(s) you want to download.
2. Click Download below.

#### Tablet
1. Open the image or file.
2. Press and hold the image to save it, or tap the share button on the file page and choose to open it with another app.

## V. Printing a File

When you need to turn a teaching file stored in "My Cloud Drive" into a physical printed document, teachers can use ClassIn's print feature; computer supports printing images, PPTs, PDFs, and similar files.

Phone and tablet do not have a "Print" feature.

1. Open the file.
2. Click Print in the top-right corner of the file.

## VI. Deleting a File (Folder)

Files and folders in My Cloud Drive can be deleted, and cannot be recovered once deleted.

1. Check the file(s) or folder(s).
2. Click Delete below.
3. Click Delete to confirm.

## VII. Editing an Image

Images in My Cloud Drive support viewing (including the original image), editing, zooming in/out, saving to the cloud drive/local photo album, or forwarding to a ClassIn class or friend.

Computer additionally supports: fitting/restoring the image to fill the screen and printing; after editing, the image is copied by default so you can paste it into other software.

1. Open the image.
2. Click Edit.
3. After editing the image, click Done.

Press and hold the image, then select Edit.
After editing the image, click Done — you can then choose to Forward or Save the image.

## VIII. Editing an EDB Whiteboard File

An EDB whiteboard file opened from My Cloud Drive supports editing. On computer, an opened whiteboard supports saving and "save as" in edb, png, or pdf format; on phone or tablet, opening a whiteboard only supports saving to My Cloud Drive.

1. Open the EDB whiteboard file.
2. After editing the EDB, click Save, or click "···" then Save As.

After editing the EDB, click Save.

Open the EDB whiteboard file in My Cloud Drive.
