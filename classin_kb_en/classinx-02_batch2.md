## ClassInX Other Common Settings

# I. Touch Response Size

## Applies to
Everyone.

## Usage Notes
When a user is using ClassInX on the large display without the Eraser tool selected, single-finger operation or two-finger swiping may sometimes be mistakenly recognized as an eraser gesture.

If this happens, we recommend going to the dock at the very bottom of the classroom screen → ClassIn → click the avatar in the bottom-left corner → Classroom Settings, find "Touch Response Size," and reduce it slightly (relative to the actual size of the large display).

## Steps
1. Tap or swipe up at the bottom-center of the screen to open the dock.
2. Click ClassIn.
3. Click the avatar in the bottom-left corner.
4. Click Classroom Settings.
5. Go to Touch Response Size and adjust it.

# II. Auto-Run on Startup

If you want ClassInX to open automatically every time you power on the large display, we recommend going to the dock at the very bottom of the classroom screen → ClassIn → click the avatar in the bottom-left corner → System Settings, find "Auto-Run on Startup," and turn it on (or off, if you'd prefer the opposite).

1. Click System Settings.
2. Turn Auto-Run on Startup on or off.

# III. Touchscreen Auto-Trigger On-Screen Keyboard

When a user opens the whiteboard or classroom using ClassInX on the large display, if they'd like to be able to type using the system's built-in on-screen keyboard, we recommend going to the dock at the very bottom of the screen → ClassIn → click the avatar in the bottom-left corner → System Settings, find "Touchscreen Auto-Trigger On-Screen Keyboard," and turn it on.

1. Click System Settings.
2. Turn "Touchscreen Auto-Trigger On-Screen Keyboard" on or off.

# IV. ClassInX Software Log Reporting

If a user runs into an issue using ClassInX software that they can't resolve on their own, they can provide ClassIn support with a description of the issue, the account involved, when it happened, and similar details, then go to the dock at the very bottom of the screen → ClassIn → click the avatar in the bottom-left corner → System Settings, and click "Report" under "Software Log Reporting," so support staff can quickly and efficiently locate the issue.

1. Under Software Log Reporting, click Report.

# V. Reporting Voice Assistant Recordings

When a user on a ClassInX 2.0 large display runs into issues like abnormal speech recognition while using the DaKe voice assistant, they can provide ClassIn support with a description of the issue, the account involved, when it happened, and similar details, then go to the dock at the very bottom of the screen → ClassIn → click the avatar in the bottom-left corner → System Settings, and click "Report" under "Report Voice Assistant Recording," so support staff can quickly and efficiently locate the issue.

1. Under Report Voice Assistant Recording, click Report.

# VI. Clearing ClassInX Cache Files

If a user opens a certain feature page in ClassInX and it takes too long to load, failing to display content properly, they can go to the dock at the very bottom of the screen → ClassIn → click the avatar in the bottom-left corner → File Transfer, click "Clear" under "Cache Files," and once cleared, click "Restart Now."

1. Click File Transfer.
2. Under Cache Files, click Clear.
3. Click Restart Now.

# VII. Clearing ClassInX Data Files

If a user in ClassInX has confirmed their schedule is set up correctly and they're logged into the right account, but still can't see the classroom entry point, they can go to the dock at the very bottom of the screen → ClassIn → click the avatar in the bottom-left corner → File Transfer, click "Clear" under "Data Files," and once cleared, click "Restart Now."

1. Under Data Files, click Clear.
2. Click Restart Software Now.

## ClassInX Extended Display Usage Guide

### I. Extended Secondary Display

When two large displays are connected, open ClassIn X software on the ClassIn X 2.0 large display, tap or swipe up to view more tools, click screen projection settings for the extended display, then select "Extend" to use the secondary display as an extended display.

### II. Extended Whiteboard (Dual-Display Sync)

If you need the extended display to show whiteboard content, you can select "Extended Whiteboard" within ClassInX's extended display settings.

**(1)** Open ClassIn X, tap or swipe up to view more tools, click Extended Display, then select or add "Extended Whiteboard."

**(2)** The extended whiteboard has "Dual-Display Sync" enabled by default. In the bottom-right corner of the extended display settings panel, you can set the whiteboard content shown on the extended display to be the "previous page," "next page," or "same page" relative to the main display. Once set, turning the page on one display will also turn the page on the other. Both displays can be written on, and content written on one syncs to the other.

**(3)** The top-right corner of the extended display settings panel also lets you set the extended display's background.

**(4)** In the classroom, once "Extended Whiteboard" is selected and set up by the teaching teacher, students in the classroom can use the extended-display control button in the bottom-right corner of the classroom to switch between viewing the main display and the extended display.

### III. Extended Whiteboard (Dual-Display Not Synced)

Once you turn off "Dual-Display Sync" in the bottom-left corner of the extended display settings panel, both whiteboards will show the same content but can be turned to different pages independently.

### IV. Extended File

If you need the extended display to show a file from Cloud Drive (Space), you can select "File" within ClassInX's extended display settings.

**(1)** Open ClassIn X, tap or swipe up to view more tools, click Extended Display, then select or add "File" — this jumps to the Cloud Drive Space page. Once you select a file (only PDF, PPT, DOC, and EXCEL formats are supported), the selected file will display on the extended display. You can write and annotate on files shown on the extended display.

**(2)** Video cannot be played on the extended display — if a PPT contains video, that video is automatically moved to the main display to play.

**(3)** The extended display supports showing up to 2 files at once. Users can click "Add" in the extended display settings window to select another file, and switch between files to adjust what's shown on the extended display.

**(4)** In the classroom, once "Extended File" is selected, the teaching teacher can set "Allow Students to Browse Freely" permission for the file in the extended display window panel. Once enabled, students in the classroom can view the extended display file in the bottom-right corner of the classroom, and can also freely turn pages in the file themselves.

### V. Showing the Video Wall on the Extended Display

Besides showing the whiteboard or file content, the extended display can also show the video wall. Users can go into the toolbox from the dock at the bottom-center of the screen, open the Video Wall tool, and the video wall feed will automatically display on the extended display.

## ClassInX Classroom Operation Gestures

# I. Shape-Drawing Shortcut

ClassInX offers a shortcut for sketching shapes, such as straight lines, circles, ellipses, rectangles, squares, diamonds, and more. Teachers just need to select the Pen tool, draw a rough shape on the whiteboard, and hold their finger on the whiteboard for 1 second — this produces a corrected, standardized version of the shape, as shown in the image.

# II. Single-Finger Operations

## Moving Courseware

Users can use any finger on either hand, placed on the edge of the courseware, to move it — for example, PPT, PDF, Word, audio, or video courseware.

## Moving Whiteboard Text, Lines, and Shapes

Users first need to select the "Select and Move" tool from the radial toolbar, then place one finger on the text/image/shape/line they want to move and drag it to the desired location.

## Playing PPT Animations or Video

Users first need to select the "Select and Move" tool from the radial toolbar, then use one finger to tap the PPT page — this triggers any animation effect on the current page, or plays any video on the current page.

## Turning PPT Courseware Pages Forward/Backward

Users first need to select the "Select and Move" tool from the radial toolbar, then use one finger to tap the PPT page and swipe forward or backward to turn the page forward or backward.

# III. Two-Finger Operations

## Swiping the Whiteboard Up/Down

Swiping two fingers on the large display can turn pages on the large whiteboard.

## Turning a Full Page of Whiteboard Content

Swiping two fingers left or right can turn a full page of whiteboard content.

## Zooming In/Out

Placing two fingers on an image, courseware, or video and swiping them together or apart zooms in or out.

## Two-Finger Selection

Placing two fingers together on an element on the whiteboard selects that element, letting you move, delete, duplicate, and otherwise operate on it. Elements that can be selected with two fingers include images, text, shapes, and lines.

# IV. Four-Finger Operations

## Summoning the Tool Dial

In the classroom whiteboard, as long as the teacher touches any location on the large display with four fingers, the tool dial will move to that location, making it convenient for the teacher to select functions from the tool dial anytime.

# V. Back-of-Hand and Palm Operations

## Eraser

The eraser is triggered by placing as much of your hand's surface area as possible against the whiteboard — the palm, back of the hand, and side of the hand are the three areas with the largest surface area, so placing any of these three against the whiteboard triggers the eraser, letting you erase whiteboard content. Note: to make sure the eraser is properly triggered, hold your hand against the whiteboard for about one second, wait for the eraser shape to appear, then move it to erase — your hand must stay in contact with the whiteboard throughout the erasing process.
