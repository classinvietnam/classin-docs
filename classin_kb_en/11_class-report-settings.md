## Unit Report Settings

### Applies to
- Primary account of the Backend Management System
- Sub-accounts with the "School Settings" permission

### Usage Notes
"Unit Report Settings" includes the following component modules: Overview, Grade Composition, Skills Analysis, Learning Process, Teacher Comments, and School Introduction. The "Overview" module is required and cannot be removed; the other modules can be added or removed as needed.

### Related Articles
"Adding Sub-accounts in the Backend"

### Steps
1. Log in to the Backend Management System.
2. Go to School Settings in the left navigation.
3. Go to Course Report Settings at the top.
4. Below, click Edit Template next to Unit Report Settings.

## Changing the Learning Report Style

### Applies to
- Primary account of the Backend Management System
- Sub-accounts with the "School Settings" permission

### Usage Notes
Teaching staff can change the learning report template style in the Backend Management System. There are two learning report styles available in the backend.

2. Go to School Settings in the left navigation.

## Automatically Pushing Post-Class Report Notifications

### Applies to
- Primary account of the Backend Management System
- Sub-accounts with the "School Settings" permission

### When to use this
If teachers want ClassIn to automatically remind them or their students to check the teaching or learning report after each class ends, teaching staff can enable automatic notification pushes in the Backend Management System. This way, teachers and students won't forget to check their reports.

### Usage Notes
Teaching staff can check to enable or disable automatic push notifications for school reports and teaching reports in the Backend Management System. If students also have ClassIn notifications enabled on their devices, both teachers and students will receive a ClassIn system notification to view the report once the teaching report or learning report has been generated.

### Related Articles
"Adding Sub-accounts in the Backend"

### Steps
1. Log in to the Backend Management System.
2. Go to School Settings in the left navigation.
3. Open Activity Report Settings.
4. Click Edit Template.
5. Under "Class Report Notification Settings," turn "Automatically push school report and teaching report notifications" on or off.
