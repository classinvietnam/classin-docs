## Quiz

## I. What Is a "Quiz"?

The "Quiz" feature in ClassIn is essentially an "exam paper," designed to assess a student's mastery of knowledge and skills in a specific subject or field. Exams are not just an important way to check learning outcomes — they also help schools and educational institutions evaluate teaching quality and how effective their curriculum design is. In addition, quizzes help students self-check their own learning progress and weak points. By taking a quiz, students can see how well they've mastered each subject and quickly spot gaps. This helps students focus their study, improve efficiency, and close knowledge gaps quickly.

## II. Creating a "Quiz"

## 1. Creating a Quiz Activity

### Applies to
Head teachers and teachers.

### Usage Notes
On the question-adding screen within the quiz:

Teachers can add questions or exam papers from the "ClassIn Question Bank" under "Select from Question Bank," and can filter questions and papers by keyword or condition.

If a teacher has previously entered their own questions, they can pull from previously entered questions and papers under "My Question Bank."

If the school has granted the teacher access to question/paper resources, the teacher can pull from those authorized resources under "Organization Question Bank."

Add the needed questions and papers to the question basket; questions already added to the basket can be removed there, and adding them to the current paper completes question selection.

Teachers can also manually add a single question, or add questions in bulk, via "Add/Bulk Add Questions." Because bulk-added questions must follow a specific format for ClassIn to recognize them, teachers should first download the template, add questions following the template and entry instructions, save the completed questions, and then upload them.

On computer or tablet, teachers can have an AI agent generate questions based on a teaching objective or specific knowledge point.

Added questions support setting points, moving position, deleting, editing, duplicating, and other actions. Preview is supported, letting teachers see how the paper will look to students on computer and phone. Saving the paper as a resource to "My Question Bank" is also supported, and on computer, teachers can also download the paper locally.

**Settings available when creating a "Quiz":**

| Setting | Function |
| --- | --- |
| Time | Set the quiz's start and due time. |
| Time limit | Set a time limit for students to complete the quiz. |
| Grading | Set the quiz's grading scheme. |
| Publish to | Publish the quiz to a specific class, to some group members or specific students within a class, or to multiple classes at once. |
| Teacher | Assign the activity's teacher to receive related notifications. |
| Course | Choose which course the quiz belongs to. Defaults to the current course. |
| Unit Topic | Choose which unit topic the quiz belongs to. If not selected, it goes into the default unit. |
| Manual grading for fill-in-the-blank | Once enabled, if a student's fill-in-the-blank answer doesn't exactly match the correct answer, it's automatically routed for manual grading. |
| Allow late submission after the activity ends | Once enabled, if a student didn't complete the quiz on time, they can submit it after the activity has ended. |
| Allow students to see each other's content and grades | Sets whether students can view each other's content and grades — and whether this applies once the quiz is submitted, once it's graded, or once it has ended. |
| Publish answers and explanations | Sets whether answers and explanations are made public — and whether this applies once the quiz is submitted, once it's graded, or once it has ended. |
| Allow newly joined students to submit | Once enabled, students who join the class before the quiz activity ends can also take part in the already-published quiz. |
| Unlock conditions | Add prerequisite activities that must be completed. If unlock conditions are added, students must complete them before starting this quiz activity. |

## 2. Bulk Adding Questions

### When to use this
When a teacher needs to import a large number of questions into ClassIn at once, they can use the "Bulk Add Questions" feature.

Under Bulk Add Questions → Upload Questions, you can directly copy and paste questions from a local Word or Excel document that follows the entry format into the "Bulk Add Questions" window. You can also drag and drop a local Word or Excel document that matches the template directly into the window.

Under Bulk Add Questions → Edit Questions, you can edit or delete questions, and also save them to "My Question Bank."

#### (1) Single Choice Question Format

**Question number format:**
- Must be an Arabic numeral.
- Must be followed by punctuation or a space, e.g. "1." or "1、" or "1 ".

**Question stem format:**
- Can include text and images; text up to 15,000 characters.

**Options area format:**
- Option labels must be uppercase letters.
- Each option must be followed by punctuation or a space, e.g. "A." or "A、" or "A ".
- Number of options: 2–26, labeled A–Z in order.
- Option content can include text and images; text up to 200 characters.

**Answer area format:**
- Must follow the required format, e.g. "Answer: A."

**Explanation area format (optional):**
- Must follow the required format, e.g. "Explanation: Why the answer is A."
- Explanation content can include text and images; text up to 15,000 characters.

Multiple choice question number format, stem format, and options area format all follow the same rules as single choice questions.

**Answer area format:**
- Must follow the required format, e.g. "Answer: A."
- The system only auto-detects a question as multiple choice if multiple answer options are set.

**Explanation area format (optional):** same as single choice.

#### (3) True/False Question Format

**Question number format:**
- Must be an Arabic numeral.
- Must be followed by punctuation or a space, e.g. "1." or "1、" or "1 ".

**True/false answer area:**
- Must follow the required format, e.g. "Answer: A."
- The answer must be one of: 正确/错误 (Correct/Incorrect) or T/F, where 正确/T means correct and 错误/F means incorrect.

**Explanation area (optional).**

#### (4) Fill-in-the-Blank Question Format

**Question number format** and **stem format:**
- Each blank must be at least three underscores long.
- With multiple blanks, the number of blanks must match the number of answers; number of blanks can be 1–40.

**Fill-in-the-blank answer area:**
- If there are multiple answers, separate them with "|".
- Answer text is up to 500 characters.

**Explanation area (optional).**

Note: press Shift and the "-" key to the right of "0" on the main keyboard row to type an underscore "_" (must be in English input mode).

**Question number format:**
- Must use an Arabic numeral.

**Answer area (optional):**
- The system automatically identifies it as a short-answer question, which requires manual grading.
- The answer can include text and images; text up to 15,000 characters.

**Explanation area (optional).**

**Sub-question format:**
- Follows the format requirements for the relevant question type above: single choice, multiple choice, true/false, fill-in-the-blank, or short answer.

## III. Editing a "Quiz"

Once a quiz is published, its questions and title can no longer be edited.

For drafts and quizzes that haven't started, "Course" cannot be changed; everything else can be edited.

For quizzes currently in progress, the quiz content cannot be edited, and "Start Time," "Time Limit," "Course," and "Manual grading for fill-in-the-blank" in the settings also cannot be changed.

For quizzes that have ended, the quiz content cannot be edited, and the following settings can no longer be changed: time, time limit, publish to, teacher, course, manual grading for fill-in-the-blank, allow newly joined students to submit, and unlock conditions.

For drafts, in-progress, and ended quizzes, saving the paper as a resource to "My Question Bank" is still supported.

1. Go to Home.
2. Enter the class.
3. Go to the course.
4. Find the quiz, click "···," then select Edit.

## VII. Sharing a "Quiz"

Teachers can share an assigned quiz to WeChat or other platforms even when a student hasn't logged into ClassIn or hasn't enabled ClassIn notifications, making it easier for teachers to prompt students to study on time.

When a teacher shares a quiz from a computer, they can share it to a ClassIn class or friend, or copy the link, or scan a WeChat QR code with their phone to share to WeChat friends or groups.

When a teacher shares a quiz from a phone or tablet, they can share it to a ClassIn class or friend, or to WeChat friends/groups/Moments, Weibo, or QQ friends, or by copying a link.

Viewing a shared quiz outside the ClassIn app only shows things like the exam paper's structure — not the actual question content. To answer the questions, the student still needs to launch ClassIn and join the class.

## VIII. Students Taking a "Quiz"

**Finding the quiz:** find the teacher-assigned quiz under the course tab within the class.

**Entering the answering screen:** tap the "Start Answering" button to the right of the quiz, and you'll enter the answering screen. At the top, you can see the number of questions and total points. The remaining time to answer also appears in the bottom-left corner — important information for pacing your answers.

**Answering process:** you can now begin answering. Based on the question, select the correct answer or fill in your answer. Once you complete a question, the system automatically marks it as answered on the answer card to the right, helping you track answered and unanswered questions; you can also tap questions on the answer card to quickly jump to them.

**Submitting the quiz:** once you've finished, tap the "Submit Quiz" button in the bottom-right corner. This means you've finished answering, and the paper will be automatically collected.

Once a student submits a quiz, they can no longer edit their answers — so please double-check your answers before submitting.

For a time-limited quiz, the timer keeps running even if you exit partway through; once time runs out, the system automatically submits it.

1. Go to To-Dos.
2. Go to Pending.
3. Find the quiz by search or filter.
4. Tap Go Answer, then tap Start Answering.

## IX. Grading a "Quiz"

"Grading a quiz" refers to the process of a teacher evaluating and scoring a student's answers. If a student actually took the quiz offline, teachers can still grade it. When grading, the teacher works through the student's answers based on the quiz's question requirements and standard answers, taking into account the student's understanding, problem-solving ability, accuracy and completeness, expression, and reasoning, in order to assign an appropriate score or rating.

Once a student submits a quiz, the teacher can find the corresponding quiz under the course tab within the class page, and click the "Go Grade" button on the right. This takes the teacher into the "Pending Grading" section, where they can judge each question one by one. Besides right/wrong, multiple choice and short-answer questions also support "partially correct." Teachers can make manual judgments on top of the automatic grading, based on the student's answers and the question's answer key; even for objective question types (true/false, single/multiple choice) that were automatically graded by the system, teachers can still edit the grading result. The answer card on the right also supports tapping to jump directly to a question.

Once grading is complete, teachers can click "Done" or "Save & Grade Next" to finish the current student's grading, or continue on to the next student. If "Save & Grade Next" is selected, the system automatically jumps to the next student's answer sheet.

Teachers can re-grade a student's submitted quiz multiple times; no history of intermediate grading is kept — only the final record applies.

Use search or filters to find what you need.

1. Find the quiz, then click Go Grade.

## X. Viewing/Downloading "Quiz Data"

Teachers can download quiz data from the Backend Management System. In addition, teachers can directly view or download quiz data within the app itself. Teachers can use this data to analyze and evaluate student learning, and to deliver personalized teaching and targeted feedback.

When viewing quiz data, you can view it question by question, and filter by question type. Clicking on a specific question shows the correct answer, that question's accuracy rate and the overall accuracy rate, how many students chose each option, and the percentage for each option.

When exporting a student's detailed quiz data from a computer, the data is saved locally as an Excel file. The spreadsheet includes, per student: class nickname, whether the quiz was submitted, whether the student submitted late, submission time, time spent answering, whether the quiz has been graded, score, accuracy rate, number of correct answers, number of incorrect answers, number of partially correct answers, number of unanswered questions, the score for each question, and the selected answer for each question. Additional information is also included: class ID, class name, quiz title, unit ID, unit name, number of questions, full score, and grader.
