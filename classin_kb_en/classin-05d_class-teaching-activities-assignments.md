## Assignments

## I. Creating an "Assignment"

### Applies to
Head teachers and teachers.

### When to use this
The "Assignment" feature refers to a teacher assigning students a certain amount of learning tasks or questions, which students are required to complete and submit within a set time. Teachers assign homework to help students reinforce what they learned in class, build self-directed learning and problem-solving skills, and use it as a way to assess and give feedback on student learning.

### Usage Notes
After entering the class page, teachers can assign homework under the course tab. An assignment supports several types of attachments — images, voice recordings, cloud drive files, local files, and website links — to help students better understand and complete the assignment. File limits: up to 15 image attachments, up to 15 recording attachments, up to 15 video attachments, and the combined total of local files, cloud drive files, and links cannot exceed 15; each video or file must be under 500MB. When uploading assignment attachments from a computer, you can drag and drop images and files directly into the assignment.

On computer or tablet, teachers can have an AI agent help generate or polish assignment content based on a teaching objective or specific knowledge point.

Teachers can select assignment resources authorized by their organization, or resources from their own cloud drive.

Teachers can also set an answer key for the assignment, which also supports uploaded attachments. The answer key's visibility can be set to: never public, public immediately, public after submission, public after grading, or public once the assignment ends.

**Settings available when creating an "Assignment":**

| Setting | Function |
| --- | --- |
| Time | Set the assignment's start and due time. |
| AI grading | Once enabled, an AI agent will grade student submissions based on the assignment content; the AI's grading is saved as a draft for the teacher to review. This feature can only be configured by teachers on computer or tablet. |
| Grading | Set the assignment's grading scheme and points. |
| Publish to | Publish the assignment to a specific class, to some group members or specific students within a class, or to multiple classes at once. |
| Teacher | Assign the activity's teacher to receive related notifications. |
| Course | Choose which course the assignment belongs to. Defaults to the current course. |
| Unit Topic | Choose which unit topic the assignment belongs to. If not selected, it goes into the default unit. |
| Allow late submission after the activity ends | Once enabled, if a student didn't complete the assignment on time, they can submit it after the activity has ended. |
| Allow students to see each other's assignments and grades | Sets whether students can view all of each other's assignments and grades.<br><br>Once enabled, you can choose "all visible" or "only excellent content and grades visible"; and the visibility timing can be set to "visible immediately," "visible after submission," "visible after grading," or "visible after the assignment ends." |
| Allow newly joined students to submit | Once enabled, students who join the class before the assignment activity ends can also take part in the already-assigned assignment. |
| Allow students to download attachments | Once enabled, students can download the teacher-uploaded attachments in the assignment. |
| Unlock conditions | Add prerequisite activities that must be completed. If unlock conditions are added, students must complete them before starting this assignment activity. |

### Notes
If "a student was removed from the class by a teacher," "the class was dissolved," or "a student left the class voluntarily," whether the departed student can still view assignment attachments depends on the class setting for allowing students who left the class or whose class was dissolved to view course content.

If you select "AI Grading Helper," "Assignment Review & Feedback Assistant (supports assignment answer key)," "Short-Answer Grading Assistant (supports assignment answer key)," or "RE Dictation Grading Assistant (supports assignment answer key)" as the AI grading agent, the AI will grade based on the standard answer key the teacher uploaded with the assignment, improving grading accuracy.

## II. Editing an "Assignment"

Assignments can be edited, but what can be edited depends on the assignment's status.

For drafts and assignments that haven't started, "Course" cannot be changed; everything else can be edited.

For assignments currently in progress, content can be edited, but "Start Time" and "Course" in the settings cannot be changed.

For assignments that have ended, content can no longer be edited, and the following settings can no longer be changed: time, publish to, teacher, course, allow newly joined students to submit, and unlock conditions.

For in-progress and ended assignments, the assignment resource can be saved to the cloud drive for future use.

1. Go to the course.
2. Find the assignment, click "···," then select Edit.

## VI. Uploading Grades

If a teacher publishes an assignment on ClassIn but the student actually completed it offline, the teacher can use the "Upload Grades" feature in the assignment to upload the student's offline grade to ClassIn — making it easier to statistically analyze grades later.

Teachers using a computer can upload grades for in-progress and ended assignments that have a grading scheme.

The Upload Grades feature in ClassIn supports manually adding a grade for a single student, or downloading a template to bulk-add grades for students — once filled in and uploaded, the students' existing grades will be overwritten.

Because the assignment grade spreadsheet must follow a specific format for ClassIn to recognize it, when bulk-uploading assignment grades, teachers need to download the template from ClassIn's upload grades screen. The template's first column is the student's name for the current assignment, and the second column is their score; once the completed Excel spreadsheet is ready, upload it in the "Upload Grades" window.

**Computer**
1. Enter the Assignment.
2. Click the three-dot icon, then select Upload Grades.

## IX. Students Doing an "Assignment"

## 1. Doing an Assignment in ClassIn

When a student opens a teacher-assigned assignment, they should first open the teacher's uploaded attachments to fully understand the assignment questions. While working on the assignment, students should use the system's support for loading the teacher's original assignment content, and build on it with their own creative thinking to produce a high-quality answer.

Students can upload various types of attachments to enrich their submission — images, recordings, videos, files from their personal cloud drive, local files, and links. File limits: up to 15 image attachments, up to 15 recording attachments, up to 15 video attachments, and the combined total of local files, cloud drive files, and links cannot exceed 15; each video or file must be under 500MB. When uploading assignment attachments from a computer, you can drag and drop images and files directly into the assignment.

Once a student submits an assignment, if the teacher hasn't yet graded it, the student can still edit their submission. If the teacher requests a revision when grading, they can mark the student's assignment as "Sent Back for Revision" — the student can then revise their submitted assignment and resubmit it.

1. Go to To-Dos.
2. Go to Pending.
3. Find the assignment, then tap Do Assignment.

## 2. Doing an Assignment in the WeChat Mini Program

When a teacher shares a ClassIn assignment to WeChat, if the student's phone or tablet doesn't have ClassIn installed, they can fill in and submit the assignment directly inside the ClassIn assignment mini program in WeChat.

**Login restrictions:** the assignment mini program supports logging in with a phone number or email.

**Student features:** students can use the assignment mini program to submit an assignment, edit an already-submitted assignment, submit late, or revise an assignment sent back by the teacher.

**Teacher features:** the assignment mini program does not support teacher grading — please grade within the ClassIn app.

**Mutual viewing permission:** once "Students can see each other's assignments and grades" is enabled for the assignment in ClassIn, students can view classmates' assignment grades and content within the mini program.

**Attachment types:** the assignment mini program supports submitting text, images, recordings, videos, and files — unlike the ClassIn app, the mini program does not support adding links.

**Attachment source:** attachments can be taken/recorded directly, selected from the photo album, or selected from WeChat chat history. Selecting from the ClassIn cloud drive is not supported.

**Attachment limits:** in the mini program, a single recording can be up to 10 minutes, and a recorded video up to 1 minute; other attachment limits match those for submitting an assignment in ClassIn. Images and videos are processed and compressed according to WeChat's rules.

1. Open a ClassIn assignment someone else shared in WeChat.
2. Tap Submit Assignment.
3. In the privacy notice, tap Agree.
4. Log in to your ClassIn account.
5. Tap Submit Assignment again to open the content entry area.
6. After completing the assignment, tap Submit Assignment.

## XI. Grading an "Assignment"

"Grading an assignment" refers to the process of a teacher reviewing and scoring a student's submitted work. If a student actually completed the assignment offline, the teacher can still grade it. Grading typically involves understanding and analyzing the submission, evaluating and scoring it, and writing comments and suggestions. By grading assignments, teachers help students understand their academic performance and progress, and guide them toward improvement in knowledge and skills.

Once a student submits an assignment, the teacher can find it in the class or their to-dos to grade it.

Teachers grading on computer can see the grading status of every student's assignment in the sidebar, and can select a pending assignment to jump directly into grading it.

While grading, teachers can view and download the attachments a student submitted, to better assess the quality of their work. Teachers can also upload attachments to a student's assignment, or delete attachments the student uploaded, and can mark up image attachments directly to grade the work.

Once done reviewing and grading, teachers can leave feedback on the student's assignment, supporting both text and voice comments.

## XIV. Downloading Assignment Content

Head teachers and class teachers using a computer can download assignment content from the details page of a published assignment. The downloaded content includes the teacher's assigned content, all submitted student content, and the content as it stands after teacher grading.

Two ways to bundle the content are available: the default method bundles everyone's assignment attachments into a single folder, with content mixed together; the other method groups content by student, generating a subfolder named for each student's class nickname, containing all of that student's content (including graded content), with the teacher's assigned content stored separately in its own subfolder.

Once you choose a local download location, a download task is created immediately in ClassIn's file transfer feature; once complete, you can view it locally.

The top-level folder is named: Assignment Name-Class Name-Organization Name-Download Time.

Once downloaded locally, assignment content is converted as follows:

**(1) Text:** displayed as an HTML web page.
- Default bundling: teacher content file name = assignment title; student content file name = student's class nickname.
- Grouped by student: both teacher and student content file names = assignment title.

**(2) Files (images/EDB whiteboard files/audio-video/regular files):** kept in their original format.
(EDOC files can only be viewed within ClassIn, and are not supported for local display or download.)
- Default bundling: teacher attachment name = assignment title + file name; student attachment name = student's class nickname + file name.
- Grouped by student: teacher attachment name = assignment title + file name; student attachment name = file name.

**(3) Links:** displayed as a .txt file.
- Default bundling: teacher's links are all saved into a single .txt file named "Web Links"; student links are all saved into a single .txt file named "Student's Class Nickname + Web Links."
- Grouped by student: links are all saved into a single .txt file named "Web Links."

1. In the top-right corner of the assignment details page, go to More, then click Download Assignment Content.
2. Choose the bundling method: Default or By Student.
