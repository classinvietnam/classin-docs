## K-12 Backend Management System

## I. Campus/Class/Course Management

#### Campus Management

**Creating a Campus**

If no school exists yet: log into the Backend Management System → go to "Course Management" → click "Create Grade/Homeroom Class" → create a new school and campus.

If a school already exists: log into the Backend Management System → go to "Course Management" → click the "···" to the right of the campus → select "Create Campus" to create a sub-campus under an existing school.

Note: the steps above require a "primary account" or "administrator" account.

**Editing a Campus**

Log into the Backend Management System → go to "Course Management" → click the "···" to the right of the campus name to edit the campus name.

**Deleting a Campus**

Log into the Backend Management System → go to "Course Management" → find the campus → click the "···" to the right of the campus name → select "Delete Campus."

#### School Level/Grade Management

**Creating a School Level/Grade**

Log into the Backend Management System → go to "Course Management" → find the school and campus → click the "···" to the right of the campus → click "Create School Level."

**Editing a Grade**

Log into the Backend Management System → go to "Course Management" → click the "···" to the right of the grade name → select "Edit."

**Deleting a Grade**

Log into the Backend Management System → go to "Course Management" → find the grade → click the "···" to the right of the grade name → select "Delete Grade."

**Deleting a School Level**

Log into the Backend Management System → go to "Course Management" → find the school level → click the "···" to the right of the school level name → select "Delete School Level."

#### Class Management

**Creating a Class**

Log into the Backend Management System → go to "Course Management" → find the campus and grade → click the "···" to the right of the grade → click "Create Homeroom Class."

**Editing a Class**

Log into the Backend Management System → go to "Course Management" → find the class → click the "···" to the right of the class name → select "Edit."

**Deleting a Class**

Log into the Backend Management System → go to "Course Management" → find the class → click the "···" to the right of the class name → select "Delete Homeroom Class."

#### Course Management

**Creating a Course**

Log into the Backend Management System → go to "Course Management" → find the class → click "Create Course" within the class.

**Editing a Course**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go into the course and click "Edit" under "Settings" to change the course's information and permissions.

**Ending a Course**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go into the course and select "End Course" under "Settings."

#### Member Management

**Adding a Head Teacher**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go to the "Members" tab → click "Set Head Teacher."

Note: the steps above require a "primary account" or "administrator" account (see how to add an administrator).

**Replacing the Head Teacher**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go into the course, and in "Members," click the "···" next to the head teacher and select "Replace Head Teacher."

**Adding a Teacher**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go to the "Members" tab → click "Set Teacher."

**Removing a Teacher**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go into the course, and under "Members," remove an already-added teacher.

Notes:

**(1)** The steps above require a "primary account" or "administrator" account.

**(2)** A teacher who is currently teaching, or who has an upcoming class session that hasn't started yet, cannot be removed.

**Adding a Student**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go to the "Members" tab → click "Set Course Students."

**Removing a Student**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go into the course, and under "Members," remove a student.

**Bulk-Removing Students**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go into the course, and under "Members," click "Bulk Actions" then select "Bulk Delete."

#### Class Session Management (Classroom)

**Adding a Class Session**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go to the "Class Sessions" tab within the course → click "Add Class Session."

**Bulk-Adding Class Sessions**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go to the "Class Sessions" tab within the course, and click "Bulk-Add Class Sessions."

**Editing a Class Session**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → then go into the course, select calendar view under "Class Sessions," open the session you want to edit, then click "Edit."

**Bulk-Editing Class Sessions**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → then go into the course, select list view under "Class Sessions" → find the information/permission you want to change → hover your mouse over that information/permission, then click the pencil icon to edit it.

**(2)** Bulk editing only supports editing class session information on the current page.

**Deleting a Class Session**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → then go into the course, select list view under "Class Sessions," find the session you want to delete, then open Actions on the right and select "Delete."

**(2)** A class session can be deleted anytime before it officially starts.

**Bulk-Deleting Class Sessions**

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → then go into the course, select list view under "Class Sessions," find the sessions you want to delete, open Actions on the right and select "Delete," then check "Bulk Edit."

**(2)** Bulk deletion only supports deleting class sessions on the current page (a session can be deleted anytime before it officially starts).

**Restrictions When Editing a Class Session**

Different pieces of a class session's information and settings have different editable time windows — see the timing table below for details.

#### Weekly Schedule

Log into the Backend Management System → go to "Course Management" → go into the class and find the course (if no campus has been created, look for the course directly under "Uncategorized Courses") → go to the Class Sessions tab → Copy Weekly Schedule.

Once you set a teaching cycle, the current week's schedule will be filled into the date range of that teaching cycle.

If class sessions already exist within the selected teaching cycle, existing sessions will not be overwritten.

## II. Class Playback Video Management

**Downloading a Playback Video**

Log into the Backend Management System → go to "Class Session Management" → find the session, click "Actions" on the right → then go to "Recorded Video Data."

Download method for Windows users:

Method 1: once in the video player window, click the three dots below, then select Download.

Method 2: once in the video player window, right-click and "Save Video As."

Method 3: right-click directly in the video list and "Save Video As."

Download method for Mac users:

Go into the video list, right-click the video's download button, and choose "Save File As." If there's no such option, hold Option while clicking the download button.

**Uploading a Playback Video**

Log into the Backend Management System → go to "Class Session Management" → find the class session you want to upload video for → click "Actions" on the right → go to "Recorded Video Data" → click "Upload Video" → select a local video and upload it.

**(1)** Video cannot be uploaded for a class session that didn't have recording enabled.

**(2)** The system only supports MP4 files encoded with H.264. Before uploading, please confirm the encoding using a media player or video processing tool — if the encoding is incorrect, you may end up with audio but no video. If the file isn't in MP4 format, it may fail to play.

**(3)** The maximum supported resolution is 1080P — anything higher may fail to play.

**Deleting a Playback Video**

Log into the Backend Management System → go to "Class Session Management" → find the class session whose video you want to delete → click "Actions" on the right → go to "Recorded Video Data" → find the video you want to delete → click "Delete" on the right.

## III. Livestream/Playback Management

#### Getting the "Livestream/Playback" Link

**Getting the Course Link**

Log into the Backend Management System → go to "Course Management" → then go into the campus on the left to find the class (if your course isn't under any class, look for it under "Uncategorized Courses") → go into the course and select "Class Sessions" → select list view on the right → then get the course's livestream/playback link below.

**Note:** if none of the class sessions under a course have recording enabled, no course livestream/playback link will appear here.

**Getting the Class Session Link**

Log into the Backend Management System → go to "Class Session Management" → get the course's and class session's playback link from within the teaching class or activity class.

#### Livestream/Playback Settings

**Changing Client-Side Playback Viewing Permission**

Log into the Backend Management System → go to "System Settings" → enable or disable client-side playback viewing under "Class Session Playback Settings" (once disabled, every student under this platform will be unable to watch historical playbacks or playbacks generated by new class sessions).

**Note:** the playback permission here only affects the ClassIn client — it doesn't affect users watching playback via the web.

**Changing Historical Playback Viewing Permission for Newly Added Students**

Log into the Backend Management System → go to "System Settings" → under "Class Session Playback Settings," allow or disallow students newly added to a course from watching playback videos of historical class sessions.

**(1)** You need to turn the toggle on first, then add students, for it to take effect.

**(2)** This setting doesn't apply to the scenario of a course's auditor becoming a formal student.

**(3)** A course's auditors will never be able to watch playback videos of historical class sessions.

**(4)** Once this changes a student's status in a historical class session, it cannot be reversed — please proceed carefully.

**Changing Historical Playback Viewing Permission for Removed Students**

Log into the Backend Management System → go to "System Settings" → under "Class Session Playback Settings," allow or disallow a student removed from a course from continuing to watch playback videos of historical class sessions.

**(2)** Once this changes a student's status in a historical class session, it cannot be reversed — please proceed carefully.

**(3)** A student removed and blocked from watching playback becomes a "transfer student" in historical class sessions, marked with a red icon in the school's backend.

**(4)** If a student removed and blocked from watching playback is later re-added to that class session's class as a "transfer student," they still won't be able to watch that session's playback or learning report.

**Changing Livestream/Playback Viewing Permission**

Log into the Backend Management System → go to "Course Management" → then go into the campus on the left to find the class (if your course isn't under any class, look for it under "Uncategorized Courses") → go into the course and select "Class Sessions" → go to calendar view on the right → then click the session you want to edit → click Edit → change the web livestream/playback viewing permission below in the edit screen.

**(1)** Once "Web Livestream" is checked, if the teacher shares the livestream link and the lead teacher records normally, anyone holding the livestream link can watch the class's web livestream (unchecking it means the link can no longer be used to watch that session's livestream).

**(2)** Once "Web Playback" is checked, if the teacher shares the link and the lead teacher's recording succeeded, anyone holding the playback link can watch the class's web playback (unchecking it means the link can no longer be used to watch that session's playback).

**(1)** Web livestream/playback only works for class sessions that have recording enabled.

**(2)** Web livestream can only be edited up to 20 minutes before class starts.

**(3)** Web playback can be edited at any time.

**Livestream Reservation Feature**

Log into the Backend Management System → go to "System Settings" → enable or disable the web livestream reservation feature under "Web Livestream/Playback Settings."

**Note:** reservations can be made anytime more than 30 minutes before class; within 30 minutes of class start, reservations are no longer possible. One minute before a livestream session starts, the system sends an SMS notification to remind the user — for domestic and international SMS billing, see the financial overview.

**Changing the Livestream/Playback Cover Image**

Log into the Backend Management System → go to "System Settings" → set the default web livestream/playback cover image under "Web Livestream/Playback Settings."

**Note:** if a class session has its own web livestream/playback cover set individually, that session's cover takes priority for display.

**Livestream Data Display**

Log into the Backend Management System → go to "System Settings" → set what livestream data to display under "Web Livestream/Playback Settings."

**Changing the Prompt Text**

Log into the Backend Management System → go to "System Settings" → change the web livestream/playback prompt text under "Web Livestream/Playback Settings."

**Anti-Recording Protection for Client-Side Playback Video**

Log into the Backend Management System → go to "System Settings" → "Class Session Playback Settings" → under Anti-Recording Settings below → enable or disable anti-recording protection for client-side playback viewing (this displays the student's client nickname).

## IV. Resources and Storage

**Uploading Public Resources**

Log into the Backend Management System → go to "School Materials" to upload public courseware resources.

**(1)** A single courseware file can be up to 500MB.

**(2)** The backend courseware resources support creating up to 2,000 folders.

**(3)** We recommend putting courseware into folders, since when granting a teacher courseware access, you can only select a folder — not an individual courseware file directly.

**Enabling Client Download for Authorized Courseware**

Log into the Backend Management System → go to "School Materials," where you can enable or disable permission for courseware to be transferred and downloaded within the app.

**Note:** this feature isn't supported for folders.

**Storage Management**

Log into the Backend Management System → go to the "Storage Management" tab → here you can view the total storage used across the current school's backend, and delete or lock/protect recorded videos and classroom monitoring images for individual class sessions (bulk deletion supported).

**Authorized Resources**

**(1)** Schools can grant students access to content within School Materials from here.

**(2)** Students can view and open these anywhere — IM, classroom, prep room, whiteboard editor, and so on.

**(3)** You can choose public authorization, or authorize an individual student separately.

Note: once the organization question bank goes live, students will no longer be able to see authorized exam papers, though other file formats remain accessible and viewable as normal.

## V. Setting Up Administrators

#### Role Management

**Creating a New Role**

Log into the Backend Management System → go to "Permission Settings" → add a new role under Role Management; each role can have different permissions configured.

**Editing a Role's Permissions and Name**

Log into the Backend Management System → go to "Permission Settings" → go to the Permission Settings tab → find the role whose name or permissions you want to change under Role Management, then click Edit on the right.

**Deleting a Role**

Log into the Backend Management System → go to "Permission Settings" → find the role you want to delete under Role Management → click Delete on the right.

#### Setting Up Administrators

**Adding an Administrator**

Log into the Backend Management System → go to "Permission Settings" → add a new administrator under Personnel Management.

**Adding Permissions for an Administrator**

Log into the Backend Management System → go to "Permission Settings" → edit an already-added administrator under Personnel Management.

**Removing an Administrator**

Log into the Backend Management System → go to "Permission Settings" → remove an already-added administrator under Personnel Management.

## VI. Classroom Monitoring Management

**Adding a Classroom Monitor**

Log into the Backend Management System → go to "Permission Management" → create a role under "Role Management" (this role needs "Classroom Monitoring" permission checked) → then add a monitoring account under "Personnel Management" and link it to the newly created role.

**Starting Classroom Monitoring**

Log into the Backend Management System → go to "Classroom Monitoring" → find the class session by its name or the teacher's account → click "Enter Classroom."

**(1)** Once a monitor enters the classroom, no one else can see them.

**(2)** Monitors can use local recording.

## VII. Bell Schedule (Class Timing Template)

**Creating a Bell Schedule**

Log into the Backend Management System → go to School Settings → Bell Schedule Configuration → click "Create Bell Schedule" → you can create class periods for any day Monday through Sunday, up to one week's worth of classes at a time, up to 20 periods per day, with each period's duration customizable, and you can copy one day's class period arrangement to other days. (An already-created bell schedule can be applied directly when creating class sessions.)

**Editing a Bell Schedule**

Log into the Backend Management System → go to School Settings → Bell Schedule Configuration → hover your mouse over the schedule's name → an options button appears on the right → click it and select Edit.

**Deleting a Bell Schedule**

Log into the Backend Management System → go to School Settings → Bell Schedule Configuration → hover your mouse over the schedule's name → an options button appears on the right → click it and select Delete, then click Confirm in the prompt that appears.

## VIII. Classroom Data

**Teaching Analysis**

Log into the Backend Management System → go to Class Session Management → search for the class session, then view its classroom data on the right.
