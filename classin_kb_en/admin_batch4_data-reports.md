## Viewing/Downloading AI Teaching Analysis Reports in the Admin Console

### Who this applies to
- The Admin Console primary account
- Sub-accounts with "Teacher Development" access

### Overview
Once AI Teaching Analysis is enabled under Value-Added Services in the Admin Console, if academic staff check "Cloud Recording" (recording the ClassIn classroom or the physical classroom) and "AI Teaching Analysis" when scheduling a session, and the teacher records normally with clear audio, an AI Teaching Analysis report will be generated for that teacher after class.

Teachers can view and download their own AI Teaching Analysis report within ClassIn.

Academic staff in the Admin Console can review a teacher's classroom performance (including overall score and flagged issues to watch) under "Teaching Management > Teacher Development," and can view or download the detailed report for each session.

The report can also be deleted from the Admin Console — this action is irreversible. Once deleted, the teacher can no longer see the AI Teaching Analysis section in their ClassIn class playback, and staff viewing that session's score and issues under "Teacher Development" will see "Report Deleted."

### Related articles
- "Adding Sub-accounts in the Admin Console"

### Steps
1. Log into the Admin Console.
2. Go to Teacher Development in the left navigation.
3. Find the session.
4. Click "Actions" on the right, then select "View Report" or "Download Report."

## Downloading Quiz Data in the Admin Console

### Who this applies to
- The Admin Console primary account
- Sub-accounts with "Assignment Management" access

### When to use this
The "Quiz Management" module in the Admin Console lets academic staff view or download quiz data for the school. Staff can filter quizzes by title, course name, teacher/student name, phone number, email, quiz status, display status, assignment time, start time, or end time. Quiz data includes: quiz title, associated course, start/end time, status (not started / in progress / ended), total score, time limit, number of questions, whether answers are public, whether late submissions are allowed, total number of students assigned the quiz, number who submitted, number graded by the teacher, the teacher's name and phone number, when the quiz was assigned, and its display status (visible or hidden in the client).

### Related articles
- "Adding Sub-accounts in the Admin Console"
- "Viewing/Downloading Quiz Data in the App"

### Steps
1. Log into the Admin Console.
2. Go to Quiz Management in the left navigation.
3. Find the quiz.
4. Click "Data" on the right, then choose "This Quiz's Data" or "Session Quiz Data" (to download, click "Download Table" or "Bulk Download" in the top-right).

## Viewing/Downloading Assignment Data in the Admin Console

### Who this applies to
- The Admin Console primary account
- Sub-accounts with "Assignment Management" access

### Overview
Academic staff can view or download assignment data for the school in "Admin Console > Assignment Management." Staff can filter by assignment title, course name, teacher/student name, phone number, email, assignment status, display status, assigned time, start time, or end time. Downloaded assignment data includes: course ID, assignment title, associated course, teacher's name/phone/email, start and end time, status (not started / in progress / ended), total score, grading display method (numeric score, percentage, letter rating, ABCD rating, etc.), how the assignment is shared, whether late submissions are allowed, total students assigned, total submissions, total graded, number of students rated "excellent," the responsible teacher, when it was assigned, display status (visible or hidden in the client), submission rate, number of late submissions, how many students' work has been graded, how many were sent back for revision, how many students revised their work, number of "excellent" ratings, and the average, highest, and lowest scores.

### Notes
- Each download covers a maximum of one month's data.

### Related articles
- "Adding Sub-accounts in the Admin Console"

### Steps
1. Log into the Admin Console.
2. Go to Assignment Management in the left navigation.
3. Find the assignment.
4. Click "Data" on the right, choose "This Assignment's Data" or "Course Assignment Data" (to download, click "Download Table" on the right — the file saves to your computer).

## Exporting Class Data in the Admin Console

### What is "class data"?
"Class data" refers to statistics generated from tool usage and interactions within the classroom, covering both teacher and student attendance and behavior analysis. It has two sections: "Teaching Analysis," which covers teacher performance data during class, and "Learning Analysis," which covers student learning behavior data.

### Who this applies to
- The Admin Console primary account
- Sub-accounts with "Course Management" access

### When to use this
When a teacher wants to download class attendance and behavior statistics to their computer, they can filter the desired data in Class Data and export it as an Excel spreadsheet.

### Overview

**Teaching Analysis**

In Class Data, the "Teaching Analysis" page lets you analyze data for a specific teacher or time period, including: attendance, average number and duration of courseware used, average number of rewards given, hand-raises, tool authorizations, and usage of other teaching tools. This data can also be shown as a line chart of usage counts and cumulative duration over time. "Count" and "Cumulative Duration" can be toggled via the chart customization controls in the top-left of the chart.

At the bottom of the Teaching Analysis page, you can view or download per-session detail data, including: total teaching time per session, teacher attendance per session, student attendance per session (excluding auditing students), student ratings/comments for the teacher, teacher ratings/comments for students, total number of students who watched the class playback in the ClassIn app, average playback viewing duration across students, total playback video duration per session, and detailed usage counts/durations for: text-based courseware (Word, PowerPoint, PDF, and other document types), audio/video courseware, mute-all actions, student removals, student rewards, student hand-raises, tool-authorized student tool usage, "Screen Share," "Timer," "Dice," "Buzzer," "Response Clicker" (including accuracy and detail breakdown), "Mini Whiteboard" (including detail breakdown), "Collaborative Text," "Multi-way Screen Share," "Browser," "Assignment" tool, "Countdown Timer," "Random Picker," "EDB Courseware" (with names, open times, and sources), "Breakout Rooms" (including detail breakdown), "Auxiliary Camera," and "Video Wall."

**Learning Analysis**

In Class Data, teachers and admins can use the "Learning Analysis" page to better understand student performance, including: total time per session, attendance records, teacher ratings/comments for the student, and the number and duration of times a student watched the class playback. It also covers statistics on student speaking, going on stage, raising hands, being removed, and being rewarded, as well as usage of buzzer and response clicker tools. Total camera-on duration per session is also tracked. This data helps teachers and admins understand student performance and take targeted steps to improve learning outcomes.

### Related articles
- "Adding Sub-accounts in the Admin Console"

### Steps
1. Log into the Admin Console.
2. Go to Class Management in the left navigation.
3. Find the class, click "Class Data" on the right.
4. In the top-left, go to "Teaching Analysis" or "Learning Analysis."
5. Filter the data.
6. Click "Download Table" at the bottom.
