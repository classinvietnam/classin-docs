## Time Reminders

### Countdown Timer

The countdown timer offers a countdown feature, letting you set a fixed duration and start the countdown, with a maximum settable duration of one hour (durations over one hour cannot be set). Pausing isn't supported once counting down, and a bell rings when the countdown ends. Once finished, you can reset the countdown, restoring it from 0:00 back to the originally set duration.

| Command | Description | Example Phrasing |
| --- | --- | --- |
| Open Countdown Timer | Opens the countdown timer tool | "Open countdown" |
| Reset Countdown Timer | Resets the countdown timer from its finished 00:00 state back to the initial set duration | "Reset countdown" |
| Start Countdown Timer | Starts the countdown | "Start countdown" |
| Set Countdown to 5 Minutes | Sets the countdown timer to five minutes and starts it | "Give everyone 5 minutes" |
| Close Countdown Timer | Closes the countdown timer tool | "Close countdown" |

### Timer (Stopwatch)

The timer offers a stopwatch feature, counting up from zero. It supports starting, pausing, and — while paused — resuming or resetting. Useful for measuring how long students take to complete a task, or for pacing an activity.

| Command | Description | Example Phrasing |
| --- | --- | --- |
| Open Timer | Opens the timer tool | "Open stopwatch" |
| Start Timer | Starts the stopwatch | "Start timing" |
| Pause Timer | Pauses the stopwatch | "Pause timing" |
| Resume Timer | Resumes the stopwatch | "Resume timing" |
| Reset Timer | Resets the timer to zero | "Reset timing" |
| Close Timer | Closes the timer tool | "Close stopwatch" |

# Distributed Answer Boards

This category of tools is used to organize and run various teaching activities, including interactive exercises, virtual labs, and teaching aids.

### Whiteboard Small Blackboard

Whiteboard Small Blackboard is a window-based small blackboard tool. Once the teacher opens it, they can draw preset content on it — such as practice questions — then distribute it to other online students in the classroom, who can then continue writing their own answers on it. During this time, the teacher can view what students are writing in real time, and recall the small blackboard whenever needed to end the answering period. Once recalled, the teacher can then go over what students wrote. The teacher can also reset the small blackboard to start a new round of activity.

| Command | Description | Example Phrasing |

### Text Small Blackboard

Text Small Blackboard is a text-editor-style window tool. Once the teacher opens it, they can type text content — such as a question or set of instructions — then click "Distribute" to send it to all or specific students. Once students receive it, they can add and edit their own text answers in the text area. Throughout, the teacher can view every student's answer in real time and offer guidance as students type. Once the activity ends, the teacher can click "Recall" to take back students' access to the text small blackboard, then display and go over student answers in class. The teacher can also reset it to clear the content and start a new round of text interaction.

| Command | Description | Example Phrasing |

### Go Small Blackboard

Go Small Blackboard is a window-based tool designed specifically for teaching Go (the board game). Once the teacher opens it, they'll see a standard 19x19 Go board, and can place black and white stones to demonstrate a specific game position or tactic. The teacher can click "Distribute" to send the current board state to students, who can then continue placing stones to try solving the position or continue playing. The teacher can monitor each student's moves in real time, and use voice guidance or markup features to point out key spots as needed. Once the activity ends, the teacher clicks "Recall" to end student input, then can show the correct move or best tactic, along with commentary and explanation. The teacher can also reset the board to start new content.

| Command | Description | Example Phrasing |
| --- | --- | --- |
| Open Go Small Blackboard | Opens the Go teaching board | — |
| Close Go Small Blackboard | Closes the Go teaching board | — |

### Multi-Directional Browser

Multi-Directional Browser is a window-based tool for web-based teaching. Once the teacher opens it, they can preview and prepare the webpage content needed for the lesson, then click "Distribute" to send the currently viewed webpage to students. Once received, students can browse, search, and interact with that webpage — for example, filling out a web form, reading specified content, or completing an online task. The teacher can monitor students' webpage activity in real time to track their progress. Once the web-based activity ends, the teacher clicks "Recall" to take back students' control of the browser, then can show a reference walkthrough or guide students on proper use of the web resource. The teacher can also switch to a new URL to move on to the next web-based teaching segment.

### Camera

Camera control lets the teacher manage their video input device — turning the camera on for face-to-face communication, and off when not needed, protecting privacy and reducing network bandwidth usage.

| Command | Description | Example Phrasing |
| --- | --- | --- |
| Turn On Camera | Enables the camera and shows the camera feed window | "Show camera" |
| Turn Off Camera | Disables the camera and hides the camera feed window | "Hide camera" |
