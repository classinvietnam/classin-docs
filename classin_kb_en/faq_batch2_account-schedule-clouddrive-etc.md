## FAQ: Account

### 1. "No permission" message
**Issue**: When registering a ClassIn account, clicking "Get verification code" returns "No permission."

**Solution**: This is usually caused by an incorrect system clock on your computer. Reset the system time as follows, then try getting the code again:
1. Right-click the clock in the bottom-right corner of your computer.
2. Go to "Adjust date/time."
3. Turn on "Set time automatically" and "Set time zone automatically."
4. Restart your computer so the time change takes effect.
5. Try registering for ClassIn and requesting the code again.

### 2. Multiple people sharing one account
**Q**: Can one ClassIn account support multiple students attending class at the same time?

**A**: Using the same ClassIn account for multiple students at once has limitations. An account can only be active in one classroom at a time — if it's already logged into a classroom on one device, logging into a different classroom with the same account on another device will force the first device out. If multiple students must share an account, make sure their class times never overlap to avoid being unable to join.

### 3. Registering ClassIn from outside China
**Q**: Can users outside China register a ClassIn account with a foreign phone number?

**A**: Yes. As long as the phone number can receive the verification code SMS, registration works normally.

## Resync Data

### Applies to
Everyone

### When to use this
If you're logged into the correct ClassIn account, have joined the right class, and that class does have scheduled sessions, but you still run into issues like: can't find the classroom entrance, garbled class info, or no visible courses — try the "Clear Data Files" feature in app settings (called "Resync Data" on phone/tablet).

### Steps

**Computer**
1. Click your profile picture in the bottom-left corner.
2. Go to File Transfer.
3. Find Data Files and click Clear on the right.

**Phone**
1. Tap Home in the bottom navigation.
2. Tap your profile picture in the top-left corner.
3. Go to App Settings.
4. Tap Resync Data.

**Tablet**
1. Tap your profile picture in the bottom-left corner.

## FAQ: Cloud Drive

### 1. Error: "Upload failed, please try again later"
**Issue**: Uploading local courseware to ClassIn Cloud Drive fails partway through with "Upload failed, please try again later."

**Solution**: Try either of the following:
- **Restart your router**: an unstable network during upload can cause this. Power the router off, then back on.
- **Switch your network connection**: if using a laptop, try a wired connection, or connect via a phone's 5G hotspot for a more stable connection.

### 2. Courseware shows an exclamation mark
**Issue**: After uploading courseware to Cloud Drive, its icon shows a red exclamation mark.

**Solution**: A red exclamation mark means the file conversion failed — a file that fails to convert can't be shown in the classroom. Review the "Courseware Production Standards" and adjust your local file, then re-upload it. If the red exclamation mark persists after re-uploading, contact ClassIn support: 1) message the ClassIn Assistant in the after-sales support group, or 2) call support at 400-077-1585.

### 3. Cloud Drive shows no courseware
**Issue**: Opening the Cloud Drive tool in the classroom shows no courseware and no message at all.

**Solutions**:
- **Reload**: click the "Reload" button in the top-right corner of the Cloud Drive window.
- **Clear cache**: leave the classroom, clear the ClassIn cache, then re-enter.
- **Switch server**: leave the classroom and quit ClassIn, then log back in. On the login screen, click "More settings" in the bottom-right, and choose one of the first three servers under Auto.

## FAQ: Speaker

### 1. No sound at all
**Issue**: You can't hear any sound in the classroom — neither audio/video courseware nor other people talking.

**Windows computer**, try any of the following:
- Turn up the speaker volume in Classroom Settings.
- Turn up the computer's system speaker volume.
- Use "Repair Hardware" in Classroom Settings to fix a potential sound card driver issue.
- If your laptop is connected to an external display, click the speaker icon in the bottom-right of the desktop and switch to the correct audio output channel.

**Mac**, try any of the following:
- Restart the computer — audio/video usually recovers automatically.
- If connected to an external display, click the speaker icon in the top-right of the desktop and switch to the correct output channel.

**Phone/tablet**, try any of the following:
- Use the volume buttons on the side of the device to turn it up.
- Try plugging in headphones, or unplugging them if already connected, to see if sound returns.

### 2. Sound is too quiet in the classroom
**Issue**: Other people's voices in the classroom are very quiet or hard to hear.

**Computer**, try any of the following:
- Turn up the speaker volume in Classroom Settings.
- Turn up the computer's system speaker volume.

**Phone/tablet**:
- Use the physical volume buttons to turn it up.
- Try plugging in headphones (or unplugging them if already connected, to rule out a headphone issue).

### 3. Echo in the classroom
**Issue**: You hear an echo in the classroom.

**Solution**: When multiple students are speaking on stage, the teacher can locate the source: ask all students to stay quiet, then speak. If you hear your own echo, watch each student's microphone indicator for movement to find the culprit. Once identified, mute that student's microphone when they're not speaking, to prevent further echo. For the affected student, try either of the following:
- **Increase device distance**: if using an external speaker and microphone, point them in opposite directions and increase the distance between them.
- **Use headphones**: have the affected student wear headphones during class, which effectively prevents echo.

## FAQ: Recording

### 1. Cloud recording interrupted
**Issue**: While teaching on a computer, the cloud recording status icon in the top-right of the classroom (teacher view) turns red, indicating the recording was interrupted.

**Solution**: To keep recording running smoothly:
- **Don't plug/unplug audio devices** during recording (headsets, speakers, Bluetooth headphones) — Bluetooth headphones in particular can cause interruptions due to unstable connections.
- **Close antivirus/security software**: quit programs like 360 Security Guard, 360 Antivirus, Tencent PC Manager, 2345 Security Guard, Microsoft PC Manager, Lenovo PC Manager, etc., which can interfere with recording.
- **Disable the firewall** to make sure it isn't blocking the recording service.
- **Improve your network connection**: if using a laptop, try a wired connection or a phone's 5G hotspot.
- **Contact support**: if none of the above works, message the ClassIn Assistant in the after-sales support group, or call 400-077-1585.

### 2. Classroom window shrinks after recording starts
**Issue**: When a teacher starts recording, the classroom window automatically shrinks and can't be resized.

**Solution**:
1. Open the ClassIn client and go to Settings.
2. Find and select "Recording area."
3. Check "Current-size classroom window."
4. Save, then re-enter the classroom and start recording.

### 3. "This feature requires screen-recording permission"
**Issue**: On Mac OS 10.15 or later, a message asks for screen-recording permission when starting to record.

**Solution**, try either of the following:
- **Set the recording area**: go to ClassIn Settings > "Recording area" and select "Current-size classroom window," then re-enter the classroom to record.
- **Grant screen-recording permission**: on Mac, go to System Preferences > Security & Privacy > Screen Recording, and check the box to authorize ClassIn.

### 4. Can teachers or students download recorded playback videos?
**Issue**: Can teachers or students download recorded class playback videos?

**Solution**: Teachers with download permission in the Admin Console can download class playback videos; students cannot download these videos.

## FAQ: Schedule

### 1. Can't find the classroom (no class / class not showing)
**Issue**: After logging into ClassIn, a student can't find the classroom for a class they've joined.

**Solutions**, try either of the following:
- **Check the account**: click the profile picture in the top-left corner to check your personal info, and confirm the logged-in account matches the one the teacher used to schedule the class. (On phone/tablet, tap the profile picture in the top-left, then check "Account & Security.")
- **Clear data files**: if the account is confirmed correct, use "Clear Data Files" in ClassIn settings. Note: the message list only shows classes starting within the next 24 hours — for classes further out, search by date or class in the "Schedule" panel on the left. (On phone/tablet, use "Resync Data" in settings.)

### 2. Message list stuck on "Loading..."
**Issue**: After logging in, the ClassIn homepage message list can't load any classes and stays stuck on "Loading."

**Computer**, try any of the following:
- **Log back in**: quit ClassIn and log in again.
- **Wait a moment**: the network connection may just be briefly delayed.
- **Close antivirus/security software**: e.g. 360 Security Guard, 360 Antivirus, Tencent PC Manager, 2345 Security Guard, Microsoft PC Manager, Lenovo PC Manager, etc.
- **Disable the firewall** temporarily to make sure your network isn't restricted.
- **Restart your router**: unplug it, then plug it back in.
- **Try a different network**: on a laptop, try a wired connection or a phone's 5G hotspot.

**Phone/tablet**, try any of the following:
- **Restart the device**, then log back into ClassIn.
- **Move closer to your router** for a stronger signal.
- **Switch networks**: e.g. disconnect Wi-Fi and use mobile data instead.

### 3. Wrong class start time shown
**Issue**: The class start time shown in ClassIn doesn't match what the teacher actually scheduled.

**Solution**: Set your computer's local time zone to the correct time zone for your current location.

### 4. Can ClassIn's schedule sync to my phone's calendar?
**Q**: Can class times in ClassIn sync directly to my phone's calendar?

**A**: Currently, class times in ClassIn cannot be synced directly to a phone calendar.

### 5. Can I watch the playback if I missed class?
**Q**: If a student didn't attend class and never entered the classroom, can they still watch the class playback afterward?

**A**: Yes. Even if a student never entered the classroom, they can still watch the class playback afterward, as long as: they're an official enrolled student for that class, cloud recording was enabled for the class, and the teacher recorded the session normally.

## FAQ: Web Live Stream

### 1. "The teacher is on their way"
**Issue**: While watching a ClassIn live stream in a browser, the video and audio suddenly cut out and show: "The teacher is on their way, please wait."

**Solutions**, try any of the following:
- If the teacher hasn't entered the classroom yet, wait for them to enter and start teaching, then press F5 to refresh the page.
- If the teacher has entered the classroom but hasn't started teaching, contact academic staff to have them ask the teacher to click "Start recording now" on the recording countdown prompt in the classroom.
- If recording was interrupted due to the teacher's unstable network or a device issue (e.g. plugging/unplugging a speaker), check the recording status, then message the ClassIn Assistant in the after-sales support group, or call 400-077-1585.

### 2. "This session is not public"
**Issue**: Opening a ClassIn live-stream link in a browser shows no video or audio, with the message "This session is not public and cannot be viewed."

**Solution**: This happens because the class doesn't have "Web Live Stream" enabled. When creating the class, the teacher needs to check "Web Live Stream" so browser viewers can watch. If the class was already created, a teacher with class-creation permission can still enable "Web Live Stream" in the class settings, as long as it's more than 20 minutes before class starts.

### 3. "The teacher has temporarily left the classroom"
**Issue**: While watching a ClassIn live stream in a browser, video and audio suddenly cut out with the message "The teacher has temporarily left the classroom, please wait."

**Solution**: This can happen if the teacher manually left the classroom, or was disconnected due to an unstable network. Wait for the teacher to re-enter and resume teaching, then press F5 to refresh and continue watching.

### 4. Live stream shows a black screen but audio still works
**Issue**: Watching a class live stream via a web link, you can hear audio from the classroom but see no video.

**Solution**:
1. Have the teacher temporarily leave the classroom.
2. Open ClassIn Settings > System Settings > Advanced Settings, and under "Recording codec," check "Legacy mode."
3. Have the teacher re-enter the classroom and start recording again.
4. Viewers should refresh the page to reload the live stream.

## FAQ: Microphone

### 1. No sound when speaking (microphone icon gray)
**Issue**: When speaking on stage, others can't hear you. On computer, the microphone icon in the bottom-left of your camera view is gray; on phone/tablet, the audio indicator bar below your camera view is gray.

**Solution**: This means you've manually disabled your microphone. Re-enable it in Classroom Settings.

### 2. No sound when speaking (microphone icon red)
**Issue**: A student speaking on stage can't be heard by others. On computer, the microphone icon in the bottom-left of their camera view is red; on phone/tablet, the bar below their camera view is red.

**Solution**: This means the teacher has muted the student. The teacher can unmute them from the roster, or via the shortcut below the student's camera view.

### 3. No sound when speaking (microphone icon green, but no waveform while talking)
**Issue**: The microphone is turned on but others still can't hear you, and there's no waveform movement on the microphone icon (computer) or audio bar (phone/tablet) while you speak.

**Windows computer**, try any of the following:
- **Enable "Auto-adjust microphone volume"** in Classroom Settings.
- **Switch microphone device** if multiple microphones are connected.
- **Repair hardware**: use "Repair Hardware" in Classroom Settings.
- **Check microphone privacy settings**: right-click the speaker icon in the bottom-right of the desktop, choose "Open sound settings," go to "Microphone privacy settings," and enable "Allow apps to access your microphone."
- **Disable spatial audio**: right-click the speaker icon and turn off "Spatial sound."
- **Disable exclusive control**: right-click the speaker icon > Sounds > Recording, right-click your active microphone > Properties > Advanced, and uncheck "Allow applications to take exclusive control of this device."
- **Switch microphone mode**: in ClassIn settings, switch microphone mode to "Legacy mode."

**Mac**, try either of the following:
- **Grant microphone permission** to ClassIn in system settings, then restart. If already granted, try re-granting it and restarting.

**Phone/tablet**, try either of the following:
- **Restart the device.**
- **Use headphones** (or unplug them if already connected).

### 4. Microphone turns off automatically after being enabled
**Issue**: The microphone setting automatically switches back to disabled shortly after you turn it on.

**Solution**, try either of the following:
- **Repair hardware**: use "Repair Hardware" in Classroom Settings to fix the microphone driver.
- **Update your sound card driver**: if the issue persists, contact your computer's after-sales support and install the latest sound card driver.

### 5. Static or noise when speaking
**Issue**: When a teacher or student speaks, others hear noise — buzzing, static, electrical interference, etc.

**Solutions**:
- **Move to a quieter room** if you're the one producing the noise.
- **Enable noise reduction**: turn on "Microphone Noise Reduction" in Classroom Settings.
- **Use a headset**: recommended for the affected user.
- **Move electronics away**: keep phones and other electronics away from your computer and audio devices to avoid electrical interference.

### 6. Muffled or unclear voice
**Issue**: A teacher or student's voice sounds unclear when speaking on stage.

**Solutions**:
- **Try a different microphone device** temporarily to confirm it works properly.
- **Use a headset** if not already wearing one, to improve clarity.

## FAQ: Courseware

### 1. PPT auto-advances (auto-plays)
**Issue**: A PPT courseware file auto-advances slides or auto-plays animations in the classroom without being triggered manually.

**Solution**:
1. Open the PPT file on your local computer.
2. Uncheck "Automatically advance slides."
3. Click "Apply to All" to make sure the change takes effect.
4. Save the updated PPT file.
5. Re-upload the updated file to ClassIn Cloud Drive.

### 2. Misaligned or overlapping text in PPT
**Issue**: Text appears misaligned or overlapping when a PPT file is opened in the classroom.

**Solution**:
- **Chinese fonts**: use built-in system Chinese fonts such as SimSun, SimHei, or Microsoft YaHei for best compatibility and display.
- **English fonts**: use "Arial" to avoid display issues, and avoid italic, underline, or bold effects, which can increase the chance of misalignment or overlap.
- **Save and re-upload**: after editing locally, save the file and re-upload it to Cloud Drive so it displays correctly across devices.

### 3. Can't open a .txt file
**Issue**: A .txt file won't open in the classroom.

**Solution**: If the .txt file is larger than 1MB, it can't open normally in the classroom. Copy its contents into a Word document and re-upload that to Cloud Drive instead — this avoids the file-size limitation.

### 4. Courseware opens but shows no content
**Issue**: Courseware opens in the classroom but shows no content — just a blank white or black screen.

**Solutions**, try any of the following:
- **Reopen it**: close the courseware and open it again.
- **Clear cache**: clear the ClassIn cache.
- **Log back in**: leave the classroom, quit ClassIn, and log back in.

### 5. PPT won't display full screen
**Issue**: After maximizing a PPT in the Cloud Drive tool in the classroom, black bars remain on both sides and it doesn't fill the screen.

**Solution**: Adjust the PPT file's width and height locally to match the classroom's aspect ratio:
- **Standard screen mode**: width 31.75cm, height 13.851cm — or width 63.5cm, height 27.7cm.
- **Large-screen mode or with the roster hidden**: height 33.4cm.

After adjusting, re-upload the PPT to Cloud Drive for a true full-screen display.

### 6. Error: "Image too large to display"
**Issue**: On iPad or iPhone, opening a PDF file in Cloud Drive shows "Page image too large to display normally."

**Solution**: This happens when images inside the PDF are too large, overloading the device's memory on iPad/iPhone. Try either of the following:
- **Reduce the number of images** per page in the PDF editor, then re-upload.
- **Shrink the image sizes** in the PDF editor, then re-upload.

### 7. How to upload courseware larger than 500MB
**Q**: How do I upload courseware larger than 500MB?

**A**: Split it into multiple smaller files and upload them separately.

### 8. Can't see the courseware
**Issue**: You can't see courseware that others have opened in the classroom.
