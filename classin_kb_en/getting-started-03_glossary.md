## Glossary of Terms

| ClassIn Term | Explanation |
| --- | --- |
| IM | Short for Instant Messaging area. The main interface you land on after logging into ClassIn is the IM interface, which includes modules like your personal avatar, message list, to-dos, contacts, space, schedule, whiteboard, and settings. |
| Personal Avatar | Located in the top-left corner of the ClassIn main interface; click it to set your personal information, including avatar, name, contact card sharing, QR code sharing, phone number binding, email binding, password change, gender, date of birth, region, and personal signature. |
| Message List | A module in the ClassIn main interface for receiving messages from classes and friends. Computer users access it via the left navigation bar; phone and tablet users access it via the bottom navigation bar. In this list, you can receive messages from classes and friends, and pin, mute, or delete conversations. |
| Contacts | Users can go to the "Contacts" module via the left navigation bar (on computer) or bottom navigation bar (on phone/tablet) to add friends, view class and friend lists, handle friend requests, and view/manage friend details. |
| Authorized Resources | Public teaching resources — such as courseware and exam papers — that a school grants specific teachers access to use. Through authorization, teachers can use standardized teaching resources, ensuring consistency and quality in teaching content. |
| On Stage | In the classroom, the position where a teacher invites a student to show their camera using the "Roster" tool is called being "on stage." An on-stage student can communicate via voice with the teacher and other on-stage students, and every classroom member can see their camera feed. |
| Go On Stage | The action of a teacher inviting a student to show their camera "on stage" via the "Roster" tool. |
| Go Off Stage / Return Off Stage | When a teacher stops a student from showing their camera, this is called having them "return off stage." |
| Off Stage | Classroom members not showing their camera "on stage" are considered to be listening from "off stage." |
| Authorization | The permission a teacher grants a student, via the "Roster" tool, to use classroom tools such as the pen, select/move tool, click tool, eraser, text input tool, screenshot tool, and cloud drive. |
| Blank | When a user opens a certain ClassIn screen and nothing displays in it, this is called "blank." Common cases include a blank screen after opening assignments, quizzes, the cloud drive, or courseware. |
| White Screen | When a user opens a certain ClassIn screen and nothing displays in it, this is called a "white screen." Common cases are similar to "blank." |
| Black Screen | When a user opens a certain ClassIn screen and nothing displays except a solid black page, this is called a "black screen." Common cases include a black screen after opening the cloud drive or courseware. |
| Scheduling a Class Session | The user clicks "Create Class" on the ClassIn main interface, goes into the "Course" tab within the newly created class, clicks "New," and selects "Class Session" to schedule it. |
| Starting a Class Session | The user clicks "Create Class" on the ClassIn main interface, goes into the "Course" tab within the newly created class, clicks "New," and selects "Class Session" to start it. |
| Creating a Class Session | The user clicks "Create Class" on the ClassIn main interface, goes into the "Course" tab within the newly created class, clicks "New," and selects "Class Session" to create it. |
| Video Wall | A teaching tool that lets the teacher monitor every student's camera feed in the class in real time, making it easy to observe how students are doing during class. If a student hasn't turned on their camera, the teacher will only see their video placeholder. |
| Online Classroom, Local Classroom, Temporary Classroom | **Local Classroom:** the "Whiteboard" feature on the ClassIn main interface, for users to get familiar with classroom features and create whiteboard content, with no time limit.<br>**Online Classroom:** the "class session" in ClassIn, where teachers and students take class.<br>**Temporary Classroom:** can be created anytime by teachers and students, free to use. |
| Learning Activity | Any activity within a class that's for teaching purposes and content, including class sessions, recorded courses, assignments, quizzes, check-ins, answer sheets, discussions, and learning materials. |
| Multi-Class Quiz | When creating a quiz, the teacher checks multiple classes under the "Class" field in the quiz settings, letting students from every selected class take part in that quiz. |
| Echo | When a classroom speaker's sound gets picked up by the microphone and played back into the classroom, causing an echo. This is usually caused by the microphone being too close to the speaker. |
| Focus Mode | A feature that helps improve students' focus during class. Once enabled, a computer user's classroom interface stays full-screen and can't be switched away from; a phone or tablet user will automatically exit the classroom if ClassIn is sent to the background. |
| Fix Hardware Driver | A hardware-fix feature in ClassIn used to resolve issues with devices like the microphone, speaker, and camera. |
| EDB | ClassIn's proprietary electronic whiteboard file format, used to save whiteboard content a teacher creates in the classroom, making it easy to reuse and share later. |
| Whiteboard | **Whiteboard feature on the main interface:** refers to the local classroom, for teachers and students to get familiar with classroom features.<br>**Whiteboard within the classroom:** the interactive tool teachers and students use during class.<br>**Small Blackboard tool in the classroom toolbox:** used for answering and interacting during the teaching process. |
| Large Display All-in-One | A device that integrates a display screen and a computer host together, typically used for presentations, demonstrations, and information display. |
| Large Display All-in-One vs. Large Display Mode | **Large Display All-in-One:** the device that integrates a display screen and a computer host.<br>**Large Display Mode:** the control interface mode used in the ClassIn classroom. |
| Course | **The "Course" module within a class in the software:** where you can add unit topics and learning activities.<br>**The "Course" in the Backend Management System:** has the same meaning as "class" in the software. |
| Backend Management System | ClassIn's management platform, where academic teachers can create courses and class sessions, manage teachers and students, monitor classroom data, and configure personalized settings, among other things. |
| Time Units | Half an hour = 30 minutes; one hour = 60 minutes. |
| Data Units | 1GB = 1024MB, 1MB = 1024KB, 1KB = 1024 bytes. |
| Phone | A portable electronic communication device supporting calls, texts, internet access, and more, typically running iOS, Android, or HarmonyOS. |
| Tablet | A portable electronic device using a touchscreen and virtual keyboard, typically running iOS, Android, or HarmonyOS. |
| Class-Taking Client | Refers to the ClassIn client (app). |
| Web Playback | The web version of a class playback video, viewable via a shared link starting half an hour after class ends; requires cloud recording to be enabled. |
| Teaching Assistant | Refers to the co-teacher. |
| Classroom | "Classroom" refers to any location where a teaching activity takes place, including: the formal class session, a class's temporary classroom, a friend's temporary classroom, and the local classroom. |
| Space | Space, also known as the cloud drive, refers to a feature that provides online storage. Using Space, users can upload files from a local device to the cloud, enabling remote storage and access to files. Users just need to connect any device to the internet, log into ClassIn, and go to the Space tab to view, share, download, or edit their files online.<br><br>Space's advantage lies in its high reliability and excellent cross-device compatibility. User file data is stored on cloud servers, which not only ensures data integrity and security, but also lets users conveniently access and manage files remotely from any location on any device. In addition, Space offers a variety of online editing tools, letting users edit and process files directly online without downloading local editing software. In short, Space is an efficient, convenient, and secure way to store and manage files online, offering users great convenience and peace of mind.<br><br>In ClassIn, you can reach "Space" from two different locations: one is via the navigation bar on the ClassIn main interface, and the other is via the "Space" tool within the classroom's teaching tools — data in "Space" is shared and synced between both entry points. Space's main function is to give users a place to store courseware online. Within Space, users can use authorized courseware from the "Resource Center" and "Authorized Resources," and can also build custom exam papers using the "ClassIn Question Bank" and "ClassIn Exam Paper Library." Users can also directly access TeacherIn from Space. |
| Client | Refers to the ClassIn client (app). |
| 1v1 | "1v1" refers to the number of people whose camera feed is shown simultaneously in the classroom — that is, 1 teacher and 1 student. The ClassIn platform supports various on-stage headcount configurations, including 1v1, 1v2, 1v3, 1v4, 1v5, 1v6, 1v7, 1v8, 1v9, 1v10, 1v11, 1v12, 1v13, 1v14, and 1v15. |
