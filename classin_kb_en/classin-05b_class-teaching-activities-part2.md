## Answer Sheet

## I. What Is an "Answer Sheet"?

On the ClassIn platform, an "Answer Sheet" is an answering tool commonly used for exams. Compared to the complex question-entry process of a traditional "Quiz," an Answer Sheet doesn't require entering the question content — you just upload an image of the exam paper and add the corresponding answer options, which greatly reduces the effort of entering questions. Answer Sheets support multiple question types: single choice, multiple choice, true/false, fill-in-the-blank, and short answer. Both head teachers and teachers can create answer sheets, giving students a convenient way to answer.

## II. Creating an "Answer Sheet"

### Applies to
Head teachers and teachers.

### Usage Notes
After entering the class page, teachers can create an answer sheet under the course tab. There are limits on the number of attachments for the exam paper file and answer file — for example, up to 15 images, up to 15 audio recordings, and up to 15 local or cloud drive PDF/Word/audio files. Uploading from a computer supports drag and drop.

You can save the answer options you've added as an answer sheet template, and you can also select from previously saved templates.

Answer sheets support these question types: single choice, multiple choice, true/false, fill-in-the-blank, and short answer. Up to 200 questions' worth of answer options can be added. Bulk adding of questions is supported, as is adding structural notes.

On computer or tablet, teachers can have AI generate an answer sheet by analyzing an exam paper file — supported formats for AI analysis are image, PDF, and Word.

**Settings available when creating an "Answer Sheet":**

| Setting | Function |
| --- | --- |
| Time | Set the answer sheet's start and due time. |
| Time limit | Set a time limit for students to complete the answer sheet. |
| Grading | Set the answer sheet's grading scheme. |
| Publish to | Publish the answer sheet to a specific class, to some group members or specific students within a class, or to multiple classes at once. |
| Teacher | Assign the activity's teacher to receive related notifications. |
| Course | Choose which course the answer sheet belongs to. Defaults to the current course. |
| Unit Topic | Choose which unit topic the answer sheet belongs to. If not selected, it goes into the default unit. |
| Manual grading for fill-in-the-blank | Once enabled, if a student's fill-in-the-blank answer doesn't exactly match the correct answer, it's automatically routed for manual grading. |
| Allow students to see each other's content and grades | Sets whether students can view each other's content and grades — and whether this applies once the answer sheet is submitted, once it's graded, or once it has ended. |
| Publish answers and explanations | Sets whether answers and explanations are made public — and whether this applies once the answer sheet is submitted, once it's graded, or once it has ended. |
| Allow late submission after the activity ends | Once enabled, if a student didn't complete the answer sheet on time, they can submit it after the activity has ended. |
| Allow newly joined students to submit | Once enabled, students who join the class before the answer sheet activity ends can also take part in the already-published answer sheet. |
| Unlock conditions | Add prerequisite activities that must be completed. If unlock conditions are added, students must complete them before starting this answer sheet activity. |

### Notes
Creating an answer sheet is not currently supported on phone.

## III. Editing an "Answer Sheet"

For drafts and answer sheets that haven't started, "Course" cannot be changed; everything else can be edited.

For answer sheets currently in progress, question types and options cannot be added or removed; "Start Time," "Time Limit," and "Course" in the settings also cannot be changed.

For answer sheets that have ended, question types and options cannot be added or removed; the following settings also cannot be changed: time, time limit, publish to, teacher, course, manual grading for fill-in-the-blank, allow newly joined students to submit, and unlock conditions.

For drafts, in-progress, and ended answer sheets, saving as a template and editing the answer set in the options are both still supported.

Editing an answer sheet is not currently supported on phone.

1. Go to Home.
2. Enter the class.
3. Go to the course.
4. Find the answer sheet, click "···," then select Edit.

### When to use this
Teachers can share an assigned answer sheet to WeChat or other platforms even when a student hasn't logged into ClassIn or hasn't enabled ClassIn notifications, making it easier for teachers to prompt students to study on time.

Viewing a shared answer sheet outside the ClassIn app only shows things like the exam paper's structure — not the actual question content. To answer the questions, the student still needs to launch ClassIn and join the class.

## VIII. Students Using an "Answer Sheet"

**Finding the answer sheet:** find the teacher-assigned answer sheet under the course tab within the class.

**Entering the answering screen:** tap the "Start Answering" button to the right of the answer sheet, and you'll enter the answering screen. On the left is the exam paper file view, which can be collapsed or expanded; it supports switching between file pages/images, zooming in/out and resetting the image, and playing recorded audio from the bottom-left corner. On the right is the answer sheet view, showing the number of questions and total points. The remaining time to answer also appears in the bottom-left corner — important information for pacing your answers.

**Answering process:** you can now begin answering. Based on the exam paper, select the correct answer or fill in your answer for each question in the interface. Once you complete a question, the system automatically marks it as answered in the question list on the right (on tablet it appears on the left; on phone, in the top-right corner), helping you track answered and unanswered questions. You can also tap questions in the list to quickly jump to them.

**Submitting the answer sheet:** once you've finished, tap the "Submit" button in the bottom-right corner. This means you've finished answering, and the exam paper will be automatically collected.

Once a student submits an answer sheet, they can no longer edit their answers — so please double-check your answers before submitting.

For a time-limited answer sheet, the timer keeps running even if you exit partway through; once time runs out, the system automatically submits it.

1. Go to To-Dos.
2. Go to Pending.
3. Find the answer sheet, then tap Go Answer.

## IX. Grading an "Answer Sheet"

"Grading an answer sheet" refers to the process of a teacher evaluating and scoring a student's submitted answers. When grading, the teacher works through the student's answers based on the exam paper and answer key, taking into account the student's understanding, problem-solving ability, accuracy and completeness, expression, and reasoning, in order to assign an appropriate score or rating.

Once a student submits an answer sheet, the teacher can find the corresponding answer sheet under the course tab within the class page, and click the "Go Grade" button on the right. This takes the teacher into the "Pending Grading" section, where they can judge each question one by one. Single choice, multiple choice, and true/false questions are graded automatically by the system based on the answer set in the answer sheet, and the automated result cannot be edited during grading (if a particular option's answer was set incorrectly, the teacher should fix the answer sheet's answer set instead). Fill-in-the-blank and short-answer questions support manual grading, and besides right/wrong, "partially correct" is also supported. In addition, the question list on the right also supports tapping to jump directly to a question.

Once grading is complete, teachers can click "Done" or "Save & Grade Next" to finish the current student's grading, or continue on to the next student. If "Save & Grade Next" is selected, the system automatically jumps to the next student's answer sheet.

Teachers can re-grade a student's submitted answer sheet multiple times; no history of intermediate grading is kept — only the final record applies.

Use search or filters to find what you need.

1. Find the answer sheet, then click Go Grade.

## X. Viewing/Downloading "Answer Sheet" Data

## When to use this
In ClassIn, teachers can directly view or download answer sheet data, using it to analyze and evaluate student learning, and to deliver personalized teaching and targeted feedback.

When viewing answer sheet data statistics, you can view them question by question, and filter by question type. Clicking on a specific question shows the correct answer, that question's accuracy rate and the overall accuracy rate, how many students chose each option, and the percentage for each option.

When exporting a student's detailed answer sheet data from a computer, the data is saved locally as an Excel file. The spreadsheet includes, per student: class nickname, whether the answer sheet was submitted, whether the student submitted late, submission time, time spent answering, whether the answer sheet has been graded, score, accuracy rate, number of correct answers, number of incorrect answers, number of partially correct answers, number of unanswered questions, the score for each question, and the selected answer for each question. Additional information is also included: class ID, class name, answer sheet title, number of questions, full score, and grader.

Phone and tablet can only view the data statistics, not export a student's detailed answer sheet data.

View the Data Statistics, or click Export.

## Recorded Courses

## I. What Are "Recorded Courses"?

The "Recorded Course" feature lets teachers pre-record teaching videos and upload them to the "Recorded Courses" module under "Learning Activities," for students to watch anytime. This format isn't limited by where or on what device students watch, and is typically used for pre-class preview, post-class review, and asynchronous (non-real-time) course delivery.

## II. "Recorded Course" vs. "Recorded Class Playback Video" — What's the Difference?

On the ClassIn platform, "Recorded Course" and "Recorded Class Playback Video" are two different features.

"Recorded Class Playback Video" refers to when a teacher uses ClassIn's "Cloud Recording" feature during a live lesson in the classroom, automatically saving the teacher's-eye-view recording of the class as a "playback video" that can be watched afterward in the "Schedule."

"Recorded Course," by contrast, refers to teaching videos a teacher records ahead of time and uploads to the "Recorded Courses" module under "Learning Activities." These videos can be watched by students anytime, and are suited to pre-class preview, post-class review, and non-real-time course delivery. This format is not limited by where or on what device students watch.

## III. Creating a "Recorded Course"

### Applies to
Head teachers and teachers.

### Usage Notes
Supported video formats for recorded courses: mp4, 3gp, mpg, mpeg, 3g2, avi, flv, wmv, h264, m4v, mj2, mov, ogg, ogv, rm, qt, vob, webm.

Up to 15 video files can be uploaded per recorded course, each up to 2GB.

When uploading recorded course videos from a computer, you can drag and drop videos directly into the recorded course content.

**Settings available when creating a "Recorded Course":**

| Setting | Function |
| --- | --- |
| Time | Set the recorded course's start and due time. |
| AI recorded course summary | Optionally have an AI agent produce an intelligent summary of the recorded course content, including chapter summaries and a subtitle list. |
| Grading | Set the recorded course's grading scheme and points. |
| Publish to | Publish the recorded course to a specific class, to some group members or specific students within a class, or to multiple classes at once. |
| Teacher | Assign the activity's teacher to receive related notifications. |
| Course | Choose which course the recorded course belongs to. Defaults to the current course. |
| Unit Topic | Choose which unit topic the recorded course belongs to. If not selected, it goes into the default unit. |
| Allow variable playback speed | Once enabled, students can watch at a variable speed the first time they play the video. |
| Allow dragging the progress bar | Once enabled, students can drag the progress bar the first time they play the video. |
| Allowed number of views | Set the maximum number of times the recorded course video can be watched; each viewing must cover at least 75% of the video's duration to count. Once the maximum is reached, the video can no longer be watched. The maximum settable value is 20 views, or you can set it to unlimited. |
| Allow watching after the activity ends | Once enabled, students can still watch the videos in this "Recorded Course" activity after it has ended. |
| Discussion area | Once enabled, discussions can be precisely anchored to a point in the video's timeline. Once disabled, neither teachers nor students will see a discussion area. |
| Scrolling watermark and anti-recording | Once enabled, the viewer's nickname and phone number move randomly around the video area, and screen recording is blocked while watching. Mobile devices also cannot mirror to another device. This effectively protects the copyright and security of teaching resources. |
| Allow newly joined students to watch | Once enabled, students who join the class before the "Recorded Course" activity ends can also watch the videos in the already-created recorded course. |
| Unlock conditions | Add prerequisite activities that must be completed. If unlock conditions are added, students must complete them before starting this "Recorded Course" activity. |

### Notes
How long a recorded course video can be watched depends on the due date, allowed number of views, and whether watching after the activity ends is allowed, all as set by the teacher. In addition, if "a student was removed from the class by a teacher," "the class was dissolved," or "a student left the class voluntarily," whether the departed student can still view the recorded course video depends on the class setting for allowing students who left the class or whose class was dissolved to view course content.

## Check-Ins

## I. What Are "Check-Ins"?

"Check-Ins" in ClassIn are a tool for tracking completion of recurring learning tasks. Teachers often assign tasks that need to be completed repeatedly — for example, memorizing 100 English words each day. Teachers can create a check-in task in ClassIn, describe the requirements in detail, and publish it to students. After completing the task, students can log their check-in with a photo, video, or audio recording. This check-in mechanism mainly helps teachers understand how well students are mastering the material, and decide whether more focused teaching is needed in certain areas. Teachers can adjust their teaching content and methods based on check-in results, to better support student needs. Check-ins also help boost student motivation and task completion efficiency.

## II. Creating a "Check-In"

### Applies to
Head teachers and teachers.

### Usage Notes
After entering the class page, teachers can assign check-ins under the course tab. A "Check-In" task supports several types of attachments — images, voice recordings, cloud drive files, local files, and website links — to help students better understand and complete the check-in content the teacher described. File limits: up to 15 image attachments, up to 15 recording attachments, up to 15 video attachments, and the combined total of local files, cloud drive files, and links cannot exceed 15; each video or file must be under 500MB. When uploading check-in attachments from a computer, you can drag and drop images and files directly into the check-in content.

**Settings available when creating a "Check-In":**

| Setting | Function |
| --- | --- |
| Check-in period | Set the check-in's start and end time, frequency, and daily reminder time. |
| Grading | Set the check-in's grading scheme and points. |
| Publish to | Publish the check-in to a specific class, to some group members or specific students within a class, or to multiple classes at once. |
| Teacher | Assign the activity's teacher to receive related notifications. |
| Course | Choose which course the check-in belongs to. Defaults to the current course. |
| Unit Topic | Choose which unit topic the check-in belongs to. If not selected, it goes into the default unit. |
| Allow makeup check-ins | Once enabled, you can set a time limit — up to 30 days — during which students can complete a makeup check-in after missing one. |
| Allow students to see each other's content and grades | Once enabled, students can view each other's check-in content and grades. |
| Allow newly joined students to submit | Once enabled, students who join the class before the check-in activity ends can also take part in the already-assigned check-in. |

## IX. Students Submitting a "Check-In"

Once a teacher publishes a check-in, students can find and view it, and submit, from the ClassIn class or their to-dos.

On the check-in page, after a student selects the check-in date, they can see the remaining time to check in that day, or the makeup check-in deadline. After tapping "Check In Now" or "Makeup Check-In," students fill in the check-in content, which supports uploaded attachments — images, recordings, videos, files from their personal cloud drive, local files, and links. File limits: up to 15 image attachments, up to 15 recording attachments, up to 15 video attachments, and the combined total of local files, cloud drive files, and links cannot exceed 15; each video or file must be under 500MB. When uploading check-in attachments from a computer, you can drag and drop images and files directly into the check-in content.

After filling in the check-in content, students can tap Submit Check-In.

Once a student submits a check-in, if the teacher hasn't yet commented on it, the student can still edit or delete the submitted content. If the teacher requests a revision when commenting, they can mark the student's check-in as "Sent Back for Revision" — the student can then revise and resubmit; a revised check-in that hasn't yet been commented on can still be edited by the student, but can no longer be deleted.

2. Go to the check-in page.

## XI. Students Using "Check-Ins"

Applies to students.

Students can view and submit check-ins from their to-dos or within the class. Entering the check-in page shows the check-in leaderboard, a calendar, check-in details, "My Check-Ins," and check-in activity feed.

On the leaderboard, students can see their own number of check-in days and check-in rate, as well as the class's ranking by check-in rate; they can also share their ranking as an image.

On the check-in calendar, students can tap to switch between dates, viewing that day's check-in content, or completing a check-in or makeup check-in; a grey or green checkmark is shown under each date to indicate whether the check-in was completed.

Under check-in details, students can see the teacher's assigned check-in content and details like the activity's start and due time.

Under "My Check-Ins," students can see their number of check-in days, current streak, number of "Excellent Check-In" awards, and likes received; they can also see each day's check-in content, the teacher's comment, score, and likes; students can like, share (either that day's check-in or their overall check-in record), edit, or delete their own check-ins (a submitted check-in that hasn't yet been commented on can be edited or deleted; once revised, it can still be edited but not deleted before the teacher comments). Students can also check in or complete a makeup check-in directly from "My Check-Ins."

If the check-in allows students to see each other's content and grades, once a student selects a date, in addition to seeing their own check-in for that day, they can also see other classmates' check-in content, score, and likes in the activity feed, and like them.

Once the check-in ends, students can no longer edit or delete their own check-in content.

1. View the check-in Leaderboard.
2. View "My Check-Ins" — submit, complete a makeup check-in, like, share, edit, or delete your own check-ins.
3. Select a date to see classmates' check-ins with likes.

## XII. Teachers Using "Check-Ins"

After finding an in-progress or ended check-in in their to-dos or within the class, teachers can enter to review students' check-ins and comment. Entering the check-in page shows a leaderboard, calendar, check-in details, and students' check-in records.

On the leaderboard, teachers can see overall check-in progress, and each student's number of check-in days, check-in rate, and ranking; the ranking can also be shared. On computer, teachers can download students' check-in analysis data locally; on tablet, they can save it to their cloud drive or send it to a ClassIn class/friend. The data includes each student's check-in score, number of check-in days, number of makeup check-ins, longest check-in streak, likes received, and number of "Excellent Check-In" awards.

On the calendar, teachers can tap to switch between dates and see that day's check-in progress; each date shows the completion rate — if a date is fully surrounded by a green ring, all students submitted a check-in that day; a red dot under a date indicates that day's check-ins need teacher review.

Under check-in details, teachers can see the check-in content they assigned, along with the activity's start and due time.

Teachers can remind students or review and comment on check-ins under the "Not Submitted," "Pending," "Sent Back," and "Graded" tabs. For a submitted check-in, teachers can like, comment on, share (either that check-in or the student's overall check-in record), and delete the content, and can see the number of likes it has received. Clicking a student's nickname followed by their streak count takes the teacher to that student's check-in record; teachers can also access a student's check-in record by clicking their check-in rate or number of check-in days in the leaderboard. A student's check-in record shows their number of check-in days, current streak, number of "Excellent Check-In" awards, and likes received; teachers can see each submission's content, their own comment, score, and likes received, and can like, share (either that check-in or the overall record), or delete a student's check-in content.

1. Select a date to view, like, comment on, share, or delete a student's check-in.
2. View a student's check-in record.
