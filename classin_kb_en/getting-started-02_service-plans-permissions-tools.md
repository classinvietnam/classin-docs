## III. Class Member Permissions

### Head Teacher Permissions

| Role | Permission Details |
| --- | --- |
| Class management | • Chat area permissions: send messages, send files, start a temporary classroom, take screenshots, upload class files<br>• Disband class: the head teacher can disband the entire class.<br>• Edit class info: change the class name, cover image, and description<br>• Class group chat management: publish notices, pin messages, mute everyone<br>• Member management: add or remove class members, adjust member roles, edit teacher/student nicknames<br>• Class feature settings: enable/disable "Allow Open Joining," "Show Join-Class Entry Point on Share Page," "Allow Teachers to Create New Class Sessions," "Allow Class Members to Add Each Other as Friends," "Allow Students to Edit Their Class Nickname," "Allow Students to Edit the Class Board," and "Allow Course Content to Remain Viewable for Students Who've Left the Class or After the Class Is Disbanded." |
| Course module | • Unit topics: create, edit, and delete.<br>• Class sessions: create, edit, and delete.<br>• Recorded courses: create, edit, and delete.<br>• Assignments: create, edit, grade, and delete.<br>• Quizzes: create, edit, grade, and delete.<br>• Discussions: create, edit, and delete.<br>• Learning materials: create, edit, and delete.<br>• Answer sheets: create, edit, and delete.<br>• Check-ins: create, edit, and delete. |
| Classroom teaching | The head teacher can enter the classroom to teach, provided they hold at least one of the following roles: lead teacher, co-teacher, or transfer student. |
| Post-class access | • Class playback: watch the class playback video.<br>• Teaching report: view the class's teaching report. |

### Class Teacher Permissions

| Role | Permission Details |
| --- | --- |
| Within the class | Publish class notices, pin group messages, mute everyone, edit member nicknames, send messages, send files, start a temporary classroom, take screenshots, upload class files |
| Within the course module | • Create, edit, and delete class sessions (requires the head teacher to enable "Allow Teachers to Create New Class Sessions" in class management)<br>• Create, edit, and delete recorded courses<br>• Create, edit, grade, and delete assignments<br>• Create, edit, grade, and delete quizzes<br>• Create, edit, and delete discussions<br>• Create, edit, and delete learning materials<br>• Create, edit, and delete answer sheets<br>• Create, edit, and delete check-ins |
| Whether they can enter the classroom to teach | A class teacher can enter the classroom to teach, provided they hold either the lead teacher or co-teacher role. |
| Post-class access | • Watch class playback videos (only for sessions they participated in)<br>• View class teaching reports (only for sessions they participated in) |

### Class Student Permissions

| Role | Permission Details |
| --- | --- |
| Within the class | Send messages, send files, start a temporary classroom, take screenshots, upload class files |
| Whether they can enter the classroom to take class | Once a student is assigned to a class session, they can enter the corresponding classroom to take class. |
| Post-class access | • Watch class playback videos (only for sessions they personally attended)<br>• View class learning reports (only for sessions they personally attended) |
