## Admin Users

### Who this applies to
- The Admin Console primary account
- Sub-accounts with "Permission Management" access

### Overview
The Admin Console is used to manage school data such as courses, teachers, and students. The primary account holder can add admins (sub-accounts) to the Admin Console, letting them log in and granting each one a different set of permissions. Each permission controls which area of the console that admin can manage:

| Section | Area | What the admin can do |
| --- | --- | --- |
| Course Center | Class/Session Management | Create, edit, and end classes; add students to a class; create, edit, and delete sessions. |
| | Public Classes | Create, edit, delete public classes; add students to a public class. |
| Storage Management | Teacher Management | Add, edit, activate/deactivate teachers; assign resources and tags to teachers. |
| | Student Management | Add, edit, hide, show, delete students; assign resources and tags to students. |
| | Data Overview | View storage usage in the Admin Console. |
| | Org Cloud Drive | Create folders, upload courseware, copy/move courseware. Includes delete, download, and member-management sub-permissions, each independently toggleable. |
| | Question Bank | Add, edit, delete questions and papers in the org question bank. |
| | Class Resources | View storage used by each session's recordings, monitoring screenshots, and whiteboard notes; lock these to prevent accidental deletion; manually delete them. |
| | Class Group Resources | View storage used by class files, course attachments, and co-created documents; lock these to prevent accidental deletion; manually delete them. |
| | Resource Center | Add resource products and manage resource orders; view resources acquired by the primary account. |
| Teaching Management | Live/Playback | View and edit personalized settings for web live stream and playback. |
| | Teaching Data | Edit post-class evaluations; view teaching reports, learning reports, and teaching/learning analysis in class data. |
| | Assignment Management | View/download assignment data. |
| | Quiz Management | View/download quiz data. |
| Academic Management | Class Monitoring / Account Lookup | Sit in on live classes; view teacher and student attendance; view network and device status during class. |
| Finance Center | Finance Center | View billing rules, order details, invoices, and related information. |
| My School | My School | View and edit the organization's personalized configuration. |
| | Permission Management | Add more admins to the school's console, and edit or remove existing admins. |
| Client Permissions | Create Public Class / Class | Create public classes or classes directly from the ClassIn app. |

### Notes
- When editing an admin, the account/email cannot be changed — only the display name and permissions can be updated.

### Steps

**(1) Add an admin**
1. Log into the Admin Console.
2. Go to Permission Management in the left navigation.
3. Click Add Sub-account on the right.
4. Enter the sub-account's basic info.
5. Set the sub-account's permissions.
6. Click Confirm.

**(2) Edit an admin's permissions**
1. Search for the admin (top-left).
2. Click Edit next to their name.

**(3) Remove an admin**
1. Search for the admin (top-right).
2. Click Delete next to their name.

## School/Org Name & Logo

### Who this applies to
- The Admin Console primary account
- Sub-accounts with "School Settings" access

### Overview
Uploaded images support fixed-ratio cropping; the recommended image dimensions are 260×90px, under 1MB. The school name and logo set here appear on the web live/playback page and on teaching reports.

### Related articles
- "School/Org Introduction"
- "Adding Sub-accounts in the Admin Console"

### Steps
1. Log into the Admin Console.
2. Go to School Settings in the left navigation.
3. Go to General Settings at the top.
4. Under "Brand Name & Logo," click Edit.
5. Set the brand name and logo.
6. Click Confirm.

## School/Org Introduction

### Who this applies to
- The Admin Console primary account
- Sub-accounts with "School Settings" access

### Overview
The introduction supports text and images about the school, an enrollment phone number, and an enrollment link. (Images must be no wider than 690px, any height, under 800KB each — avoid uploading too many or overly large images, as it can slow page load times.) This introduction appears on the web live/playback page, the public class registration page, and learning reports.

### Related articles
- "Setting the School Name and Logo"
- "Adding Sub-accounts in the Admin Console"

### Steps
1. Log into the Admin Console.
2. Go to School Settings in the left navigation.
3. Go to General Settings at the top.
4. Under "School Introduction Settings," fill in or edit the introduction.

## Logging In / Out of the Admin Console

### Who this applies to
- The Admin Console primary account
- Admin Console sub-accounts

### When to use this
Every school using ClassIn has its own dedicated Admin Console. There, academic staff can schedule classes, adjust settings, monitor class groups and sessions, and view teaching data and billing — all of which directly affects how classes, teachers, students, and other features function in the app. To schedule classes or change settings, staff must first log into the Admin Console.

### Overview
Each school's Admin Console has one primary account with full access to all console permissions. If multiple staff members need access, the primary account can add sub-accounts and assign each one a different set of permissions, enabling multi-person collaboration.

The Admin Console supports the following display languages: English, Simplified Chinese, Korean, Vietnamese, Japanese, Arabic. Switch languages from the top-right corner of the console homepage.

If a teacher holds a sub-account or primary account at multiple schools, they can log into the console and switch to another school's console from the top-right corner.

### Related articles
- "Adding Sub-accounts in the Admin Console"

### Steps

**(1) Log into the Admin Console**
1. Open your browser.
2. Go to www.eeo.cn.
3. Click "Admin Console" in the top-right corner.
4. Log in with your ClassIn username/password, or via verification code.

**(2) Switch to another school's console**
1. From the Admin Console, use the top-right corner to switch to another school's console.

**(3) Log out of the Admin Console**
1. Click your profile picture in the top-right corner.
2. Click Log Out.

## Verification Documents

### Who this applies to
- The Admin Console primary account

### Overview
Academic staff use the "Verification Documents" page in the Admin Console to submit or update the school/organization's verification info. Required fields include: school/business name, logo, primary business category, region, detailed address, contact person's name/phone/email, and verification method. Common verification methods include business license, ID card, or passport. For example, business license verification requires a photo of the license, company name, legal representative, and unified social credit code. After submitting, the verification undergoes review.

To use ClassIn's cloud recording feature, the account's verification status must be "Verified."

### Steps
1. Log into the Admin Console.
2. Go to Verification Documents in the left navigation.
3. Click Edit to update your verification information.
4. Click Confirm to save.
