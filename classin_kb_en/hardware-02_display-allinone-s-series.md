## [Large Display All-in-One] Power/Signal Issues

# 1. No Signal After Power-On, Cannot Reach the Windows Desktop

**Symptom:** after powering on the large display all-in-one device, the screen keeps showing "Connecting Signal," "No Signal," or "NO SIGNAL," and it never reaches the Windows desktop.

**Solution:** try any of the following methods to resolve this.

**Confirm the OPS host is receiving power normally:**

Check the "POWER" indicator light on the OPS host on the back of the all-in-one device: if the "POWER" light is on, the computer is powered on and running normally; if the "POWER" light is off, click the POWER button below to power it on (as shown in the image).

**Try switching the OPS input:**

Click the power button on the right side of the all-in-one device, select the signal source, and switch it to the built-in computer.

**Restart the OPS host:**

Find the POWER button on the OPS host on the back of the all-in-one device.

Press and hold the POWER button until the OPS host fully shuts down.

Press the POWER button again to restart the OPS host.

# 2. System Shows a Blue Screen

**Symptom:** unable to enter Windows — the screen shows a blue-screen error (as shown in the image).

**Solution:** please try the following steps.

Restart the system to see if that resolves it.

Click the power button on the right side to enter the Android menu.

Tap Settings, then tap About This Device.

Select Windows System Restore.

## [Large Display All-in-One] Audio/Video Issues

# 1. No Sound from the Large Display All-in-One

**Symptom:** while using the large display all-in-one device, no sound can be heard at all.

**Solution:** try any of the following methods to resolve this.

Check whether the sound setting in the all-in-one device's Android menu has been disabled.

**Check whether Windows system volume is muted:**

Click the "arrow" icon in the bottom-right corner of the Windows desktop.

Click the "speaker" icon.

Drag left or right to adjust the system volume (as shown in the image).

**Check whether the "86 (XX) Monitor" device is disabled in Windows sound settings:**

Right-click the "speaker" icon and select "Sounds."

Go to the "Playback" tab.

If the "86 Monitor" device is disabled, right-click it and select "Enable."

Click "OK" below (as shown in the image).

If none of the above resolves it, we recommend restarting the large display all-in-one device and reinstalling the audio driver using 360 Driver Master or Driver Genius.

## [Large Display All-in-One] Display Issues

# 1. Adjusting Screen Brightness

**Symptom:** while using the large display all-in-one device, the screen brightness isn't right.

**Solution:** please follow these steps to adjust the screen brightness.

Click the all-in-one device's power button.

In the Android pop-up, manually adjust the backlight brightness.

# 2. The Screen Shows Jumpy/Rippling Touch Points

**Symptom:** while using the large display all-in-one device, the touchscreen shows jumpy or rippling touch points (as shown in the image).

**Solution:** this is caused by the display's screen bulging outward, which disrupts the touch module's signal. You can refer to the fix method below.

Try gently pressing the middle of the screen glass with your fist several times, to try to flatten the screen back out.

If possible, try slightly propping up the bottom of the all-in-one device so the screen tilts up at an angle — this may help restore normal touch function.

If the above doesn't resolve the issue, we recommend contacting ClassIn after-sales support for repair.

# 3. The Screen Shows Lines or Flickering

**Symptom:** the large display all-in-one device's screen shows lines or a flickering image (as shown in the image).

**Solution:** this issue is usually caused by a fault in the screen's OC (driver circuit) or TCON (timing control circuit) board. We recommend contacting ClassIn after-sales support for factory repair.

# 4. The All-in-One Screen Flickers

**Symptom:** after powering on, the screen flickers and cannot be used normally.

**Solution:** download 360 Driver Master, Driver Genius, or a similar tool to update your graphics driver.

# 5. The All-in-One Screen Freezes/Goes Black

**Symptom:** after powering on, the all-in-one device stays frozen on the ClassIn logo screen, or stays on a black screen and never reaches the system.

**Solution:** this issue is most likely a power board or motherboard fault — we recommend contacting ClassIn after-sales support for repair.

## [Large Display All-in-One] Cable Connection and Screen Projection Issues

# 1. Wireless Screen Projection on the Large Display All-in-One

**Symptom:** while using the large display all-in-one device, you need wireless screen projection.

**Solution:** try the following approach.

**Using Android screen projection:**

Click the power button on the large display.

An Android menu will pop up — select "Screen Projection."

Follow the on-screen prompts to connect to the Wi-Fi network and enter the password to start projecting; the password is: 88887777.

**Using the ClassIn X software to project:**

On the large display, open ClassIn X software, log into your account, then select "ClassIn Screen Projection."

On your computer, log into the ClassIn software, select "Screen Projection" on the left, choose the corresponding Wi-Fi network, and enter the projection code to start projecting.

# 2. Wired Screen Projection on the Large Display All-in-One

Please see below for the different connection methods:

Connect your laptop to the large display all-in-one device using an HDMI cable (the all-in-one device has three HDMI input ports, located on the front panel and as HDMI1/HDMI2 on the rear-left panel — any of them can be used).

Connect your laptop to the large display all-in-one device using a USB A-B touch cable (the all-in-one device has two touch ports, on the front panel and the rear-left panel as TOUCH-USB — either can be used).

If no image displays, try switching to a different HDMI port on the all-in-one device.

When connecting the large display and laptop using the wired methods above, please make sure to connect the microphone and camera to the laptop, not the large display all-in-one device.

## [Large Display All-in-One] Touch Input and Handwriting Issues

# 1. On-Screen Keyboard Doesn't Appear

**Symptom:** while using the all-in-one device, tapping the "keyboard" icon in the bottom-right corner of the system desktop doesn't bring up the on-screen keyboard, making it impossible to type using it.

**Solution:** follow these steps.

Click the "Windows" icon in the bottom-left corner of the desktop to open "Settings."

In "Settings," select "Devices."

Select "Typing," then find and enable "Show the touch keyboard when not in tablet mode and there's no keyboard attached" (if it's already enabled by default, try turning it off, back on, and restarting the computer).

# 2. Laggy Writing

**Symptom:** while recording class with ClassIn on the large display all-in-one device, using the classroom's pen tool to write on the whiteboard feels laggy.

**Solution:** try any of the following methods to resolve this.

**Adjust resolution and display scale:**

Set the all-in-one device's Windows desktop resolution to 1920x1080.

Set the display scale to 150%.

**Clear the ClassIn cache:**

Open the ClassIn main interface, click Settings in the bottom-left corner.

Go into "System Settings."

Click "Clear Cache."
