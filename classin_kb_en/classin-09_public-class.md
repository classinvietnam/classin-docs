## Creating a Public Class

### What Is a "Public Class"?
On the ClassIn platform, a "Public Class" is a quick, simple way to set up a class session. Unlike a regular class, a "Public Class" has no class group chat — creating one immediately generates a standalone class session. Students can join a "Public Class" in one of two ways: scanning the public class QR code, or entering the public class's "In" passcode. Because of this, "Public Class" is especially well suited to scenarios like parent meetings, one-off tutoring sessions, interest-group classes, and various lectures.

### Applies to
The school/institution's primary account.

Backend school/institution administrators with "Client — Create Public Class, Class" permission.

## Usage Notes
Teachers with the relevant permission can create a public class from the top of the ClassIn app's home page; the lead teacher defaults to whoever created it.

2. Click Create Public Class.
3. Configure the relevant parameters.

## Adding Students to a Public Class

### Applies to
The public class's lead teacher or co-teacher.

### Usage Notes
In a public class, teachers cannot add their ClassIn friends as public class students directly. Instead, the teacher shares the "Public Class QR Code" and "Public Class In Passcode" with the students who need to join, and students then sign up on their own to enter the public class.

### Steps

#### Computer/Tablet
1. Go to Schedule.
2. Select the date.
3. Click the public class.
4. Choose a way to add students: QR code sharing, In passcode, or email invitation.

#### Phone
1. Click Invite Students.

## Editing a Public Class

### Applies to
The public class's lead teacher.

### Usage Notes
In the ClassIn client, the public class's lead teacher can edit an already-created public class. Editable information and settings include: the public class name, class date, class start time, class duration, co-teacher(s), on-stage headcount, cloud recording, web live stream, web playback, and so on. Please follow the related rules and time limits below.

Settings that can be changed up to 20 minutes before class starts: public class name, class start time and duration, co-teacher(s), OMO livestream broadcast, on-stage headcount, cloud recording (Record ClassIn Classroom, Record On-Site), web live stream, web playback, show on-stage seats, and students auto-join on stage.

Settings that can be changed at any time before the class session ends: adding/replacing co-teacher(s), and web playback.

Settings that can be changed at any time, without time restriction: web playback.

### Notes
Before the public class officially starts (including the pre-entry window), it can be deleted at any time. However, once the public class reaches its scheduled start time, it can no longer be deleted.

A public class that has already ended cannot be deleted.

### Steps

#### Computer/Tablet
1. Go to Schedule.
2. Select the date.
3. Click the public class.
4. Click Edit.

## Deleting a Public Class

### Applies to
The public class's lead teacher.

### Usage Notes
In the ClassIn client, the public class's lead teacher can delete an already-created public class before it officially starts.

### Notes
Before the public class officially starts (including the pre-entry window), it can be deleted at any time. However, once the public class reaches its scheduled start time, it can no longer be deleted.

A deleted public class cannot be recovered — proceed with caution.

A public class that has already ended cannot be deleted.

### Steps

#### Computer/Tablet
1. Go to Schedule.
2. Select the date.
3. Click the public class.
4. Click Delete.

#### Phone
1. Click "···."
