## Default State: "Allow Members to Create Temporary Classrooms"

### Applies to
- Primary account of the Backend Management System
- Sub-accounts with the "School Settings" permission

### Usage Notes
Teaching staff can enable or disable, before creating a class, whether teachers and students in that class can create temporary classrooms by default, based on how each class is used.

### Notes
Once enabled, this only takes effect for newly created courses (classes); existing courses (classes) are unaffected.

### Related Articles
"Adding Sub-accounts in the Backend"

### Steps
1. Log in to the Backend Management System.
2. Go to School Settings in the left navigation.
3. Go to Class Settings at the top.
4. Under "Members Allowed to Enable Temporary Classrooms by Default," turn on or off the permission for teachers and students to create temporary classrooms.

## Syncing Class Nicknames

### Applies to
- Primary account of the Backend Management System
- Sub-accounts with the "School Settings" permission

### Usage Notes
Teaching staff can enable a class nickname sync feature in the Backend Management System. Once enabled, every time a student joins a class under this school, the student's name in the Backend Management System is automatically synced as their nickname in the newly joined class.

Note that this sync only happens when a student first joins a class. If the student's name is later changed in the Backend Management System, the new name will not be synced to classes they've already joined. This feature also only applies to classes at this school — if a student joins a class at a different school, their nickname will not be synced.

### Related Articles
"Adding Sub-accounts in the Backend"

### Steps
1. Log in to the Backend Management System.
2. Go to School Settings in the left navigation.
3. Go to Class Settings at the top.
4. Under "Class Nickname Sync Settings," turn on or off "Sync a newly joined student's backend name as their ClassIn class nickname."

## Allow Students Who Left the Class or Whose Class Was Dissolved to View Course Content

### Applies to
- Primary account of the Backend Management System
- Sub-accounts with the "School Settings" permission

### Usage Notes
When this feature is enabled, in situations such as "a student was removed from the class by a teacher," "the class was dissolved," or "a student left the class voluntarily," students who have left the class can still view class/lesson playbacks, whiteboard writing, recorded lesson videos, and other activity attachments.

When this feature is disabled, in the same situations, students who have left the class will no longer be able to view class/lesson playbacks, whiteboard writing, recorded lesson videos, or other activity attachments.

### Notes
Enabling or disabling "Allow Students Who Left the Class or Whose Class Was Dissolved to View Course Content" only affects the playback videos of courses (classes) created after the change; playback videos of courses (classes) created before the change are unaffected. Even if this setting is toggled again later, access permissions for students already affected by it at the time will remain unchanged.

Access to whiteboard writing, recorded lesson videos, and other activity attachments will be adjusted according to the current state of "Allow Students Who Left the Class or Whose Class Was Dissolved to View Course Content." Both new and existing courses (classes) are affected by this setting, and the state can be changed at any time.

### Related Articles
"Adding Sub-accounts in the Backend"

### Steps
1. Log in to the Backend Management System.
2. Go to School Settings in the left navigation.
3. Go to Class Settings at the top.
4. Under "Allow Students Who Left the Class or Whose Class Was Dissolved to View Course Content," turn on or off "Enable 'Students who left the class or whose class was dissolved may view course content' by default for classes."

## Default Course Cover

### Applies to
- Primary account of the Backend Management System
- Sub-accounts with the "School Settings" permission

### When to use this
Teaching staff can set a default "course (class)" cover in the Backend Management System. When a teacher at the school creates a class without a custom "course (class)" cover, the system will use the default "course (class)" cover set in the Backend Management System. The teacher can still change to a custom "course (class)" cover at any time.

### Usage Notes
Images uploaded by teaching staff support fixed-ratio cropping; the recommended image ratio is 900px x 900px, and the file size should not exceed 1MB.

### Related Articles
"Adding Sub-accounts in the Backend"

### Steps
1. Log in to the Backend Management System.
2. Go to School Settings in the left navigation.
3. Go to Basic Settings at the top.
4. Under "Default Course Cover (Default Class Avatar)," click Edit to set the default class cover.
