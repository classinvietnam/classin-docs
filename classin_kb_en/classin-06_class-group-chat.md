## Class Group Chat

## I. Sending Class Messages

### Applies to
All class members.

### When to use this
The "Chat" section within a class is an area for students to communicate, discuss, and share outside the classroom. Here, students can discuss course-related topics, academic questions, or personal interests, and share their learning experience and resources with each other. The purpose of this section is to encourage communication and collaboration among classmates, supporting their learning and personal growth.

### Usage Notes
Within a class, members can communicate in the class group chat in several ways:

**Text messages:** teachers and students type text to communicate and share ideas in the class group.

**Voice messages:** teachers and students can communicate via voice on the ClassIn phone app — a quicker, more convenient way to talk.

**Image sharing:** teachers and students can send images to the class group to show or share something.

**File sharing:** teachers and students can send local files from their computer or phone, or files from their ClassIn cloud drive, to the class group, making it easy for other class members to view and download.

**Emoji:** teachers and students can use emoji in the class group to express and convey emotion, adding warmth to the conversation.

### Notes
Sending voice messages is not supported on computer.

Users who newly join a class can see the previous chat history.

### Steps

2. Find the class in the message list and go into it.
3. Go to the class chat area on the right.
4. Below, you can send text, stickers, @mention other members, send a screenshot, send a file, send a friend's contact card, or start a temporary classroom.

## II. Recalling a Class Message

Applies to all class members.

If a user sends an incorrect message in the class group chat, they can use the message recall feature. Recalling a message means the user can, within a certain window of time, withdraw a message they've sent so it no longer appears in the class group chat. This gives users a convenient way to correct any incorrect or inappropriate content.

The "head teacher" and "teacher" in the class group chat can recall their own sent messages at any time, with no time limit.

Students in the class group chat can only recall messages they sent within the last 24 hours; after that window, they can no longer recall them.

1. Right-click a message you sent, then select Recall.

## III. Forwarding/Saving Files from the Class Group

If you want to forward a file — one you sent or one sent by someone else — from the class chat to a friend or another class, you can use the multi-select feature. In the class group chat, right-click a file, select "Multi-Select," check the items you want to forward, then click "Forward One by One." If you want to save multiple files from the class, you can also use multi-select to check the files and save them locally on your computer or to your personal cloud drive.

Only images, videos, and files can be saved locally to your computer or to your personal cloud drive.

Multi-selecting files in the chat group is not currently supported on phone or tablet.

1. Go to Messages in the left navigation.
2. Right-click the image/file you want to forward or save.
3. Select Forward or Save As.

## IV. Muting a Student in the Class

Applies to "head teachers" and "teachers."

This feature is mainly used to prevent an individual student from posting inappropriate remarks or images in the class, or from creating a temporary classroom that disrupts class order — helping keep the class running smoothly and preventing the spread of inappropriate content. Teachers can mute a student from within the class settings.

Teachers can mute a student's chat; once muted, that student can no longer send content in the class group.

1. Right-click a member.
2. Select Mute.

## V. Muting All Students in the Class

When students in a class post inappropriate remarks or unsuitable topics to the whole group, or students create temporary classrooms without permission and disrupt class order, the class teacher can enable "Mute All Students" in the class settings to prevent inappropriate content from spreading, and to maintain class order and a good learning atmosphere. This measure helps teachers maintain class discipline and protects students' right to learn.

Teachers can mute an individual student's chat, or mute all students in the class at once; once muted, students can no longer send content in the class group.

1. Click Home in the left navigation.
2. Find and enter the class.
3. Click the class name in the top-left corner.
4. In Class Settings, go to Class Management.
5. Turn "Mute All Students" on or off.

Chat history cannot be saved — only forwarded.

Multi-selecting chat history is not currently supported on phone or tablet.

1. Go to Messages.

3. Right-click a message.
4. Select Multi-Select.
5. After multi-selecting messages...

## VII. Class Temporary Classroom

A class temporary classroom can meet a variety of specific needs, including but not limited to temporary meetings, course discussions, supplementary teaching, and after-class communication.

Any member of a class (including teachers and students) can create a temporary classroom in the class chat area. Whoever creates the temporary classroom — teacher or student — takes on the role of lead teacher within that temporary classroom, while the other class members (teachers and students alike) join as students to listen in. A class temporary classroom only supports 1v6 teaching mode — one lead teacher and six students shown with camera video on stage, with other students listening in below the stage.

Both class teachers and students can start a temporary classroom. If you need to prevent students from creating temporary classrooms freely, class teachers can apply "Mute Individually" or "Mute All" to students in the class settings — muted students will not be able to send any messages in the class chat area or create a temporary classroom.

The temporary classroom does not have a "class notes" feature.

The temporary classroom's grace period for running over is 1–2 minutes; after the same person creates a temporary classroom, they must wait until the grace period ends before they can create another one.

If teaching staff want to configure the default state for whether newly created classes allow or prevent creating temporary classrooms, this can be set in the Backend Management System under "Default State: Allow Members to Create Temporary Classrooms."

## VIII. Pinning a Class Message

Teachers in a class can right-click (or press and hold, on phone or tablet) a message — their own or one sent by another class member — and pin it to the top of the class, so it's prominently visible to all class members.

1. Right-click a message you or someone else sent, then select Pin (click the "x" to the right of a pinned message to unpin it).

## IX. Hiding a Student's Message

"Head teachers" and "teachers" can hide messages sent by students.

"Head teachers" can hide messages sent by teachers.

When a student posts an inappropriate remark or image in the class, the class's "head teacher" or "teacher" can hide that student's message to help maintain class order. A hidden message cannot be recovered, and other class members will no longer be able to see its content.

1. Right-click a message sent by a student, then select Hide.
