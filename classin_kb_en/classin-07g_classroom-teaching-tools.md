## Teaching Tools

## I. Click Tool

### What is the Click Tool?
The "Click Tool," also called cursor mode, is one of the commonly used tools in the classroom toolset. Teachers can use it to trigger animation effects in PPT courseware, play embedded audio and video in PPT courseware, and click through content on a webpage in the browser. It's also used to operate equipment in the virtual "Chemistry Lab" and "Physics Lab." When a teacher uses the "Student Screen Share" tool, the Click Tool can also control file operations on the student's desktop. Using the Click Tool lets teachers teach more flexibly and efficiently, improving teaching outcomes.

### Applies to
Lead teacher, co-teacher, authorized students.

## II. Select/Move

### What is the Select/Move Tool?
The "Select/Move" tool is one of the commonly used tools in the classroom toolset. Users can use it to single-select, multi-select, and move various whiteboard elements — images, shapes, text, and so on. Once you select an element on the whiteboard, a "secondary editing" bar pops up below it. Users can use the shortcuts in this bar to modify and adjust the selected element(s).

### Usage Notes
With the "Select/Move" tool, you can single-select or multi-select images, text, shapes, and other elements in the classroom, and further edit these elements once selected. "Box-select mode" lets you draw a rectangle on the whiteboard, selecting every element inside it. "Free-select mode" lets you draw a freeform lasso, selecting every element it encloses.

To use the "secondary editing" feature of the "Select/Move" tool, first click an element on the whiteboard; a row of functions for further editing the selected element appears below it. Users can use these functions to further modify and edit the currently selected element.

When multiple whiteboard elements are selected at once, you can change the color of all of them at the same time.

**(1) Secondary edits supported for image elements:**

| Function | Description |
| --- | --- |
| Cutout | Uses the secondary editing cutout feature to separate the subject in an image from the original background, making the background transparent. |
| Lock image position | Fixes an image at a specific spot on the whiteboard, preventing it from being accidentally dragged or deleted. The image must be unlocked before it can be moved, edited, or deleted. |
| Resize image | Changes the image's size on the whiteboard. |
| Change image layer | Adjusts the image's display layer on the whiteboard. When multiple images, shapes, or text overlap in the same spot, the one on a higher layer displays in front, unobstructed by other elements. |
| Duplicate image | Creates multiple copies of the image on the whiteboard. |
| Delete image | Removes the image from the whiteboard. |

**(2) Secondary edits supported for shape elements:**

| Function | Description |
| --- | --- |
| Change shape border color | Changes a shape's border color, making it stand out and stay distinguishable from other elements. |
| Add or change shape fill color | Adds a fill color to a shape on the whiteboard that doesn't have one, or changes the fill color of a shape that already does. |
| Lock shape position | Fixes a shape at a specific spot on the whiteboard, preventing it from being accidentally dragged or deleted. The shape must be unlocked before it can be moved, edited, or deleted. |
| Resize shape | Changes the shape's size on the whiteboard. |
| Change shape layer | Adjusts the shape's display layer on the whiteboard; a shape on a higher layer displays in front, unobstructed by other elements. |
| Duplicate shape | Creates multiple copies of the shape on the whiteboard. |
| Delete shape | Removes the shape from the whiteboard. |

**(3) Secondary edits supported for text elements:**

| Function | Description |
| --- | --- |
| Change text size | Changes the font size of text on the whiteboard. |
| Change text color | Changes the color of text already entered on the whiteboard. |
| Lock text position | Fixes text at a specific spot on the whiteboard, preventing it from being accidentally dragged or deleted. The text must be unlocked before it can be moved, edited, or deleted. |
| Change text layer | Adjusts the text's display layer on the whiteboard. When multiple images, shapes, or text overlap in the same spot, the text on a higher layer displays in front, unobstructed by other elements. |
| Duplicate text | Creates multiple copies of the text on the whiteboard. |
| Delete text | Removes the text from the whiteboard. |

"Free-select" mode is not currently supported on phone or tablet.

## III. Pen

### When to use this
The Pen tool is one of the classroom's commonly used teaching tools, packed with features that let users mark up, write, and draw on the whiteboard, courseware, and images. It supports drawing several shapes — circles, ellipses, squares, rectangles, irregular triangles, equilateral triangles, straight lines, and curves — as well as writing text.

Users can choose either the regular pen or a highlighter pen. The regular pen behaves like chalk, while the highlighter pen is semi-transparent, suited to highlighting key points on text, courseware, or images. Users can also choose between solid and dashed line styles.

The Pen tool also lets users freely adjust pen color and thickness, to meet different drawing and annotation needs. For users, the Pen tool substantially improves teaching interaction and classroom outcomes.

When a user selects "curve" mode and draws an irregular shape on the whiteboard (like a circle, square, straight/vertical line, or triangle), the system automatically performs shape recognition about 1.5 seconds after the user stops drawing. If recognition succeeds, the system converts the user's irregular shape into a regular one.

**(1) Pen modes and shortcuts:**

**Curve mode:** hold Shift to draw a straight line.

**Line mode:** hold Shift to draw a horizontal straight line.

**Square mode:** hold Shift to draw a perfect square.

**Circle mode:**
- Hold Shift to draw a perfect circle.
- Hold Ctrl to draw a circle centered on the point where you started drawing.
- Hold Shift+Ctrl to draw a perfect circle centered on the point where you started drawing.

**Shortcuts:**

Hold Alt and press "1," "2," "3," or "4" on the number pad to switch the pen to "curve," "line," "circle," or "square" mode, respectively.

Hold Alt and press "q," "w," "e," "r," "a," "s," "d," "f," "z," "x," "c," or "v" on the keyboard to change the pen color.

Hold Ctrl and press Z to undo the last drawing action.

Note: shortcuts and settings may vary across different software and operating systems. The above describes the general case — actual behavior may vary depending on your specific software and OS. (The "Ctrl" key on Windows corresponds to "Command" on Mac; "Alt" on Windows corresponds to "Option" on Mac.)

In highlighter pen mode, the pen defaults to a solid line and cannot be switched to dashed. The pen shape defaults to curve and cannot be selected or changed.

Shapes already drawn on the whiteboard cannot have their color changed using shortcuts — only via the secondary editing feature.

A shape that has been auto-converted into a regular shape cannot be undone with Ctrl+Z.

When a teacher or student draws or writes using the Pen tool in the classroom, everyone in the classroom can watch the drawing and writing happen in real time.

## IV. Eraser

The eraser is one of the classroom's commonly used teaching tools. Users can use the eraser to erase content drawn or written with the Pen tool on the whiteboard, and it also includes a "one-click clear" feature — if you encounter whiteboard elements that can't be erased normally, use "one-click clear" to wipe the entire whiteboard clean.

The eraser cannot erase text entered with the "Text" tool.

The eraser cannot erase locked shape elements.

Students' eraser tool doesn't have the "one-click clear" feature.

Using "one-click clear" cannot be undone.

If a user accidentally deletes whiteboard content while teaching, they can try pressing Ctrl+Z on the keyboard to undo the last deletion.

The eraser cannot erase straight lines drawn using the Pen tool's "line" mode. To delete a straight line, first select it with the "Select/Move" tool, then delete it.

## VIII. Cloud Drive

"Cloud Drive" is available both on the ClassIn main interface and inside the classroom, and data between the two is fully synchronized. It's one of the classroom's commonly used tools — teachers and students can upload various local courseware resources (audio, video, documents, etc.) to Cloud Drive for safe, reliable storage, ready to be flexibly recalled during class. In the classroom, users can quickly find and display courseware they've uploaded via "My Cloud Drive → Documents." Public courseware the school has authorized for a lead teacher can be found and used under "Authorized Resources," and related textbooks a teacher obtained from the Resource Center will also appear under "Authorized Resources."

The classroom only shows organization cloud drive files belonging to the current class session's school.

**Personal courseware:** open the cloud drive, go to My Cloud Drive, and open locally uploaded courseware.

**School/institution-authorized courseware:** open the cloud drive, go to Organization Cloud Drive, go to School Materials, and open the authorized courseware.

**Organization courseware:** open the cloud drive, go to Organization Cloud Drive, and open organization courseware.

**Resource Center courseware:** open the cloud drive, go to Resource Center, go to My Resources, and open courseware obtained from the Resource Center.

## IX. LMS

## Applies to
## When to use this
The classroom's Learning Management System (LMS) is one of its commonly used tools. Through LMS, teachers can assign in-class assignments, quizzes, and answer sheets, and promptly grade what students submit. In addition, assignment, quiz, and answer sheet data within the classroom syncs seamlessly with data outside the class, improving teaching management convenience. Teachers can also use LMS to assign after-class homework, grading it on the fly during teaching and providing real-time feedback. This significantly improves teaching efficiency and the student learning experience.

## Notes
iPhone, Android phone, and Android tablet do not have the classroom LMS feature.

## X. Class Notes

Everyone.

Class Notes is one of the classroom's commonly used tools. Its main function is to record important notes and highlight moments during class via screenshots, supporting the saving of annotations and analysis on classroom courseware (PDF, PPT, Word, etc.), and letting you further edit saved images and add text captions, to more clearly express and record key knowledge points. Class Notes also lets you download note images locally to save and share.

Notes must be at least 10 seconds apart from each other.

Phone and tablet do not have the "Class Notes" feature.

Each user can record up to 100 notes at a time.

## XI. Chat Tool

The Chat tool is one of the classroom's commonly used teaching tools. It includes two main modules: the Chat module and the Questions module. In the Chat module, teachers and students can freely type messages, and either side can recall a message they've sent; translating the other person's message is also supported. Teachers additionally have permissions to mute a student's chat, or delete a message a student has already sent. In the Questions module, students can ask the teacher questions, and the teacher can view students' questions and respond accordingly.

Once you exit the classroom after class ends, the chat records in the classroom's chat box are cleared and cannot be saved.

## XII. Roster

#### Class Students Section
**Go on stage/off stage:** the teacher controls whether a student shows their camera on stage, or sends them off stage so they listen to the lesson without showing their camera.

**Authorize:** grants a student permission to use teaching tools, or revokes that permission.

**Mute:** prevents a student from typing messages in the chat window.

**Microphone:** mutes or unmutes a student's microphone.

**Camera:** view a student's camera status.

**Reward:** give a student a trophy.

**Raise hand:** view a student's raised-hand status.

**Private chat:** the teacher and student enter a 1v1 camera private-chat classroom.

**Remove:** removes a student from the classroom.

**View other devices:** view what type of device a student is using for class.

**Rotation:** rotate through displaying different students' cameras.

#### Co-Teacher Section
**Co-teacher go on stage/off stage:** the lead teacher invites the co-teacher to show their camera on stage, or sends them off stage so their camera no longer shows (the co-teacher can also control their own on-stage status).
