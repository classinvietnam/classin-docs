## Cross-Class Linked Lessons Usage Guide (Dual-Teacher Class)

# I. What Is a Dual-Teacher Class?

A dual-teacher class is an innovative teaching model that uses the ClassIn platform to bring students from different classes together to learn as one. This approach breaks past the boundaries of a traditional single class, significantly improving both teaching and learning efficiency and outcomes. By removing spatial limits, dual-teacher classes let an outstanding teacher's lesson be replicated without limit, letting more students benefit from top-quality educational resources.

# II. Applicable Scenarios

**Teaching Management:** an outstanding teacher can livestream a lesson to multiple small classes at once, dramatically extending that teacher's reach while preserving high-quality teaching content in one place.

**Learning Outcomes:** each small class's teaching assistant can interact with students within their own class, and can also grade assignments and distribute materials before and after class, enabling personalized management.

**Service Operations:** meets parents' need to closely monitor classroom attendance and student learning behavior — the teaching system continuously records performance data and progress for every student.

**Enrollment and Renewals:** delivers the pricing and scale of a large class with the experience and outcomes of a small class, helping institutions establish a differentiated advantage, build their reputation, and multiply their revenue.

# III. Usage Notes

**Dual-teacher classroom:** made up of one main classroom and multiple sub-classrooms. Each main classroom can link up to 100 sub-classrooms.

**Video and audio:** during teaching, the video and audio of the "lead teacher" and any "student brought into a live call" in the main classroom are transmitted to every classroom. Beyond that, students and teaching assistants in a sub-classroom cannot see or hear the video/audio of anyone else in the main classroom (including its teaching assistants), and cannot see or hear the video/audio of students and teaching assistants in other sub-classrooms. Likewise, the lead teacher, teaching assistant, and students in the main classroom cannot see or hear the video/audio of students and teaching assistants in other sub-classrooms.

**Text chat:** in the main classroom, every teacher and student can use the chat tool to see text messages sent by teaching assistants or students in every sub-classroom. In a sub-classroom, however, teaching assistants and students can only see text messages sent by members of their own classroom, plus text messages from the main classroom's "lead teacher" — they cannot see messages from other sub-classrooms, nor messages sent by anyone else in the main classroom besides the "lead teacher" (including its teaching assistants).

**One-Click Reset:** before class starts, students in a sub-classroom may have been granted permission to write and draw on the whiteboard. To keep content consistent between the main classroom and sub-classrooms, once the "lead teacher" enters the main classroom, they can use the "One-Click Reset" feature before starting the lesson. To do this: click the four-dot icon in the top-right corner and select "Reset." This performs the following: clears the whiteboard content in every classroom, closes all courseware and tools, sends every teaching assistant and student in every classroom off stage, clears every student's authorization status, and resets trophy counts and each student's on-stage count. This ensures every classroom starts from the same state, supporting a smooth start to the lesson.

**Teaching tools available in the main classroom:** Cursor Mode, Select/Move tool, Pen, Eraser, Text Entry, Screenshot, Laser Pointer, Cloud Drive, Class Notes, Chat tool, Roster, Open Local File, Save/Share Whiteboard, Projection tools, Screen Share, Dice, Timer, Countdown Timer, Browser, Physics/Chemistry Lab, Trophy Leaderboard (only shows the main classroom's leaderboard), Teaching Materials Library, Auxiliary Camera, Drag-and-Point Laser Pointer, Ruler & Compass Tools, Geometric Shapes, Dual-Teacher Answer Clicker, Live Call, and Two-Device Single Account (PC/iPad only — using PC as the primary device is recommended).

**Tools and features disabled in the main classroom:** LMS, Small Blackboard, Group Discussion, VNC, Livestream Chat, Random Student Picker, Buzzer, Video Wall (including viewing only the main classroom's students or viewing every sub-classroom's students), Student Screen Share, Text Collaboration, and Multi-Directional Browser.

Before officially starting the class, we recommend running a complete rehearsal covering every step — scheduling, lesson prep, teaching, maintaining classroom order, recording, and post-class student review. Only start the class officially once every step has been confirmed to work correctly.

# IV. Must-Read for Academic Staff

## 1. Activating the Dual-Teacher Class Service

To activate the dual-teacher class service, please contact your dedicated account manager.

## 2. Creating a Class Session in the Backend

Note: a dual-teacher class doesn't need a separate class group — you can use an existing class for teaching. If you do need to create a new class, just follow the standard class-creation process.

### 2.1 Creating the Main Class Session

In the main class, select a specific class session (note: not the entire class group) to serve as the basis for the main classroom, then create its sub-sessions. If no class session has been added to the class group yet, refer to the image below to create one. (Path: log into the backend → Class Management → go into the class → Add Class Session.)

### 2.2 Adding Sub-Sessions

Go into the class group, check an already-created class session to designate it as the main session, then click "Bulk-Create Sub-Sessions." While adding sub-sessions, you'll need to specify which class group each sub-session belongs to. Refer to the image below to create them. (When choosing the class group, you can search by class name or by tag in the search bar above for faster results.)

Notes:

**(1)** Each main class session can have up to 100 sub-sessions created for it (up to 50 at a time — if you need more than 50, you'll need to run the process twice).

**(2)** You cannot create sub-sessions if the main class session's start time is less than 5 minutes away, or has already passed.

**(3)** You can add a co-teacher to all sub-sessions in bulk, or add a co-teacher individually to each sub-session. (Adding a co-teacher is optional, not required. If you add one by mistake, you can use the "Remove All" feature to remove them.)

**(4)** If a co-teacher needs to monitor chat activity across multiple classes at once during the lesson, you can assign that co-teacher to both the main session and multiple sub-sessions, letting them view the overall chat area from within the main classroom.

**(5)** Once created, any non-shared details of a sub-session can be edited within the corresponding class.

**(6)** For recording, you can choose either "Use the Main Session's Class Recording" or "Cloud Recording (each sub-session recorded separately)." Note: if you choose to have sub-sessions record separately in the cloud, each recording sub-classroom needs a teaching assistant present the whole time to handle the recording.

### 2.3 Editing and Deleting

Both the ClassIn app (client) and the backend interface let you edit and delete the main class session, and the related content in sub-sessions will automatically update to match. (Edit the session in the software) (Edit the main session in the Backend Management System.)

The ClassIn app (client) doesn't let you directly edit or delete a sub-session — you can only do this in the backend. You can go into the class corresponding to the sub-session to edit or delete it through the standard process, or click the "Actions" button on the far right of the main session, select "Online Dual-Teacher," and then delete it from there.

## 3. Downloading Post-Class Support Materials

**(1)** Screenshots the teacher takes with the main classroom's answer clicker tool can serve as a starting point for a teaching assistant's follow-up conversations. These screenshots are stored in the backend under Class Management → Class Data (Main Session) → Teaching Analysis → Answer Clicker Data.

**(2)** Click to view images to see every answer-clicker screenshot from that session; clicking "Download Images" in the top-right corner lets you download all images in a bundle, making it easier for post-class support teachers to communicate with students/parents.

**(3)** For institutions where teaching assistants don't have backend access, an academic teacher will need to download these on their behalf.

**(4)** Post-class support teachers can use these answer-clicker screenshots and student response data to provide personalized tutoring.

# V. Must-Read for Teachers

## 1. Lead Teacher Devices

Lead teachers can only teach using a computer or iPad (we recommend prioritizing a computer, since it offers more complete functionality) — phone and Android tablet are not supported for teaching.

## 2. Key Classroom Tools

**Live Call**

Live Call is an important channel for the lead teacher to communicate with students.

**(1)** In a dual-teacher class's main classroom, the lead teacher can bring a specific student into a live call by either "opening the teaching tool for live call" or "right-clicking a chat message" (only one person can be in a live call at a time); once a student is brought into a call, their audio/video syncs to the main class and every sub-class.

**(2)** Once the live call ends, you can hover over the video window and select "End Live Call," or "Open Live Call List" to choose another student for a call.

**(3)** The live call video window supports free resizing and repositioning; its resolution matches the resolution of the student on-stage seats, and its display logic is independent of the on-stage seats — meaning a single student can appear both in the live call window and in the on-stage seats at the same time.

**(4)** Both the lead teacher's computer and iPad support the live call feature.

**Chat**

The chat area is an important channel for the lead teacher to communicate with students in sub-classrooms (features like authorizing sub-classroom students or awarding trophies are not supported here).

**(1)** When a sub-classroom student speaks, their class name appears before their name.

**(2)** The main classroom's chat tool lets you choose to view "chat from every classroom" or "chat from one specific sub-classroom" at the top.

**(3)** The chat area in both the main classroom and sub-classrooms doesn't support the "Questions" feature. If a student has a question, they can ask it in the "Chat" window instead.

**(6)** Note: the chat area blocks part of the courseware in the playback recording; sub-classroom students watching the class playback will also see chat content from other, unrelated classes. Teachers can manually click the "Move Chat Window Outside the Classroom" button before recording so the chat area isn't recorded.

**Dual-Teacher Answer Clicker**

The answer clicker is the lead teacher's main way of gathering data on student understanding.

**(1)** Sending an answer clicker in a dual-teacher classroom works the same way as a regular answer clicker.

**(2)** While students are answering, the teacher can see the overall correct-answer rate and how many students chose each option, across every class.

**(3)** You can filter by class above the answer clicker to view a specific class's answers.

**(4)** Once answering ends, you can award trophies to students who answered correctly, or to everyone who participated. This is the only way for the lead teacher to award trophies to sub-classroom students.

**(5)** At any point during answering, the teacher can use the answer clicker's built-in screenshot tool (typically used after explaining a question, to capture the problem-solving approach) — this screenshot is saved in the backend as material for the teaching assistant's later follow-up.

**(6)** Once answering ends, sub-classroom students can only see their own class's answer details. (If academic staff have set "sub-classrooms use the main classroom's class recording," sub-classroom students will be able to see every class's answer data in the playback.)

**One-Click Reset**

Before class starts, sub-classroom students may in some cases have been authorized to write and draw on the whiteboard, and so on. To keep the main classroom and sub-classrooms consistent, once the lead teacher enters the classroom, they can use the classroom reset feature before starting the lesson (top-right four-dot icon → Reset):

Clears the whiteboard content in every classroom

Closes all courseware and tools

Sends every teaching assistant and student in every classroom off stage

Clears every student's authorization status, trophy count, and on-stage count

**Ending Class**

**(1)** A sub-classroom's co-teacher does not have the "End Class for Everyone" feature.

**(2)** Once the main classroom uses "End Class for Everyone," every sub-classroom ends class together with the main classroom.

# VI. Must-Read for Teaching Assistants

## 1. Basic Teaching Assistant Responsibilities

During class:

1. On the backend's Classroom Monitoring page, check for absent students and reach out to them.

2. Maintain classroom order — if inappropriate content appears in a classroom's chat area, address it or delete it promptly within that sub-classroom.

3. Use the sub-classroom Video Wall to check students' learning status in real time and give reminders as needed.

4. Help resolve any software issues students run into.

5. Provide supplementary guidance for their own class, in addition to what the lead teacher covers.

Prohibited actions:

1. A co-teacher in the main classroom should not casually operate the courseware or whiteboard, since those changes won't sync to sub-classrooms (this will be improved in a future version).

2. A co-teacher in a sub-classroom should not operate the same feature (whiteboard, courseware, teaching tools) at the same time as the lead teacher, since this could cause the main classroom and sub-classrooms to become out of sync.

After class:

1. Grade assignments, quizzes, and other pre/post-class activities.

2. Communicate with families, using materials such as the teacher's answer-clicker screenshots from class to provide thorough, personalized analysis of student progress and tutoring.

## 2. Using the Chat Area

When scheduling, the academic teacher schedules the teaching assistant (co-teacher) into both the main class session and every sub-session they're responsible for.

By default, a co-teacher watches student messages in the main classroom's chat area; if they notice something unusual (for example, an inappropriate comment or question from a student), the co-teacher can use the student's class information to go into that sub-classroom, open the chat area, and handle it — deleting the message, muting the student, or replying directly.

Currently, a teaching assistant cannot handle issues directly from within the main classroom — this will be supported in the future.

Students in a sub-classroom can only see chat content from their own class, plus chat messages the lead teacher posts in the main classroom.

## 3. Post-Class Communication Materials

Besides regular communication content like assignments and quizzes, screenshots the lead teacher takes with the main classroom's answer clicker can also serve as a starting point for a teaching assistant's follow-up. These screenshots are stored in the backend under Course Management → Class Data → Answer Clicker Data.

Click to view images to download all of that session's answer-clicker screenshots as a bundle.

Teaching assistants without backend access can ask an academic teacher to download these on their behalf.
