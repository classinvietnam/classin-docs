## Clear Cache

### Applies to
Everyone

### When to use this
While using ClassIn, you may sometimes run into the following issues:
- The Homework or Quiz page appears blank, with no content shown.
- After opening courseware in the classroom, the page shows as all-black or all-white, and the original content does not display.
- After opening the Cloud Drive tool in the classroom, it stays stuck on "Loading" and the courseware in Cloud Drive won't display.

For any of the above situations, try using the "Clear Cache" feature in the app settings to resolve the issue.

### Steps

**Computer**
1. Click your profile picture in the bottom-left corner.
2. Go to File Transfer.
3. Click Clear Cache.

**Phone**
1. Tap Home in the bottom navigation.
2. Tap your profile picture in the top-left corner.
3. Go to App Settings.

**Tablet**
1. Tap your profile picture in the bottom-left corner.

## Repair Registry

### Applies to
Everyone

### When to use this
When a teacher uses the classroom-monitoring feature in the Admin Console and the browser fails to launch the ClassIn app, try using the "Repair Registry" feature in ClassIn settings to resolve this.

### Steps

**Computer (Windows)**
1. Click your profile picture in the bottom-left corner.
2. Go to System Settings.
3. Find Registry Repair and click Repair on the right.

## Eyecare Mode

### Applies to
Everyone

### When to use this
To reduce the harm blue light can cause to your eyes while using ClassIn, you can enable "Eyecare Mode" in ClassIn settings. When enabled, the screen shifts to a softer yellow tone, reducing blue-light strain and easing eye fatigue and dryness. Turning it off restores the screen to its normal color temperature.

### Notes
- On computer, Eyecare Mode affects the entire screen; quitting the ClassIn app restores normal color temperature.
- On phone or tablet, Eyecare Mode only affects the ClassIn screens.

### Steps

**Computer**
1. Click your profile picture in the bottom-left corner.

3. Turn Eyecare on or off.

**Phone**

2. Tap your profile picture in the top-left corner.

## Device Check (Audio/Video)

### When to use this
"Device Check" helps you fully check your computer's audio/video devices before class in ClassIn, so you can spot device issues or misconfigurations in time and make sure your microphone, speaker, and camera all work properly during class.

### How it works
On the Device Check page, complete four steps to make sure your devices work properly during class and avoid device issues affecting the classroom experience:
- **System check**: quickly see your OS, CPU model, network latency, and packet loss rate.
- **Camera check**: verify the camera works. If no image shows, switch cameras on this page or use the built-in repair assistant to fix the camera driver.
- **Speaker check**: confirm the speaker works. After clicking Play, you should hear a sound and check off the sound type you heard. If there's no sound, switch speakers on this page or use the repair assistant to fix the audio driver.
- **Microphone check**: confirm the microphone works. After clicking Record, the waveform bar should move as you speak. If it doesn't move, switch microphones on this page or use the repair assistant to fix the audio driver.

### Notes
- Device Check is not available on phones or tablets.

### Steps

**Computer**
1. Click your profile picture in the bottom-left corner.
2. Go to Device Check.
3. Click the feature you want to check on the right — system, network status, microphone, camera, or speaker.

## Teen Mode

### I. Turning on Teen Mode

**Applies to**: Students

**When to use this**: Teen Mode is a ClassIn safeguard designed to give students a safer learning environment and let parents effectively monitor their child's online activity. After enabling Teen Mode, you'll set a password; entering that password lets you later modify or turn off Teen Mode. Once enabled, you can turn the following restrictions on or off:

- **Disallow creating classes** — students can't create new classes, keeping the learning environment orderly.
- **Disallow creating public classes** — students can't create public classes, keeping the learning environment orderly.
- **Disallow adding friends** — students can't proactively add anyone as a friend, including classmates; others can still add a student with Teen Mode enabled as a friend.
- **Disallow opening the browser** — students can't access inappropriate websites, protecting their online safety.
- **Disallow signing out** — tapping Sign Out in ClassIn won't work.
- **Disallow proactively joining classes** — students can't join a class by searching for a class code or In-code.

**Steps**

Computer: Profile picture (bottom-left) → System Settings → scroll down to Teen Mode → Turn on Teen Mode → enter a password → Next → toggle the permissions you want.

Phone: Home tab → profile picture (top-left) → App Settings → Teen Mode → Turn on Teen Mode → set a password → Turn on Teen Mode.

Tablet: profile picture (bottom-left) → enter a password → Turn on Teen Mode.

### II. Editing or Turning Off Teen Mode

Once Teen Mode is on, if a student needs a restricted feature, enter Teen Mode with the password to change the relevant setting; you can also turn Teen Mode off entirely from the same screen.

### III. Forgot Password — Teen Mode

If you forget the Teen Mode password, go to Teen Mode and tap "Forgot Password," then follow the emailed instructions to reset it.

### IV. Change Password — Teen Mode

In Teen Mode, tap "Change Password" to update it. Enter the old password, then enter the new password twice to confirm.
