## Class Sessions

## I. What Is a "Class Session"?

On the ClassIn platform, a "class session" is the dedicated place where a teacher delivers knowledge to students — also called a lesson or live classroom. In a class session, the teacher carries out teaching activities through explanation, demonstration, and questioning, aiming to promote student learning and development. How the classroom environment is designed and organized is critical to improving teaching outcomes and student engagement. Common features within a class session include on-stage seats, the blackboard, and various teaching tools, ensuring the teaching process runs smoothly.

## II. Creating a "Class Session"

### Applies to
Head teachers.

Class teachers, once "Allow Teachers to Create Class Sessions" is enabled.

### Usage Notes
When creating a class session within a class, the following can be configured:

| Setting | Function |
| --- | --- |
| Class session name | Give the class session a clear name so students and teachers can easily identify it. |
| Start time and duration | Set the class session's start time and duration. The earliest the start time can be set is the current time; the duration can be set to as short as 15 minutes and as long as 23 hours 55 minutes. |
| Publish to | The "class session" can be published to a specific class, to some group members or specific students within a class. |
| Lead teacher | The creator is the lead teacher by default; the head teacher can assign other class teacher members as the lead teacher. Only one lead teacher can be set per class session. |
| Co-teacher(s) | Teachers in the class can be selected as co-teachers. Up to 6 co-teachers can be added per class session. When one co-teacher goes on stage to show their camera, it doesn't take up a lead-teacher or student seat, but when multiple co-teachers go on stage, they do take up student seats. |
| Select course | Choose which course the "class session" belongs to. Defaults to the current course. |
| Unit topic | Choose which unit topic the "class session" belongs to. If not selected, it goes into the default unit. |
| OMO livestream broadcast | Lets students watch the teacher's livestream broadcast feed, which students can choose to view; suited to blended in-person/online teaching scenarios. This feature must be enabled in the Backend Management System before it can be selected. |
| On-stage headcount | The number of people that can appear on the on-stage seats at the top of the classroom at the same time. Minimum: 1 lead teacher and 0 students; maximum: 1 lead teacher and 12 students. |
| Record ClassIn Classroom | Cloud recording is split into "Record ClassIn Classroom" and "Record On-Site." Record ClassIn Classroom captures the entire class session view. |
| Record On-Site | Cloud recording is split into "Record ClassIn Classroom" and "Record On-Site." Record On-Site only captures the selected teacher's camera feed, showing the full teaching scene. |
| Web live stream and playback permission | With cloud recording checked, you can set the class session's web live stream and playback permission, determining whether users outside the class can watch the live stream and playback via the web. |
| AI class session summary | With cloud recording checked, you can choose to have an AI agent generate an intelligent summary of the class session playback content, including chapter summaries and a subtitle list. |
| Show on-stage seats | Once enabled, it makes it easier for teachers and students to interact online, communicate, and answer questions at any time. Once disabled, class sessions focus on blackboard-based teaching; teachers can also adjust this again from within the classroom. |
| Students auto-join on stage | With "Show on-stage seats" enabled, you can set whether students automatically show their camera on stage when entering the classroom. |
| Allow students to see each other's learning reports | Once enabled, students can view other classmates' learning reports. |

### Notes
When creating a class session within a class, the teacher can choose the on-stage headcount. The system defaults to the option used the last time a class session was created on the current device. If you switch devices, the system won't remember your previous choice, and you'll need to set it again.

If you're unable to add a lesson or course, it may be because the number of lessons under the current course has reached its limit.

Regardless of the class session's scheduled duration, formal classrooms have a 20-minute grace period for running over, while temporary classrooms have a 2-minute grace period.

If the "head teacher" is also the "lead teacher," there's no need to separately set the lead teacher when creating the class session, since the lead teacher defaults to the head teacher when creating a class session on the client.

If "a student was removed from the class by a teacher," "the class was dissolved," or "a student left the class voluntarily," whether the departed student can still view recorded class playback videos in ClassIn depends on the class setting for allowing students who left the class or whose class was dissolved to view course content.

## III. Editing a "Class Session"

Lead teachers with the permission to create class sessions.

In the ClassIn client, the head teacher can edit any class session already created, while a teacher with the permission to create class sessions can only edit class sessions where they are the lead teacher.

Editable information and settings include: class session name, class date, class start time, class session duration, lead teacher, co-teacher(s), on-stage headcount, cloud recording, web live stream, and web playback. Please follow the related rules and time limits below.

Settings that can be changed up to 20 minutes before class starts: class session name, class date, class start time, class session duration, published class/members, OMO livestream broadcast, on-stage headcount, cloud recording (Record ClassIn Classroom, Record On-Site), web live stream, web playback, show on-stage seats, and students auto-join on stage.

Settings that can be changed at any time before the class session ends: changing the lead teacher, adding/replacing co-teacher(s), and web playback.

Settings that can be changed at any time, without time restriction: AI class session summary, web playback, unit topic, and allow students to see each other's learning reports.

Before the class session officially starts (including the pre-entry window), the class session can be deleted at any time. However, once the class session reaches its scheduled start time, it can no longer be deleted.

Class sessions that have ended cannot be deleted.

1. Go to Home.
2. Enter the class.
3. Go to a created course.
4. Find the class session, click "···," then select Edit.

## IX. Watching "Recorded Class Playback Videos" in the Class

### What is a playback video?
A "playback video" refers to when a class session was created in the class with "Record ClassIn Classroom" or "Record On-Site" checked (i.e. cloud recording), and the lead teacher entered the formal classroom to teach and record the entire class session. These videos are automatically turned into "playback videos" about 30 minutes after the class ends.

### What's the difference between "recorded class playback videos" and "recorded courses"?
"Recorded class playback video" refers to a video the lead teacher records of the entire teaching process, from the teacher's point of view, using ClassIn's cloud recording feature. These videos are automatically generated and available for playback about 30 minutes after the class session ends. "Recorded course," by contrast, refers to a specific teaching activity the head teacher or a teacher creates within the class, where the teacher can upload a video from their local computer to the "recorded course" for students and teachers to watch and learn from at any time.

Applies to class teachers and class session students.

As long as the lead teacher's recording during the class session went normally, half an hour after class, all teachers in the class and the class session's students can find the class session in the class and watch the playback video.

While watching the video, based on the recording settings, you can choose to play either the recorded video or the recorded on-site video; if the playback includes multiple video segments, you can switch between segments while watching.

Playback video supports windowed playback, variable playback speed, volume adjustment, and dragging the progress bar for flexible viewing.

If the chapter summary and subtitle list under "AI class session summary" were checked when creating the class session, you can also view the AI-generated summary and subtitle list for the class session while watching the playback, and can copy them.

If "Record ClassIn Classroom / Record On-Site" and "AI Teaching Analysis" were checked when creating the class session, and the lead teacher's recording completed successfully with normal audio, the lead teacher can view AI Teaching Analysis for that class session in the class session playback after class, and can also download the analysis as a PDF to keep.

Transfer students can watch the "playback video" of class sessions they took part in.

To grant newly joined students access to view the class's historical playback videos, enable "Allow Students Newly Added to the Course to Watch Playbacks of Historical Class Sessions" in the "Backend Management System," then add the student to the class.

To prevent students removed from the class from continuing to watch historical class session playback videos, enable "Students Removed from the Course Cannot Watch Historical Playback Videos" in the "Backend Management System," then remove the student from the class.

Only teachers with Backend Management System access, or organization administrators, can download playback videos from the www.eeo.cn Backend Management System — teachers and students cannot download them within ClassIn.

1. Go to a created course.
2. Find the class session, then click Playback.

## X. Viewing "Whiteboard Courseware" in the Class

### What is "whiteboard courseware"?
When a teacher types text or draws annotations on the blackboard or courseware while teaching, ClassIn automatically saves the teacher's whiteboard writing and courseware. These auto-saved items can be viewed after class in "Class Session Details" or the "Schedule." Teachers and students can easily review and revisit class session content.

"Whiteboard courseware" includes both "classroom whiteboard" and "annotated courseware." "Classroom whiteboard" is the writing on the blackboard in a formal classroom; "annotated courseware" is courseware opened in a formal classroom. As long as either the "classroom whiteboard" or "annotated courseware" is generated, a "whiteboard courseware" entry point will appear after class.

There are certain conditions for generating "whiteboard courseware":

First, whiteboard courseware retention must be enabled in the Backend Management System at www.eeo.cn.

Second, while teaching in a formal classroom, if the teacher types any amount of text on the blackboard, or on an opened PPT/PDF/Word (docx/doc)/Epub courseware (including courseware authorized for saving), or annotates with the pen tool across more than 10 elements (for PPT courseware, more than 10 pen-annotated elements on a single slide), ClassIn will automatically save the whole annotated whiteboard content and the entire courseware after class.

Teachers in the class and the class session's students can view that class session's "whiteboard courseware" in the class after class; the class session's lead teacher, co-teacher(s), and students can also view that class session's "whiteboard courseware" in the Schedule.

The class session's lead teacher and co-teacher(s) can share "whiteboard courseware" to a ClassIn class/friend, or to WeChat; on phone or tablet, they can also share to Weibo, QQ, and so on, or copy the link to send to others. Saving the generated "classroom whiteboard" as a JPG image to your personal ClassIn cloud drive is also supported.

After meeting the save conditions on the blackboard or in the courseware, pressing Ctrl+N or using one-click clear on the whiteboard will preserve the whiteboard content from before it was cleared.

"Annotated courseware" is ultimately saved as a PDF, with the preview thumbnail showing the first page of the courseware.

"Whiteboard courseware" is only generated after class for formal classrooms that meet the conditions.

1. Find the class session, then click Whiteboard Courseware.

## XI. Viewing the "Teaching Report" in the Class

As long as the lead teacher or co-teacher(s) in a formal classroom attended normally, a "teaching report" for that class session is generated about half an hour after class ends. The class session's lead teacher, co-teacher(s), and head teacher can view the "teaching report" within the ClassIn class; the lead teacher and co-teacher(s) can also view it in the Schedule.

The "teaching report" defaults to showing the new-version report, with an option at the top to switch to the old version; it supports viewing content in 12 languages; and it displays class session info, including the lead teacher's avatar and class nickname, the class session's start time, and its duration.

The "teaching report" data includes five parts: attendance, class participation rate, class activity time distribution, class records, and class achievements.

**Attendance:** view the number of students who were present, late, and left early for this class session; viewing the details also shows each student's specific attendance status, class duration, and learning report — and on computer, attendance data can be exported.

**Class participation rate:** shows the participation rate for students using the answer clicker, small blackboard, interactive messages (chat within the classroom), and buzzer in the classroom; viewing the details shows each student's specific participation, and on computer, the detailed data can be exported.

**Class activity time distribution:** shows how much time the teacher spent using teaching tools in the classroom, split into four parts — formative assessment (including answer clicker, small blackboard, buzzer), teaching interaction (including random student picker, raise hand, group discussion, interactive messages, timer/countdown, etc.), and classroom incentives (trophies given to students); viewing the details gives a clearer view of how long and how often each tool was used.

**Class records:** includes classroom whiteboard, highlight moments (monitoring images), and class notes from within the classroom.

Classroom whiteboard is the writing on the blackboard; the condition for generating a classroom whiteboard image is that the blackboard has pen-marked elements exceeding 10, or contains typed text input — pressing Ctrl+N or using one-click clear will also save the whiteboard image from before it met the generation condition.

Highlight moments (monitoring images) are images automatically saved from the teacher's classroom window, useful for reviewing the teaching process within the classroom.

Class notes are note images saved after a teacher using a computer uses the class notes feature within the classroom.

If a teacher views images in class records using a phone or tablet, they can press and hold to save the image to their local photo album.

**Class achievements:** includes the accuracy ranking for students' answer clicker (in-class practice) answers, and the ranking based on trophies awarded by the teacher; viewing the details shows each student's data, and on computer, the detailed data can be exported.

The teaching report also supports sharing: on computer, it can be shared to a ClassIn class/friend; on phone or tablet, it can also be shared to Weibo, QQ, and so on, or the link can be copied to send to others.

## XII. Viewing the "Learning Report" in the Class

## 1. Students Viewing Their Own "Learning Report"

Applies to class session students.

A "learning report" for a student in that class session is generated about half an hour after class ends. Class session students can view their "learning report" within the ClassIn class, or in the Schedule.

The "learning report" can be viewed in 5 languages, and supports 2 display templates — which one is shown depends on the class report settings in the Backend Management System.

The "learning report" shows the student's personal nickname (if present) / their name from the Backend Management System (if absent), and includes: the teacher's rating and comments, class achievements, answer accuracy rate, activity level, attendance stats, classroom whiteboard, class notes, and highlight moments.

**Teacher's rating and comments:** the star rating and comments the lead teacher/co-teacher(s) gave the student for this class session, with the star rating shown under the student's personal nickname/Backend Management System name.

**Class achievements/My rewards:** shows how many trophies the student earned in this class session, and how they rank against classmates by trophy count.

**My answer accuracy rate:** shows the student's answer clicker breakdown for this class session, their personal accuracy rate, and the class average accuracy rate.

**Activity level:** shows how long the student spent on stage, speaking (not muted by the teacher), and authorized during this class session.

**Attendance stats:** includes this class session's attendance status, as well as the student's attendance record for other ended class sessions in this class.

**Classroom whiteboard:** an image of the writing on the blackboard, automatically generated once the save condition is met; when a student views the whiteboard image on a phone or tablet, they can tap the image and save it to their local photo album.

**Teacher's class notes:** note images saved after a teacher using a computer uses the class notes feature within the classroom; when a student views these on a phone or tablet, they can press and hold to save the image to their local photo album.

**My class notes:** note images saved after the student, using a computer, uses the class notes feature within the classroom; when viewed on a phone or tablet, students can press and hold to save the image to their local photo album.

**Highlight moments:** images automatically saved from the teacher's classroom window, useful for reviewing the teacher's explanations during class; when a student views these on a phone or tablet, they can press and hold to save the image to their local photo album.

The learning report also supports sharing: on computer, it can be shared to a ClassIn class/friend; on phone or tablet, it can also be shared to Weibo, QQ, and so on, or the link can be copied to send to others.

## XIV. Exporting Class Session Data

Applies to class teachers and head teachers.

Besides being able to download class session data from the Backend Management System at www.eeo.cn, class teachers can also export it within ClassIn. The Backend Management System offers two data types for download — "teaching analysis" and "learning analysis" — but ClassIn only supports downloading "learning analysis" data.

The class session's "learning analysis" data includes: lesson name, lesson ID, start time, end time, lesson duration, student name, student's actual class duration, whether the student was present/late/left early, teacher's rating (teacher's rating of the student), teacher's comment (teacher's comment on the student), student's rating (student's rating of the teacher), student's comment (student's comment on the teacher), the number of valid times and total duration the student watched the playback within the ClassIn client, this class session's total playback video duration, the student's speaking duration, how many times the student went on/off stage and for how long, how many times the student was removed from the classroom by the teacher, how many times the student was rewarded, how many times the student raised their hand, how many times and for how long the student was authorized, how many times the teacher used the buzzer, how many times the student took part in buzzer questions, how many times the student answered first, the student's total answer clicker attempts, number of correct answers, answer breakdown, and how long the student's camera was on. This data is broken down in detail for every student.

Phone and tablet do not support exporting class session data within the ClassIn class.

## XV. Viewing "AI Teaching Analysis" in the Class

ClassIn's AI Teaching Analysis is based on a class session's recorded video. It analyzes the teacher's delivery and classroom interaction, reconstructs the teaching process, and provides AI evaluation and scoring across multiple dimensions of teaching performance.

Once an eeo Backend Management System administrator turns on the AI Teaching Analysis switch under "School Settings → Value-Added Services," and both "Record ClassIn Classroom/Record On-Site" and "AI Teaching Analysis" are checked when creating a class session in a class, then — provided the lead teacher's recording completed successfully with normal audio — the lead teacher can view AI Teaching Analysis for that class session in the class session playback after class, and can also download the analysis as a PDF to keep.

The AI Teaching Analysis report includes: a class session overview; a reconstruction of the class session (teaching time allocation, a time-allocation timeline chart, a classroom keyword cloud, and a table of high-frequency classroom terms); detailed class session data (analysis of speech delivery effectiveness, analysis of the logic and structure of teaching language, and interaction analysis); and an overall AI evaluation of the class session with optimization suggestions. The AI Teaching Analysis report is only available in Chinese and does not support other languages.
