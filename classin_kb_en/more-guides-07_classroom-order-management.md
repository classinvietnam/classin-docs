## Classroom Order Management

## I. School Management Plan

### 1. School Management (Administrator)

#### 1.1 Enabling Anti-Unauthorized-Recording

1.1.1 Editing a Custom Classroom

Log into the ClassIn backend, go to "System Settings" in the left navigation, select "Classroom Settings," then under "Custom Classroom Settings" below, edit an already-enabled custom classroom or create a new one.

1.1.2 Enabling the Scrolling Marquee

After opening custom classroom settings, go to "Toggle Settings," find item 7, "Student and Auditor Classroom Marquee Setting," and check "Once a student enters the classroom, that student's nickname and phone number will move randomly around the classroom."

Tip: this is intended as an anti-recording/anti-leak deterrent — the moving nickname and phone number make it harder to screen-record or screenshot the class content without it being traceable back to the student.

#### 1.2 Hiding the Classroom Chat Window

1.2.1 Editing a Custom Classroom: log into the ClassIn backend, go to "System Settings" in the left navigation, select "Classroom Settings," then under "Custom Classroom Settings" below, edit an already-enabled custom classroom or create a new one.

1.2.2 Hiding the Chat Window: after opening custom classroom settings, go to "Toggle Settings," find item 2, "Chat Window Settings," and check "Hide Chat Button." Tip: disabling the chat window school-wide effectively prevents disorderly text chatting among students during class. Suited to school-wide meetings or events.

### 2. Class Management (Head Teacher)

#### 2.1 Disabling the Join-Class Entry Point

Go into the class, then from the class group chat's top-right corner go into class settings, then go to "Class Management," and disable both "Allow Open Joining" and "Show Join-Class Entry Point on Share Page."

#### 2.2 Managing Speech in the Class Group Chat

2.2.1 Muting a Specific Student

Go into the class, then from the class group chat's top-right corner go into class settings, then in "Class Members," right-click the student you want to mute and select "Mute."

2.2.2 Muting All Students

Go into the class, then from the class group chat's top-right corner go into class settings, and check "Mute All Students."

#### 2.3 Hiding a Message in the Class Group Chat

Go into the class, right-click the message you want to hide, then select "Hide."

#### 2.4 Requiring Students to Use Their Real Name in Class

Go into the class, then from the class group chat's top-right corner go into class settings, then in "Class Members," right-click a student and select "Edit Class Nickname."

#### 2.5 Removing a Student from the Class

Go into the class, then from the class group chat's top-right corner go into class settings, then in "Class Members," right-click a student and select "Remove Member."
