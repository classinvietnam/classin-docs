## CamIn Usage Guide

#### What Is CamIn?

CamIn is a virtual camera and video production tool, designed to help every user easily create polished videos. By adding PPT/PDF/images alongside your on-camera presence, you can easily record demo videos, teaching videos, or micro-lectures.

You can also apply effects like beauty filters, virtual backgrounds, and stickers, and pair CamIn with video conferencing or livestream teaching software to make your teaching explanations or video conferences more professional and engaging.

#### Minimum System Requirements for CamIn

CamIn currently supports desktop use only — mobile isn't supported yet. Below are the minimum requirements for each OS.

| | Windows | Mac |
| --- | --- | --- |
| OS | Windows 10 64-bit or higher | macOS 10.15 or higher |
| Processor | Intel Core 6th generation or newer / AMD Ryzen 3000 series or newer | 2017 MacBook Pro or newer |
| Memory | 8GB RAM | 8GB RAM |
| Disk Space | 8GB free disk space (for program install, cache, and media storage) | 8GB free disk space (for program install, cache, and media storage) |
| Graphics | NVIDIA GTX 900 series or higher / AMD RX560 or higher / Intel HD 5500 or higher, with a GPU driver dated 2018 or newer, and 2GB GPU VRAM (integrated graphics that share system RAM counts toward total RAM) | 2GB GPU memory |
| Display Resolution | 1920x1080 or higher | Built-in display: 2560x1600 or higher; external display: 1920x1080 or higher |

#### Downloading, Installing, and Logging Into CamIn

(1) Downloading CamIn

Open a browser on your computer, go to www.camin.cn in the address bar, then click "Download Now" on the page.

(2) Installing CamIn

Run the downloaded CamIn installer; if Windows shows a security prompt, click "Yes." On the language selection screen, click "Confirm," check "I have read and agree," then click "Quick Install." Wait for installation to finish.

(3) Logging Into CamIn

If you already have a ClassIn account, you can log into CamIn directly with it. You can also log in by scanning a WeChat QR code or via SMS. Alternatively, you can open the ClassIn app on your phone and log in by scanning a QR code.

#### Creating and Configuring Scenes

(1) Creating a New Scene

CamIn comes with one scene by default. Users can create up to 5 scenes, and each scene can contain multiple video or image sources.

(2) Setting a Background

For each scene, users can set a background image of their choice — either from CamIn's built-in options or a local image from their computer.

#### Managing the Content Area

**(1)** Adding a Camera Source

Users can add multiple video sources within each scene — for example, if your computer has two cameras connected, you can add both camera sources at once to show different camera feeds. The camera window supports full-screen enlargement or custom resizing, and can switch between a square or circular border. In the settings below the camera window, users can configure various camera settings, including virtual background, green-screen chroma key, beauty filters, custom headwear, virtual avatar, saturation, contrast, opacity, zoom, and brightness.

CamIn also supports adding a physical camera as a content source. When using a camera as a content source, please choose the official app provided by your camera's brand. Then select and add the camera following the steps below.

For Sony cameras, see: https://www.sony.com/zh-cn/electronics/support/articles/00247038

For Fujifilm cameras, see: https://fujifilm-dsc.com/zhs/manual/x-h2_connection/overview_usage/webcam/

For Nikon cameras, see: https://www.nikon.com.cn/sc_CN/service-and-support/downloads/app.tag/app/webcam.dcr

For Canon cameras, see: https://www.canon.com.cn/special/webcam/index.html

For other camera brands, check the corresponding official website's recommendation.

**(2)** Opening a Local File

Users can insert various local files into each scene — PPT courseware, PDF courseware, images, videos, and more.

2.1 Courseware

Once you open a courseware file, first select "Cursor Mode" below, which lets you resize the courseware and turn pages. You can also use the pen and other teaching tools below to mark up or draw on the courseware.

2.2 Video

Once you open a video file, first select "Cursor Mode" below, which lets you resize the courseware, turn pages, toggle loop playback, adjust playback speed, and adjust the volume. You can also use the pen and other teaching tools below to mark up or draw on the video.

**(3)** Sharing Your Screen

Users can share their screen within each scene — supporting sharing the entire desktop or a specific app's window, including websites. Screen sharing also supports sharing computer sound, and the shared window can be freely resized. Users can also use the common tools below to mark up or draw on the shared window.

**(4)** Phone Screen Mirroring

Users can mirror a phone or tablet screen within each scene. Mirroring modes include "Apple Mirroring" and "ClassIn Mirroring." If you're using an iPhone or iPad and don't want to download any mirroring tool, choose "Apple Mirroring" mode; if you're using an Android phone or tablet, choose "ClassIn Mirroring" mode.

**(5)** Opening a Cloud Drive File

Users can load a file from their ClassIn cloud drive into CamIn to open it.

**(6)** Adding an Online Media Source

Users can add polished images or motion graphics provided officially.

**(7)** Adjusting Content Layers

When some content is obscured by other content, users can adjust the layering between pieces of content.

**(8)** Deleting Content

Delete content you've added (the background cannot be deleted).

#### Teleprompter

The teleprompter is only visible to yourself — no one else can see it.

#### Recording, Editing, and Saving Video

Once a user finishes recording a video with CamIn, they can edit it directly.

#### Adjusting Video Quality (Resolution)

Adjust the resolution used when streaming live.

#### Activating CamIn Membership

Activating CamIn membership unlocks access to more personalized features.

#### Streaming a Livestream

Once you add a stream-push URL from ClassIn or another platform to CamIn, you can use CamIn to go live.

Full stream URL format: rtmp://livepush.eeo.cn/eeolive/3786113a1b9e9ed9d1aa_406b449dd48bccac?txSecret=e7dd199f9e005588e3402cd33a97d2c4&txTime=7d8d37cd&record=mp4&record_interval=7200

Tip: in the format above, the first part is the "stream push address," and the second part is the "stream key."
