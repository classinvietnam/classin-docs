## Running Multiple Instances of ClassIn

### Running Multiple Instances on Windows

Open the ClassIn icon on your desktop multiple times to open multiple ClassIn login windows.

### Running Multiple Instances on Mac

1. Open Finder.
2. Go to Applications.
3. Right-click ClassIn.
4. Select Copy (Duplicate).
5. Double-click the ClassIn copy.
6. Once verification finishes, you can log into your second ClassIn instance.

## Changing a Video's Audio Channel (Format Factory)

### I. Downloading Format Factory

Open your browser and go to http://www.pcgeshi.com/ to download Format Factory.

### II. Changing the Audio Channel

1. Open Format Factory.
2. Drag the video whose channel you want to change into Format Factory.
3. Click Settings/Config.
4. Change the channel to "2 Stereo."
5. Click OK → Start.
6. Wait for the conversion to finish.

## Upgrading ClassIn on a Bastion-Host-Managed Device

## I. Enabling the System Restore Software

Have your IT teacher open the system restore software (using Faronics Deep Freeze as an example here) and enter the password.

Note: the screens and steps will vary slightly depending on which system restore software you use.

## II. Disabling System Restore

Disable the system restore feature, then restart the large display / all-in-one device.

(Note: the screens and steps will vary slightly depending on which system restore software you use.)

## III. Upgrading ClassIn

Once the device restarts, upgrade ClassIn X or ClassIn.

## IV. Re-Enabling System Restore

Open the system restore software, enter the password, re-enable system restore, then restart the large display / all-in-one device.

By following the steps above, you can complete the ClassIn upgrade. The screens and steps will vary slightly depending on which system restore software you use.
