# Vị trí lưu file mặc định

### Đối tượng áp dụng

Tất cả người dùng

### Trường hợp áp dụng

Tính năng này dùng để thiết lập đường dẫn lưu file mặc định của ClassIn, bao gồm: ảnh lưu trong lớp học, bảng viết trong lớp học, video ghi hình cục bộ, và file tải xuống từ nhóm lớp. Thiết lập này giúp quản lý và sử dụng các file liên quan hiệu quả hơn.

### Lưu ý

Điện thoại và máy tính bảng không có tính năng này.

### Các bước thực hiện

#### Máy tính

Nhấn vào ảnh đại diện ở góc dưới bên trái

Vào mục Truyền file

Sửa đường dẫn lưu file mặc định
