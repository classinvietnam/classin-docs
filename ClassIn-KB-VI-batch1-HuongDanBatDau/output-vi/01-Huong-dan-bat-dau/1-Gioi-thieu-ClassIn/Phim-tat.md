# Phím tắt

Hướng dẫn sử dụng (bản tiếng Anh)

# I. Ngoài lớp học

Chụp màn hình: `Ctrl+Alt+C`

Mở phần mềm: `Ctrl+Alt+X`

Gửi tin nhắn: `Enter`

# II. Trong lớp học

### (1) Khác biệt phím tắt giữa máy Mac và Windows

Phím "Ctrl" trên Windows tương ứng với phím "Command" trên Mac

Phím "Alt" trên Windows tương ứng với phím "Option" trên Mac

Phím "Page Up/Down" trên Windows tương ứng với "Fn + Up/Down" trên Mac

Phím "Home/End" trên Windows tương ứng với "Fn + Left/Right" trên Mac

### (2) Phím tắt dùng chung trong lớp học

| Chức năng | Phím tắt |
| --- | --- |
| Chọn tất cả | Ctrl + A |
| Sao chép | Ctrl + C |
| Dán | Ctrl + V |
| Xóa | Ctrl + D / Delete |

### (3) Phím tắt cho thanh công cụ bên phải / bảng công cụ tròn

| Chức năng | Phím tắt |
| --- | --- |
| Nhấn hiệu ứng PPT (sau khi chọn có thể điều khiển hiệu ứng động của PPT) | Ctrl + G |
| Chọn & di chuyển | Ctrl + M |
| Bút vẽ | Ctrl + P |
| Tẩy | Ctrl + E |
| Công cụ văn bản | Ctrl + T |
| Chụp màn hình | Ctrl + Alt + X |
| Bút laser | Ctrl + L |

### (4) Phím tắt cho bút vẽ và công cụ văn bản

| Chức năng | Phím tắt |
| --- | --- |
| Gọi nhanh hình/màu tương ứng | Alt + số/chữ tương ứng |
| Khi đang vẽ đường cong | Giữ Shift để chuyển thành vẽ đường thẳng; giữ Alt để chuyển thành vẽ hình tròn đều |
| Khi đang vẽ đường thẳng | Giữ Shift để chuyển thành đường gấp khúc 45 độ |
| Khi đang vẽ hình tròn | Giữ Shift để vẽ hình tròn đều |
| Khi đang vẽ hình vuông | Giữ Shift để vẽ hình vuông đều |

### (5) Phím tắt chỉ áp dụng cho Bảng đen lớn (học liệu và bảng con không hỗ trợ)

| Chức năng | Phím tắt |
| --- | --- |
| Hoàn tác thao tác trước (lùi lại) | Ctrl + Z |
| Làm lại thao tác trước (tiến tới) | Ctrl + Y |
| Xóa toàn bộ nội dung trên bảng/học liệu chỉ với 1 lần nhấn (kể cả hình ảnh) | Ctrl + N |
| Mở tính năng tải file (tải ảnh hoặc bảng viết) | Ctrl + O |
| Mở tính năng lưu/chia sẻ bảng viết | Ctrl + S |
| Đến trang giữa của bảng | Ctrl + Shift + O |
| Trang trước | Page Up |
| Trang sau | Page Down |
| Về trang đầu | Home |
| Đến trang cuối | End |
| Di chuyển nội dung đang chọn | Left/Right/Up/Down |

### (6) Phím tắt chỉ áp dụng cho Bảng đen cục bộ và phòng soạn bài (không áp dụng trong lớp học)

| Chức năng | Phím tắt |
| --- | --- |
| Đưa lên 1 lớp (layer) | Ctrl + Shift + Page Up |
| Đưa xuống 1 lớp (layer) | Ctrl + Shift + Page Down |
| Đưa lên lớp trên cùng | Ctrl + Shift + Home |
| Đưa xuống lớp dưới cùng | Ctrl + Shift + End |

**Lưu ý:** Giữ Ctrl + nhấp chuột trái vào nội dung trên bảng cũng có thể mở cài đặt lớp (layer) ở góc trên bên phải của nội dung đang chọn.

### (7) Phím tắt điều khiển camera trong lớp học

| Chức năng | Phím tắt |
| --- | --- |
| Di chuyển camera từ khu vực chỗ ngồi lên bảng (giữ nguyên kích thước) | Ctrl + kéo camera bằng chuột trái |
| Kéo camera vào bố cục cửa sổ | Shift + kéo camera bằng chuột trái |

### (8) Phím tắt khi mở học liệu PPT / audio / video

| Chức năng | Phím tắt |
| --- | --- |
| Phát / tiến 1 bước | Phím cách (Space) |

### (9) Phím tắt khi mở học liệu PDF / Word

| Chức năng | Phím tắt |
| --- | --- |
| Lật xuống 1 trang | Phím cách (Space) |

### (10) Các phím tắt khác ảnh hưởng đến lớp học

| Chức năng | Phím tắt |
| --- | --- |
| Đóng lớp học | Alt + F4 |
| Điều chỉnh âm lượng | Phím điều chỉnh âm lượng của hệ thống |
